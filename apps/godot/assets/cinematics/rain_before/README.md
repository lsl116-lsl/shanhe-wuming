# 序章动画样片《雨来之前》

`rain_before_demo_90s.ogv` 是 Godot 直接播放的 90 秒动画样片，包含完整镜头、字幕、对白、环境音和基础配乐。

时间结构：

- 0—10 秒：黑场与洛水、木船声，旧渡从晨雾中显现。
- 10—30 秒：河雾、木屋、船、芦苇与生活细节。
- 30—50 秒：少年与禾安互动，旧粥碗作为伏笔出现。
- 50—70 秒：辛衡教少年把本世姓名写入渡册；重点是名字如何进入现实关系，不是寻找真名。

本样片中的“写名”是一段日常登记行为。项目长线不再追问主角的隐藏姓名或真实身份，而是通过不同社会位置理解同一段历史。
- 70—90 秒：商船靠岸，船夫喊出“宋地乱了”。

运行方式：双击 Godot 工程根目录的 `run_animation_demo.bat`。播放结束后可重播，或进入现有可玩序章。

`source_images/` 与 `timeline.json` 保留了后续重制和替换正式美术所需的源结构；动画入口不依赖现有可玩序章的场景实现。
