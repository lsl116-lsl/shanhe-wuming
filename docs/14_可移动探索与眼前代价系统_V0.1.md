# 《山河无名》可移动探索与眼前代价系统 V0.1

> 文档状态：玩法与交互设计规则  
> 适用范围：网页原型、Godot 正式版、全部章节可移动 AVG 场景  
> 核心原则：玩家可以不知道最终结果，但必须看见眼前代价。

## 1. 玩法定位

《山河无名》后续方向不是纯文字点击 AVG，也不是动作战斗游戏。

推荐定位：

```text
2D 可移动探索式历史叙事 AVG
```

玩家可以操控苏醒者在章节场景中移动、调查物件、与人物对话、触发事件，并在关键节点做出选择。

但游戏核心仍然是：

```text
人物关系
名籍记录
因果回响
历史处境
```

不是：

```text
打怪
连招
刷装备
动作操作
开放世界乱跑
```

## 2. 核心交互原则

最重要的一条：

```text
移动负责让玩家看见。
互动负责让玩家承担。
```

玩家移动时，可以观察、靠近、听见更多信息。

玩家按下互动键时，才真正确认自己优先处理哪件事，并由此记录因果。

因此，移动本身不应立刻锁死重大后果。真正锁定路线的，应是明确的交互动作。

## 3. 眼前代价系统

定义：

```text
玩家做关键行动前，必须能通过场景、声音、人物喊话和交互提示，看见每个行动方向的即时压力。

游戏不提前告诉玩家长远后果，但必须展示眼前代价。
```

玩家不能靠天眼猜答案。

玩家可以不知道：

```text
这个选择三幕之后会让谁离开。
这份湿简后续会不会成为无名录的一部分。
谁会在二十年后因此记住主角。
```

但玩家必须知道：

```text
车下孩子正在哭。
湿简正在被雨泡开。
棚下有人正在认错亲人。
我先做一件事，其他事就会继续恶化。
```

## 4. 信息呈现流程

关键场景不能直接把玩家丢进地图里乱跑。

必须遵守：

```text
先看见问题
→ 再走向问题
→ 靠近后获得更多信息
→ 最后确认行动
```

### 4.1 先看见问题

进入场景时，用镜头、声音、人物动作让玩家看清现场。

例如序章翻车现场：

```text
镜头扫过翻倒的车。
车辕下有孩子哭。
泥水里有几片木简被雨泡开。
棚下有人在喊失散亲人。
韩宁冲向湿简，又被人拉住。
禾安拖着热水桶喊你。
辛衡把空木牍塞给你，说：“先看眼前的人。”
```

### 4.2 再走向问题

玩家获得控制权后，场景中应自然存在多个清晰方向。

例如：

```text
车下孩子
泥水湿简
棚下人群
```

不要依赖大红箭头，但可以使用：

```text
火把光源
人物喊话气泡
短暂镜头推进
雨水冲刷动画
可互动物件轻微描边
声音方向提示
```

### 4.3 靠近后获得更多信息

靠近目标后，玩家应获得更具体的眼前代价提示。

例如靠近孩子：

```text
禾安：“搭把手！车辕还压着他！”

【E】抬车救孩子

提示：泥里的湿简还无人去捡。
```

靠近湿简：

```text
韩宁：“别踩！那不是废木头！”

【E】抢救湿简

提示：车下孩子的哭声断了一下。
```

靠近人群：

```text
柳娘：“先认人！别让孩子被领错！”

【E】让活人互认

提示：雨水还在冲刷湿简，车下仍有人被压着。
```

### 4.4 最后确认行动

真正触发因果的是玩家按下互动键，而不是走到附近。

互动确认后，可以锁定主要行动：

```text
先救车下的孩子。
先抢泥水里的湿简。
先让还活着的人彼此认出彼此。
```

## 5. 时间压力规则

时间压力要可感知，不能暗中扣分。

玩家站着不动时，场景可以变化：

```text
孩子哭声变轻。
湿简上的墨扩散。
棚下有人喊错名字。
禾安又喊你一次。
韩宁开始挣扎。
```

但前几秒不应立刻惩罚玩家。

推荐节奏：

```text
前 3 秒：镜头展示现场，不计后果。
第 4—10 秒：玩家移动观察，轻微变化。
第 10 秒后：某些后果开始加重，但仍可挽回一部分。
按下互动键后：锁定主要选择。
```

该节奏只作为设计参考，可按场景紧张程度调整。

原则是：

```text
让玩家感到时间在流逝，而不是让玩家因为不了解规则被惩罚。
```

## 6. 引导方式

引导要藏在场景里，不要过度游戏化。

不推荐：

```text
请选择 A 救孩子 / B 抢湿简 / C 互认
```

推荐使用人物、声音和物件自然引导。

### 禾安引导救人

```text
禾安在雨里回头喊你：

“别站着！这边压着人！”
```

### 韩宁引导湿简

```text
韩宁挣开人群，扑向泥水。

“那几片不能烂！”
```

### 柳娘引导互认

```text
柳娘抱着孩子，声音已经哑了。

“谁家少了人？先喊名字！”
```

### 辛衡给总目标

```text
辛衡把空木牍塞给你。

“先看眼前的人。看清楚，再落笔。”
```

## 7. 选择公平性

《山河无名》的选择不能是猜谜。

玩家可以不知道最终结局，但必须知道自己正在优先处理什么。

公平选择至少满足：

```text
每个可行动方向都有清楚的现场信号。
每个方向都有一位人物或物件作为引导点。
每个方向都有即时收益与即时代价。
玩家靠近后能获得更清楚的信息。
重大后果由明确互动触发，而非无意走位触发。
```

不公平选择包括：

```text
玩家不知道湿简重要，事后才说“你没捡所以坏结局”。
玩家不知道孩子会死，事后才说“你走慢了所以孩子死”。
玩家没有看到人群混乱，事后才说“没人互认所以有人失踪”。
玩家只是路过某个区域，就被强制锁定路线。
```

## 8. 与“名与籍”的结合

可移动探索特别适合表现“名与籍”。

不要只用旁白解释“入册危险”。

可以让玩家在场景里看到：

```text
一片木牍上只写：韩宁，宋地来人，同行母妹，一人途中亡。
旧邑：空。
旧里：空。
父名：空。
田属：空。
债役：空。
```

玩家调查后，才理解：

```text
这不是姓名没写全。
是这个人在社会里的位置被故意留空了。
```

再让玩家靠近官吏、韩宁母亲、禾安，就能听见不同压力：

```text
官吏：旧里不写，粮怎么发？
韩宁的母亲：先生，叫他韩宁就好。
禾安：册上多一户，明早就多一张嘴；册上少一户，今晚就少一个能领水的人。
```

这样玩家不是被解释概念，而是在场景里理解概念。

## 9. 场景设计格式

以后设计可移动 AVG 场景时，应按以下模板：

```text
场景名：
章节 / ACT：
玩家可移动区域：
玩家进入时先看到什么：
主要行动方向：
方向 A：
  视觉信号：
  声音 / 台词信号：
  交互提示：
  即时收益：
  眼前代价：
方向 B：
  视觉信号：
  声音 / 台词信号：
  交互提示：
  即时收益：
  眼前代价：
方向 C：
  视觉信号：
  声音 / 台词信号：
  交互提示：
  即时收益：
  眼前代价：
重大因果由哪个互动触发：
是否存在观察窗口：
是否存在时间压力：
是否避免无意走位锁死路线：是
```

## 10. 翻车现场示例

场景名：序章结尾 / ACT01 开场：最后一辆车  
玩家可移动区域：渡口翻车点、泥水湿简、遮雨棚人群  
玩家进入时先看到：车翻、孩子哭、湿简泡水、人群互喊、禾安拖水、韩宁扑简、柳娘抱孩子、辛衡递空木牍。

### 方向 A：车下孩子

```text
视觉信号：车辕压住孩子，禾安在旁边拖热水。
声音信号：孩子哭声断断续续，禾安喊“这边压着人”。
交互提示：【E】抬车救孩子。
即时收益：孩子获救概率提高，禾安信任上升。
眼前代价：泥里的湿简还无人去捡。
```

### 方向 B：泥水湿简

```text
视觉信号：几片湿简在泥水里浮沉，墨迹扩散。
声音信号：韩宁喊“那几片不能烂”。
交互提示：【E】抢救湿简。
即时收益：保住更多名籍线索，韩宁信任上升。
眼前代价：车下孩子的哭声越来越轻。
```

### 方向 C：棚下人群

```text
视觉信号：棚下有人互相拉扯，有孩子被抱错。
声音信号：柳娘喊“谁家少了人？先喊名字”。
交互提示：【E】让活人互认。
即时收益：口述见证更完整，减少失散和误领。
眼前代价：湿简继续被雨冲，车下仍有人被压着。
```

## 11. 最终标准

一个合格的可移动 AVG 关键场景，应让玩家产生：

```text
我知道眼前有几件事正在同时恶化。
我知道每个方向大概是在处理什么。
我不知道未来会怎样，但我知道我此刻先顾了谁。
我不是被系统坑了，而是在看见代价之后做了选择。
```

这就是《山河无名》的交互底线。
