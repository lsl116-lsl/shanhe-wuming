## 2. 八份标准文件分别解决什么

| 文件 | 只负责回答 | 不应替代 |
|---|---|---|
| 00 章节定位与史实边界 | 何时、何地、哪些史实可亲历、哪些不可越界 | 人物戏和台词 |
| 01 主线大纲 | 一生如何被历史压力推动，八幕怎样构成完整人生 | 职业详细剧情 |
| 02 人物关系表 | 人物是谁、想要什么、怎样独立行动与变化 | 单纯 NPC 名单 |
| 03 职业线嵌入表 | 每个社会位置如何拥有独立故事、权限、责任与结局 | 数值职业树 |
| 04 因果节点表 | 选择怎样进入事实、记录、人物和后世 | 善恶值 |
| 05 记忆碎片表 | 本章新增哪一种历史视角，怎样补充或纠正旧认识，何时影响现实 | 超能力、预知和身份谜题 |
| 06 故事剧本 | 场景、行动、冲突、对白目标和演出需求 | 只有梗概没有戏 |
| 07 衔接过渡文 | 如何读取所有合法分支并拼成完整时代变迁 | 固定结局旁白 |

## 3. 每章统一结构

每章原则上使用八幕：

```text
ACT01 苏醒与本世家庭，或承接序章后的第一现实压力
ACT02 共同成长与第一次时代压力
ACT03 主动选择社会位置
ACT04 职业承诺与第一次独立代价
ACT05 私人关系和时代矛盾同时升级
ACT06 职业线独立高潮
ACT07 全职业从不同位置进入共同历史危机
ACT08 晚年、档案、未尽之事与跨章交接
```

第一章例外：序章已承担“苏醒、写名、宋亡、裂钟、第一选择”，所以第一章 ACT01 从“序章三选一后果”开始，不重复序章剧本。

推荐内容比例：

```text
共享场景：55%—65%
职业 / 社会位置独有场景：25%—35%
稀有人物与因果回收：10%
```

职业独立不等于多套互不相干的游戏。独立指每条线都有自己的欲望、对手、关系核心、三次升级、专属高潮和结局判断。

## 4. 职业 / 社会位置设计规范

职业不是开局菜单，不是战斗职业，也不是善恶阵营。

职业数量不固定，应按本章主题裁剪。

设计每条职业线时必须填写：

| 字段 | 要求 |
|---|---|
| `route_promise` | 玩家选择这条线后会经历什么独特人生 |
| `route_desire` | 本世真正想得到什么，不得只是“做好职业” |
| `route_fear` | 最害怕失去什么 |
| `route_blind_spot` | 人物性格造成的判断盲点 |
| `mentor_or_peer` | 一名能理解玩家、也会反对玩家的人 |
| `human_opponent` | 有合理利益和私人情感的对手 |
| `institutional_pressure` | 不可被击败的制度或时代压力 |
| `three_escalations` | ACT04、ACT05、ACT06 三次不可重复的升级 |
| `route_climax` | 只有该职业能够完成的行动 |
| `irreversible_cost` | 无法通过读档思维“全都要”的损失 |
| `unique_evidence` | 进入本章档案的独有材料 |
| `convergence_role` | ACT07 共同危机中的不可替代责任 |
| `route_ending` | 成为、离开、被逐、改行、牺牲或传承等合法结局 |
| `next_chapter_trace` | 下一章能够现实回收的载体 |

如果把职业名称替换后故事仍成立，说明职业差异不够。

如果高潮只是在同一场战斗中使用不同技能，说明项目已经偏离历史叙事人生 RPG。

### 4.1 第一章当前职业结构

第一章采用：

```text
八职业线 + 乡土地基 + 隐退倾向。
```

八职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”不作为第一章独立职业线，转为乡土地基。

“隐士”不作为第一章独立职业线，转为隐退倾向。

该裁剪只规定第一章。后续章节应根据本章主题重新评估，不机械套用固定职业数量。

## 5. 人物立体度规范

### 5.1 核心人物九字段

每名核心人物必须拥有：

```text
surface_identity       公开身份
private_desire         私人欲望
public_claim           对外宣称的原则
fear                   最深恐惧
blind_spot             认识盲点
tenderness             不用于推进剧情的柔软处
material_interest      现实利益
line_never_cross       自认为绝不跨越的线
line_actually_crossed  最终可能跨越的线
```

### 5.2 人物不是玩家附属物

核心人物必须：

```text
在玩家缺席时采取至少一次行动。
至少一次拒绝玩家。
有一段不围绕苏醒者存在的关系。
可能因自己的判断成功或失败。
不因好感度高就放弃根本利益。
在不同职业线中保持同一人格，只改变彼此看见的侧面。
```

### 5.3 人物命运

人物命运至少包含：

```text
fixed_action         无论玩家如何都会做的事
preventable_loss     玩家可以避免或转移的损失
irreversible_change  一定发生、但表现可变的改变
survival_variants    生还、死亡、失踪、迁徙、改名、决裂
testimony_variants   此人留下的事实版本
carrier_variants     此人可能带走的跨章载体
```

“生还”不是自动好结局，“死亡”也不能成为制造深刻感的廉价按钮。

## 6. 故事剧本格式

### 6.1 场景头

```text
scene_id:
act:
route:
time:
location:
present_characters:
historical_pressure:
player_goal:
character_goals:
entry_conditions:
exit_states:
assets:
```

### 6.2 场景正文

每场按以下顺序：

1. **视觉开场**：一个可被画面和声音表现的动作。
2. **现实目标**：人物必须在场景结束前完成或失去什么。
3. **冲突升级**：至少两个人的合理目标不能同时满足。
4. **玩家行动**：选择具体做法，而不是抽象立场。
5. **人物反应**：由性格、利益和共同债决定，不由好感度单独决定。
6. **状态落点**：明确写入事实、关系、资源、记录或因果。
7. **余波钩子**：下一场为什么必然发生。

### 6.3 对白标准

```text
台词必须来自人物此刻的目标，不能替作者讲总纲。
同一观点由不同身份说出时，词汇、比喻和关心对象必须不同。
重要选择前不给“明显正确答案”的语气提示。
历史称谓按本章史实边界处理。
允许沉默、误解、谎言和说一半。
每名核心人物建立三项语言特征，禁止所有人都说宏大金句。
```

## 7. 选择设计

每个主选择至少改变下列两项：

```text
事实结果
人物关系
资源或伤病
制度权限
官档版本
私人记录
口述版本
因果载体
后续责任
```

选项文案描述玩家要做的动作，不替玩家规定情绪：

```text
合格：把缺粮户写进今夜补录名单
不合格：选择仁慈
```

延迟结果不得全部隐藏。玩家当场至少要知道：

```text
自己做了什么。
谁立即承担风险。
哪项结果仍不确定。
```

## 8. 分支收敛规范

### 8.1 收敛不是归零

所有职业会进入同一历史危机，但必须从不同现实位置进入。

第一章示例：

```text
同一危机：长平与战后归旧渡
├─ 医者：伤病、临终口供和救不完的人
├─ 吏官 / 记录：名册、死伤册、错籍和空格
├─ 商贾：粮道、关验、路断和失踪名单
├─ 武将：征发、同伍、战场责任和无人认领者
├─ 戏子：喊名、旧曲、口述和不敢唱全的人名
├─ 工匠：道路、车辙、器物和战争使用的工具
├─ 谋士：盟书、调停、误判和被话语牵动的人
└─ 仕官：政策、执行链、官档缺口和公开责任
```

乡土地基让所有职业最终面对旧渡、禾安、阿梁和粥碗。

隐退倾向让所有职业都可能产生私藏见证、不入官档或晚年远离权力的结局姿态。

ACT07 结束时，历史结果相同，人间结果不同。

### 8.2 章节交接包

每章固定输出：

```text
historical_result
route_result
core_character_fates
truth_state
official_record
private_record
oral_version
primary_carrier
secondary_traces
institutional_legacy
memory_cue
unanswered_question
mandatory_callbacks
```

### 8.3 过渡文由模块拼成

过渡文不得只写一篇固定散文。文件必须包含：

```text
固定历史结果。
按职业线切换的段落。
按核心人物命运切换的段落。
按记录版本切换的段落。
按无名录 / 档案载体切换的段落。
进入下一章的共同钩子。
```

## 9. 记忆碎片规范

记忆碎片必须：

```text
由本世物件、声音、地点或文字触发。
只加深主题，不替玩家解题。
不精准预告未来。
不提供技能、药方、战术或官署密码。
不提前确认苏醒者是某个具体历史人物。
```
