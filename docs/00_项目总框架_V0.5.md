# 《山河无名》项目总框架 V0.5

> 文档状态：保留的详细整合稿，不再是最高层入口。
>
> 当前最高层口径：`docs/00_核心文档/01_项目概述_V1.0.md`、`02_项目框架_V1.0.md`、`03_全篇故事走向_V1.0.md`。如有冲突，以三份 V1.0 核心文档为准。
>
> 当前口径：序章 + 七章 + 终章；第一章《钟裂于洛水》，主题为“礼崩之世”
>
> 核心母题：一段历史只有从许多人的位置出发，才可能被逐渐看清。

## 0. 核心结论

《山河无名》最适合做成：

> **以 AVG 为主体、以轻量人生 RPG 为骨架的章节式历史叙事游戏。**

比例建议：

```text
叙事、调查、对话与选择：约 70%
关系、资源、职业责任与因果管理：约 30%
```

项目不依靠高频战斗、等级刷取、装备数值和随机抽卡制造循环。它真正的循环是：

```text
进入一段人生
→ 认识具体的人
→ 从一个社会位置理解时代
→ 在有限信息和资源中选择
→ 事实、关系与记录发生分歧
→ 承担本世结果
→ 将一部分因果交给后世
→ 下一章在新的现实事件中回收
```

全游戏不是七部松散的朝代短篇，而是一场逐章推进的长问题：

```text
谁建立秩序
→ 谁承担秩序
→ 秩序崩裂后谁保存共同生活
→ 盛世由谁供养
→ 文明为何不能自动免于覆亡
→ 旧制度为何无法组织新世界
→ 无名者如何成为历史主体
```

## 1. 项目定位

### 1.1 核心一句话

一个在中国历史关键转折处反复苏醒的人，每一世都从不同社会位置活进同一条历史长河；玩家通过医者、吏员、商贾、军卒、艺人、工匠、谋士、仕官及更多普通人的眼睛，看见彼此矛盾又互相补足的历史，逐步形成自己的理解。

### 1.2 类型定义

| 项目维度 | 定义 |
|---|---|
| 产品类型 | 单机、章节式、历史叙事人生 RPG / AVG |
| 叙事类型 | 中国历史长河、轮回人生、普通人视角、跨章因果 |
| 核心玩法 | 阅读与调查、关系选择、职业责任、有限资源、事实与记录分层 |
| 章节结构 | 序章 + 七章 + 终章；每章一段完整人生 |
| 核心体验 | 在个人无法改写的大势中，从不同位置行动、承担，并比较同一历史的不同面貌 |
| 长线动力 | 追踪同一历史问题在不同时代、阶层与职业中的变形，让各章证词彼此印证、冲突和校正 |
| 目标平台 | 以 Godot / PC 原生版本为核心，移动端按条件评估；网页旧原型仅作历史参考 |
| 发行方式 | 先序章 / 第一章垂直切片，后按章持续制作和发布 |

### 1.3 本项目不是什么

```text
不是随机投胎模拟器。
不是朝代百科和历史知识问答。
不是帝王将相改史爽文。
不是互不相干的职业副本。
不是用现代知识碾压古人的穿越故事。
不是寻找真名、前世身份或天命血统的悬疑故事。
不是靠善恶值、好感度和完美选项判定人生。
不是以战斗刷取、装备收集或抽卡驱动的数值 RPG。
不是把“人民”作为终章突然贴上的口号。
```

## 2. 玩家体验与设计支柱

### 2.1 五项体验承诺

每章都必须让玩家：

1. **活在时代里**：有姓名、家庭、师友、社会位置、债务、疾病、饥饿、劳役和无法轻易舍弃的人。
2. **从社会位置看历史**：同一事件在不同人生位置里看到的信息、责任和代价并不相同。
3. **面对没有纯净答案的选择**：救一户可能连累邻户；保存真名可能暴露活人；统一标准可能同时打破特权和伤害具体家庭。
4. **看见选择继续生长**：通过人物、制度、文字、地点、物件和记忆回收，而不是旁白结算善恶。
5. **逐步修正“历史是什么”的理解**：每一条人生只提供局部经验，后来的视角会补充、质疑甚至推翻玩家先前的判断。

### 2.2 三项不可动摇的设计支柱

#### 普通人不是历史背景

大事件必须落到一条路、一份名册、一户人的役期、一船粮、一场救治或一封未送达的信上。

#### 选择改变人间尺度，不抹掉历史

玩家不能阻止秦统一、安史之乱、宋元易代或近代民族危机，却能改变谁活下来、谁被写下、某项制度在一地如何执行，以及后来人能够依据什么理解当时。

#### 记录本身也是权力

每章都要同时追踪：

```text
事实发生了什么。
玩家知道什么。
官档怎样写。
私人怎样记。
民间怎样讲。
谁为这个版本承担代价。
```

## 3. 职业与社会位置规则

职业不是开局菜单，不是战斗职业，也不是善恶阵营。

职业决定：

```text
玩家最先看见什么。
玩家能动用什么资源。
谁会来邀请、拒绝或托付玩家。
玩家必须对哪一类后果负责。
本章能留下哪一种独有证据。
```

职业数量不固定，按章节主题裁剪。

第一章《钟裂于洛水》当前固定为：

```text
八职业线 + 乡土地基 + 隐退倾向。
```

八职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”不再作为第一章独立职业线。

```text
土地、粮水、田亩、空户、旧渡、灶火、没有米下锅、禾安和粥碗，属于所有职业共同面对的乡土地基。
```

“隐士”不再作为第一章独立职业线。

```text
隐退、私藏见证、不入官档、少介入和晚年去向，属于所有职业都可能附着的隐退倾向。
```

后续章节可以按本章经验继续裁剪，不强行恢复十职业。

## 4. 双重长线

### 4.1 外部主线：谁组织山河

```text
旧礼失效
→ 新法与统一
→ 帝国制度进入日常
→ 帝国崩裂、流亡与再组织
→ 盛世、边疆与劳动代价
→ 文治、商业、技术与覆亡
→ 旧帝国面对工业与世界体系失配
→ 无名者组织起来并成为历史主体
```

### 4.2 内部主线：怎样认清一段历史

| 阶段 | 玩家暂时形成的认识 | 新视角如何修正它 |
|---|---|---|
| 序章 / 第一章 | 乱世似乎只是旧礼崩坏、战争逼近 | 流民、本地人、记册者、供粮者和被征者让玩家看见，崩坏首先发生在具体生活里 |
| 第二章 | 统一似乎能够终止混乱 | 编户者、戍卒、农户、官吏和史家揭示秩序的保护、效率与代价同时存在 |
| 第三章 | 帝国分裂似乎只意味着失序 | 迁徙者、留守者、门阀、边民和宗教共同体展示人如何在裂土中重建生活 |
| 第四章 | 盛世似乎能够代表整个时代 | 都城、边塞、商路、工役和普通家庭让繁华与供养繁华的代价同时显形 |
| 第五章 | 文治、商业与技术似乎天然带来强盛 | 商贩、匠人、文士、军民和亡国者展示文明繁荣与政治生存并非同一件事 |
| 第六章 | 近代危机似乎只是器物落后 | 官署、船坞、乡村、商埠、军队和民间组织共同揭示制度如何失去组织未来的能力 |
| 第七章 | 历史似乎仍由少数人物推动 | 工人、农民、学生、军人、妇女和基层组织让玩家看见普通人如何成为行动主体 |
| 终章 | 玩家想为历代经验写出一个最终答案 | 活着的人以不同记忆和立场修订它，确认历史理解必须保持开放、具体并接受校正 |

苏醒者是叙事载体，不是等待揭晓真身的谜底。每一世的姓名、家庭和成长经验都真实属于本世；残梦只让玩家短暂接触其他时代、其他位置的经验。它们不是寻找真名的线索，而是提醒玩家：眼前所见从来不是历史的全部。

### 4.3 多视角历史模型

同一历史节点至少要从三种位置被呈现：

```text
承受者：谁失去土地、亲人、食物、自由或安全。
执行者：谁把命令、制度和战争落实到具体人身上。
解释者：谁通过官档、私记、传唱、器物或后世研究说明它。
```

不同视角之间允许矛盾。设计目标不是让玩家挑出唯一正确版本，而是让玩家判断：每个版本看见了什么、忽略了什么、为何这样叙述、由谁承担后果。

“名”“籍”“无名录”继续保留，但它们只是历史材料和观察媒介之一。无名指的是长期未进入主流叙事的普通人，不是主角没有名字，也不是终章要揭晓的隐藏身份。

## 5. 一章一生与章节窗口

基本纪律：

```text
每章选择普通人能够活过的关键窗口，不承担连续展示整部通史。
主交互跨度原则上为 30—70 年。
开场从少年或青年开始，结尾完成本世关系、职业和因果交接。
更早历史通过制度遗产、地方记忆、旧物和传说进入。
更晚历史通过晚年短尾声或下一章遗产进入。
不为罗列名人而任意延长寿命。
历史研究优先核对制度、称谓、衣食住行和普通人的行动边界。
```

全章节推荐窗口：

| 章 | 历史主题范围 | 推荐主交互窗口 | 本章主要转折 |
|---|---|---|---|
| PROLOGUE《雨来之前》 | 第一章前置 | 前 286 年旧渡雨前至翻车选择 | 本世生活、宋亡流民、名籍处境、裂钟、第一选择 |
| CH01《钟裂于洛水》 | 礼崩之世 / 春秋战国遗产 | 约前 286—前 221 年 | 雨后流民、新法现实、百家余响、长平、天下归一 |
| CH02《大一统之梦》 | 秦汉 | 约前 218—前 180 年，晚年可略后 | 秦制日常、徭役戍边、秦末、楚汉、汉初继承与调整 |
| CH03《裂土与风骨》 | 魏晋南北朝 | 约 307—347 年，晚年可至东晋中期 | 永嘉之乱、洛阳崩裂、南渡、侨置、门阀与流民 |
| CH04《长安与边塞》 | 隋唐 | 约 730—763 年，晚年进入战后 | 天宝盛世末期、边塞输血、安史之乱、战后重建 |
| CH05《文治与铁骑》 | 宋元 | 约 1234—1285 年 | 南宋末世、商业与文治、战争、宋亡、元初重组 |
| CH06《旧梦与海潮》 | 明清制度遗产与晚清转折 | 约 1835—1865 年，人生可收束至 1895 年前后 | 海上冲击、战争、条约、内乱、船政与旧制失配 |
| CH07《山河重铸》 | 近现代 | 约 1905—1949 年 | 学堂与工厂、旧制退出、民族危机、社会组织、革命与新中国成立 |
| FINAL《无名者有名》 | 新时代门槛 | 1949 年后的象征性尾声 | 多种普通人经验进入公共历史，并由后来者继续讨论和修订 |

| CH07 | 让无名者从被治理对象成为组织与创造主体 | 当旧秩序无法承载山河，谁来重新命名山河？ | 条约、工厂、乡村、学校、旧曲与无名名册 | 人民自己的档案、未完成的名册、公共纪念与未来问题 |
| 终章 | 汇合并检验历章认识 | 经历如此多的位置以后，我们怎样理解这段历史？ | 全部人物、制度、文字、地点、遗物与记忆 | 不给唯一终极定本；把继续调查、争论和书写的权利交给活着的人 |

## 7. 当前制作重点

### 7.1 序章《雨来之前》

序章负责本世入口，不是高频选择题关卡。

制作节奏固定为：

```text
动画化叙事 + 轻探索 + 少量关键选择
```

序章负责到：

```text
主角做出第一选择：先救孩子 / 先抢湿简 / 先让活人互认。
```

### 7.2 第一章《钟裂于洛水》

主题：礼崩之世。

第一章从序章三选一后果开始。

它必须完成：

```text
雨后流民。
旧仓与旧册。
新法入乡。
职业自然成形。
百家灯火。
战争前夜。
长平血雾。
长平后归旧渡，禾安问阿梁消息。
晚年回旧渡，禾安已逝，只留下粥碗。
秦统一与无名录去向。
```

第一章不得重复序章可玩剧本。

## 8. 系统框架

### 8.1 核心系统

```text
人物关系系统：信任、距离、债、秘密、风险。
资源系统：粮、药、钱、时间、证据、制度权限。
事实 / 记录分层：事实、官档、私录、口述、玩家认知。
职业责任系统：职业决定可见信息、可用资源和必须承担的后果。
因果节点系统：选择进入人物、制度、物件和后世。
记忆碎片系统：裂钟、旧物、声音和场景触发共同回声。
章节交接系统：每章根据合法分支生成交接包。
```

### 8.2 交接包字段

每章结束至少输出：

```text
historical_result
route_result
core_character_fates
truth_state
official_record
private_record
oral_version
primary_carrier
secondary_traces
institutional_legacy
memory_cue
unanswered_question
mandatory_callbacks
```

## 10. 开发原则

```text
现阶段以 Godot 原生序章垂直切片验证核心叙事与演出，不在单文件 HTML 上继续堆叠。
正式方向优先 Godot 第一章垂直切片。
内容与运行时分离，剧情条件和状态变化不得写死在 UI 中。
所有重要选择都要通过事件记录，便于存档升级、路线审计和跨章回收。
先证明序章与第一章能成立，再扩展后续章节。
```
