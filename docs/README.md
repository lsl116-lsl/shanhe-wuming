## 1. 当前项目口径

```text
产品形态：章节式 2D 历史叙事人生 RPG / AVG
结构：序章 + 七章 + 终章
当前制作重点：序章《雨来之前》与第一章《礼崩之世》
第一章结构：八职业线 + 乡土地基 + 隐退倾向
正式方向：网页验证核心叙事，Godot 制作第一章垂直切片
```

第一章八职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”已转为乡土地基。  
“隐士”已转为隐退倾向。  
不得恢复旧的十职业或九职业口径。
