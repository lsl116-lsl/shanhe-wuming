# 《山河无名》项目概述 V1.0

## 1. 这是什么项目

《山河无名》是一款以中国历史长河为骨架、以普通人的多重视角为核心的单机历史叙事 RPG / AVG。

玩家会在中国历史的关键转折处一次次醒来。每一次醒来，玩家都拥有一个新的姓名、家庭、身体、社会关系和完整人生。玩家可能成为医者、吏员、商贾、军卒、艺人、工匠、谋士、仕官，也可能首先只是一个需要吃饭、照顾家人、承担赋役、躲避战乱的普通人。

这些人生不是为了让玩家寻找自己的隐藏身份，而是让玩家站到不同的位置，重新看见同一段历史。

> 山河不是一张帝王年表。
>
> 历史要从许多人的眼睛里，才能逐渐看清。

## 2. 故事的核心意思

传统历史叙述往往从王朝、战争、制度与名人出发。《山河无名》关心的是：

```text
一项新制度落到一户人家时，究竟改变了什么？
一场战争除了胜负，还留下了哪些伤者、失踪者、债务与沉默？
一座盛世城市的灯火，由哪些看不见的人供养？
一次王朝更替以后，普通人为什么仍要继续吃饭、治病、工作和寻找亲人？
同一件事为什么会在官档、私记、戏曲、账本和亲历者口中变成不同的样子？
```

游戏不要求玩家找到一份绝对完整的历史答案。它让玩家不断获得新的位置、新的证词和新的反证，逐步发现自己此前的理解并不完整。

故事最终表达的是：

> 历史由许多具体的人共同经历。理解历史，不是找到一个包办一切的答案，而是看见不同位置的人经历了什么、为何这样选择、又由谁承担结果。

## 3. 玩家是谁

玩家是“苏醒者”，但苏醒者不是天命之子、长生英雄或历史之外的观察神。

苏醒者有三条基本规则：

1. **每一世都是真实人生**：姓名、家庭、成长与关系全部属于这一世，不是临时借来的外壳。
2. **记忆始终不完整**：裂钟和残梦只会带来其他时代、其他社会位置的片段，不能提供未来答案。
3. **没有隐藏真名任务**：玩家不需要拼出“我究竟是谁”。真正的长线问题是“我怎样理解这段历史”。

因此，苏醒者的价值不是拥有超能力，而是能够让原本相隔数百年的普通人经验彼此照见。

## 4. “无名”是什么意思

“无名”不是主角没有名字，也不是所有人最终共享一个抽象名字。

“无名”指的是：

- 史书中只剩一个数字的人；
- 名册上被漏写、错写或故意删去的人；
- 只留下工具、伤口、账目、曲调或一封未送达家书的人；
- 参与建设、供养、照护和抵抗，却没有成为叙事中心的人；
- 明明活过，却没有足够材料让后来者理解其处境的人。

项目要做的不是替这些人统一命名，而是给他们的经验留下位置，并承认记录永远可能不完整。

## 5. 玩家在游戏中做什么

玩家的核心循环不是刷怪、升级和收集装备，而是：

```text
进入一段具体生活
→ 认识与自己有真实关系的人
→ 从当前社会位置接触历史压力
→ 在有限信息、时间和资源中行动
→ 让其他人物按照自己的意志继续行动
→ 承担关系、事实和记录产生的后果
→ 在后续人生或后续朝代重新看见这件事
→ 用新的视角修正此前的理解
```

玩家可能需要移动、调查、对话、救治、记账、护送、造物、执行文书、组织撤离或决定一份材料交给谁。这些操作都服务于人物和历史处境，而不是独立的数值玩法。

## 6. 玩家能改变什么

玩家通常不能阻止既定的大规模历史转折，例如秦统一、安史之乱、南宋覆亡或近代战争结果。

玩家能够改变：

- 谁获救、受伤、失踪、迁徙或死亡；
- 谁与玩家建立信任、产生裂痕、离开或反向行动；
- 一项制度在某个地方怎样执行；
- 有限的粮、药、船位、时间和证据怎样分配；
- 哪个版本进入官档、私录、口述、戏曲、账本或工图；
- 某段经验以什么形式被后世发现、误读、补充或质疑。

这种能动性不是“改变天下”，而是改变历史中的一小片人间。

## 7. 不同视角为什么重要

职业在本项目中不是战斗职业，而是社会观察位置。

例如同一场战争：

| 视角 | 最先看见的历史 |
|---|---|
| 武将 / 军卒 | 命令、道路、军纪、战机与同伍生死 |
| 医者 | 伤口、疫病、药材、分诊和战争余痛 |
| 吏员 / 记录者 | 征发、兵籍、死伤册、失踪与责任链 |
| 商贾 | 粮价、运输、信用、断路与投机 |
| 工匠 | 车辆、桥梁、兵器、维修和劳动组织 |
| 戏子 / 艺人 | 士气、传言、悼亡、宣传与民间记忆 |
| 谋士 | 情报、承诺、策略及没有写进方案的人 |
| 仕官 | 制度权限、执行边界、公共责任和政治代价 |
| 乡土生活 | 土地、家人、灶火、赋役和“谁还能回来” |

任何一条线都不能代表全部历史。不同路线必须提供新的信息边界、责任和代价，而不是重复相同剧情。

## 8. 四个核心意象

### 裂钟

裂钟象征旧秩序在历史转折处发出的裂响，也是跨时代视角短暂重叠的入口。它不授予技能，不预告未来，也不回答身份。

### 河流与渡口

河流连接迁徙、商路、战争、粮运与回乡。渡口是人被分类之前短暂停留的地方，也是不同人生不断相遇的现实空间。

### 名与籍

名字让人被称呼，籍册让人获得社会位置。入册可能带来粮、田、居住和承认，也可能带来赋役、追索与连坐。

### 无名录

无名录是第一章开始形成的民间见证。它能补充官档，却同样受记录者视角和材料残缺限制。它不是唯一真相，更不是苏醒者身份的答案。

## 9. 作品气质

关键词：

```text
历史转折、普通人、生活质感、有限选择、长期因果、彼此纠错、克制、余味。
```

避免：

```text
穿越开挂、历史名人打卡、职业换皮、纯苦难展览、简单善恶、为了深刻而故作高深、让角色替作者说主题。
```

人物首先要像真实生活中的人。他们会关心家人、粮食、工作、名誉和安全，也会因为恐惧、自利、责任、爱与误判作出不完美的选择。

## 10. 当前制作目标

当前不追求一次做完整部中国史。

当前目标是完成：

1. 序章《雨来之前》的完整 Godot 可玩 Demo；
2. 让玩家在 20—30 分钟内喜欢旧渡、认识主要人物、理解项目的多视角叙事方式；
3. 让雨夜翻车选择真正体现“只能先做一件事”的代价；
4. 以序章验证故事、人物、美术、声音、镜头和交互是否能够共同成立；
5. 再进入第一章《钟裂于洛水》的正式制作。
