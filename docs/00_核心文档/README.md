# 《山河无名》核心文档入口

> 文档版本：V1.0
>
> 用途：让新成员、Codex、编剧、美术、音频和程序在最短时间内理解同一个项目。

## 先读这三份

1. [项目概述 V1.0](01_项目概述_V1.0.md)：这是什么游戏，玩家是谁，故事真正想表达什么。
2. [项目框架 V1.0](02_项目框架_V1.0.md)：章节、视角、因果、玩法和制作边界如何协同。
3. [全篇故事走向 V1.0](03_全篇故事走向_V1.0.md)：序章至终章发生什么，每章怎样推动总故事。

读完三份文档后，应能回答：

```text
玩家为什么会跨越时代？
为什么每章都要从普通人的位置出发？
不同职业线除了职业不同，究竟看见了什么不同的历史？
玩家不能改变哪些历史，又能改变哪些具体人生？
裂钟、残梦、无名录和“无名”分别是什么意思？
序章、第一章、后续六章和终章怎样连成一个完整故事？
```

## 文档权威顺序

发生冲突时，按以下顺序判断：

```text
本目录三份 V1.0 核心文档
→ 根目录 AGENTS.md
→ 目标章节 README 与当前主线大纲
→ 人物、因果、记忆、职业和制作规范
→ 旧版本框架与历史原型说明
```

## 当前已经确定

- 项目核心不是寻找主角真名，而是通过不同社会位置逐步认清历史。
- “苏醒者”是连接时代与视角的叙事载体，不是等待揭晓身份的谜底。
- 每章是一段真实、完整的人生，不是借身体旅行的空壳。
- 宏观历史结果原则上不被玩家改写；玩家改变人间尺度的结果。
- 第一章使用八条职业视角线，并共享乡土地基与隐退倾向。
- 序章与第一章是当前正式制作重点；后续章节仍以故事总纲和概念验证为主。
- 正式制作使用 Godot 原生 Windows 工程；网页原型只作历史参考。

## 当前尚未完全冻结

- 第二章以后每章最终保留多少视角线。
- 后续章节全部关键人物、场景数量和具体玩法密度。
- 苏醒机制是否在文本中获得有限解释；无论怎样处理，都不能回到寻找真名。
- 终章的具体历史时点、人物阵容和最终演出形式。

## 旧文档如何使用

旧文档不是全部废弃，但要区分用途：

| 文档类型 | 当前用途 |
|---|---|
| `docs/00_项目总框架_V0.5.md` | V1.0 的上游材料，保留详细系统字段；若与本目录冲突，以本目录为准 |
| `docs/01_跨朝代因果总表_V0.1.md` | 跨章载体与回响资料库，不单独决定项目主题 |
| 各章节 `01_主线大纲` | 当前章节故事来源；第二章以后仍允许调整 |
| `docs/08_项目落地方案_V0.1.md` | 早期落地路线，其中网页阶段已过时 |
| `docs/10_阶段A...`、`11_阶段B...` | 历史原型记录，不作为当前制作目标 |
| Godot 制作规格 | 实现与验收依据，不得反向改变故事核心 |

## 一句话校准

如果一项新增内容不能帮助玩家从一个具体人的位置，更清楚地理解历史如何发生、如何落到普通人身上，它就不应成为《山河无名》的主线内容。
