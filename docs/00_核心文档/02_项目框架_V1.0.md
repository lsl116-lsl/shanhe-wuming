# 《山河无名》项目框架 V1.0

> 本文回答“这个项目由哪些层组成、每章怎样运作、不同视角为什么不是换皮路线，以及游戏怎样把故事变成可玩的体验”。

## 1. 总体结构

《山河无名》采用“序章 + 七段历史人生 + 终章”的章节结构。

```text
序章《雨来之前》
→ 第一章《钟裂于洛水》：春秋战国
→ 第二章《同书异命》：秦汉
→ 第三章《两岸旧乡》：魏晋南北朝
→ 第四章《灯火的来路》：隋唐
→ 第五章《一页山河》：宋元
→ 第六章《潮来以前》：晚清
→ 第七章《把名字写回来》：近现代
→ 终章《这里还少一个人》
```

每章不是一堂历史课，也不是若干随机事件的拼盘，而是一段有出身、关系、成长、失去和晚年的完整人生。跨越朝代的“苏醒者”负责让这些人生彼此照见，但不凌驾于这些人生之上。

## 2. 三层叙事同时推进

### 2.1 人生层：玩家先活成一个人

每一章首先要成立的是具体生活：家里有没有粮，亲人是否平安，师父为什么教他，朋友为何离开，眼前的工作怎样完成。

这一层负责让玩家关心人物。若没有这一层，制度、战争与历史都只剩背景说明。

### 2.2 历史层：时代怎样落到生活里

历史转折不以年表旁白直接压给玩家，而通过可以感知的变化进入生活：

- 粮车减少，陌生人增加；
- 新法木牌挂到村口；
- 户籍重新核定，同一个人被两本正确的册子重复征发；
- 长安灯火仍亮，运河和边塞却已先承受代价；
- 印刷、机器和新学被引入，却无法单独解决制度与组织问题。

宏观历史保持史实边界。玩家不能阻止秦统一、安史之乱、南宋覆亡或近代战争，但会亲手经历这些事件如何改变一个地方、一户人和一段关系。

### 2.3 认识层：新视角修正旧理解

一条人生只能看到局部。后续人生不是把前章答案再讲一次，而是提供新的材料和反证。

例如玩家可能先把统一理解为结束战乱，下一章却从户籍、征发与基层执行中看到统一秩序的保护与伤害；可能先把长安理解为盛世象征，后来才从漕运工、边军和工匠的位置看见灯火的来路。

全篇真正的成长不是数值变强，而是：

```text
先相信一个简单解释
→ 在一段人生里看见它的理由
→ 在另一种位置看见它的盲点
→ 接受历史不能被单一答案包办
```

## 3. 单章标准结构

每一章使用同一条骨架，但不能写成同一个故事的换皮：

```text
苏醒：进入本世身体与生活，不知道未来答案。
安身：认识家人、故乡、工作与现实难题。
受压：时代变化第一次破坏原有生活秩序。
成路：玩家的行动逐渐形成社会位置或职业责任。
入局：个人关系与历史事件无法再分开。
共危：不同视角共同面对本章的历史高潮。
失去：产生无法被完美挽回的结果。
回望：晚年重新理解年轻时的判断。
留证：留下文字、物件、技艺、口述或关系回响。
沉睡：这一世结束，未尽问题进入下一章。
```

其中“职业成形”必须来自生活和能力积累，不能开局弹出职业菜单。主角成为医者，是因为长期跟随师父治病并承担病人的生死；成为武将，是因为从护送、护车和军中责任一步步走到下令，而不是点击“选择武将”。

## 4. 多视角系统

### 4.1 职业是认识历史的位置

职业不只决定玩家会做什么，也决定五件事：

| 维度 | 含义 |
|---|---|
| 信息 | 玩家最先知道什么，又必然不知道什么 |
| 资源 | 玩家能调动药、粮、车、文书、关系、技艺或权力中的什么 |
| 责任 | 选择出错时，玩家需要对谁负责 |
| 盲点 | 这一位置最容易忽略谁、误解什么 |
| 证据 | 这段人生最终能留下哪一种独有材料 |

同一历史节点至少要出现三类位置：

```text
承受者：制度与战争落在谁身上。
执行者：谁把命令、规则和资源分配落实到具体的人。
解释者：谁记录、传唱、计算或为事件赋予意义。
```

一个人物可能同时处在两类位置，但任何单一路线都不能掌握全部事实。

### 4.2 第一章当前固定结构

第一章采用八条职业视角线：

```text
医者、吏官 / 记录、商贾、武将、戏子、工匠、谋士、仕官。
```

土地、粮水、田亩、灶火、家庭与徭役是八条线共同踩着的乡土地基，不另设农人副本。隐退、拒仕、私藏见证和晚年归处是各路线可能出现的选择倾向，不另设隐士副本。

第二章以后的旧文档仍保留十职业清单，那些内容目前只作为视角素材库。后续章节最终保留几条线，要按照该章的核心冲突、人物关系和制作规模重新裁剪，不能机械套用十职业模板。

## 5. 玩家能动性边界

### 玩家不能改变

- 已确定的王朝兴亡和大规模战争结果；
- 社会结构凭一个人的意志被彻底改造；
- 所有人同时获救、所有证据同时保全；
- 凭残梦预知未来并选择唯一正确答案。

### 玩家能够改变

- 谁先得到帮助，谁因此错过机会；
- 一项制度在一个地方被机械执行、变通执行或被人抵抗；
- 一段关系成为信任、亏欠、裂痕、传承还是遗憾；
- 哪份材料被写入官档、私录、账本、戏文或口述；
- 一个器物、药方、名单、曲调或方法是否被后人看见；
- 后世从什么入口重新理解前世留下的问题。

因此，游戏不提供“完美通关”。好的选择也有代价，严厉的选择可能保护更多人，善意也可能在后续结出苦果。

## 6. 因果结构

因果不是善恶值，而是事件之间可追溯的关系。每个重大选择至少改变下列一项：

| 因果层 | 示例 |
|---|---|
| 人物 | 救下、辜负、误解、托付、结怨 |
| 事实 | 谁活着、谁失踪、哪件事实际发生 |
| 记录 | 哪个版本被写下，谁的名字被漏掉 |
| 物质 | 粮、药、船位、工具、道路和居所如何分配 |
| 记忆 | 后人通过何种残片理解或误解这件事 |

因果可以在本世立即结果，也可以多年后、下一章甚至终章才被重新发现。后世得到的不是完整答案，而是有出处、有缺口、可能互相冲突的材料。

## 7. 跨章载体

长线连续性主要由下列载体承担，而不是靠苏醒者讲解前世：

### 裂钟

在历史转折处触发短暂重叠。它只让玩家看见另一个位置的片段，不授予技能，不预言未来，也不解释身份。

### 河流与渡口

连接迁徙、粮运、商路、战争与归乡。渡口既是人被登记、分流的现实空间，也是不同人生短暂交会的地方。

### 名字、名册与各种记录

名字使人可以被称呼，名册使人进入制度。官档、私记、伤簿、账本、工图、戏文和口述都能保存历史，也都受记录者位置限制。

### 普通物件

旧粥碗、木片、工具、旧地图、书页和未送达的信不承担神秘能力。它们有力量，是因为曾被具体的人使用、保存和误解。

### 《无名录》

《无名录》是第一章开始形成的一份民间见证，后来被抄写、损坏、补充、质疑。它不是唯一真相，更不是苏醒者身份答案；它的价值是给官方叙事之外的经验留下可讨论的位置。

## 8. 可玩体验框架

核心循环是：

```text
进入具体场景
→ 观察人物、环境和可用资源
→ 通过移动、调查与对话获得有限信息
→ 在时间、权限或资源压力下行动
→ 看见其他人物独立反应
→ 承担即时结果与长期回响
→ 后来从另一位置重新理解这件事
```

交互遵守一句话：

> 移动负责让玩家看见，互动负责让玩家承担。

选择优先发生在空间与行动中，而不是连续弹出 A / B / C。例如序章翻车现场让玩家实际走向孩子、湿简或失散人群；靠近只能了解情况，按住互动键才锁定“先做什么”。

## 9. 人物与对白规则

重要人物必须拥有自己的欲望、恐惧、现实负担和行动路线。即使主角不出现，他们也会继续生活并作出选择。

写作必须遵守：

- 人物先说眼前的事，不替作者讲主题；
- 行为必须符合处境、能力、关系和常情；
- 善良要有资源成本，现实判断不等于冷酷；
- 人物可以误判，但不能为了推动剧情突然变蠢；
- 关键关系要经过相识、相处和变化，不能突然成亲、背叛或牺牲；
- 深意从动作与后果中产生，不写故作高深的总结句。

## 10. 历史与虚构规则

每章在细写前必须建立史实边界：时间窗口、地理范围、制度称谓、物质条件、交通速度、医疗与技术水平。

真实历史人物不是打卡对象。若其出现，只能因为普通人的工作与生活确实会接触到其政策、军队、作品或组织。虚构人物负责承载具体生活，但不能用现代观念和现代术语替代当时处境。

## 11. 制作文件如何衔接

```text
V1.0 核心文档
→ 目标章节 README 与主线大纲
→ 人物关系、因果、记忆与职业视角表
→ 可读故事 / 剧本
→ 场景流程、镜头、交互和音频规格
→ Godot 内容数据与场景实现
→ 路线审计、剧情审查和可玩测试
```

下游文件不得反向修改上游核心。发现冲突时先记录问题，再由项目层决定是否修订核心文档。

## 12. 当前里程碑

当前唯一需要做完整的产品闭环是序章《雨来之前》：

```text
标题进入
→ 旧渡生活
→ 登记本世姓名
→ 宋亡消息与流民到来
→ 裂钟多视角片段
→ 雨夜翻车的空间选择
→ 选择后果与第一章标题
```

现阶段暂缓扩大后续朝代内容量。先用序章验证：人物是否可信、旧渡是否令人留恋、多视角是否可感知、选择是否有代价、美术与声音是否形成统一气质。

## 13. 交付前质量门槛

任何新增主线内容都要能回答：

1. 这个事件为什么在此时、此地发生？
2. 人物为什么会做出这个行动？
3. 该视角提供了其他路线看不到的什么？
4. 玩家具体承担了什么，而不只是点了什么？
5. 它改变了人物、事实、记录、物质或记忆中的哪一项？
6. 它是否在偷换成寻找真名、天命身份或全知穿越故事？
7. 如果删除这一段，故事是否真的受损？

无法清楚回答的问题，不应直接进入制作。
