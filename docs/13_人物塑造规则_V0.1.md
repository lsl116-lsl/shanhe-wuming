# 《山河无名》人物塑造规则 V0.1

> 文档状态：角色写作与剧情打磨规范  
> 适用范围：全章节、全部主要人物、职业线人物、亲属与后人线  
> 核心原则：人物不按好坏分类，人物的好坏由玩家根据行为、代价与立场自行判断。

## 1. 总原则

《山河无名》不能写成简单的好人坏人故事。

每个重要人物都必须有自己的来处、欲望、恐惧、底线、习惯动作和不得已。

文本不替玩家审判人物。文本只展示人物如何选择、如何承担、如何隐瞒、如何保护，至于这个人是好是坏，交给玩家自己判断。

人物写作的基本问题不是：

```text
他是好人还是坏人？
```

而是：

```text
他想保住什么？
他害怕失去什么？
他相信什么？
他做过什么不能轻易说出口的事？
他愿意让谁承担代价？
他不愿意承认自己亏欠了谁？
```

## 2. 人物不替主题喊口号

人物不能为了说明设定、解释主题或推动剧情而存在。

人物首先必须像一个活人。

他要有自己的日常压力：粮、药、债、亲人、旧案、身份、职业责任、身体疲惫、名册风险、被牵连的人。

例如：

- 禾安不是“善良少女”。她是旧渡长大的孩子，知道一锅米能撑几个人，也知道多救一个人就要多欠一笔债。
- 辛衡不是“智慧导师”。他懂文字和名册的重量，也可能曾经用文字伤过人。
- 韩宁不是“可怜流民”。他想被承认，又不敢把旧里说全，因为他说出的每个地名都可能牵连还活着的人。
- 柳娘不是“温柔戏子”。她知道一句唱词能安魂，也知道一句地名能害人。

## 3. 人物必须有矛盾

鲜明人物一定要有内在矛盾。

| 人物 | 外在行为 | 内在矛盾 |
|---|---|---|
| 禾安 | 数米、数水、数柴，嘴上现实 | 她知道代价，却见不得人死在眼前 |
| 辛衡 | 写名册、教主角识字 | 相信记录，也害怕记录伤人 |
| 韩宁 | 不说旧里，护着残简 | 想被承认，又怕名字害死活人 |
| 柳娘 | 唱旧曲，却删去地名 | 靠旧曲安人，也知道旧曲会暴露人 |
| 主角的母亲 | 每日看河道尽头 | 她知道等待不能当饭吃，却仍不愿承认主角的父亲不会回来 |
| 主角的父亲 | 随官运粮后未归 | 他不应只是失踪者，后续可牵出官粮、旧仓、失踪与记录冲突 |

人物越重要，矛盾越不能只写在旁白里，必须落在动作、停顿、物件和选择上。

## 4. 人物台词不要自我说明

不要让人物直接解释自己的人格。

不要写：

```text
禾安其实是一个善良但现实的人。
```

要写：

```text
禾安蹲在灶前，把米袋倒过来抖了抖。
袋底落下一点碎米。

她看了你一眼。

“别看我。就这么多。”

你还没说话，她已经把碎米倒进锅里。
```

不要写：

```text
辛衡曾经犯错，所以他很愧疚。
```

要写：

```text
辛衡拿起空木牍，迟迟没有落笔。
灯火晃了一下，他把笔放回砚边。
```

不要写：

```text
韩宁害怕自己的旧里害死亲人。
```

要写：

```text
听见“旧里”两个字，韩宁先按住袖中的木片。
```

## 5. 少解释，多留白

人物关系、旧债和悬念不要一次说透。

序章尤其要克制。

序章只需要让玩家知道：

```text
韩宁的父亲和旧册有关。
韩宁手里的残简不是普通木片。
辛衡看见残简后知道事情不简单。
主角的父亲随官运粮后未归。
主角的母亲仍在等。
```

不要在序章直接说：

```text
韩宁的父亲拆散了名册。
辛衡曾经删过名字。
主角父亲到底出了什么事。
```

这些应当在 ACT01、ACT02、ACT03 和后续章节中逐渐被玩家发现。

## 6. 家庭关系必须写清主语

涉及父母、亲属、后人、旧债时，必须明确写出是谁的父母、是谁的旧债、是谁的后人。

避免只写：

```text
母亲站在门口。
父亲没有回来。
```

应写：

```text
你的母亲站在门口。
你的父亲随官运粮后未归。
```

涉及韩宁时，应写：

```text
韩宁的母亲守在他身旁。
韩宁的父亲原先替宋地某处管过旧册。
```

《山河无名》后续会涉及父辈旧债、后人回收、家族与名册因果。主语不清会直接破坏玩家理解。

## 7. 好坏交给玩家

同一人物的同一行为，应当允许玩家产生不同评价。

| 行为 | 一种玩家判断 | 另一种玩家判断 |
|---|---|---|
| 辛衡删名 | 他是在保护活人 | 他抹掉了死者存在 |
| 禾安藏粮 | 她自私，只顾旧渡 | 她知道旧渡也要活 |
| 韩宁隐名 | 他拖累别人一起承担风险 | 他说出来会害更多人 |
| 柳娘不唱地名 | 她怯懦，不敢完整记住故乡 | 她在保护流民 |
| 主角的母亲继续等待 | 她不愿面对现实 | 她用等待保住这个家的最后一点完整 |

文本要展示代价，不要给玩家贴答案。

## 8. 每个主要人物必须有记忆点

主要人物需要一个可反复出现的动作、物件或说话方式。

| 人物 | 记忆点 |
|---|---|
| 禾安 | 数米、数水、数柴；嘴硬；手上不耽误救人 |
| 辛衡 | 敲案、停笔、看木牍；说话慢，每句都有重量 |
| 韩宁 | 按住袖中木片；不说旧里；看人时像被逼到墙角的兽 |
| 柳娘 | 唱到地名处停顿；戏箱垫在漏风处；发簪总插得很正 |
| 主角的母亲 | 望河道尽头；不说等，却一直等 |
| 主角的父亲 | 留下“新笔”的承诺；官粮车队；未归的方向 |

## 9. 人物模板

后续补人物时，使用以下模板：

```text
人物名：
他 / 她想要什么：
他 / 她害怕什么：
他 / 她相信什么：
他 / 她说不出口的事：
最鲜明的动作 / 物件：
让玩家可能喜欢的地方：
让玩家可能不舒服的地方：
可能种下的因：
文本是否替玩家判断：否
```

## 10. 序章人物基调

### 禾安

她不讲大义。她算米、算水、算柴，也算明早谁会饿。

她不是圣母，也不是冷漠的人。她知道代价，却不愿让人死在眼前。

她的表达方式应当是：嘴上现实，手上不慢。

### 辛衡

他懂名字和记录的重量。

他不是全知导师。他有旧事、有回避、有停笔的时候。

他教主角写名字，不是单纯启蒙，而是把主角推向“名字会救人，也会害人”的世界。

### 韩宁

他是流民少年，也是旧册悬疑的入口。

他不说旧里，不只是害怕，而是知道说出来会牵连别人。

他要让玩家同时想帮他、怀疑他、被他隐瞒信息而不安。

### 柳娘

她不是装饰性的戏子。

她的旧曲可以安人，也可能害人。她唱到地名处停顿，就是她的人物核心动作。

她的“删去”既可能被看成保护，也可能被看成对故乡的再次抹去。

### 主角的母亲

她让主角这一世落地。

她不需要说太多等待的话。她只要反复望向河道尽头，玩家就会明白她在等谁。

### 主角的父亲

他暂时不登场。

他的作用不是制造简单寻父任务，而是把主角的私人家庭牵挂接到官粮、旧仓、流民、名册和辛衡旧事上。

## 11. 写作警戒线

后续写人物时避免：

- 把人物写成单纯好人或坏人。
- 用旁白替人物解释人格。
- 让人物直接说出作者主题。
- 让角色为了推动剧情突然变蠢或突然变坏。
- 让所有秘密在首次登场时说透。
- 让善良没有代价。
- 让现实人物没有情感。
- 让父母、亲属、旧债的主语模糊。

## 12. 最终标准

一个《山河无名》的人物，应该让玩家产生这样的感受：

```text
我能理解他为什么这样做。
但我不一定认同。
我想帮他。
但帮他会伤到别人。
我想责怪他。
但换成我，也未必做得更好。
```

人物不是为了被审判而存在。

人物是为了让玩家看见：

```text
在乱世里，人是怎么活下去的。
```
