| 职业 / 题名 | 欲望与盲点 | 关系核心 / 人性对手 | 三次升级 | 专属高潮 | 不可逆代价 | 终章材料 |

## 2. 八幕嵌入

| 幕 | 收敛内容 | 独立线要求 |
|---|---|---|
| ACT01 | 夜学、缺席名字 | 职业人格种子，不锁定 |
| ACT02 | 共和与换旗不停机 | 看见政治突破与社会连续 |
| ACT03 | 五四与公共行动 | 与不同群体共同改写诉求 |
| ACT04 | 职业承诺、群众组织 | 付出第一次结构性代价 |
| ACT05 | 1927 后失败与重建 | 独立地理线、关系线和纠错 |
| ACT06 | 全民族抗战、七日名册 | 共同危机，不同岗位与证据 |
| ACT07 | 战后与 1949 前 | 各职业完成独立高潮 |
| ACT08 | 人民自己的书 | 交出材料和错误，不清空债 |

## 3. 状态与反滥用

| 职业 | 核心状态 | 反滥用 |
|---|---|---|
| 隐士 | `network_security` / `member_agency` | 高安全不能等于一人控制全部信息 |
| 仕官 | `service_continuity` / `public_oversight` | 稳定不能自动压过监督 |
| 谋士 | `coordination` / `informed_participation` | 胜率高不等于可隐瞒所有代价 |
| 武将 | `unit_effectiveness` / `civil_discipline` | 战功不能抵消军纪债 |
| 医者 | `care_capacity` / `patient_choice` | 多救人数不能自动合理化弃人 |
| 乐人 | `mobilization_reach` / `subject_voice` | 传播不替代当事人权利 |
| 商贾 | `productive_capacity` / `worker_power` | 爱国资本不免除劳动关系 |
| 工匠 | `technical_control` / `collective_control` | 熟练工不能垄断工人组织 |
| 吏官 | `archive_completeness` / `identity_safety` | 全记录可能成为镇压工具 |
| 农人 | `land_change` / `weak_household_protection` | 多数决定不能吞没弱户 |

## 4. 收敛规则

- 1905、1911、1919、1921、1927、1931 / 1937—1945、1949 是历史锚点，不要求所有路线亲临全国中心现场。
- 材料接力必须标记来源、延迟、删改与风险；不能让主角全知。
- “人民成为主体”由参与决策、组织纠错、承担责任和公共记录四类玩法证明，不靠旁白口号。
- 玩家所在组织也会犯错；正确方向不等于每个具体决定自动正确。
