# 第七章《山河重铸》人物关系表 V0.1

> 人民不是无差别背景。人物之间既有共同目标，也有阶级、城乡、性别、职业、组织经验和生存压力造成的真实冲突。

| 许澄—方真 | 程序连续与革命突破 | 把程序向谁负责说清并接受监督 | 双方都可能造成的延误或强制 |
| 周行—田青 | 征粮、驻军和军纪 | 公示军需、借粮有据、申诉可达 | 士兵曾进入谁家 |
| 苏雁—白露 | 医疗隐私与宣传动员 | 当事人决定匿名、画面与删改 | 已公开的影像无法收回 |

## 3. 人物主动性

- 方真可能为行动安全绕过玩家；这不是固定背叛，而由授权机制与压力累积决定。
- 田青不会因为城市主角“觉悟高”就交出乡村组织领导权。
- 何澄可以真诚抗战，同时压制工人；两者必须并存。
- 周行服从正确组织也仍需对具体命令负责，不能以阵营清空行为后果。
- 乌兰拒绝成为“多民族团结的展示人物”，她拥有具体家乡、职业和政治判断。
- 林秋、苏雁、白露、田青的行动不围绕恋爱线成立，亲密关系不能覆盖其公共角色。

## 4. 立体度验收

每人至少出现一次日常生活、一次自主行动、一次内部矛盾、一次合理但伤人的选择和一次不能靠好感度消除的分歧。
