# 第七章《山河重铸》章节定位与史实边界 V0.1

> 推荐主交互窗口：1905—1949 年
> 主空间：以上海及相连江南工厂、铁路和乡村为共同起点；职业线可沿真实交通进入华北、华中、东南与抗战后方，但禁止主角无成本瞬移全国
> 章节责任：完成从“谁治理普通人”到“普通人如何组织、认识并成为历史主体”的转向；把历代无名录变成人民自己维护的公共记录。

## 1. 核心问题

```text
君主制结束以后，旧社会关系为什么没有自动结束？
分散、处境不同的普通人，怎样形成能够共同选择和行动的人民？
新的组织和公共记录，怎样避免再次把具体的人压成数字？
```

## 2. 史实锚点

- 1905 年科举制度废除，新式学堂扩展；教育内容、招生、经费、性别和城乡差异形成新的机会与门槛。
- 1911 年辛亥革命推翻清朝统治、结束延续两千多年的君主专制制度并建立共和，但反帝反封建的历史任务没有因此自动完成。
- 五四运动由学生先锋扩展到工人和社会各界，推动新的思想、公共讨论和社会力量登上历史舞台。
- 1921 年中国共产党成立；此后工人、农民、青年和妇女等组织实践经历发展、挫折、分裂和牺牲。
- 中国人民抗日战争从 1931 年局部抗战延续至 1945 年胜利，1937 年进入全民族抗战；侵略造成巨大灾难，工人、农民、士兵、学生、女性、工商界和各族人民以不同方式参与。
- 1949 年中华人民共和国成立，开启历史新纪元。本章以此为新时代门槛，不虚构“所有矛盾当日消失”。

## 3. 禁止

- 不把辛亥革命写成无意义插曲；要同时呈现其历史突破与未竟任务。
- 不把五四写成只有青年学生，不把革命写成少数领袖替沉默群众完成。
- 不把“人民”写成没有职业、性别、地域、民族、利益和意见差异的整齐人群。
- 不把工人、农民天然英雄化；组织需要学习，会犯错误，也要纠错和承担责任。
- 不把国民党、共产党及其他政治力量的历史位置模糊化，也不把复杂个体直接等同于组织整体。
- 不把日本军国主义侵略与中国内部冲突混为一谈，不以个人善恶淡化侵略责任。
- 不让玩家成为所有重大事件的幕后关键人物。
- 不以“胜利”清空战争伤残、失踪、家庭裂痕、错误决定和未查明姓名。

## 4. 贯穿载体

| 载体 | 本章演化 | 终章形态 |
|---|---|---|
| 条约副本 | 进入反帝运动、工厂、港口和国家主权讨论 | 旧时代主权受损的公开证据 |
| 船坞工册 | 转为工资、工会、事故、迁厂和生产名册 | 劳动者共同记忆 |
| 学堂课本 / 译报 | 进入夜校、乡校、报刊和理论讨论 | 人人可读、可批注的公共知识 |
| 乡民自救册 | 进入农会、减租、互助、战时生产和土地记录 | 农民自己书写的乡村档案 |
| 旧戏新词 | 进入街头剧、救亡演出和集体歌声 | 人民共同演出而非被代言 |
| 无名录 | 从“替人记名”转为本人、同伴、家属共同登记 | 人民公共档案 |
| 裂钟 | 与罢工钟、警报、汽笛、集合声重叠 | 不再哀悼旧王朝，转为共同苏醒 |

## 6. 交给终章

- 一份由当事人共同维护、允许纠错和补名的“人民自己的书”；
- 工人名册、乡村记录、交通员家书、伤亡与失散名册；
- 学生、士兵、医护、女性组织者、商贩和少数民族参与者的交叉证言；
- 每条职业线的具体组织经验与错误；
- 1949 作为旧时代根本转折和新建设开端的生活证据；
- “苏醒者不是人民之外的代言人，他就在共同记忆与行动之中”的最后推断。
