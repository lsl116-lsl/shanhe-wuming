# 第七章至终章衔接过渡文《长桌》V0.1

## 1. 固定过渡

最早的时候，名字刻在竹简上，决定谁服役、谁受罚、谁属于哪一户。后来名字上了军册、侨籍、粮账、工册、学堂点名、地下名单和战时名册。

许多人一生都在册上，却从未决定册怎样写。

1949 年，长桌被抬进一处仍在修缮的公共屋舍。窗没有安完，雨会吹进来。工人用废木垫桌脚，农民带来用布包着的土地页，士兵放下家书，医者补写伤员，家属来纠正死亡日期。有人不识字，就把话说给同伴听；有人不同意组织记录，就在旁边另写一栏。

这不是一本已经完成的历史。

这是历史第一次如此明确地把继续书写的权利交还给创造它、承受它的人。

## 3. 人物命运拼图

系统选择三类人物各一名：

1. **仍在场者**：亲手带来材料，允许玩家与其最后争论。
2. **已牺牲 / 失踪者**：由至少两个互相矛盾的来源拼出，保持空白。
3. **关系破裂者**：其异议必须完整进入，不因玩家胜利被改写。

示例：

- 林秋在场时会删掉“受教育群众”，改成“印刷工人、夜学教员林秋”；若不在，她的工友完成修改。
- 石砧若伤残，会把“机器保全”旁添上事故日期；若牺牲，机器编号与饭盒姓名互证。
- 田青会要求土地页单列妇女、雇农和外来户异议，不准只写“全村一致”。
- 方真若曾隐瞒损失，成功计划与公开检讨必须同页。
- 周行的战功与误伤不能拆到两本书里。
- 乌兰若带档回乡，中央长桌保留她决定不交出的空位，并写明空位属于谁。

## 4. 历代拼图

| 时代 | 来到长桌的碎片 | 与当代拼出的完整部分 |
|---|---|---|
| 春秋战国 | 裂钟、长平残名、无名录初页 | 国家争霸由谁承受 |
| 秦汉 | 双籍、服役误计、基层吏异议 | 统一制度怎样进入个人 |
| 魏晋南北朝 | 侨籍、渡江名单、两岸歌 | 迁徙者怎样被重新分类 |
| 隋唐 | 水图、边报、粮账、坊市曲 | 繁华与战争依靠何种供给 |
| 宋元 | 五栏新刻本、海图、工记 | 文明如何在覆亡中由普通人携带 |
| 晚清 | 条约执行册、船坞名册、译报 | 新世界冲击与局部改革的组织困境 |
| 近现代 | 工人、农民、士兵、学生和家属共同档 | 无名者怎样由被记录对象成为历史主体 |

任何一块碎片都不能单独给出终极答案。只有不同阶层、职业、地域和时代的材料互相校验时，“完整朝代变迁故事”才出现：

```text
秩序建立
→ 分类与征用
→ 繁荣与扩张
→ 代价被转嫁
→ 危机与迁徙
→ 普通人保存生活
→ 新组织经验产生
→ 人民开始共同决定和书写
```

## 5. 记录冲突

### 谁创造历史

> 旧书把功业归给君主名臣，地方志补上官绅，工册补上匠人，粮账补上农户，家书补上照护者，群众剧本又把“被帮助的人”改成行动者。不是前一本全错，而是每一次补写都改变了谁站在历史中央。

### 苏醒者是谁

> 裂钟记得持锤者，竹简记得抄写者，海图记得水手，机器记得工人，土地记得耕作者。苏醒者没有一条能贯穿其间的私人族谱，只有一种不断出现的共同经验：劳动、受难、抵抗、互助、记录与重新开始。

## 6. 终章入口正文

夜里，雨从未装好的窗吹进来。所有人同时去按住桌上的纸。

那一刻，苏醒者听见裂钟。

不，声音并不是钟。是桌脚被扶正，是纸页翻动，是许多人指出名字写错，是机器重新开工前的检查，是锄头落地，是有人说“这里还少一个人”。

他终于不再追问自己曾是哪位帝王、将军、名臣、先贤或无名英雄。

长桌另一端，一个孩子抬头问：

> “这本书叫什么？”

所有职业材料、人物分支和历代残页在此进入终章《无名者有名》。

## 7. 动态拼装

```text
固定过渡
→ 主职业回声
→ 在场者
→ 牺牲 / 失踪者
→ 关系破裂者异议
→ 历代碎片三至五组
→ 一组记录冲突
→ 终章入口
```

验收：

- 至少一个重大空白不被虚构补完；
- 至少一名与玩家决裂者保留完整异议；
- 至少五个时代、六种普通人身份参与拼图；
- “人民”必须表现为共同决定、劳动、纠错与承担，不是整齐口号；
- 终章仍需完成命名和开放式未来，过渡文不抢答最后一句。
