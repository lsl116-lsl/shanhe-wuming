## 1. 最终推断链

| 组合 | 推断 |
|---|---|
| M01 + M03 + M06 | 记忆属于处境不同、能互相争论的普通人 |
| M04 + M07 + M11 | 记录权从少数保管者转向当事人共同维护 |
| M05 + M09 + M10 | 历史变化由组织起来的劳动、战争与选择推动 |
| 全部 + 前六章碎片 | 苏醒者不是神、名人、家族或单一灵魂，而是无名者共同历史经验形成的回声 |

## 2. 终章前禁区

- 本章可以由玩家说出“我就在他们中间”“我不是一个私人前世”。
- 不弹出任何关于主角真名或身份的系统答案；本章只让不同社会位置的经验进入公开讨论。
- M12 不赋予主角超自然控制群众或读取所有人思想的能力。
