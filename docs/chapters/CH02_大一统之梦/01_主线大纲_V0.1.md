# 第二章《大一统之梦》主线大纲 V0.1

> 历史窗口：约前 218 年至前 180 年
>
> 人生范围：苏醒者从约十二岁到五十岁左右，完成一段秦末汉初人生
>
> 故事题名：《同书异命》

## 1. 本章一句话

一个在秦制户籍中长大的少年，因为一枚迟到的归役简看见制度的精确与错误；当秦亡汉兴，他花半生保护的不是某个王朝的册，而是让同一批人在旗号改变后仍能被辨认为具体的人。

## 2. 本世起点

前 218 年，宁里进行户、田、役核验。

苏醒者本世家庭包括：

- 母亲阿蓁：经营田地与陶器副业，公开主张“先把这一户保住”。
- 异母兄阿野：成年劳力，既渴望军功改变家境，又不愿成为家中唯一被征走的人。
- 童年故人绵：母亲来自旧六国流民，名字在明册与私录中不同。

第一章载体通过四种路由之一进入核验现场：

```text
ARCHIVE      县廷重抄旧简
DISTRIBUTED  家户拿残件作身份旁证
BELL_CACHE   郡库清点裂钟夹藏
SONG         乐人因旧曲人名被盘问
```

四条路由在本幕结束前汇入同一件事：绵的母亲是否能被写入宁里本户。

## 3. 八幕主线

## ACT01 同字异名

**时间**：约前 218 年。
**年龄**：约十二岁。
**地点**：宁里、县廷临时核验案。

### 主线事件

县廷要求核定本里户、田和未来役责。统一书写让来自不同旧国的文书可以比较，但旧简中的异体、旧地名和无法核验者也被标成“待删”。

绵的母亲在私录中有名，在官册中只有“附口”痕迹。若写入本户，阿蓁一家的赋役计算会改变；若不写，她可能失去领取种粮和合法居住的依据。

### 主要冲突

- 程墨坚持把可核验内容重抄清楚。
- 年轻书吏庚认为无法核验就不能让全里承担风险。
- 阿蓁愿意收留，但要求绵一家共同承担本户的役与粮。
- 绵不愿以“被施舍的人”进入别家名下。

### 关键选择

- 以第一章残件作旁证，接受其中错误也被写入。
- 由邻里共同作证，承担后续连带责任。
- 暂时隐藏绵母，先保阿蓁本户核准。
- 要求保留“未核”而非删除，让问题进入下一次复核。

### 幕末

一枚从外地寄来的归役简被放在案角。它证明宁里一名役夫早已完成役期，但官册因文书迟到仍把他写作“亡”。那人的家庭已经替他承担了数月缺额。

## ACT02 道路如绳

**时间**：前 216 年至前 212 年。
**年龄**：十四至十八岁。
**地点**：三川郡道路、邮亭、粮仓与工程役地。

### 主线事件

苏醒者随程墨和邮人乌辛追查迟到归役简。道路使公文快速流动，也把粮、役夫和处罚汇向同一方向。

玩家看到：

- 邮书经过多个节点，每个节点都有时间和责任。
- 归役简曾按时发出，却因一处道路征用和一次抄写错误迟到。
- 当事役夫已经回乡又被再次拘走。
- 官署宁愿把错误归为“役夫逃亡”，因为承认邮传失误会牵涉多名吏员。

### 主线冲突

纠正一人的状态，会重新计算过去数月的役额、粮额和惩罚：

- 立即更正，让替役邻户得到补偿，但多名书吏受罚。
- 只从今日更正，不追究过去，保住执行链但留下旧债。
- 把责任写成道路灾损，避免个人受罚，却掩盖可避免错误。
- 公开完整传递链，让制度能够纠错，也让乌辛和程墨失去位置。

### 幕末

阿野收到征发通知。归役简明明已经证明制度会错，阿野却说：“正因为会错，我得自己去，把回来的字亲眼带回来。”

## ACT03 一户两役

**时间**：前 211 年至前 209 年初。
**年龄**：十九至二十一岁。
**地点**：宁里、县廷、崤函道路周边。

### 主线事件

工程、戍役和地方生产同时缺人。阿野与另一户青年被编入不同役队，绵家因最初核验状态再次被要求补役。

苏醒者发现县廷存在两本都“正确”的簿册：

- 户曹按家庭登记。
- 司空相关簿册按实际役次登记。

抄写时序不同，使同一个人被计算两次。

### 主要冲突

庚要求先完成名额再复核；程墨要求停下整个征发链对册；阿蓁只想让其中一个孩子留下；阿野拒绝以绵家替自己补缺。

### 人生分流

玩家通过解决“一户两役”主动进入十种社会位置：

- 隐士：护送拒绝再入役簿者进入芒山。
- 仕官：进入县廷或郡属官署争取复核机制。
- 谋士：为地方主事者推演征发与民变风险。
- 武将：进入守卫道路和役队的军伍。
- 医者：判断伤病、劳损与役免。
- 乐人：随行旅传播役夫消息与家属寻人。
- 商贾：承接粮运、赎役和道路补给。
- 工匠：进入道路、量器、车辆和官营工程。
- 吏官：进入户曹、仓曹或役簿抄写。
- 农人：留在宁里承担劳力缺口、种粮和互保。

### 幕末

前 209 年的起事消息沿道路传来。最先到的不是口号，而是一个邮亭不再回信、一队役夫不再前行和一枚被折断的官印。

## ACT04 天下有声

**时间**：前 209 年至前 208 年。
**年龄**：约二十一至二十二岁。

### 主线事件

县廷要求各里按时完成粮役，路上却不断有人逃归、改投和传递起事消息。宁里第一次发现：一旦多数人不再相信命令能够兑现，制度越精确，缺额扩散得越快。

共同事件“折印之夜”：

- 一批役夫要求县廷销毁追索名册。
- 一批家属要求保留名册证明谁被征走。
- 庚要守住档案和粮仓。
- 乌辛带来上级命令，但封检已经破损，真伪难定。

### 玩家能改变

- 哪些追索字段被销毁。
- 哪些家庭凭据被分出。
- 粮仓由谁接管。
- 县廷人员能否安全离开。
- 起事者是否得到完整户籍与道路资料。

### 不可改变

秦末动荡继续扩大，地方旗号会变化。

### 幕末

县廷旗帜被换下。第二天，新的主事者仍然要求程墨拿出户册、仓册和道路图。

## ACT05 县廷夜火

**时间**：前 208 年至前 206 年。
**年龄**：二十二至二十四岁。

### 主线事件

宁里和周边县邑在不同势力间反复更换控制。每一方都需要粮、道路、壮丁和合法性，也都声称自己要终结前一套暴政。

一夜，县廷档案库起火。火源可能来自：

- 役夫为销毁追索册纵火。
- 庚为避免档案落入敌手下令焚毁。
- 商队失火。
- 玩家此前转移灯油或简册造成的意外。

火源根据前因确定，不在现场临时随机。

### 核心选择

玩家只能优先抢救一类：

- 户籍与田册：保护家户凭据，也保留征发工具。
- 役簿与归役简：保存错误责任链和未归者。
- 仓簿与道路图：帮助救济和运输，也服务下一支军队。
- 私录、家书与无名录抄页：保留人的声音，却缺少官方效力。

其他材料不会全部消失，由未选职业 NPC 根据关系尝试抢救，结果有成功、残损和失败。

### 幕末

秦朝灭亡。有人庆祝旧法结束，阿蓁却拿着烧焦的田册问：“明日谁来证明这块田不是谁先拿到就是谁的？”

## ACT06 楚汉之间

**时间**：前 206 年至前 202 年。
**年龄**：二十四至二十八岁。
**地点**：河洛道路、宁里、军队驻扎点与粮运节点。

### 主线事件

楚汉争夺让河洛交通圈反复承受驻军、征粮、道路控制和人口迁移。玩家的主职业拥有独立高潮，但共享一个问题：

> 当旧朝已经不存在，普通人曾经承担的役、债、军功和罪名还算不算？

阿野可能以不同旗号归来，也可能只留下家书。绵可能利用改名活下，也可能坚持恢复母亲身份。庚从“维护秦法”转为维护任何仍能运行的档案秩序，遭到旧同僚和起事者双方怀疑。

### 共同危机

一支军队准备征用宁里冬粮，另一方承诺数日后来保护；承诺无法同时相信。玩家只能控制自己所在的一环：

- 隐士控制山路和藏粮点。
- 仕官处理交涉、缓征和撤离。
- 谋士判断承诺与风险分配。
- 武将管理驻军和乡民冲突。
- 医者面对军民共用药粮。
- 乐人传播消息，也可能制造恐慌。
- 商贾组织运输和价格。
- 工匠修桥、拆桥和修车。
- 吏官记录征用、借粮还是掠夺。
- 农人决定交种、藏粮、逃离或共同守仓。

### 幕末

战争结束的消息到来时，宁里没有欢呼。众人先清点剩余种粮，再问谁将回来、谁欠谁、哪一个旗号写下的凭据还有效。

## ACT07 新朝旧籍

**时间**：前 202 年至前 190 年前后。
**年龄**：二十八至约四十岁。

### 主线事件

汉初重新建立地方秩序。新的核验案再次摆在宁里：

- 秦籍仍是最完整的户田依据。
- 秦末不同势力发出的凭据互相冲突。
- 军功、逃亡、归附、失踪和改名需要重新判定。
- 新朝缓和部分赋役，但基层仍需要确定谁属于哪一户。

玩家面对与 ACT01 相似却不相同的场景：当年被判断的少年，如今成为能够影响记录的人。

### 本章总选择

玩家必须确定“秦汉两籍”怎样建立：

1. 以秦籍为底，逐项补入战争变化。
2. 以当前活人为底，旧籍只作旁证。
3. 官册只写最低必要信息，私录保留争议。
4. 由里中共同核验，允许异议长期存在。

每种方案都有便利、风险和代价，不存在全知完美册。

### 人物回收

- 程墨与庚必须正面讨论：忠于制度是否等于忠于一个王朝。
- 阿蓁决定是否让本户再次接纳失籍者。
- 阿野的军功、逃亡或未归状态必须落入两籍。
- 绵决定恢复旧名、保留新名、并列二名或拒绝公开。
- 第一章载体完成本章第一次强制回收，不能继续只做神秘物件。

### 幕末

苏醒者发现秦籍和汉籍把自己写成同一个人，梦中却同时出现写册的吏、被写的农户、送册的邮人和被册追索的逃亡者。没有一个身份能解释全部熟悉感。

## ACT08 梦醒未安

**时间**：前 190 年至前 180 年前后。
**年龄**：约四十至五十岁。

### 主线事件

本世进入中晚年。宁里恢复生产，孩子不再认识秦时旧旗，却仍使用道路、县乡、名籍和尺度。新朝的“缓”是真实变化，制度继承也同样真实。

玩家整理本章交接包：

- 秦汉两籍。
- 迟到归役简。
- 戍卒家书。
- 主职业证据。
- 第一章载体的本章变形。
- 官档、私录和口述之间无法消除的冲突。

### 视角认识推进

玩家可确认：

```text
同一套编户制度在案前与案后呈现不同面貌。
互相排斥的社会位置可以同时提供真实经验。
熟悉感来自相似处境，而不是同一件祖传宝物或私人前世。
```

本章不解释苏醒机制，只完成对“统一等于安定”这一单一认识的第一次系统修正。

### 最终抉择

- 把两籍交地方官藏，换取最高公共效力。
- 分抄给家户，让记录离开单一权力中心。
- 将争议部分交给史家或抄手，承担被重新叙述。
- 让旧曲和口述携带无法合法入册的人。

### 尾声

暮年苏醒者听见道路远处传来同样整齐的木牍声。他第一次没有把声音当作裂钟。

他知道那是许多人同时在写、在被写、在争辩自己应当怎样被写。

## 4. 十职业共享与独有

| 职业 | 独立故事 | ACT06 专属高潮 | ACT07 不可替代材料 |
|---|---|---|---|
| 隐士 | 芒山藏籍者是否形成新的排外共同体 | 决定开放哪条山路与藏粮点 | 逃亡、假名、生还和山中埋葬 |
| 仕官 | 用有限权限建立可纠错的役籍 | 在两方军队间签下缓征与撤离责任 | 命令、驳回、执行时限 |
| 谋士 | 为地方选择旗号却看见所有选择都要征粮 | 写三份归附策并公开代价承担地 | 承诺、删改和实际结果 |
| 武将 | 从秦卒到改旗军伍，忠诚对象不断变化 | 保护军伍、乡民或粮道的冲突 | 改旗、军功、逃亡与同伍证言 |
| 医者 | 役伤、战争与疫病把身份差异带进救治 | 军民同营中的分诊和撤离 | 伤病、死亡时间和身份误写 |
| 乐人 | 被要求唱统一、起事和胜利的不同版本 | 在楚声与旧曲中藏入未归者姓名 | 口述、曲词和传播变形 |
| 商贾 | 统一尺度带来便利，战争让信用和钱失效 | 用最后一支车队选择粮的去向 | 关卡、债契、运输与价格 |
| 工匠 | 造量器、道路和车辆，也被要求毁掉它们 | 修桥、拆桥与保留标准工具 | 工记、尺度、车号和工程后果 |
| 吏官 | 一支笔跨过两朝，是否仍能对人负责 | 火中抢册并建立秦汉对照 | 两籍、划改、封检和责任链 |
| 农人 | 同一块田三次换凭据、两次被征粮 | 守种、守人、守田只能优先一项 | 小地名、田界、收成和家户口述 |

## 5. 历史结果与玩家能动性

不可改变：

- 秦末动荡、秦亡、楚汉战争和汉建立。
- 大规模战争结果。
- 基层文书和赋役不会因一名玩家彻底消失。

可以改变：

- 宁里多少人活过战争并保有身份。
- 迟到归役简的责任是否被追溯。
- 县廷夜火中哪些材料留下。
- 阿野、绵、程墨、庚等人的命运与证言。
- 同一户在秦籍、战争凭据和汉籍中的差异。
- 主职业证据怎样进入第三章。

## 6. 章节交接

本章固定交给第三章：

```text
historical_result: 秦亡汉兴，基层制度继承并调整
primary_carrier: 秦汉两籍 / 戍卒家书 / 职业材料 / 旧曲
institutional_legacy: 郡县、乡里、编户、邮驿、文书和尺度
memory_cue: 木牍碰合、封泥压印、道路车轴、旧曲转调
unanswered_question: 帝国崩裂后，谁有资格决定一个人属于哪里？
mandatory_callback: 洛阳将乱时的身份与迁徙核验
```

## 7. 验收

- [x] 一生覆盖秦末汉初而非整个两汉。
- [x] 统一同时表现组织能力和普通人承受极限。
- [x] 秦吏、起事者和汉初执行者都不被写成单一标签。
- [x] 十职业拥有独立故事与共同历史危机。
- [x] 秦亡不等于制度清零，汉兴不等于苦难自动结束。
- [x] 本章用编户者、被编户者与戍卒视角修正“统一等于安定”的单一理解。
