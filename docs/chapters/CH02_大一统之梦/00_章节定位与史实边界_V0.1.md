# 第二章《大一统之梦》章节定位与史实边界 V0.1

> 推荐主交互窗口：约前 218 年至前 180 年
>
> 主空间：三川郡洛阳周边、崤函道路、县乡聚落、楚汉战争影响下的河洛交通圈
>
> 章节责任：把第一章讨论的新法、编户、郡县和统一变成普通人的日常，再让玩家亲历秦亡汉兴中制度的延续、崩裂与调整。

## 1. 核心问题

```text
统一以后，人真的安定了吗？
同一种文字和律令，是否让所有人更有名字？
一个王朝崩溃后，支撑它的制度会不会继续活着？
```

## 2. 本世人生

苏醒者约在前 218 年以十二岁左右的少年身份醒于三川郡洛阳近郊虚构聚落“宁里”。本世家庭、童年和亲属关系真实存在；苏醒发生在一次户、田、役核验之日。

人生范围：

```text
少年：统一制度进入家庭
青年：道路、邮驿、赋役与县廷文书塑造社会位置
壮年：秦末动荡、县廷崩裂与楚汉争夺
中晚年：汉初重新编户、缓役与制度继承
暮年：决定秦汉两朝记录怎样进入后世
```

本章不覆盖整个两汉，也不让苏醒者活到魏晋。汉代数百年通过制度延续、档案重抄、家户传说、地点和载体损毁进入第三章。

## 3. 史实硬锚点

- 前 221 年秦完成统一，本章开场已经处于统一之后。
- 秦代郡县、县廷、乡里和基层文书是日常治理的重要结构。
- 户籍、赋税、徭役、邮驿、仓储、司法和工程会通过具体簿册运行。
- 秦末起事、秦亡与楚汉战争集中在同一代人可以亲历的时间内。
- 汉初不是把秦制全部推倒，而是在郡县、乡里和编户等结构上继承并调整。
- 汉初存在郡国并行等不同于秦的安排，本章只从普通人能接触的基层变化表现，不做制度百科。

## 4. 戏剧压缩与虚构

允许：

- 以虚构“宁里”和县廷人物凝聚三川郡普通家户经验。
- 将多次核验、邮传迟误、役期争议凝聚为“迟到的归役简”。
- 让秦末动荡以道路断裂、县廷改旗、粮仓争夺和军伍转换进入，而不是让玩家旁观所有著名战役。
- 让楚汉战争通过河洛交通、征粮、驻军与地方选择汇入。
- 用汉初重新登记同一批人，表现王朝更替后制度的延续和调整。

禁止：

- 把秦亡简单归因于某一个暴君或坏官。
- 让秦吏全部冷酷、反秦者全部正义。
- 让汉建立等于所有赋役、战争和地方矛盾立即消失。
- 让玩家成为陈胜、吴广、刘邦、项羽等真实人物的关键军师。
- 使用纸张作为基层主要书写载体。
- 让一卷秦简未经重抄和损毁直接完好进入魏晋。

## 5. 普通人的信息边界

苏醒者通过以下途径知道天下变化：

- 县廷公文、邮人和传递时限。
- 商旅的道路消息。
- 军伍、役夫和归乡者。
- 地方旗号、印记、度量、钱币和征发对象变化。
- 乐人和乡里的口述版本。

玩家不能同时掌握各方军政全貌。每条职业线必须保留自己的信息盲区。

## 6. 关键制度与物质媒介

本章使用：

```text
木牍、简册、笥牌、封检与印记
户籍、田册、役簿、仓簿、邮书和军册
道路、邮驿、粮车、关卡与通行文书
量器、权衡、半两钱与地方旧尺度残留
公田、民田、种粮、户赋与劳役
```

制度不能只做背景。每一项必须落实到：

- 谁书写。
- 谁核验。
- 谁执行。
- 谁等待。
- 谁承担错误。
- 错误如何留下或被抹去。

## 7. 统一的双重经验

本章必须同时展示：

### 组织能力

- 道路与邮驿让命令和消息跨地域传递。
- 统一书写和尺度降低部分交换与核验成本。
- 县廷、仓储和户籍能够调动粮、役与救济。
- 出身并非唯一身份来源，部分普通人能通过新秩序改变位置。

### 承受极限

- 同一套制度也能更精确地征粮、征人和追索逃亡。
- 邮书迟误和抄写错误会成为普通人的现实灾难。
- 地方执行者在完成名额时会把缺额转给具体家庭。
- 高度组织能力一旦失去信任，会让崩裂传播得同样迅速。

## 8. 秦末与楚汉表现边界

本章中心不是“选秦还是选楚汉英雄”，而是：

- 县廷档案是否保存、销毁或被各方利用。
- 粮仓和道路由谁控制。
- 被征者是否能回乡。
- 同一户在不同旗号下被怎样重新登记。
- 旧债、军功和罪名是否随王朝更替改变。

各方军队中都必须有：

- 相信秩序的人。
- 借乱牟利的人。
- 只想保住同伍与家庭的人。
- 被迫改变旗号的人。

## 9. 本章贯穿载体

| 载体 | 本章作用 | 合法后世形态 |
|---|---|---|
| 秦汉两籍 | 同一户在秦末和汉初的不同写法 | 重抄残件、家户旁证、地方旧档 |
| 迟到的归役简 | 邮驿、役期与错误责任链 | 抄件、故事、案例批注 |
| 北地戍卒家书 | 家庭等待与未归状态 | 家族旁证、误认祖先、残句 |
| 旧尺度与新量器 | 统一便利与征收能力 | 器物、刻记、标准遗产 |
| 亡国旧曲新变 | 从战国悼亡进入秦末民间之声 | 楚声、汉初民歌、互相冲突版本 |
| 无名录重抄页 | 第一章材料进入帝国书写 | 官档、私录、口述或缺页 |

## 11. 交给第三章

本章历史结果：

```text
秦亡，楚汉战争结束，汉初秩序建立。
基层郡县、乡里、编户与文书并未随秦完全消失，而是被继承和调整。
```

必须交出：

- 一份秦汉两籍或其损毁证明。
- 一封未归戍卒家书。
- 一项职业独有材料。
- 一名人物被误写成祖先、逃亡者或亡者的争议。
- 一段在不同共同体中含义不同的旧曲。
- 苏醒者“不属于单一家族谱系”的明确反证。

第三章固定开场压力：

> 洛阳将乱，一户人必须用旧籍证明自己属于哪里；同一份档案既能救人，也能把另一批人排除在城门之外。
