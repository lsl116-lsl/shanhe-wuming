# 第二章《大一统之梦》记忆碎片表 V0.1

> 上游文档：`../../00_项目总框架_V0.5.md`、`01_主线大纲_V0.1.md`、`04_因果节点表_V0.1.md`
>
> 本章认识任务：从写册、被写、送册和躲避册四个位置理解统一制度，不把记忆写成寻找私人前世的线索。

## 1. 本章记忆规则

第二章的记忆不再只是陌生梦境，而会与第一章载体发生熟悉感。但每次熟悉都必须产生反证：

- 同一种制度动作会在不同位置引发相反感受。
- 同一段旧曲同时带来互相冲突的社会位置。
- 裂钟或无名录不是私人传家信物。
- 记忆有时来自写册者，有时来自被写者、送册者和躲避册者。

本章记忆不能：

- 告知秦何时灭亡。
- 指出战争胜负。
- 提供现代制度方案。
- 直接说出“人民”。
- 证明某名历史人物是前世。

## 2. 揭示等级

| 等级 | 玩家可理解 |
|---|---|
| L0 | 只是身体错觉或梦 |
| L1 | 第一章载体确实触发异常熟悉 |
| L2 | 熟悉感与本世经历、物件所有权对不上 |
| L3 | 同一时刻出现互相排斥的普通人经验 |
| L4 | “没有单一位置能够解释制度全貌”成为可靠结论 |

本章上限为 L4，不解释苏醒机制，也不提供终极历史答案。

## 3. 共享碎片

| 字段 | 内容 |
|---|---|
| 首次触发 | ACT01 核验案开始 |
| 类型 | 情绪回声 |

| 字段 | 内容 |
|---|---|

## 4. 职业变体

| 职业 | MEM-007 火中首先看见 | MEM-013 落笔方式 |
|---|---|---|
| 隐士 | 抱走孩子和藏名者 | 在山壁、木片和口述间分散 |
| 仕官 | 抢命令与驳回 | 盖印、署名、承担迟到 |
| 谋士 | 抢未采用方案 | 原稿、删改稿并列 |
| 武将 | 抢同伍与归役册 | 点名、托物、家书 |
| 医者 | 抢伤簿和药 | 体貌、伤痕、死亡时间 |
| 乐人 | 抢曲谱和记名节拍 | 停顿、绰号、改词 |
| 商贾 | 抢债契、路图和关戳 | 车号、最后出现地点 |
| 工匠 | 拆梁救人或护器具 | 刻度、工记、修补痕 |
| 吏官 | 抢两套互相冲突的册 | 划改、留白、封检 |
| 农人 | 抢田册与种粮 | 井名、田界、实际耕作 |

职业变体只改变感知重点，不改变共享揭示结论。

## 5. 人物知情

| 人物 | 可能知道 | 反应 |
|---|---|---|
| 阿蓁 | 苏醒者偶尔提前知道一句旧话 | 先问是否影响吃睡，不神化 |
| 绵 | 知道玩家同时熟悉多个名字 | 要求玩家不要用异常替她决定身份 |
| 程墨 | 认为是看过旧档后遗忘 | 鼓励查证，不接受神谕 |
| 荇 | 发现玩家提前知道转调 | 认为曲调属于许多人，不属于前世 |
| 章女 | 记录发作时身体状态 | 排除部分疾病，但不宣布超自然 |
| 景休 | 可能利用异常提高判断 | 若玩家同意，会增加关系风险 |

最多三名人物知道较完整异常。公开神化会导致利用、盘问和误传，不产生崇拜奖励。

## 6. 错过与重复

- P1 碎片错过后在下一共享事件以较低信息量补偿。
- 同一碎片第二次触发只显示一个感官线索，不重播全文。
- 玩家主动压制记忆不会阻断主线，只会减少可用询问并增加误解。
- 记忆记录必须区分 `seen`、`understood`、`misread` 和 `confirmed`。

## 7. 交给第三章

第三章记忆任务不再继续证明“没有单一家族”，而是进一步推翻：

> 我只属于一个故乡和一种共同体。

第二章交出触发物：

- 秦汉两籍中的祖籍冲突。
- 北地家书与洛阳身份争议。
- 南北不同旧曲。
- 同一制度下写者、被写者、送者和逃者的共同回声。
