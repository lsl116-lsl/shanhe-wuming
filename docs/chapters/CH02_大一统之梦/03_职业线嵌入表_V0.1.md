# 第二章《大一统之梦》职业线嵌入表 V0.1

> 上游文档：`01_主线大纲_V0.1.md`、`02_人物关系表_V0.1.md`
>
> 原则：十职业共享秦制日常、秦末崩裂、县廷夜火、楚汉争夺和汉初两籍；ACT04—ACT06 各有独立主线。

## 1. 共享事件

| 幕 | 共享历史压力 | 所有路线必须回答 |
|---|---|---|
| ACT01 | 户、田、役核验 | 无法核验的人是否保留位置 |
| ACT02 | 迟到归役简 | 制度错误由谁负责 |
| ACT03 | 一户两役 | 主职业从何种行动中形成 |
| ACT04 | 折印之夜 | 追索档案与家庭凭据如何分开 |
| ACT05 | 县廷夜火 | 哪类材料优先抢救 |
| ACT06 | 楚汉争夺 | 旧债和新旗号如何处理 |
| ACT07 | 汉初重新登记 | 以旧籍、活人还是共同证言为底 |
| ACT08 | 两籍交接 | 记录怎样越过数百年而不变成神器 |

## 2. 路线结构

每条路线拥有：


## 3. 隐士线《芒山有名》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 在制度外建立庇护地，并面对共同体自身也会排外 |
| 欲望 | 让逃役、失籍与厌战者拥有暂时不被追问的地方 |
| 恐惧 | 一个人泄露山路，所有人都被追索 |
| 盲点 | 把封闭视作自由 |
| 关系核心 | 芒伯、绵 |
| 人类对手 | 庚；他坚持缺额不能凭空消失 |
| 制度压力 | 连带责任、粮食有限、道路清查 |

独立三次升级：

1. ACT04：藏下一名役夫，山下同伍被加役。
2. ACT05：夜火后大量人携不同旗号凭据上山，聚落决定谁算“自己人”。
3. ACT06：两方军队都要经过芒山，开放一条路必然危及另一处。

专属高潮：

> 玩家主持一次“无官印核验”：由求助者、山民和家属共同确认假名、保护期限与真实去向，并亲自拒绝无法承载的人。

不可逆代价：聚落曝光、山下邻户背债、后来者被拒或玩家被逐。

ACT07 贡献：山中生还、逃亡、埋葬和假名保护册。

结局：守山、下山作证、带人远迁、被聚落驱逐。

第三章痕迹：假名册被误当作家谱。

## 4. 仕官线《缓令不缓》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 进入县廷，用有限权限修正一套正在失去信任的制度 |
| 欲望 | 建立不靠私人恩情也能纠错的役籍程序 |
| 恐惧 | 离开职位后再无人愿意改 |
| 盲点 | 总认为下一次有更多权限 |
| 关系核心 | 景休、庚、程墨 |
| 人类对手 | 借缓令逃役的有力家户 |
| 制度压力 | 名额、时限、上级追责和旗号更替 |

独立升级：

1. ACT04：玩家签发第一份缓役令，却发现强户抢占名额。
2. ACT05：新主事者要求玩家用原官印继续调粮，合法性与救急分离。
3. ACT06：两方都要求宁里归附，玩家只能让一份撤离、缓征或开仓文书获得执行。

专属高潮：

> 玩家必须在公开署名下签出一份会救一批人、也让另一批人承担缺额的命令，并保存驳回与执行时间。

ACT07 贡献：缓令、驳回、执行链和地方改良条款。

结局：汉初属官、罢官乡老、被罪者、主动辞印者。

第三章痕迹：缓役旧例被后世当作地方特权来源。

## 5. 谋士线《三份归附策》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 在多方争夺中替地方选择，却无法把所有风险算清 |
| 欲望 | 让宁里不成为任何一方展示决心的牺牲品 |
| 恐惧 | 所有谨慎都被胜者解释为反复 |
| 盲点 | 把可预测性高估为可控制性 |
| 关系核心 | 景休、绵、柏舟 |
| 人类对手 | 一名主张尽早押注强者的同门 |
| 制度压力 | 情报迟误、承诺不对等、军粮现实 |

独立升级：

1. ACT04：判断上级命令真伪，任何结论都会暴露消息来源。
2. ACT05：火中只能救归附谈判、户籍或道路材料之一。
3. ACT06：写出三份面向不同势力的归附策，每份牺牲不同道路、粮仓或家户。

专属高潮：

> 公开三份策而非只交最终方案，让乡里知道每个选择由谁承担；公开会削弱谈判，却归还共同决定权。

ACT07 贡献：承诺原文、删改、实际执行与未采用方案。

结局：汉初谋议者、失势抄手、流亡门客、公开认责者。

第三章痕迹：后世只留下被采用方案，玩家必须为反事实旁证留路。

## 6. 武将线《旗换同伍》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 经历军伍改旗，决定忠诚究竟属于命令、同伍还是不持兵器的人 |
| 欲望 | 让每名同伍的归役与生死真正送回家 |
| 恐惧 | 昨日同伍明日成为敌人 |
| 盲点 | 只把熟悉同伍当作完整的人 |
| 关系核心 | 北生、阿野 |
| 人类对手 | 要求以乡民补军粮的军吏 |
| 制度压力 | 军功、连带处罚、改旗与报复 |

独立升级：

1. ACT04：守县廷时面对曾共同服役的起事者。
2. ACT05：档案库与粮仓同时遭袭，只能守一处。
3. ACT06：军伍换旗后被要求征用宁里冬粮，阿野可能站在队中或对面。

专属高潮：

> 玩家决定军伍是服从征粮、允许乡民撤粮、放弃军功离队，还是公开拒命；同伍会根据共同债分裂，而非全员服从玩家。

ACT07 贡献：改旗时间、同伍点名、军功与归乡状态。

结局：归乡守卒、汉军小吏、伤残者、受罪者、失踪者。

第三章痕迹：多名同名军卒被合并为英雄祖先。

## 7. 医者线《军民同簿》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 让身体证据穿过身份与旗号，同时承担隐私和辨认冲突 |
| 欲望 | 让每个死者有人知道其最后状态 |
| 恐惧 | 为保护活人改名，导致家属永远找不到 |
| 盲点 | 默认不公开就是保护 |
| 关系核心 | 章女、阿野、北生 |
| 人类对手 | 以伤病证明逃役的掮客 |
| 制度压力 | 药材、分诊、军民优先和疫病 |

独立升级：

1. ACT04：为起事者、秦卒和役夫同时看伤，任何顺序都暴露立场。
2. ACT05：火灾和冲突造成伤者，玩家要在救人和抢伤簿间分配时间。
3. ACT06：军民混营出现疫病，隔离会让一方失去撤离机会。

专属高潮：

> 建立不按旗号排序的伤簿，同时决定哪些真名封存、哪些体貌公开寻亲。

ACT07 贡献：病伤、死亡时间、身体特征和身份误写。

结局：乡医、军医、流动医者、失去行医能力的教徒者。

第三章痕迹：医方保留，病者姓名和原始隐私规则丢失。

## 8. 乐人线《秦声楚声》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 同一支旧曲被统一、禁唱、起事和胜利不断改词 |
| 欲望 | 让曲子保存普通人的真实而不害死唱歌的人 |
| 恐惧 | 传播越广，原意越少 |
| 盲点 | 相信暗语总会被正确理解 |
| 关系核心 | 荇、绵 |
| 人类对手 | 要求改词换取同行口粮的乐团领头 |
| 制度压力 | 演出许可、禁词、军心与口述失真 |

独立升级：

1. ACT04：旧曲被当作起事暗号，玩家必须证明或利用误认。
2. ACT05：夜火中乐人以歌词记住烧毁名单，顺序却开始错乱。
3. ACT06：不同军队分别要求唱秦、楚和胜利版本，同行生存依赖接受改词。

专属高潮：

> 在一场军民共同听见的演唱中，把未归者姓名藏进可由家属辨认的停顿和节拍，同时承担误认造成的后果。

ACT07 贡献：曲词版本、改词命令、绰号和口述寻人。

结局：民间传唱者、军中乐人、禁曲携带者、失声教唱者。

第三章痕迹：旧曲被南北不同群体各自认作祖传之歌。

## 9. 商贾线《同钱不同命》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 统一尺度和道路带来信用，战争又让钱、契和承诺同时失效 |
| 欲望 | 维持一条能持续运粮、送信和还债的商路 |
| 恐惧 | 只剩自己因乱世获利 |
| 盲点 | 把无法支付的人从需求中删去 |
| 关系核心 | 柏舟、阿蓁、乌辛 |
| 人类对手 | 以征用名义不付凭据的军需者 |
| 制度压力 | 关卡、货币、征用、信用和粮价 |

独立升级：

1. ACT04：道路断裂使旧债无法履行，玩家决定先还同行、农户还是官仓。
2. ACT05：夜火中柏舟先救债契，玩家决定是否与他分开抢救。
3. ACT06：最后一支车队只能维持商路、运冬粮、送撤离者或给军营。

专属高潮：

> 玩家必须决定是否兑现一张已经没有政权承认、却代表普通人交粮的旧凭据。

ACT07 贡献：债契、关戳、车号、价格和实际粮流。

结局：汉初行商、官运承办者、破产救援者、沿路寻名者。

第三章痕迹：债契被当作土地所有凭据，引发身份争议。

## 10. 工匠线《三次重刻》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 制造统一尺度、道路和车辆，也亲手面对它们被战争夺用 |
| 欲望 | 留下一把不因掌权者变化而欺骗人的尺 |
| 恐惧 | 技艺只让征收和行军更精确 |
| 盲点 | 把用途归给下令者 |
| 关系核心 | 石生、乌辛、柏舟 |
| 人类对手 | 逼迫工坊赶制军车的监工 |
| 制度压力 | 官营材料、同坊连坐、工程时限 |

独立升级：

1. ACT04：道路设施被起事者破坏，修复可恢复民用也恢复追兵速度。
2. ACT05：夜火蔓延，拆梁救档会毁掉县廷与周边住所。
3. ACT06：同一座桥必须在修、拆、限载和伪装承重之间选择。

专属高潮：

> 将秦尺第三次重刻为汉初校验尺，并保留前两层刻痕，证明标准既延续又改变。

ACT07 贡献：三次刻度、工坊名、桥车责任和器物去向。

结局：官营匠、乡间匠、伤残退匠、带尺流亡者。

第三章痕迹：木尺被神秘化；后章必须拆解神话，恢复工匠责任链。

## 11. 吏官线《一字两朝》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 亲手让同一批人在秦籍、乱世凭据和汉籍中变成不同身份 |
| 欲望 | 建立一套允许更正而不抹掉旧错的册 |
| 恐惧 | 新朝只要一份干净记录，所有划改再次消失 |
| 盲点 | 以为并列材料就能自动让人理解 |
| 关系核心 | 程墨、庚、绵 |
| 人类对手 | 要求清除旧朝痕迹的新主事者 |
| 制度压力 | 证据门槛、销毁、重抄和责任追溯 |

独立升级：

1. ACT04：决定追索字段、家庭凭据和官署责任分别保留多少。
2. ACT05：夜火中进入档案库，抢救顺序直接决定本章公共事实。
3. ACT06：不同势力要求用旧册征粮，玩家必须限制、改册或拒交。

专属高潮：

> ACT07 主持秦汉两籍对照，允许“未归”“争议”“双名”和证言来源存在，不把不确定性清洗掉。

ACT07 贡献：两籍、划改、封检、时序和抄手责任。

结局：汉吏、被罪改册者、私录守护者、离任教字者。

第三章痕迹：最完整，也最可能成为排斥流民的权威依据。

## 12. 农人线《三次授田》

| 字段 | 内容 |
|---|---|
| 路线承诺 | 一块田先由秦籍核定、再被战争争夺、最后由汉初重新确认 |
| 欲望 | 让田与家庭劳动真正建立稳定关系 |
| 恐惧 | 每次改旗都有人拿新凭据夺走收成 |
| 盲点 | 守住本里时排斥新来者 |
| 关系核心 | 阿蓁、绵、阿野 |
| 人类对手 | 持军功或新政权凭据来取田的归来者 |
| 制度压力 | 劳力、军粮、种粮、田册和互保 |

独立升级：

1. ACT04：起事消息使有人拒交粮，有人担心仓储断绝。
2. ACT05：田册残损后，实际耕作者与旧籍持有人冲突。
3. ACT06：冬粮、种粮和军粮只能优先保一类，阿蓁与绵立场分开。

专属高潮：

> ACT07 由实际耕作、邻里证言、旧籍与战争凭据共同核田，并决定是否给新流民留下公共田和种粮。

ACT07 贡献：小地名、田界、耕作年、实际收成和家户接纳史。

结局：稳定农户、失田迁徙者、公共田组织者、军功田争议者。

第三章痕迹：田册成为“谁是本地人”的证据，也成为排斥南渡或北来者的工具。

## 13. ACT05 夜火抢救矩阵

玩家只能亲自完成一项，其他项由 NPC 状态决定：

| 材料 | 主责职业 | NPC 兜底 | 损毁后仍可留下 |
|---|---|---|---|
| 户籍与田册 | 吏官、农人 | 程墨、阿蓁 | 陶底人数、田界口述 |
| 役簿与归役简 | 仕官、武将 | 庚、北生 | 家书、同伍证言 |
| 仓簿与道路图 | 商贾、工匠 | 柏舟、石生、乌辛 | 车号、井名、桥记 |
| 私录与无名录抄页 | 隐士、乐人 | 绵、荇、芒伯 | 曲词、假名、口述 |
| 伤簿 | 医者 | 章女 | 体貌、药袋结法 |
| 归附与承诺草案 | 谋士 | 景休 | 未采用方案片段 |

## 14. ACT07 汇流

十条路线不是回到同一段对白，而是共同生成秦汉两籍：

```text
隐士提供册外生还者
仕官提供合法纠错和执行链
谋士提供承诺与实际结果
武将提供军伍状态
医者提供身体和死亡证据
乐人提供口述与绰号
商贾提供道路和最后出现位置
工匠提供器物、桥车和刻记
吏官建立对照结构
农人提供田界、家户和实际生活
```

玩家主职业决定主证据；其余证据完整度由人物命运和夜火选择决定。
