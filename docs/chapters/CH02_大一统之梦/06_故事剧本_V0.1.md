# 第二章《大一统之梦》故事剧本 V0.1

> 剧本题名：《同书异命》
>
> 定位：分场可制作剧本。共享场建立同一人生，职业场形成十条独立故事，县廷夜火与秦汉两籍完成汇流。

## 2. 开场路由

### CH02-ACT01-SC001 核验日

```text
时间：前 218 年
地点：宁里临时核验案
人物：苏醒者、阿蓁、阿野、绵、程墨、庚
目标：日落前完成本户户、田、役核定
```

视觉开场：数十枚木牍按同一方向排在案上，只有一枚旧简的字向相反方向倾斜。

第一章载体路由：

| 路由 | 进入方式 | 当场缺陷 |
|---|---|---|
| ARCHIVE | 程墨在待重抄旧简中找到无名录残页 | 被官署标出无法核验者 |
| DISTRIBUTED | 绵母拿家户残简证明来处 | 私人保管，无合法封检 |
| BELL_CACHE | 郡库清点旧钟时发现夹藏 | 保存久但缺上下文 |
| SONG | 荇因歌词含旧名被带到核验案 | 传播广却已改词 |

四线共同冲突：绵母能否写入宁里。

选择：

1. **把残件作为旁证递上**
   - 证据效力上升。
   - 第一章残件进入官署视野并可能被扣留。
2. **请三户邻人共同作证**
   - 绵母获得位置。
   - 三户共同承担未来逃亡和赋役风险。
3. **先核准阿蓁本户，把绵母藏到复核后**
   - 家庭即时安全。
   - 绵的 `autonomy_respected` 降低。
4. **要求在册上保留“未核”**
   - 庚反对长期悬置。
   - 程墨愿意以自己笔迹担保下一次复核。

人物对白：

> 阿蓁：“添一个名字，锅里便要多一碗。可不添，她连领种的碗都没有。”
>
> 绵：“你们一直在说添不添。我的名字，像是你们桌上的一勺粮。”
>
> 庚：“今日为她留空，明日十户都说自己尚待核。最后替这些空白服役的是谁？”
>
> 程墨：“空白若写明为什么空，便不是没有规矩。”

### CH02-ACT01-SC002 案角的归役简

核验将结束时，乌辛送来一枚数月前发出的归役简。它证明宁里役夫“垣”已完成役期，官册却把他写成“亡”，邻户已经替他补役。

程墨想立即纠正；庚认为本轮核验已封，不得倒改；垣的妻子要求补回粮和劳力；替役户要求先赔自家。

玩家的第一个跨章核心选择：

- 先恢复垣的身份。
- 先补偿替役户。
- 先查迟误链，暂不改结果。
- 将三件事分开登记，拒绝用一个字结案。

## 3. 道路段

### CH02-ACT02-SC001 五亭一简

玩家随程墨、乌辛沿路追查。每一亭都能证明自己按当时所见完成职责，错误却确实发生：

```text
发出日期正确
→ 道路临时征作军用
→ 邮人改道
→ 封检受潮
→ 重抄把“归”误入“亡”栏
→ 县廷按亡者缺额补役
```

选择不再是找一个坏人，而是决定责任如何分配：

- 罚最后抄错者。
- 追到上级征道决定。
- 认定灾损，不罚个人。
- 建立双人核对和迟误标记，但承认过去补偿无法全部完成。

### CH02-ACT02-SC002 阿野带走自己的字

阿野收到役简。他把简贴身收好，坚持亲自带回归役证明。

> 阿野：“垣叔吃亏，是因为他的字走得比人慢。我把字带在身上，总能一起回来。”
>
> 乌辛：“人走的是腿，字走的是路。路若断了，你抱着它也一样回不来。”

玩家可帮阿野准备家书、请求同队、寻找缓役依据或尊重其决定。任何选择都不能取消本章战争压力。

## 4. 分流场

### CH02-ACT03-SC001 一个人被数了两次

户曹按家庭写阿野，役簿按役队又写一次。绵家因 ACT01 状态被要求补缺。

十种解决行动构成职业入口：

| 职业 | 当场行动 |
|---|---|
| 隐士 | 带被重复征发者避入芒山，承诺处理山下缺额 |
| 仕官 | 进入县廷申请停征并建立复核 |
| 谋士 | 向地方主事者证明继续强征将引发整里逃亡 |
| 武将 | 进入役队与守卒内部核对实际人数 |
| 医者 | 检查劳损、伤病和役免，承担诊断责任 |
| 乐人 | 沿路唱寻人段落，让家属知道役队去向 |
| 商贾 | 用车队名册、粮票和赎役关系重建实际人数 |
| 工匠 | 从工具、车号和工程领用反推谁已在役 |
| 吏官 | 对照户曹、役簿和邮书，保留改册痕迹 |
| 农人 | 组织五户共同计算真实劳力和来季缺口 |

玩家完成一项，主职业锁定。其他行动由 NPC 继续，但完整度取决于关系。

## 5. 十职业独立剧情

## ROUTE-01 隐士《芒山有名》

### R01-SC01 上山不问名

芒伯允许重复征发者“垣”上山，却要求他三年内不用真名。绵质问：为保护一个名字而不让本人使用它，究竟是不是保护。

玩家决定假名由谁取、何时可公开、家属是否知道。

### R01-SC02 山下缺额

垣上山后，替役户再次被征。玩家可下山代役、用山货补偿、与庚谈条件或让垣自己决定归否。

人物性格分叉：

- 经常替人决定的玩家会直接安排垣去留。
- 尊重自主的玩家必须接受垣可能选择回去。
- 习惯把风险转移的玩家会失去绵信任。

### R01-SC03 夜火后来者

县廷夜火后，带着不同旗号凭据的人涌入芒山。旧山民提出只收早先成员亲属，聚落开始制造自己的“本地人”。

### R01-SC04 山路两端

ACT06 两方军伍分别从山路两端接近。玩家只能：

- 开路给宁里撤离。
- 开路给军粮换取不搜山。
- 封路，让山下自行承担。
- 公开聚落，与一方谈判。

专属高潮：召开无官印核验，建立假名保护期限并接受有些人无法进入。

## ROUTE-02 仕官《缓令不缓》

### R02-SC01 第一份缓令

玩家以程墨证据取得短期缓役。三户强者马上伪造相似理由，庚要求撤销全部例外。

### R02-SC02 谁能复核

玩家设计复核程序：医者、邻证、役次或家庭劳力。每项都偏向某类人，无法完全公平。

### R02-SC03 旧印新令

秦末新主事者要求玩家用旧印继续调粮。拒绝会让粮仓无人合法开启，接受则等于替新权力借旧制信用。

### R02-SC04 三张只能活一张的文书

楚汉争夺时：

- 开仓令能救当下饥者。
- 缓征令能保来年劳力。
- 撤离令能救即将被驻军波及者。

只有一份能及时送达。玩家必须署名。

专属高潮：把未获执行的两份文书与驳回时间也保存，拒绝让失败救援消失。

## ROUTE-03 谋士《三份归附策》

### R03-SC01 假命令真后果

封检破损的上级命令要求加征。玩家判断它可能是真、伪或过时，但无论如何都要建议县廷行动。

### R03-SC02 夜火中的未采用方案

火中有户籍、道路图和玩家历次未采用方案。景休说未采用方案最无用，绵却说它们能证明人不是只有后来那一个选择。

### R03-SC03 谁会赢

玩家与景休推演三方力量。计算可能准确，但柏舟指出路和粮并不服从纸面。

### R03-SC04 把代价写在策上

玩家完成三份归附策：

```text
策甲：保城，牺牲山路和外里
策乙：开城，交粮并保户籍
策丙：撤散，失去合法凭据与田
```

可只交最可能成功的一份，或向里中公开全部。公开会削弱谈判，却让承担者参与选择。

## ROUTE-04 武将《旗换同伍》

### R04-SC01 守的是什么

折印之夜，北生守县廷。门外有曾共同服役的人，门内有档案、粮和家属。

### R04-SC02 守册还是守仓

夜火和冲突同时发生。守册能保身份，守仓能保生存。北生坚持军令守仓，阿野若在场则要求先救归役簿。

### R04-SC03 改旗

军伍在秦亡后被新的地方势力接收。换旗能保同伍供给，不换则解散回乡并可能被追罪。

### R04-SC04 冬粮命令

玩家随军回到宁里，却接到征用本里冬粮的命令。阿蓁在仓门内，北生和同伍在门外。

玩家选择服从、限量、放乡民撤粮、解散军伍或拒命。同伍会按共同债各自选择，不会作为玩家私兵。

## ROUTE-05 医者《军民同簿》

### R05-SC01 先看哪边

折印之夜，秦卒、起事役夫和被踩伤孩童同时被抬来。先救谁会被所有人解释成立场。

### R05-SC02 火里还有伤簿

章女在救一个仍有生机的人，玩家可以继续救人或抢回记录许多死者的伤簿。两人可能因此产生无法消除的裂痕。

### R05-SC03 名字会传病吗

军民混营出现疫病。公开病者姓名方便追踪接触，也会让家户被驱逐；隐藏则难以隔离。

### R05-SC04 既不是秦卒也不是楚卒

一名伤者穿错旗号衣物，没有文书。各方都拒绝接收。玩家通过旧伤、口音、同伍证言和身体状态辨认，却必须决定公开多少。

专属高潮：建立军民混合伤簿，真名封存、体貌公开、死亡时间可核。

## ROUTE-06 乐人《秦声楚声》

### R06-SC01 哪一句是旧曲

荇唱出第一章旧曲，但与苏醒者记忆不同。玩家若坚持“正确版本”，会暴露自己无法解释的熟悉感，也会压过荇的传承。

### R06-SC02 一首歌成了暗号

起事者以旧曲某句为暗号，官署开始盘问所有会唱者。实际暗号可能来自误听。

### R06-SC03 火中点名

档案烧毁后，荇让众人按节拍报出家人姓名。顺序越长，错误越多；停下又会让后来者永远没机会。

### R06-SC04 三方都要胜利歌

不同军队要求同一乐团改词。玩家可以表面接受，在停顿中藏未归者，也可以公开拒绝并使同行失去口粮。

专属高潮：在军民共同听见的曲中藏入寻人信息；一处停顿被误解后，玩家必须承担误认导致的风险。

## ROUTE-07 商贾《同钱不同命》

### R07-SC01 旧债到期

道路中断，阿蓁、同行和官仓三方债同时到期。柏舟主张先保同行信用，否则以后无人运粮。

### R07-SC02 火中先救契

柏舟固定先抢债契。玩家可与他一起、转抢户册、先救人或把契扔回火中。柏舟可能感激、决裂或承认自己害怕所有关系失去凭据。

### R07-SC03 没人认的粮票

一批农户持秦时交粮凭据，当前军队拒绝承认。兑现会让车队亏空，不兑现则普通人第二次被征。

### R07-SC04 最后一支车队

车队只能选择：

- 运宁里冬粮。
- 运军粮换取道路安全。
- 运伤者和撤离者。
- 留车保住下一次运输。

专属高潮：玩家决定兑现无政权承认的民间凭据，并在账上写清谁因此没有得到粮。

## ROUTE-08 工匠《三次重刻》

### R08-SC01 尺不骗人

石生发现地方旧量与秦量换算让一批人多交粮。修正能保护农户，也会让官仓账面出现短缺。

### R08-SC02 修路给谁走

道路被破坏。修复方便邮书、百姓和追兵；不修会让归役简和家信继续迟误。

### R08-SC03 拆梁救档

县廷夜火蔓延。拆建筑梁木能压出一条救档通道，却会让相邻屋舍倒塌。

### R08-SC04 一座桥四种人

同一座桥上将经过撤离百姓、军粮、伤者和追兵。玩家可修、拆、限载或伪装损坏。石生要求玩家不要只说“器物没有立场”。

专属高潮：汉初重新刻尺时保留秦刻与战乱修补痕，拒绝制造一把看似从未出错的新尺。

## ROUTE-09 吏官《一字两朝》

### R09-SC01 写亡还是写归

玩家亲手处理迟到归役简。改字能纠正垣身份，却使过去处罚失去依据。

### R09-SC02 折印后谁能查册

追索者、家属、起事者都要求看册。玩家决定按字段拆分访问，而不是整册交出或整册焚毁。

### R09-SC03 夜火抢册

玩家进入火场，只能亲自带出一类底稿。程墨和庚分别冲向归役简与公共户册，玩家可以救人、救册或改变他们的目标。

### R09-SC04 新朝要一份干净册

汉初主事者要求覆盖旧错，只保当前有效状态。玩家可以服从、保留划改、建立官私双册或公开争议栏。

专属高潮：主持秦汉对照核验，让“未归”“双名”“证言来源”和“待复核”合法存在。

## ROUTE-10 农人《三次授田》

### R10-SC01 多一个名字少多少粮

绵母入户后，家庭分粮和役额变化。玩家必须把“接纳”落实到谁少吃、谁多做，而不是只做道德选择。

### R10-SC02 交不交最后一季粮

起事消息到来，有人主张拒交，有人担心仓与道路从此停运。阿蓁要保种粮，绵要求给失籍者留份。

### R10-SC03 火后谁的田

田册残损，实际耕作者、旧籍人和持新军凭据者都来主张同一地块。玩家可用劳动年、邻证、旧册或抽签，不同规则伤害不同人。

### R10-SC04 守种、守人、守田

冬粮危机中只能优先：

- 藏种粮。
- 保住家人不被带走。
- 守住田界和凭据。
- 开仓给全里。

专属高潮：ACT07 共同核田，并决定是否设置给后来流民的公共田。

## 6. 共享县廷夜火

### CH02-ACT05-SC-FIRE 火从哪里来

火源由前因生成。玩家先看见的不是纵火者，而是不同人冲向不同材料：

```text
程墨 → 归役简和纠错底稿
庚   → 公共户册和封检
绵   → 失籍妇女与私录
柏舟 → 债契和道路凭据
章女 → 伤者与伤簿
石生 → 拆梁开路
荇   → 让众人开口点名
```

选择界面明确提示：玩家只能亲自完成一项，其他人不会原地等待。

火后不显示“抢救成功率”，而展示：

- 谁被救出。
- 哪类事实仍能证明。
- 哪类事实只剩口述。
- 谁认为玩家选择了纸而不是人，或选择了眼前而放弃后世。

## 7. 汉初两籍

### CH02-ACT07-SC001 又一次核验

场景构图与 ACT01 相同，但位置反转：少年时站在案前的苏醒者，如今坐在案边参与判断。

待核人物包括：

- 有秦籍、无战争后凭据者。
- 无秦籍、实际耕作多年者。
- 改旗归来的军卒。
- 被记死亡却活着的人。
- 使用两个名字的绵。
- 只有旧曲或家书作证的人。

玩家先选择两籍原则，再逐项处理三个代表案例。原则不能为每个朋友随意改，若要破例必须公开写出理由。

### CH02-ACT07-SC002 阿野回来了吗

按状态生成：

| 状态 | 场景 |
|---|---|
| 生还有证 | 阿野本人要求不要只按军功写他 |
| 生还无证 | 庚要求按逃亡处理，北生作证 |
| 改旗归来 | 同伍托付和新旗号凭据冲突 |
| 失踪有信 | 家书证明意图，不证明最终去向 |
| 官册写亡 | 阿蓁要求保留“未归”，拒绝用死亡结束等待 |

这里不存在一键团圆。玩家决定的是官册如何承认不确定性，以及家庭能否继续生活。

### CH02-ACT07-SC003 绵写自己的名

绵获得亲手写下或口述自己名字的机会。

她可以根据 `autonomy_respected`：

- 恢复母亲旧名。
- 继续本世使用的新名。
- 两名并列并注明使用场合。
- 拒绝在公共册写旧名，只留封存私录。

玩家只能提供风险说明，不能替她点击选项。

## 8. 晚年

### CH02-ACT08-SC001 程墨与庚

两人围绕“忠于制度是否等于忠于秦”最后争论。

> 程墨：“我守的是有人能回来改这一笔。”
>
> 庚：“若人人都能回来改，册便永远封不了。”
>
> 程墨：“人还活着，为什么非要封？”

庚不会被一句话说服。他会根据夜火和汉初核验结果，选择继续任吏、离开、守旧档或承认自己曾烧过什么。

### CH02-ACT08-SC002 你记得的不是一个姓氏

苏醒者并列查看：

- 自己完整存在的秦籍与汉籍。
- 与自己无血缘的第一章残件。
- 阿野家书。
- 绵两个名字。
- 主职业证据。

记忆同时出现写册、送册、被写和逃册者。玩家可解释为疾病、神异、许多人的回声或暂不解释；无论选择如何，单一家族祖先说被证据关闭。

### CH02-ACT08-SC003 交接

玩家选择秦汉两籍、家书、职业材料和旧曲如何分散。系统不得允许全部进入同一安全官库。

结算展示：

```text
你在两朝中分别被怎样写
谁亲手决定了自己的名字
谁替你的命令或隐瞒承担代价
哪一份记录保存最完整
哪一份记录最容易被普通人接触
哪一件东西开始失去上下文
```
