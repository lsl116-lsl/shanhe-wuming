## 4. 夜火组合规则

### 4.1 火源

| 前置状态 | 合法火源 |
|---|---|
| `records_used_for_pursuit = high` | 役夫或失籍者主动纵火 |
| `GENG_archive_denial = high` | 庚下令焚毁以防军队夺档 |
| `merchant_oil_relocated = true` | 运输事故引发意外 |
| `battle_at_county = true` | 冲突波及档案库 |

运行时只能确定一项主火源，可保留一项次要助燃原因。不得为了戏剧方便随机甩锅给无名暴民。

### 4.2 抢救

```text
player_primary_save = 1 类
primary_route_npc_save = 1 类
high_trust_core_npc_save = 最多 1 类
其余 = DAMAGED 或 LOST_WITH_TRACE
```

即使三类材料被救，也必须各有缺损；不得获得全套完美档案。

## 5. 真相与四种记录

以“阿野是否逃亡”为例：

| 层 | 可能内容 |
|---|---|
| `truth_state` | 改旗后护送同伍离开，未在限期归营 |
| `player_knowledge` | 取决于家书、北生证言和道路记录 |
| `official_record` | 逃、亡、军功归、未归或无记录 |
| `private_record` | 家书说明动机，但可能未送达 |
| `oral_version` | 英雄归来、畏罪潜逃、死于路上等互斥说法 |
| `cost_bearer` | 阿蓁本户、替役邻户、同伍或被征粮家户 |

玩家不能通过一次调查获得全知真相，只能提高某些版本可信度。

## 6. 载体损毁

### 秦汉两籍

- 允许：重抄、缺页、并入地方旧档、拆作家户旁证、被后人补注。
- 禁止：从前 180 年原封不动保存到 307 年。

### 戍卒家书

- 允许：残句、重抄、与他人家书装订、寄信人与送信人混淆。
- 禁止：凭一封信证明完整家谱。

### 木尺

- 允许：刻度磨损、重新标记、只留工记或器物图。
- 禁止：成为记忆法器或精确复原全部故事。

### 旧曲

- 允许：南北版本、改词、换调、只保留停顿结构。
- 禁止：存在不受传播影响的唯一正确原版。
