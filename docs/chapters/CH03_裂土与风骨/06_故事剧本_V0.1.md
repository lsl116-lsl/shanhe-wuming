# 第三章《裂土与风骨》故事剧本 V0.1

> 剧本题名：《两岸旧乡》
>
> 核心戏剧：一份能让本家出城的旧籍，也会把没有旧籍的人留在城门内。

## 1. 共享场

### CH03-ACT01-SC001 箱笼

范家院中，所有人把东西放进箱笼又取出。范肃只允许携带谱、印、药、钱和贵重衣物；范蘅把工匠工具、种子和阿缃母亲的药塞进去。

玩家每放入一件，就必须取出另一件。选择揭示玩家重视：

```text
身份效力
眼前生存
具体关系
后世证据
```

### CH03-ACT01-SC002 两家一封信

范家与另一流民家都认半封戍卒家书为祖先所寄。沈简发现信背面是替另一人转述。

> 范肃：“能对上洛阳二字，便有七分。”
>
> 阿缃：“剩下三分若是别人的一生呢？”

玩家可用信争资格、公开争议、并列两家说法或暂不使用。

### CH03-ACT02-SC001 名单里没有一起吃饭的人

出城名单按谱整理，家中实际共同生活的工匠、仆役、附籍者被排除。范蘅偷改名单；范肃发现后要求玩家恢复。

没有“全带走”选项。玩家必须分队、留后或共担一项额外风险。

### CH03-ACT03-SC001 船位

陶苇只剩三船。每种排序都合理：

- 先付船价者。
- 先有家户担保者。
- 先伤弱者。
- 先能守下一处渡口者。

玩家主职业从解决船位的具体行动中形成。未获船位者不会统一死亡，他们进入留北、另路、失散或制度外庇护状态。

### CH03-ACT04-SC001 第一块借地

北来者在蒲浦借地。江稼挖出旧村祖坟边界，阿缃指出真正能耕的人都还站在田里。

顾苇提出三年共耕；范肃要求在契上写明范氏借领；玩家决定谁署名、谁承担水利役和三年后如何复核。

### CH03-ACT05-SC001 不在这里的郡

官署案上出现以北方旧地命名的侨籍。阿缃问：“那地方若已经回不去，名字放在这里，是替我们留门，还是不许我们住下？”

玩家建立名册规则，直接影响教育、役、粮和婚姻，而非只改称谓。

### CH03-ACT06-SC001 门第之门

一名实际修堤多年的无谱青年申请进入学舍，被范肃拒绝；一名谱系清楚却从未下地的子弟获准。

玩家不能废除门阀，只能决定公共学舍名额由谱、劳动、考试式考核或共同推荐如何组合。每种规则都会被某方掌握。

## 2. 职业独立场

### 隐士《坞壁之外》

1. 玄谷收留无船者，却要求交真名封存；阿缃认为这仍是另一种控制。
2. 坞壁成员拒绝继续接纳后来者，玩家决定临时身份是否能转为共同成员。
3. 决堤时高地只能再容一队人，玩家公开规则并亲自面对被拒者。

专属对白：

> 玄谷：“门不关，里头的人活不久。”
>
> 玩家可回应的不是赞成反对，而是：“谁有权决定什么时候开？”

### 仕官《侨郡无土》

1. 陆衡要求玩家用旧郡名组织粮役。
2. 侨人免役让蒲浦负担增加，顾苇拒绝再开仓。
3. 灾时三份调令只能执行一份；玩家署名并保存其余两份的迟到。

### 谋士《两家一盟》

1. 范肃与顾苇达成协议，却没有阿缃、江稼和船户位置。
2. 玩家补入小户后，大族威胁退出。
3. 决堤预警公开会造成抢船；压下会让低地无准备。玩家必须把风险分区说清。

### 武将《守渡之后》

1. 穆延要求护队军伍先上船，理由是他们将保护下一批。
2. 定居后军伍替侨户收债，保护变成地方权力。
3. 灾中军伍在守仓、护民、堵口间分裂，玩家不能强制所有人。

### 医者《南北同疫》

1. 迁徙营出现热病，无籍者被指为病源。
2. 弥娘要求同井同诊，旧村担心药粮耗尽。
3. 水灾后玩家公开体貌寻亲，同时封存会导致驱逐的疾病和身份信息。

### 乐人《两岸同曲》

1. 荻生收集到三版旧曲，每一版都删掉别人熟悉的名字。
2. 门阀宴席要求“正本”，民间版本只能在门外唱。
3. 灾中按口音、绰号和旋律寻人，一次误认让两家争同一名失散者。

### 商贾《一船之价》

1. 陶苇按重量和成本排船位，范肃要包船。
2. 北来者推高粮价，柏舟旧信用与蒲浦怨恨冲突。
3. 灾中免费征船会救当下并毁掉后续渡运；玩家公开拒载名单和成本。

### 工匠《堤下有名》

1. 北来大屋与公共堤争木料。
2. 乔砧的泄洪方案必须淹一片田。
3. 决堤时玩家选择拆大屋、仓、贫户屋或放弃一段堤，并将材料来源刻进工图。

### 吏官《籍贯何处》

1. 沈简在“已过”“未过”之外增加“附入”和“拒绝登记”。
2. 侨籍要求填写旧郡，阿缃拒绝借范氏郡望。
3. 灾中侨籍与土籍互不相通，玩家建立跨册共同簿但无法让两方都承认其权威。

### 农人《借地生根》

1. 江稼与阿缃共耕，收获后争土地和劳动归属。
2. 北来里争水，旧村以祖坟和水口为据。
3. 决堤时必须放弃一片田泄洪；玩家决定牺牲谁的收成、如何补偿和公共田是否接纳后来者。

## 3. 决堤共同场

### CH03-ACT07-SC001 雨声盖过点名

预警时机由因果决定。雨中十条行动链同时运作，玩家只控制主职业：

```text
预警 → 船粮 → 高地 → 堤料 → 守护 → 分诊 → 跨册寻人
```

NPC 根据关系独立行动：

- 顾苇固定开公共仓。
- 乔砧固定提出拆范家大屋。
- 范肃固定先保护谱与家户箱。
- 范蘅固定带人去低地接无籍者。
- 穆延若在南方则带军户守一段堤；若留北，以断信进入。

### CH03-ACT07-SC002 泥里的名字

灾后名册沾泥，谱牒、侨籍和土籍各自只认一部分人。玩家组织共同点名。

一个人可以同时被写成：

```text
北来侨户
蒲浦共耕者
无谱学徒
军户家属
灾中失踪
```

共同簿不覆盖旧册，而是把关系并列。

## 4. 晚年场

### CH03-ACT08-SC001 留北者不是空位

穆延的最后一封信或北地口述到达。他没有请求南方替他证明忠诚，只要求不要把留北者都写成死人。

若信失去，孤碑只刻已确认名字，另留空位写“仍有人未得回信”。

### CH03-ACT08-SC002 两处都是家

苏醒者在北地断信与蒲浦水名间同时产生故乡感。

> 阿缃：“非得只能有一处吗？”
>
> 范肃：“有两处，便总有人说你不够忠于其中一处。”
>
> 顾苇：“那是他们的难处，不是土地的。”

玩家决定交接材料，不决定哪个故乡更真。

## 5. 结算

```text
谁在江南仍被称作外来者
谁的劳动改变了归属
谁替留北者写了错误结局
哪两种记录仍然冲突
```
