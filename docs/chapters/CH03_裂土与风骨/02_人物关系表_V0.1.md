## 4. 关键关系

- 范蘅与范肃：都要家族活下去，一个按共同生活，一个按谱系。
- 阿缃与沈简：她需要他写，但拒绝让他替她定义；高信任也不能取消自主。
- 顾苇与陆衡：一个要求先看劳动，一个需要可执行分类；两人既合作又防备。
- 穆延与南渡者：他选择留北送信，南方不断把他的沉默误写成死亡或背叛。
- 江稼与阿缃：从争地到共耕，关系可成为伙伴、竞争者、亲密关系或彻底决裂。
