# 第三章《裂土与风骨》章节定位与史实边界 V0.1

> 推荐主交互窗口：约 307—347 年
>
> 主空间：洛阳及河洛道路、淮河与长江渡口、建康外围虚构侨置聚落“北来里”及相邻江南旧村“蒲浦”
>
> 章节责任：让大一统从理所当然变成失去后的经验；把“风骨”从名士专属词还给迁徙、留守、劳动、记录与共同承担的普通人。

## 1. 核心问题

```text
帝国裂开以后，人靠什么维持尊严与共同生活？
故乡是土地、名册、语言，还是仍愿意接纳你的人？
保存家族名字与保存无名者，是否必然冲突？
```

## 2. 史实硬锚点

- 西晋末年长期内乱削弱秩序，311 年洛阳陷落成为永嘉之乱的关键节点。
- 西晋灭亡后，317 年司马睿在建康建立东晋。
- 北人南迁并非只有士族，迁徙者包含不同社会层级。
- 东晋南朝侨州郡县、侨流人口和侨旧关系是理解制度与社会的重要线索。
- 侨置既用于安置、招诱、军事和正统叙事，也会制造名实、赋役和地方利益冲突。
- 门阀和郡望具有现实权力，但普通人的迁徙与劳动不能被“衣冠南渡”四字吞没。

## 3. 戏剧边界

允许：

- 用虚构家户和聚落表现洛阳崩裂、南渡、侨置与侨旧矛盾。
- 让苏醒者随家户与邻里共同迁徙，而非独自游历名士圈。
- 让一部分人物留北，通过断信、商路和口述形成另一半故事。
- 将数次地方核籍、征役和水患压缩为“北来里定籍与决堤之年”。

禁止：

- 把所有北方政权和族群写成同质“胡人入侵者”。
- 把江南居民写成等待北方文明输入的空白背景。
- 把南迁写成士族专属的优雅旅行。
- 把门阀人物全部写成腐朽反派或清谈名士。
- 使用成熟科举、纸币、雕版印刷等后世制度。
- 让一份秦汉旧籍直接决定四百年后的真相。

## 4. 时代内身份

本章人物可能同时拥有：

```text
本世居住地
家族声称的郡望
官籍记录
侨置州郡县归属
乡里实际接纳
军伍或坞壁关系
口音与生活习惯
```

这些身份可以冲突。游戏不得把“籍贯”做成一个永远准确的字符串。

## 5. 贯穿载体

| 载体 | 本章作用 | 下一章形态 |
|---|---|---|
| 洛阳旧籍匣 | 争取出城和南渡资格，也排斥无籍者 | 谱牒摘抄、侨籍旧例、误写郡望 |
| 半封戍卒家书 | 两个家族争认祖先 | 北地孤碑、家书残句 |
| 渡江名簿 | 记录谁过江、谁留北、谁失散 | 隋唐户籍与家族迁徙传说 |
| 侨置名册 | 旧地名在新土地上的制度存在 | 后世郡望、门第与地方身份 |
| 北地孤碑 | 留守者和失去回信的人 | 边塞地名与唐代重发现 |
| 两岸旧曲 | 南北各自改写 | 长安宫廷、民间和边塞版本 |
| 无名录抄页 | 与族谱并列，不按门第排序 | 唐代工役、军籍和救济记录 |

## 7. 交给第四章

历史结果：

```text
北方与南方长期分立，迁徙者与当地人形成新的合作、冲突和共同生活。
侨置、郡望、谱牒和流民经验成为后世重新统一时的制度与文化遗产。
```

必须交出：

- 渡江名簿或其北地对应册。
- 一份侨置名册与地方旧村记录的冲突。
- 北地孤碑、断信或留北见证。
- 两岸旧曲。
- 主职业独有材料。
- 苏醒者同时把北地与江南视为故乡的反证。
