## 3. 决堤组合

```text
预警可信度 = 谋士证据 + 工匠勘验 + 官署公开
可用船位 = 商贾路线 + 船户关系 - 抢船恐慌
高地容量 = 隐士准备 + 农人粮储
救援秩序 = 仕官调度 + 武将执行 + 医者分诊
寻人完整度 = 吏官共同簿 + 乐人口述
```

任一高值不能弥补所有低值。系统强制至少发生：

- 一处堤段失守。
- 一批人失散。
- 一项财产或田地牺牲。
- 一次侨旧互相依赖。
