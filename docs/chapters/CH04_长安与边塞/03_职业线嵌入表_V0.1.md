## 2. 路线升级

| 职业 | ACT04 第一次代价 | ACT05 独立升级 | ACT07 高潮 | 不可逆代价 |
|---|---|---|---|---|
| 隐士 | 庇护逃役者牵连城外聚落 | 庇护点被登记征用 | 开门接曾参与抢掠者或拒绝 | 粮尽、暴露、后来者死亡 |
| 仕官 | 为无凭役夫补凭据导致强户仿冒 | 庆典征调与坊户生计冲突 | 三令只执行一份并署名 | 另一坊失救、失官或迟令 |
| 谋士 | 边报删人后获得采用 | 是否公开不确定兵变消息 | 公布删节链和自己责任 | 恐慌、消息源死亡或迟误 |
| 武将 | 边军军粮优先挤压乡里 | 守驿路还是护商民 | 军令、百姓撤离、同伍取舍 | 同伍决裂、受罪或平民伤亡 |
| 医者 | 军中征药使市井缺药 | 饥病、疫病、战伤排序 | 城病公开分诊 | 一类人等待过久 |
| 乐人 | 入宫改词换同行生计 | 边曲被署给名家 | 三版并唱并公开伴奏者 | 禁演、失声、真名暴露 |
| 商贾 | 高价维持路网使贫户无粮 | 边报影响粮价和囤积 | 最后一队车的去向 | 破产、断路、被指资敌 |
| 工匠 | 修渠也提高城市征调能力 | 军械和水具争料 | 拆宫料、坊屋或军械修水 | 同坊受罚或一处失守 |
| 吏官 | 补凭使记录更易征役 | 边报、工役和失踪册冲突 | 拒绝把未归结案 | 抚恤延误或真名连累 |
| 农人 | 交粮换凭据导致种粮不足 | 庆典和军需加征 | 守种、交粮、护家、接流民 | 失田、饥荒或排外 |

## 3. 安史危机汇流

```text
谋士判断消息
→ 仕官决定公开和调度
→ 吏官形成名单
→ 商贾、农人提供粮路
→ 工匠维持水与交通
→ 武将守护或执行
→ 医者处理身体后果
→ 乐人和隐士完成寻人、庇护
```

NPC 不因未选路线停止：

- 云岫开一次门。
- 裴照签未批准撤离令。
- 明夷承认压下一封消息。
- 阿史那朔寄回边地信。
- 杜若建立分诊。
- 伽蓝保留原词。
- 安诺让最后一队车不按最高价走。
- 苏砧提出拆宫料。
- 元清私存失踪册。
- 田穗留种并组织一次共种。

## 4. 结局

每条路线至少有：

```text
守住专业但失去关系
为具体的人破坏职业位置
保留位置并公开责任
离开职业却传下证据
失踪或死亡但由 NPC 完成交接
```

宋元章必须回收路线证据所改变的城市、商业、印刷、战争或文化现实。
