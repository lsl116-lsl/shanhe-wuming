## 3. 失信边报链

```text
边地原信
→ 驿站摘要
→ 谋议删节
→ 官署判断
→ 市场传闻
→ 家户行动
```

每层独立记录 `received_at`、`changed_by`、`reason`。不能把全部迟误归给最后一名送信人。

## 4. 安史危机最小损失

无论路线多优：

- 至少一名核心人物失散、死亡或永久离开长安。
- 至少一项主载体部分损毁。
- 至少一项命令迟到。
- 灯再亮时，受益者与战前不同。
