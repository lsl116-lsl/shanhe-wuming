# 第四章《长安与边塞》章节定位与史实边界 V0.1

> 推荐主交互窗口：约 730—763 年
>
> 主空间：长安城及外围水工、东市西市、驿路、漕运节点与西北边地通信线
>
> 章节责任：让玩家真切爱上盛世的开放、工艺、乐舞和城市生活，再看见灯火依赖的粮、路、兵、役与边地承担。

## 1. 核心问题

```text
盛世是否真的覆盖了边地白骨？
中心的繁荣由谁运输、守卫和承担？
诗歌、乐舞与记录能否在灾难中保护具体的人？
```

## 2. 史实边界

- 唐长安是大型国际都会，具有宫城、皇城、外郭城、里坊与东、西市等城市空间。
- 丝绸之路带来人员、货物、宗教、乐舞和工艺交流，人物不能被简化为“异域装饰”。
- 天宝十四载（755）安史之乱爆发，长安失守与战乱成为盛唐转折。
- 763 年吐蕃一度进入长安，本章尾声可表现战后秩序仍不稳定。
- 安史之乱持续至 763 年，但本章不要求苏醒者亲历全部战场。

## 3. 禁止

- 不把盛唐写成只有宫廷、诗人和美食的主题乐园。
- 不把边地人物写成纯粹蛮族、敌人或英勇背景板。
- 不让玩家替代真实名将、诗人和政治决策者。
- 不让所有胡商、乐人、使者共享一种身份和性格。
- 不用一场灾难证明此前繁荣全部虚假；繁荣与代价必须同时真实。
- 不把安史之乱简化为一人野心或宫廷爱情后果。

## 4. 贯穿载体

| 载体 | 本章作用 | 宋元章形态 |
|---|---|---|
| 长安水图 | 城市灯火与供水、工役 | 宋代城市水工重绘本 |
| 丝路账簿 | 货物、语言、债与风险 | 海陆商账与行会旧例 |
| 驿路失信 | 边报、家书与命令迟误 | 宋元交通与军报案例 |
| 边塞诗稿 | 署名作品与无名同行者 | 刻印残页、误署名 |
| 旧曲三版 | 宫廷、民间、边塞 | 词曲、杂剧与地方唱本 |
| 工役救援簿 | 城市修建与战时撤离 | 宋代赈济、工役和坊巷记录 |
| 安史残旗 | 具体军伍经历 | 不作神器，只留织法、补缀和口述 |
