# 第四章《长安与边塞》主线大纲 V0.1

> 故事题名：《灯火的来路》
>
> 人生范围：苏醒者约十三岁随水工家庭入长安，经历城市成长、边地输血、安史之乱与战后余生。

## 1. 本章一句话

一个以修水渠进入长安的少年，花半生让城市灯火更亮；直到战乱切断粮路，他才看见自己熟悉的每盏灯后都有运粮者、守路者、边军、工匠和未被写进诗里的同行者。

## 2. 八幕

## ACT01 城门灯火

**时间**：约 730 年。

苏醒者在水工木料车上醒来，本世父亲乔成负责修渠，母亲荻娘在驿舍缝补。城门核验要求工役凭据，无凭役夫可能被算作临时劳力而失去工钱。

旧曲在城门响起，宫廷收曲者、边地军卒和搬木哑工都熟悉同一停顿。

玩家第一选择：

- 先用家户凭据入城保工期。
- 帮无凭役夫证明前段工程。
- 追查旧曲来源。
- 留城外修水车，整队共同延误。

## ACT02 灯从何来

**时间**：731—737 年。

少年在长安成长。玩家通过一场“灯市断水”认识城市链条：

```text
水工清渠
→ 农户和漕运供粮
→ 商旅运货
→ 坊市管理
→ 乐人演出
→ 军卒守门与驿路
```

灯市恢复后，诗与乐赞美长安，乔成却因夜修伤腿。谁被看见、谁被记工成为第一次矛盾。

## ACT03 十种长安

**时间**：738—741 年。

一批来自边地的军需、家书和商队同时抵达。玩家通过具体工作选择社会位置：

- 隐士：长安外庇护流民与退役者。
- 仕官：管理坊市、水役或赈济。
- 谋士：整理边报、粮路与政策利害。
- 武将：城防、驿护或边军。
- 医者：市井、驿路与军中救治。
- 乐人：市井百戏、宫廷征调与边曲。
- 商贾：东西市、丝路与漕粮。
- 工匠：水渠、宫城、车辆和军械。
- 吏官：户籍、工役、关市与军报。
- 农人：关中田、漕粮与军户家庭。

## ACT04 边报到城

**时间**：742—747 年。

盛世生活达到高点。旧曲被宫廷收录，丝路账簿记录多地货物，水图扩展城市供给。

边地人物阿史那朔寄来家书，写军粮迟到、军户负担和当地多族群共同生活。长安宴席只取其中“异域风物”段落。

玩家主职业面对第一次独立代价：自己的工作越成功，越可能提高中心从边地提取资源的效率。

## ACT05 盛世有价

**时间**：748—754 年。

长安一项大型庆典和水工改造需要额外粮、木、马、乐人与役。各职业独立故事升级。

核心共享事件“失信的驿路”：

一封关于粮道与军伍不满的边报在传递中被延误、删节或压下。玩家只能接触主职业能看见的一段。

同时，边塞诗稿在长安获赞，却删去同行军卒、译者、车夫和当地向导。

## ACT06 风从范阳

**时间**：755 年前后。

起兵消息到来，起初被不同人解释为谣言、局部兵变或政治斗争。玩家不能预知结局，只能根据粮路、驿信、军伍和市场变化行动。

共同抉择：

- 是否公开不确定消息。
- 是否提前疏散家户与流民。
- 是否保护水图、粮册、军报或人。
- 是否相信仍会按期兑现的中央命令。

## ACT07 长安失火

**时间**：756—763 年。

长安失守、逃难、回返与再度动荡通过一段持续数年的共同危机表现。

十职业在不同位置：

- 城外庇护。
- 官署撤离与赈济。
- 情报和承诺。
- 守城、护民与军令。
- 伤营与疫病。
- 寻人曲与政治改词。
- 粮、车、债与抢市。
- 水渠、桥门与工役。
- 失踪册、军报和责任链。
- 粮田、逃难和重种。

历史结果不变；玩家改变一组具体人的生还、失散、记录与战后位置。

## ACT08 灯再亮时

**时间**：763 年及其后短尾声。

城市重新点灯，但不是原样恢复：

- 部分坊巷空了。
- 边地仍承担后续战争。
- 有功军伍、外援、商人和地方力量改变城市权力。
- 旧曲被写成胜利歌、悼亡曲或寻人歌。

玩家整理水图、丝路账、边塞诗稿、驿路责任、工役救援簿和主职业材料。

身份谜题推进：

```text
苏醒者记得长安灯火中的欣喜。
也记得边地运粮、守路和等信的身体经验。
他不是只站在盛世中心或英雄位置的人。
```

## 3. 十职业独立故事

| 职业 | 题名 | 专属高潮 | 不可逆代价 | 宋元章入口 |
|---|---|---|---|---|
| 隐士 | 《城外无坊》 | 决定庇护地是否开放给曾参与抢掠者 | 粮尽、暴露或拒绝后来者 | 寺观、义庄与流民口述 |
| 仕官 | 《一坊之令》 | 在撤离、开仓、守水三令中署名一份 | 失官、迟令或牺牲另一坊 | 城市治理旧例 |
| 谋士 | 《失信的边报》 | 公布删节链与不确定性 | 恐慌、消息源暴露或迟误 | 军报与政策稿 |
| 武将 | 《守城不守名》 | 军令、百姓撤离、同伍三者取舍 | 同伍决裂、受罪或平民伤亡 | 军籍和残旗 |
| 医者 | 《城病》 | 在疫病、战伤、饥饿间建立公开分诊 | 某一类等待过久 | 伤簿与医方 |
| 乐人 | 《旧曲入宫》 | 将宫廷、边地、寻人三版并唱 | 禁演、失声或真名暴露 | 词曲和民间唱本 |
| 商贾 | 《西市闭门》 | 最后一队车给军、民、同行或未来商路 | 破产、断粮或被指资敌 | 行会账与海陆商路 |
| 工匠 | 《渠断之后》 | 拆宫料、坊屋或军械修水与桥 | 同坊受罚或一处失守 | 水图和工记 |
| 吏官 | 《没有结案的失踪册》 | 保留未归、改旗与异议，不做干净结案 | 家属无抚恤或真名连累 | 城市档案与赈济簿 |
| 农人 | 《灯下之粮》 | 守种、交粮、护家与接流民取舍 | 失田、饥荒或排外 | 漕粮、田契与乡里互助 |
