# 第四章《长安与边塞》故事剧本 V0.1

> 剧本题名：《灯火的来路》

## 1. 共享关键场

### CH04-ACT01-SC001 城门外的停顿

水工车队因石七无凭被拦。城内乐人试唱“江南古曲”，边卒阿史那朔说边地早有此调。

玩家必须在工期、石七工资、旧曲证言和全队共同延误间行动。没有抽象“公平”选项。

### CH04-ACT02-SC001 灯市断水

庆灯将开，暗渠堵塞。乔成、石七和苏醒者下渠；地面上裴照催工，伽蓝等水开演，田穗送来的粮车也堵在坊门。

乔成伤腿后，官簿只写“水工三十人”。玩家可补具体工日、争工钱、先救父亲或先开主闸。

### CH04-ACT04-SC001 被剪短的边信

阿史那朔的信写军粮、同伍和当地家庭，送入宴席前只剩“异域风物”。明夷承认删节能让上层愿意读完。

> 阿史那朔：“你们爱听边地的风，不爱听风里谁在饿。”

玩家决定全文、摘要、私传或让信件进入乐曲。

### CH04-ACT05-SC001 盛典征调

庆典需要水、灯、粮、木、马和乐人。十职业都因工作成功得到机会，也因此扩大征调：

- 水渠越好，庆典越大。
- 商路越稳，临时加运越容易。
- 乐曲越受欢迎，同行越难拒绝征调。
- 户籍越准确，役夫越难逃避。

玩家必须决定在哪一环设置上限，并承担“破坏盛事”的名声。

### CH04-ACT05-SC002 驿铃没有响

一封边报没有按时进入决策。每名角色只掌握一段：

```text
阿史那朔知道前线
安诺知道粮价和马价
明夷知道删节
元清知道收文日期
裴照知道为何压下
荻娘知道等信者
```

玩家主职业决定能拼到哪部分，不能全知。

### CH04-ACT06-SC001 风声

起兵消息传来，市场先变价、驿站先停信、军伍先调动。玩家选择公开什么、准备什么，也决定谁会指责其造谣或迟钝。

## 2. 职业独立故事场

| 职业 | 场景一 | 场景二 | 战乱高潮 |
|---|---|---|---|
| 隐士 | 云岫收无凭役夫 | 庇护点拒绝后来的退卒 | 开门接纳曾抢粮者，或让一批人无处可去 |
| 仕官 | 裴照补工役凭据 | 盛典调度伤害坊户 | 撤离、开仓、守水三令只送成一份 |
| 谋士 | 明夷删边报换采用 | 判断风声是否公开 | 公布原稿、删节、压下时间和自身责任 |
| 武将 | 阿史那朔争军粮与乡粮 | 守驿还是护民 | 军令、同伍、城门百姓只能优先两项 |
| 医者 | 杜若处理工伤与军伤 | 城中饥病被当成谣言 | 建立城病分诊，一类患者必然久候 |
| 乐人 | 伽蓝让旧曲入宫 | 同行姓名被名家署名覆盖 | 宫廷、边地、寻人三版同唱，承担禁演 |
| 商贾 | 安诺维持高价路网 | 囤积与备战界线模糊 | 最后一队车给军、民、同行或未来路线 |
| 工匠 | 乔成、苏砧争水图署名 | 庆典和军需争料 | 拆宫料、坊屋或军械修公共水路 |
| 吏官 | 元清补无凭工日 | 被要求把未归结亡 | 私存未结册，影响抚恤和改旗者安全 |
| 农人 | 田穗交粮换城市凭据 | 军粮和种粮争夺 | 守种、交粮、护家、接难民四选二 |

每个高潮后，关系核心人物会根据玩家长期性格反应：

- 总替别人决定者得到短期服从、长期决裂。
- 总把代价转移者在战乱时失去互助。
- 总公开责任者可能失去职位，却获得证言。
- 总保留不确定者会延误部分救助，也避免错误结案。

## 3. 长安失守组合场

### CH04-ACT07-SC001 坊门鼓乱

坊门鼓不再按常例。裴照的撤离令未获批准，元清仍在抄名单，荻娘用衣物暗记寻人。

玩家主职业先完成专属任务，随后只能再帮一人：

```text
乔成 / 石七：公共水路
荻娘：衣物寻人
裴照 / 元清：撤离与失踪册
伽蓝：寻人曲
田穗 / 安诺：粮与车
杜若：伤营
云岫：城外庇护
```

未帮助者不会全部死亡，由此前信任、资源和 NPC 固定行动决定。

### CH04-ACT07-SC002 灯灭

长安灯火熄灭时，苏醒者听见边地篝火、漕船夜灯和田间守粮火同时出现。

玩家第一次清楚知道：自己怀念这座城，也不能把这座城当作全部山河。

### CH04-ACT08-SC001 灯再亮

战后第一批灯点亮。有人回城，有人拒绝回来，有人因军功、商路或地方力量获得新位置。

石七若活着，要求工役簿补名；若死亡，结绳工日由乔成或苏砧解释。伽蓝拒绝只唱胜利版，田穗要求开灯前先核种粮。

玩家整理交接包，结算不问“是否守住盛唐”，而问：

```text
你让哪一盏灯先亮
谁替它送来水、粮、油和安全
谁没有等到灯再亮
谁的名字只剩在诗外
```

## 4. 演出重点

- 盛世段必须可爱、可游、可建立关系，不能只为后续摧毁。
- 战乱段复用同一场景的断水、空市、破坊版本，形成生活被改变的痛感。
- 不用大规模战斗动画替代人物选择。
- 关键插画：城门灯火、暗渠开闸、边信被剪、坊门鼓乱、灯再亮。
