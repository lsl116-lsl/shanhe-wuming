# 第四章至第五章衔接过渡文 V0.1

> 衔接章节：CH04《长安与边塞》→ CH05《文治与铁骑》
>
> 过渡跨度：约 763 年至 1234 年

## 1. 固定晚年：《灯不是自己亮的》

灯再亮以后，长安人很快学会把黑暗称作过去。

你却记得水渠里谁伤过腿，最后一队粮车去了哪里，哪一封边报到得太迟，哪几个人直到重建名册封卷仍只写“未归”。

伽蓝的曲又被改过。宫中版本更整齐，边地版本更长，荻娘和城外家属唱的版本总在姓名处停顿。没有一版能把整座城带回来。

你把水图、丝路账和失踪册放在一起。

图上画水，账上写货，册上写人。三样东西其实都在回答同一件事：

> 什么从远处来到这里，又是谁没有回来？

暮年你再看灯火，不再只看它亮不亮。

你看它的来路。

| 职业 | 余波 | 宋元回收 |
|---|---|---|
| 隐士 | 庇护点被寺观、乡里或豪族接管 | 义庄与流民救济 |
| 仕官 | 三令中成功者被颂，迟令被删 | 城市赈济制度与责任 |
| 谋士 | 边报删节链成为军政旧案 | 宋元军报和议论 |
| 武将 | 军籍与残旗分离，战功覆盖护民细节 | 守城、降附和军民关系 |
| 医者 | 医方流传，城病排序亏欠失去 | 战乱医案 |
| 乐人 | 三版曲进入词、曲、民间演出 | 亡国曲与杂剧 |
| 商贾 | 丝路账法转入河运、海运与行会 | 海陆商贸 |
| 工匠 | 水图重绘，工日姓名先失 | 宋代城市水工 |
| 吏官 | 未归被后人补成死亡数字 | 赈济、军籍和刻印档案 |
| 农人 | 种粮与漕粮账分离 | 商品粮、地契和乡里互助 |

## 3. 时间桥：《纸变多了》

长安之后，城市仍兴衰，道路仍改向。

水图被重绘，旧渠名换成新坊名。丝路账中的一些路线断了，另一些向河流和海面延伸。边塞诗被一遍遍抄写，诗人名字越来越清楚，同行者越来越模糊。

纸变多了。

文字更容易复制，错误也更容易复制。旧曲被写进唱本，失踪册的格式进入新的官簿，丝路账法被商人带进河港和海船。

数百年后，一座江南城市比旧日长安更密地铺开店铺、桥、河道、刻坊和行会。人们能买到书，能从远方订货，能用纸面凭据跨过更长的距离。

北方压力却没有因文字、商业和工艺繁荣而消失。

## 4. 第五章苏醒：《刻坊失火》

约 1234 年，一座与临安、河港和海路相连的江南城市。

你在刻坊的烟里醒来。

本世的记忆立刻回来：你是坊主收养的学徒，认得每块版木的纹理，欠着三年学资，也答应替一名船工把家书印成十份。

火势不大，真正的争执在院里。

案上有三样必须先搬走的东西：

- 一张重绘多次的旧水图。
- 一本记录海陆货物和失踪脚夫的商账。
- 一叠正在印的边塞诗，其中署名清楚，夹页却写着一串无名同行者。

坊主说先救版木，那是全坊生计。

船工说先救商账，否则一船人的债和去向都没有凭据。

一名唱曲女子抱着旧谱，说那段曲在她家已经传了几代，不该再被刻坊写成某位名家的独作。

第五章第一个选择：

- 救能继续生产的版木。
- 救水图和公共工程资料。
- 救商账与普通运输者记录。
- 救诗稿夹页和旧曲异本。

选择不会毁掉其余全部材料；其他人物会行动，关系和前章完整度决定他们能救多少。

## 5. 路由缺陷

| 主载体 | 宋元形态 | 缺陷 |
|---|---|---|
| 水图 | 多次重绘刻本 | 工匠姓名失、旧地名错位 |
| 丝路账 | 行会 / 海陆商账 | 货物完整、人名简化 |
| 边塞诗稿 | 刻印诗集夹页 | 署名强化、同行者易被删 |
| 旧曲 | 词曲与唱本 | 被名家化、宫廷化 |
| 失踪册 | 赈济与军籍格式 | 未归被补成定论 |
| 职业材料 | 行会、坊巷、军民旧例 | 原始语境改变 |
