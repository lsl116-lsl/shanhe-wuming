# 终章《无名者有名》章节定位与表达边界 V0.1

> 时间：1949 年新时代门槛后的象征性短时段
> 空间：一处由工人、农民、士兵、学生、医护、家属和基层记录者共同修缮的公共屋舍
> 章节责任：回收苏醒者身份、历代无名录与全部职业材料；把历史继续书写的权利交给人民。

## 1. 终章不是

- 不是第八次完整人生，也不再开十条互斥职业路线。
- 不是让历代人物超自然复活聚会。
- 不是把前七章复杂经验压缩成一段全知旁白。
- 不是宣布新时代从此没有矛盾、错误、牺牲和未完成工作。
- 不是让苏醒者成为人民之上的集合神、救世主或唯一代言人。

## 2. 终章要完成

```text
私人寻名 → 共同历史回声
替无名者记录 → 人民自己书写
王朝循环 → 历史主体发生根本变化
一本定本 → 可纠错、可续写的公共档案
结局封口 → 新生活与新建设开始
```

## 3. 核心表达

“无名者有名，名字是人民”不是说具体姓名不重要，恰恰相反：

- “人民”必须由一个个可区别、可争论、可纠错的具体人构成；
- 共同主体不能取消个人生命、亲属关系、地方经验和内部差异；
- 历史主体变化，体现在劳动者开始参与决定、组织、监督、记录和建设；
- 苏醒者的共同记忆只能在这些实践中存在，离开活着的人便不具有独立意志。
