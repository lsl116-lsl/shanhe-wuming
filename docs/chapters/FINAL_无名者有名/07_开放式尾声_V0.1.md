# 终章《无名者有名》开放式尾声 V0.1

## 1. 最终旁白

这片山河曾被许多名字命名。

国号写在最上面，年号刻得最深，胜者的碑立得最高。可让道路通向远方的，是脚；让田地等到下一季的，是手；让伤者活下、让消息抵达、让错字被改、让机器重新转动的，也从来不只有碑上的人。

他们曾被写作户、丁、卒、役、流民、匠、佃户、工数、伤亡若干。

他们也曾互不相识、互相误解，甚至站在彼此对面。人民不是天生整齐的一个词。人民是在共同劳动里看见彼此，在共同受难中不肯遗忘，在抵抗与互助中建立联系，在一次次错误后学会共同决定和纠正。

所以，无名不是没有名字。

每一个具体的名字都应被看见；每一个尚未找到的名字都应留下位置；每一个活着的人都应有权写下自己，也有权指出历史把自己写错。

无名者有名。

我们的名字，是人民。

## 2. 结尾画面

镜头不升到俯瞰天下，而停在桌面。

一只年幼的手在新页写：

```text
今日晴。
屋顶还漏一处。
机器下午再试。
东村来三个人补名字。
田里的水要重新商量。
这页若有错，请后来者改。
```

纸页下压着七个时代的残片。风吹起纸角，露出最早无名录上的一个空格。孩子没有替它编名字，只在旁边写：

> “还在找。”

## 3. 存档后的开放接口

通关存档保留：

- 所有未解姓名与材料缺口；
- 玩家造成的不可逆伤害；
- 与玩家关系破裂者的异议；
- 十职业组织经验和失败；
- 公共书的访问、纠错与保护规则；
- “后来者续页”空位。

二周目不是简单回到过去修出完美线，而是让玩家从另一职业和另一组人物关系看见：上一轮认为完整的历史，本来就只覆盖了一部分。

## 4. 制作落点

片尾名单应模仿公共书结构：

```text
创作与制作
历史顾问与资料来源
配音与表演
程序、美术、音乐与测试
提出异议和纠错的人
尚待改正
```

真实开发中的劳动也不应被少数主创名字覆盖。最终按钮不是“结束”，而是：

> **合上这一册，留下续页。**
