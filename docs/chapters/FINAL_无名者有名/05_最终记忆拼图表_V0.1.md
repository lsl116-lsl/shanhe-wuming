## 2. 最终碎片

### FINAL-M01《没有中心》

触发：七章材料第一次同时铺开。

画面：记忆不再按一个人的视线剪辑，而按动作接力——刻、抄、搬、种、救、唱、修、争论。玩家找不到中心机位。

结论：共同记忆不是一个灵魂经历了所有时代。

### FINAL-M02《被纠正》

触发：在场人物改掉玩家写的一句话。

画面：历代被记录者都回头指出不同的错，不说同一句台词。

结论：苏醒者不拥有全知权；被纠正正是他存在的方式。

### FINAL-M03《名字》

触发：孩子询问书名。

画面：具体姓名快速出现，不融合、不消失；它们之间形成道路、田、水、工场、学校、医院和共同桌面。

结论：“人民”保留具体姓名，而不是吞没姓名。

### FINAL-M04《醒来》

触发：众人共同命名后。

画面：历章所有“醒来”镜头反转。不是苏醒者睁眼看见时代，而是时代中的人已经在行动，苏醒者由这些行动被唤起。

结论：

> 不是他穿过历史寻找人民，是人民在历史中一次次让这份共同记忆醒来。

## 3. 身份排除表

| 候选 | 排除证据 |
|---|---|
| 神灵 / 超自然裁判 | 无法改变固定历史结果，记忆依赖具体材料与行动 |
| 帝王 / 名臣 / 圣贤 | 记忆大量来自不识字者、妇女、工人、农民、士兵和互相敌对者 |
| 单一家族祖先 | 地域、族群、身份与血缘互相矛盾 |
| 不死私人灵魂 | 同一事件存在同时发生的多视角身体经验 |
| 历史数据库 | 记忆有错、有情感、有遗漏，会受保存与权力影响 |
| 人民之上的代言人 | 他必须被当事人纠正，不能替任何人最终发言 |

## 4. 最终答案的语义

系统不弹出“身份：人民”。答案通过三步完成：

1. 玩家承认“我不止是一个私人前世”；
2. 在场者承认这些分散经验可在共同实践中连接；
3. 众人以“我们的名字”而非“你的名字”完成命名。

这样既保留苏醒者作为叙事体验入口，也不把人民私有化为主角的超能力。
