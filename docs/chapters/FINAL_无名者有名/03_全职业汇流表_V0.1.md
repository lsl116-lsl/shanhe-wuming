## 1. 汇流玩法

每次修复一份历代材料，需要三种职业动作：

```text
保存 / 识别
解释 / 质疑
交还 / 使用
```

示例：修复宋元疫船簿。

- 医者判断症状与隐私；
- 吏官核对姓名变化；
- 乐人用口述找回船民自称；
- 商贾账确认航次；
- 隐士决定哪些后人信息暂不公开；
- 最终由相关家庭决定展示方式。

主职业只能让其中一项更快，不能跳过其他视角。

## 2. 汇流完成条件

- 至少六职业参与，才可形成“可用档”；
- 十职业齐全不是完美奖杯，若无当事人授权仍判为权力集中；
- 任一职业材料都要标注“它不能证明什么”；
- 终章最高评价是多职业互相限制，而非单职业数值满格。
