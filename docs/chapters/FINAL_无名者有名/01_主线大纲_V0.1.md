# 终章《无名者有名》主线大纲 V0.1

> 终章题名：《这里还少一个人》
> 推荐时长：60—90 分钟
> 形态：汇流、调查、共同编辑、关系回收与开放式尾声。

## 1. 一句话

苏醒者在一张由普通人共同维护的长桌前，试图为历代无名者写出最终定本，却被活着的人一次次纠正；当他放下替所有人命名的笔，才明白自己不是被遗忘的某一个人，而是千千万万无名者共同留下的历史回声——这个名字，是人民。

## 2. 六幕

## ACT01 雨中的长桌

公共屋舍尚未修好，雨水打湿第七章交来的材料。玩家不能亲自救全部载体，必须把任务分给在场人物。分工结果取决于前章关系：

- 信任高者会提出不同方案；
- 被玩家压制过的人拒绝听命，改救自己认为重要的材料；
- 失踪者由同伴接替；
- 未选择职业仍以 NPC 的成果进入。

## ACT02 七次误认

玩家按时代整理材料，每一章触发一次身份误认与反证：

1. 礼崩之世：不是贵族遗民，是战场、乡里和抄录者共同记忆；
2. 大一统之梦：不是统一帝王，是被登记与执行制度的人；
3. 裂土与风骨：不是门阀名士，是迁徙者、两岸劳动者与基层分类经验；
4. 长安与边塞：不是盛世名人，是供给、边防、工匠与坊民；
5. 文治与铁骑：不是文明精英，是刻工、船工、佃户、军民与新旧身份；
6. 旧梦与海潮：不是开眼英雄，是港口、工场、乡村和家属共同受难与学习；
7. 山河重铸：不是替人民发言者，而是组织起来的人民自己。

## ACT03 谁写最后一页

玩家起草定本，系统根据前七章倾向生成一种危险版本：

- 英雄中心；
- 官册中心；
- 技术中心；
- 苦难中心；
- 单一职业中心；
- “所有人都一样”的抽象人民版本。

在场人物逐条反驳。玩家可以防守旧写法，也可开放编辑权。正确终章不要求玩家无错，而要求他允许别人改变自己的文本。

## ACT04 十职业同桌

十职业不再互斥：

- 隐士负责保护未宜公开者；
- 仕官提供公共程序与监督；
- 谋士说明决定与反对意见；
- 武将交还军民与纪律记录；
- 医者保护身体、隐私与照护者；
- 乐人让记录能被共同讲述；
- 商贾写清资源、所有权和债；
- 工匠保存劳动过程、失败和维护；
- 吏官构建索引、异议和版本；
- 农人确保土地、粮食与生活尺度不被遗漏。

它们共同形成档案，但没有一个职业取得总解释权。

## ACT05 身份揭示

裂钟声再次响起，玩家可从七个答案中排除：

```text
神灵
帝王
名臣
单一家族祖先
不死的私人灵魂
历史之外的观察者
人民之上的代言人
```

剩余答案：

> 苏醒者是千千万万无名者在劳动、受难、抵抗、互助、记录和建设中留下的共同历史回声。

孩子问书名。若玩家仍输入私人名，书会保留，但他看见下一页无法由一人续写；若玩家选择开放命名，众人共同提出“无名者有名”。

最后一句由多人而非系统神谕说出：

> “无名者有名。我们的名字，是人民。”

## ACT06 晨光与空页

屋舍外，新生活正在开始：

- 工人检查机器而非盲目开机；
- 农民讨论土地、水和下一季；
- 公共人员接受第一次申诉；
- 医者建立可进入的诊疗点；
- 学生抄书，也纠正书；
- 士兵帮忙修屋，军纪页向公众开放；
- 艺人排新戏，观众能改词；
- 孩子在空页写下当日天气。

镜头不把未来写完。最后一页只有：

```text
日期：
记录者：
本人补充：
他人异议：
尚待完成：
```

## 3. 结局层

| 层 | 条件 | 表达 |
|---|---|---|
| 基础完成 | 七章主线通过 | 识别共同历史回声，公共书成立 |
| 多声完成 | 异议、低好感者和至少六职业材料被保留 | 玩家接受不由自己控制的历史 |
| 具体完成 | 普通姓名、劳动、家属和错误链完整度高 | “人民”不抽象 |
| 开放完成 | 不伪造空白、不写唯一终本 | 新时代作为继续建设的开端 |
| 反思结局 | 玩家坚持私人名 / 唯一定本 | 不判失败，展示下一代重新打开异议栏 |

## 4. 不设完美结局

最高完成度也必须保留：

- 至少一个无法确认的姓名；
- 至少一段互相冲突的证言；
- 至少一项玩家造成且无法撤销的伤害；
- 至少一个新时代仍需解决的具体问题；
- 一页由未来的人书写的空白。
