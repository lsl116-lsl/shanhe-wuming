# 终章《无名者有名》人物关系与历代回声表 V0.1

## 1. 在场人物槽位

终章不固定所有人存活，按状态填入角色槽：

| 槽位 | 选择规则 | 戏剧责任 |
|---|---|---|
| 家庭见证者 | CH07 家庭关系影响最高且在场者 | 纠正玩家把公共理想置于具体亲人之上 |
| 劳动见证者 | 工人 / 农人 / 工匠中材料最完整者 | 说明历史如何被实际生产与维持 |
| 组织见证者 | 谋士 / 仕官 / 吏官相关人物 | 交出组织成就与错误 |
| 照护见证者 | 医者、家属、后勤或女性组织者 | 补上被英雄叙事略去的照护 |
| 表达见证者 | 乐人、记者、教师或学生 | 让被记录者拥有修改权 |
| 冲突见证者 | 与玩家关系破裂且仍有材料者 | 强制保留反对意见 |
| 缺席见证者 | 牺牲、失踪或拒绝进入中央档案者 | 让空白保持具体归属 |
| 后来者 | 儿童或青年 | 提出书名并写下开放页 |

## 2. 前七章人物进入方式

历代人物不复活，只以材料、后人争议、地名、工艺、曲调和制度痕迹进入。

| 章节 | 人物回声 | 必须避免 |
|---|---|---|
| CH01 | 家书、无名录、长平死者、职业证词 | 把所有人浓缩为一位先贤 |
| CH02 | 阿蓁、阿野等人的双籍与家书链 | 只见大一统制度不见被登记的人 |
| CH03 | 南北迁徙家庭、客主户与两岸合作者 | 用士族风骨覆盖流民与土著 |
| CH04 | 城坊供给者、边民、军民、工匠 | 用盛世繁华覆盖征调与边报 |
| CH05 | 叶娘、海生等人的刻本、海图、工记 | 只纪念亡国忠烈 |
| CH06 | 柳素、梁七、阿禾等人的工场、条约与家属记录 | 只纪念改革名臣和技术先驱 |
| CH07 | 林秋、石砧、田青等人在场或缺席材料 | 把活人变成终极答案的布景 |

## 3. 关系回收

| 历代关系母题 | 终章动作 |
|---|---|
| 家庭与公共责任 | 家人可反对把牺牲浪漫化，并决定自己材料是否公开 |
| 同伴与竞争 | 署名同时列写者、说者、做者、保管者和异议者 |
| 官与民 | 公共程序由在场者试运行，官文书只是证据之一 |
| 军与民 | 战功、借粮、误伤、军纪和家书同页 |
| 本地与外来 | 侨籍、难民、跨语材料保留自称与地名变化 |
| 专业者与普通人 | 专业判断保留，但不取消当事人知情和异议 |
| 记录者与被记录者 | 被记录者拥有查看、修改、拒绝公开与补充权 |

## 4. 关系结局不清零

- 与玩家决裂的人不会因终极真相自动原谅。
- 已逝者不能通过“精神永存”替代死亡和家属损失。
- 关系低但证据重要的人仍可进入主档。
- 关系高的人也可以拒绝公开私人材料。
- 玩家最后的成长不是赢得所有人好感，而是承认别人拥有不受他控制的历史位置。
