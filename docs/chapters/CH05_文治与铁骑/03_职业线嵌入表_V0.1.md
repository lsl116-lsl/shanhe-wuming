# 第五章《文治与铁骑》职业线嵌入表 V0.1

> 十条职业线共享王朝覆亡，不共享“同一段剧情换个技能检定”。每条线都有独立欲望、关系核心、三次升级、专属高潮、不可逆代价和晚清交接物。

## 2. 与八幕的嵌入

| 幕 | 共享骨架 | 职业独立内容必须占有的空间 |
|---|---|---|
| ACT01 | 刻坊火警、前章载体进入 | 首救物改变职业引路人第一印象，不直接锁职业 |
| ACT02 | 一字之误 | 每条线以不同受害者理解“复制错误” |
| ACT03 | 职业承诺 | 玩家做出一次有现实代价的承诺，职业才锁定 |
| ACT04 | 战报入市 | 第一、二次职业升级；建立人性对手而非纸片坏人 |
| ACT05 | 十船粮 | 每条线面对同一有限资源，但目标与证据不同 |
| ACT06 | 临安改旗 | 职业高潮前的身份重估；继续工作不是中立动作 |
| ACT07 | 海风尽处 | 专属高潮；固定亡国结果，可变具体生命、记录和关系 |
| ACT08 | 新朝旧坊 | 独立结局和下一章载体，不清空声望、债、伤病与污名 |

## 3. 职业专属状态

| 职业 | 核心状态 | 高值不是无条件“好” |
|---|---|---|
| 隐士 | `shelter_secrecy` / `shelter_openness` | 太隐秘使证言消失，太开放使藏人暴露 |
| 仕官 | `seal_legitimacy` / `civil_survival` | 合法性和民生在改朝时可能反向变化 |
| 谋士 | `intel_integrity` / `decision_speed` | 信息越全，决策可能越慢 |
| 武将 | `unit_cohesion` / `civil_trust` | 同伍服从可能建立在对百姓的伤害上 |
| 医者 | `quarantine_control` / `public_trust` | 强隔离可控病，也可能逼人隐瞒 |
| 乐人 | `reach` / `voice_integrity` | 传播越广，删改与迎合越强 |
| 商贾 | `fleet_capacity` / `credit_trust` | 保住资产可能意味着此刻不救人 |
| 工匠 | `craft_reliability` / `use_accountability` | 做得成不等于该被怎样使用 |
| 吏官 | `register_accuracy` / `identity_safety` | 真名准确可能直接带来追索 |
| 农人 | `seed_reserve` / `outsider_acceptance` | 保种与接纳流民会争夺同一土地和粮 |

## 4. 收敛规则

- 王朝覆亡、临安改旗与新朝重籍固定发生。
- 每条线必须改变“谁活下、谁背名、谁留下什么材料”，不能改变固定历史结果。
- 职业高潮产出的材料在过渡文中拥有不同可信度；工记不解释名节，唱本不单独证明人数，官文书不自动代表实际生活。
- 未选择的九条职业仍由对应角色推进为背景分支，生成简版命运；选择的职业才获得完整主线、亲密关系与高潮决策。
