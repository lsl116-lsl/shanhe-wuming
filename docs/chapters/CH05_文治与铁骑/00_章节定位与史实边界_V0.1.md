# 第五章《文治与铁骑》章节定位与史实边界 V0.1

> 推荐主交互窗口：约 1234—1285 年
>
> 主空间：南宋临安及相连江南河港、刻坊、行会、海船与战时迁徙线；元初同一城市的重组
>
> 章节责任：检验文明、城市、商业、印刷和技术繁荣并不自动等于政治军事安全；同时证明文明不是王朝私产，而能被普通人在覆亡中携带和重组。

## 1. 核心问题

```text
文治、商业和技术为何不能自动阻止覆亡？
亡国以后，文化属于旧王朝、少数士人，还是仍在生活的人？
在新秩序中继续活下去，是背叛、适应，还是承担？
```

## 2. 史实锚点

- 宋代南方经济、城市、市场和手工业高度发展，印刷与纸面凭据更广泛地进入生活。
- 南宋延续至 1279 年；1276 年临安失守，1279 年崖山失败是王朝终结的重要节点。
- 宋元战争长期而复杂，四川山城等地抵抗持续，不可压成一场骑兵横扫。
- 元统一结束长期多政权并立，也在江南延续、调整和重组商业、文化与基层制度。
- 元代江南并非单一“文化灭绝期”；南北、草原、江南和域外文化继续互动。

## 3. 禁止

- 不把宋代写成只有文人雅集、精致消费和发明清单。
- 不把蒙古、色目、北方人或降附者写成同质反派。
- 不把“文弱”当作宋亡的完整解释。
- 不让玩家凭火器、商业或现代战略挽救王朝。
- 不把继续经营、任职、行医和修城自动写成背叛。
- 不把崖山只做帝王悲剧，忽略船工、军民、家属与迁徙者。
