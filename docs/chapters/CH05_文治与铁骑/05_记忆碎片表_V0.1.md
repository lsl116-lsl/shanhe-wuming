## 1. 组合解锁

| 组合 | 解锁判断 | 错误解释被排除 |
|---|---|---|
| M01 + M03 + M12 | 知识、技术、文本由分工共同生产 | “我是某位全知发明家” |
| M05 + M08 + M09 | 改朝时道德评价、军事实践和制度分类不一致 | “忠奸标签足以解释人生” |
| M02 + M06 + M10 | 海上历史由船工、病者、家属和军民共同构成 | “末世只属于帝王将相” |
| M04 + M07 + M11 | 文明延续依靠种、艺与日常交换，也持续改变 | “王朝亡则文化亡” |

## 2. 呈现规则

- 碎片控制在 8—20 秒，不出现现代解释旁白。
- 先给感官和误认，至少隔一幕再出现反证。
- 同一碎片不得同时给出完整时间、地点、身份和结论。
- 解锁 M12 也不能直接揭晓终极身份，只能把“单一名人转世”概率降至极低。
