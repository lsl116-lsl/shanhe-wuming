## 1. 使用原则

主角设置为“天秤型人格底色”，禾安设置为“白羊型人格底色”。

这只是创作内部使用的角色原型，不在战国剧情中直接出现“星座”二字。

游戏里不能写：

```text
主角是天秤座。
禾安是白羊座。
```

游戏里要让玩家感受到的是：

```text
主角总是在称量两边的代价。
禾安总是先冲向眼前需要处理的人和事。
```

星座是底层性格模型，不是台词标签，也不是现代梗。

## 2. 主角：天秤型底色

主角的核心不是“优柔寡断”，而是“看见两边都有人”。

### 内部公式

```text
天秤底色：称量、公平、关系、位置、犹豫后的承担。
外在表现：安静、观察、迟疑、记得细节、落笔慎重。
成长方向：从想要平衡一切，到承认有些选择必然亏欠。
```

### 序章表现

主角十岁时应呈现为：

```text
旧渡孩子。
瘦。
安静。
眼神早熟。
衣服旧但干净。
手里常有木牍。
掌心会留下青铜锈。
看人时像在看眼前，也像在听很远的地方。
```

动画表现：

```text
写名字前，笔尖停一下。
看见翻车现场时，先看孩子，又看湿简，又看人群。
听见裂钟时，身体比眼神更早停住。
落笔、伸手、转身都不急，但一旦决定就不再后退。
```

主角的动作关键词：

```text
停顿。
称量。
回头听钟。
指尖墨痕。
掌心青铜锈。
空木牍。
```

### 禁止写法

不要把主角写成：

```text
因为天秤所以纠结。
因为犹豫所以无能。
只会观察不会行动。
永远需要别人替他决定。
```

主角的迟疑不是软弱，而是他知道每一笔后面都站着人。

## 3. 禾安：白羊型底色

禾安的核心不是“暴躁”，而是“人已经在眼前了，先动起来”。

### 内部公式

```text
白羊底色：行动、火、直接、保护、先冲出去。
外在表现：嘴快、动作快、抱柴、端水、数米、骂人但救人。
成长方向：从先救眼前人，到慢慢理解有些“写不写”的事也会牵出活人。
```

### 序章表现

禾安十岁时应呈现为：

```text
旧渡长大的邻家伙伴。
不精致。
头发用布条随便束起。
袖口卷着。
手上常有灶灰、米粉、柴屑。
站姿重心偏前，像随时准备去搬东西。
走路快，说话快，做事更快。
```

动画表现：

```text
抱柴进屋时不是慢慢走，是带着一点冲劲。
端粥给主角时嘴上别扭，手已经递到案边。
听见二十三户流民要来，第一反应是跑去数水瓮和米袋。
翻车现场先拖热水桶，再喊主角搭手。
```

禾安的动作关键词：

```text
抱柴。
卷袖。
倒碎米。
拨灶火。
拖热水桶。
喊主角别发呆。
```

### 禁止写法

不要把禾安写成：

```text
恋爱对象。
女主候选。
甜美女主。
只会暴躁的直线角色。
因为白羊所以无脑冲。
```

禾安可以急，但她不蠢。她也会数米、数水、数明早够不够吃。

她的核心价值不是恋爱陪伴，而是现实锚点。

## 4. 主角与禾安的关系张力

他们的关系不是恋爱张力，而是处世方式的张力。

核心句：

```text
主角怕落错一笔。
禾安怕晚伸一只手。
```

主角代表：

```text
称量。
看见两边都有人。
怕一笔写错，牵出身后的人。
```

禾安代表：

```text
点火。
先处理眼前快撑不住的人。
怕一直称量，耽误了能救的事。
```

他们互相补足：

```text
主角让禾安看见：不能只靠冲，有些东西一写下去，会牵出一整户人。
禾安让主角看见：不能一直称，有些人等不到你称完。
```

这组关系应当保留年少熟悉感和时代遗憾感，但不能发展成暧昧或恋爱。

## 5. 其他人物视觉延展

### 辛衡

关键词：

```text
旧书吏。
慢。
停笔。
看木牍。
眼神沉。
手指有墨。
```

动画表现：

```text
他不急着解释。
笔尖悬在木牍上，比台词更有压力。
递给主角空木牍时，动作很轻，但意义很重。
```

### 韩宁

关键词：

```text
瘦。
警惕。
袖中木片。
湿衣。
眼神硬。
```

动画表现：

```text
别人问旧里，他先按住袖口。
身体像要退，眼神却不退。
看见湿简落泥，会本能扑过去。
```

### 韩宁的母亲

关键词：

```text
疲惫。
护子。
比韩宁更早判断风险。
身体挡在韩宁前面。
```

动画表现：

```text
一有人问父名、旧里，她先按住韩宁的手。
她不只是哭，她知道什么话说出口会牵出更多人。
```

### 柳娘

关键词：

```text
发簪端正。
戏箱。
旧曲。
停顿。
克制。
```

动画表现：

```text
她可以用戏箱垫漏风处。
唱到地名处，眼神往下一落，声音停住。
她不需要大哭，停顿本身就是重量。
```

### 主角母亲

关键词：

```text
数米。
数柴。
数布。
望河道尽头。
不说等。
```

动画表现：

```text
手在数米，眼睛却被船声牵走。
每有船来，她看一眼，但不说自己在等。
```

## 7. Codex 动画生成注意事项

让 Codex 生成序章动画化原型时，应要求它优先使用以下人物动作差异：

```text
主角：慢半拍、先观察、落笔慎重。
禾安：先动、动作快、嘴上急但手上已经做事。
辛衡：动作少，停笔和递木牍是重点。
韩宁：按袖口、扑湿简、保护残简。
韩宁母亲：挡在韩宁前面，先按住他的手。
柳娘：发簪端正，唱到地名处停顿。
主角母亲：数米、望河道尽头。
```

不要用同一套站立 NPC 动画替代所有人。

每个人至少要有一个专属动作循环或专属停顿。

```text
主角是称量的人。
禾安是点火的人。
辛衡是停笔的人。
韩宁是护着线索的人。
柳娘是把旧曲唱断的人。
主角母亲是不说等却一直看的人。
```
