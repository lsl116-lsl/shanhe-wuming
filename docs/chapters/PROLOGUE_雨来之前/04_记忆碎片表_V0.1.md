## 2. 记忆碎片纪律

序章记忆碎片必须满足：

```text
不解释苏醒者身份。
不赋予玩家超时代知识。
不提供正确选项。
不让主角绕过现实代价。
只让玩家产生“我好像不是第一次经历这种事”的感受。
```

## 3. 记忆碎片与现实危机的关系

裂钟异常不能盖过现实危机。

序章结尾必须让玩家明白：

```text
裂钟声还在远处回荡。
可这一刻，你没有时间想它。
你必须先看眼前的人。
```

记忆碎片的作用是加深主题，不是打断或替代人物、粮、名册和流民的现实压力。
