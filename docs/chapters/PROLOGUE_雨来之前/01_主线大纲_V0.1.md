# 序章《雨来之前》主线大纲 V0.1

## 1. 主线功能

序章负责完成四个动作：

```text
让玩家落地
→ 让旧渡有人
→ 让宋亡进门
→ 让裂钟异常出现
```

序章不追求分支复杂度。它要做的是把玩家从“旁观历史”带入“这一世正在发生”。

## 2. 十一段结构

### 一、洛水旧渡的早晨

建立旧渡、主角家庭和父亲未归。

重点信息：

- 你的母亲数米、数柴、数布。
- 你的父亲随官运粮后未归。
- 你的父亲曾答应给你带一支新笔。
- 你的母亲不说等，但每有船来都会看。

玩家感受：

```text
我这一世不是凭空醒来的。
我有家，有人等，有未归之事。
```

### 二、先写自己的名字

辛衡让主角写下本世姓名。

重点信息：

- 主角知道本世姓名、年龄、居处和身边人。
- 写名时出现第一次异常熟悉感。
- 辛衡说：“本世的名字，不能也让旁人替你省掉。”

玩家感受：

```text
我知道自己是谁，但这个“我”似乎不止这一世。
```

### 三、名字不是只给自己看的

禾安登场，旧渡关于名字的生活规则出现。

重点信息：

- 禾安嘴快、现实、有生活气。
- 辛衡说名字不是只给自己看的。
- 禾安补一句：也不是只给官差看的。
- 名字连接门、田、役、债和还没逃走的人。

玩家感受：

```text
名字不是 UI 输入框，而是进入时代制度的线头。
```

### 四、宋亡的消息

东来商船带来宋亡消息。

重点信息：

- 齐、魏、楚接管宋地。
- 路上关验变化，普通人只能接收混乱消息。
- 二十三户宋地流民往洛水旧渡来。
- 船主提到有少年藏残简，问父亲是谁时其母跪下。

玩家感受：

```text
亡国不是地图变色，而是一群人要在雨夜抵达旧渡。
```

### 五、来处不是一句来处

宋地流民抵达，韩宁登场。

重点信息：

- 韩宁愿意说现名，不愿说旧里。
- 韩宁的母亲阻止追问。
- 辛衡解释旧邑、旧里、旧户的追索风险。
- 写与不写都带来代价。

玩家感受：

```text
隐名不是谜语，而是活人的风险。
```

### 六、韩宁的木片

韩宁残简和柳娘旧曲登场。

重点信息：

- 韩宁袖中的木片边缘被反复刮薄。
- 辛衡只写韩宁愿意写的信息。
- 柳娘唱旧曲，在地名处停住。
- “完整”与“危险”第一次同场出现。

玩家感受：

```text
有些名字被删掉，是为了保护；也可能因此永远无人承认。
```

### 七、碎米

禾安在灶前处理旧渡存粮。

重点信息：

- 米袋只剩一点碎米。
- 禾安嘴上现实，手上还是把碎米倒进锅里。
- 主角母亲望向河道尽头。

玩家感受：

```text
救人不是廉价善良，是从明早的饭里抠出来的一口活路。
```

### 八、木牍上的空白

辛衡迟迟不写某片木牍。

重点信息：

- 官府喜欢整齐的册子，但今夜没有整齐的人。
- 辛衡说写字的人不能只想着字。
- 韩宁的父亲和旧册有关，但不说透。
- 主角父亲未归、韩宁父亲旧册、辛衡停笔、主角本世名字形成细线。

玩家感受：

```text
这些事可能有关，但现在还不能确定。
```

### 九、雨来之前

雨意压下，旧渡准备接住后续车队。

重点信息：

- 后面还有车队。
- 新接管宋地的人正在按旧册找逃户。
- 柳娘的停顿、韩宁的木片、辛衡的湿墨都形成重复意象。
- 裂钟声第一次强烈召唤主角。

玩家感受：

```text
现实压力已经足够沉重，可还有另一个不属于本世的声音在靠近。
```

### 十、裂钟落水

主角进入旧礼器库，触碰裂钟。

重点信息：

- 旧礼器库废弃，旧礼已经失去现实用途。
- 裂钟触发残梦：王东迁、礼器断裂、名字被刮去、陌生湿手按住名册。
- 第一次听见：“这不是你第一次看见山河改色。”

玩家感受：

```text
裂钟不是能力，不是答案，而是无法解释的记忆入口。
```

### 十一、最后一辆车

现实危机把主角从裂钟异常中拉回。

重点信息：

- 车翻了。
- 孩子被压在车辕下。
- 湿简散在泥水里。
- 韩宁、柳娘、禾安、辛衡都在场。
- 辛衡把空木牍塞给主角：先看眼前的人。

玩家感受：

```text
无论裂钟意味着什么，眼前的人先要活下来。
```

## 3. 结尾交互入口

序章结尾直接进入 ACT01 第一选择：

```text
先救车下的孩子。
先抢泥水里的湿简。
先让还活着的人彼此认出彼此。
```

这三项分别对应：

| 选择 | 表层行为 | 深层代价 |
|---|---|---|
| 救孩子 | 先救命 | 湿简可能损坏，证据流失 |
| 抢湿简 | 先留证 | 伤者可能延误救治 |
| 互认 | 先建立共同见证 | 人命和证据都可能损失一部分 |

所有选择都必须保留代价，不得出现完美选项。
