# 序章《雨来之前》至 ACT01《雨后流民》过渡文 V0.1

> 功能：将序章结尾的翻车危机无缝接入第一章 ACT01 的第一组三选一。  
> 重点：裂钟异常不能抢走现实危机。玩家必须先面对眼前的人、湿简和互认。  
> 交互原则：移动负责让玩家看见，互动负责让玩家承担。

## 1. 过渡核心

序章最后，主角从旧礼器库和裂钟残梦中冲回渡口。

ACT01 开场不能再重新解释宋亡、隐名和人物关系，而要直接承接序章已建立的压力：

```text
宋地流民已经抵达。
旧渡已经开始收容。
韩宁和残简已经出现。
柳娘旧曲已经停过地名。
禾安已经把碎米倒进锅里。
主角已经写下本世姓名。
主角已经触碰裂钟并听见第一声提示。
```

因此 ACT01 的第一幕不是“介绍世界”，而是“让玩家看见同时发生的危机，然后承担选择”。

玩家不能靠天眼猜答案。进入可移动场景前，镜头和人物喊话必须让玩家看清：

```text
车下孩子正在哭。
湿简正在被雨泡开。
棚下有人正在认错亲人。
我先做一件事，其他事就会继续恶化。
```

## 2. 标准过渡文本

```text
雨水落在木牍上。

你的名字已经写在早晨那一片木牍里。

而现在，别人的名和籍正散在泥里。

车辕下的孩子哭得越来越轻。

湿简被泥水一点点泡开，残字像虫一样浮起来，又沉下去。

韩宁挣开拉住他的人，扑向那几片简，又在看见车下的孩子时停住。

柳娘抱着另一个孩子，嗓子哑了，旧曲再也接不上调。

禾安拖着热水桶，脚下一滑，半桶水溅进泥里。她骂了一声，又咬牙把桶扶起来。

辛衡把空木牍塞进你手里。

“先看眼前的人。看清楚，再落笔。”

裂钟声还在远处回荡。

可这一刻，你没有时间想它。

你必须先做一件事。
```

## 3. 可移动场景引导规则

ACT01 开场应当先进入短暂镜头展示，再给玩家移动控制权。

### 3.1 镜头展示

获得控制权前，镜头依次扫过：

```text
翻倒的车。
车辕下的孩子。
泥水里的湿简。
棚下混乱的人群。
韩宁挣扎扑简。
禾安拖热水桶。
柳娘抱着孩子喊人。
辛衡递来空木牍。
```

这个镜头不计后果，只负责让玩家看见问题。

### 3.2 玩家可移动方向

玩家获得控制权后，场景中应有三个明确方向：

```text
车下孩子。
泥水湿简。
棚下人群。
```

每个方向都要有视觉、声音和人物引导，不依赖天眼或事后解释。

### 3.3 观察窗口

推荐节奏：

```text
前 3 秒：镜头展示现场，不计后果。
第 4—10 秒：玩家移动观察，轻微变化。
第 10 秒后：某些后果开始加重，但仍可挽回一部分。
按下互动键后：锁定主要选择。
```

该节奏可按实现调整，但不能暗中惩罚玩家。

## 4. ACT01 第一选择

### 选择 A：先救车下的孩子

靠近方向：车辕下的孩子、禾安、热水桶。

```text
禾安：“搭把手！车辕还压着他！”

【E】抬车救孩子

提示：泥里的湿简还无人去捡。
```

确认后文本：

```text
你扔下木牍，先扑到车辕旁。

孩子的哭声太轻了。

轻到你怕再晚一点，就再也听不见。
```

#### 设计含义

| 层面 | 结果 |
|---|---|
| 表层行为 | 先救命 |
| 立即收益 | 孩子获救概率提高；禾安信任上升 |
| 立即代价 | 湿简损坏更多；韩宁可能对你产生裂痕 |
| 记录变化 | 官档 / 私录缺失部分名籍信息 |
| 主题 | 人命优先，但证据会消失 |

### 选择 B：先抢泥水里的湿简

靠近方向：泥水里的湿简、韩宁。

```text
韩宁：“别踩！那不是废木头！”

【E】抢救湿简

提示：车下孩子的哭声断了一下。
```

确认后文本：

```text
你先跪到泥水里，把那几片湿简按住。

墨已经化开了。

再迟一点，上面的名和籍就会变成一滩黑水。
```

#### 设计含义

| 层面 | 结果 |
|---|---|
| 表层行为 | 先留证 |
| 立即收益 | 抢回更多名籍线索；韩宁信任上升 |
| 立即代价 | 车下孩子救治延误；禾安可能产生裂痕 |
| 记录变化 | 私录 / 官档完整度提高，但人情风险上升 |
| 主题 | 留证也是救人，但不是没有代价 |

### 选择 C：先让活着的人彼此认出彼此

靠近方向：遮雨棚人群、柳娘、抱错或失散的孩子。

```text
柳娘：“先认人！别让孩子被领错！”

【E】让活人互认

提示：雨水还在冲刷湿简，车下仍有人被压着。
```

确认后文本：

```text
你攥紧空木牍，冲到棚下大喊。

“先别乱！活着的人，先说你身边少了谁！”

没人立刻听你。

雨太大了，哭声也太多了。
```

#### 设计含义

| 层面 | 结果 |
|---|---|
| 表层行为 | 先建立共同见证 |
| 立即收益 | 口述记录更完整；多人关系变化较均衡 |
| 立即代价 | 救命和抢简都不够彻底 |
| 记录变化 | 口述渠道增强，官档仍不完整 |
| 主题 | 共同见证能留住人，但不能替代手上的行动 |

## 5. 过渡后的状态继承

ACT01 必须继承以下序章状态：

```text
player.profile.name 已存在。
主角知道父亲随官运粮后未归。
主角与辛衡、禾安已有前置关系。
主角知道韩宁现名，不知道韩宁旧里。
主角知道韩宁的父亲和旧册有关，但不知道详情。
主角知道柳娘会删去旧曲地名。
主角已经触发裂钟记忆，但没有获得任何现实能力。
```

## 6. 文本禁忌

ACT01 开头不要再写：

```text
你不知道自己是谁。
你不知道这些人是谁。
宋地流民忽然出现。
韩宁忽然神秘登场。
裂钟给了你某种提示能力。
```

ACT01 应该写成：

```text
你知道自己是谁。
你知道眼前的人是谁。
你知道他们为什么害怕说旧里。
你刚刚听见了无法解释的裂钟。
但现在，车下的孩子、泥里的湿简、棚下混乱的人群，正在逼你选择。
```

## 7. 交互禁忌

ACT01 开场不要设计成：

```text
玩家没有看清现场，就开始倒计时。
玩家只是走到某个区域，就强制锁定选择。
玩家不知道湿简重要，事后才提示湿简损坏。
玩家不知道孩子会恶化，事后才提示孩子死亡。
玩家不知道人群混乱，事后才提示有人失散。
```

应设计成：

```text
玩家先看见现场。
玩家移动时获得更多信息。
玩家靠近后看到眼前代价。
玩家按下互动键后，才承担主要选择。
```

## 8. 到 ACT02 的远期连接

ACT01 的第一选择应当影响 ACT02《旧礼无声》中：

| ACT01 偏向 | ACT02 可回响 |
|---|---|
| 先救孩子 | 旧渡认为主角心软可靠，但记录缺口更大 |
| 先抢湿简 | 韩宁更愿意靠近主角，但禾安会记住那一刻的延误 |
| 先互认 | 口述系统更强，但官档和救治两边都有遗憾 |

这三条都不应导向“正确路线”。

它们只应导向不同的亏欠、信任和记录形态。

## 9. 过渡总结

序章到 ACT01 的交接主题是：

```text
你刚刚写下自己的名字。
现在，你要决定先救一条命，先留一份名籍，还是先让活着的人彼此记住彼此。
```

这就是《山河无名》第一组真正的选择。
