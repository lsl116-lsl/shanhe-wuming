# 序章《雨来之前》至 ACT01《雨后流民》过渡文 V0.1

> 功能：将序章结尾的翻车危机无缝接入第一章 ACT01 的第一组三选一。  
> 重点：裂钟异常不能抢走现实危机。玩家必须先面对眼前的人、湿简和互认。

## 1. 过渡核心

序章最后，主角从旧礼器库和裂钟残梦中冲回渡口。

ACT01 开场不能再重新解释宋亡、隐名和人物关系，而要直接承接序章已建立的压力：

```text
宋地流民已经抵达。
旧渡已经开始收容。
韩宁和残简已经出现。
柳娘旧曲已经停过地名。
禾安已经把碎米倒进锅里。
主角已经写下本世姓名。
主角已经触碰裂钟并听见第一声提示。
```

因此 ACT01 的第一幕不是“介绍世界”，而是“让玩家立刻承担选择”。

## 2. 标准过渡文本

```text
雨水落在木牍上。

你的名字已经写在早晨那一片木牍里。

而现在，别人的名字正散在泥里。

车辕下的孩子哭得越来越轻。

湿简被泥水一点点泡开，残字像虫一样浮起来，又沉下去。

韩宁挣开拉住他的人，扑向那几片简，又在看见车下的孩子时停住。

柳娘抱着另一个孩子，嗓子哑了，旧曲再也接不上调。

禾安拖着热水桶，脚下一滑，半桶水溅进泥里。她骂了一声，又咬牙把桶扶起来。

辛衡把空木牍塞进你手里。

“先看眼前的人。”

裂钟声还在远处回荡。

可这一刻，你没有时间想它。

你必须先做一件事。
```

## 3. ACT01 第一选择

### 选择 A：先救车下的孩子

```text
你扔下木牍，先扑到车辕旁。

孩子的哭声太轻了。

轻到你怕再晚一点，就再也听不见。
```

#### 设计含义

| 层面 | 结果 |
|---|---|
| 表层行为 | 先救命 |
| 立即收益 | 孩子获救概率提高；禾安信任上升 |
| 立即代价 | 湿简损坏更多；韩宁可能对你产生裂痕 |
| 记录变化 | 官档 / 私录缺失部分姓名信息 |
| 主题 | 人命优先，但证据会消失 |

### 选择 B：先抢泥水里的湿简

```text
你先跪到泥水里，把那几片湿简按住。

墨已经化开了。

再迟一点，上面的名字就会变成一滩黑水。
```

#### 设计含义

| 层面 | 结果 |
|---|---|
| 表层行为 | 先留证 |
| 立即收益 | 抢回更多姓名和残字；韩宁信任上升 |
| 立即代价 | 车下孩子救治延误；禾安可能产生裂痕 |
| 记录变化 | 私录 / 官档完整度提高，但人情风险上升 |
| 主题 | 留名也是救人，但不是没有代价 |

### 选择 C：先让活着的人彼此认出彼此

```text
你攥紧空木牍，冲到棚下大喊。

“先别乱！活着的人，先说你身边少了谁！”

没人立刻听你。

雨太大了，哭声也太多了。
```

#### 设计含义

| 层面 | 结果 |
|---|---|
| 表层行为 | 先建立共同见证 |
| 立即收益 | 口述记录更完整；多人关系变化较均衡 |
| 立即代价 | 救命和抢简都不够彻底 |
| 记录变化 | 口述渠道增强，官档仍不完整 |
| 主题 | 共同见证能留住人，但不能替代手上的行动 |

## 4. 过渡后的状态继承

ACT01 必须继承以下序章状态：

```text
player.profile.name 已存在。
主角知道父亲随官运粮后未归。
主角与辛衡、禾安已有前置关系。
主角知道韩宁现名，不知道韩宁旧里。
主角知道韩宁的父亲和旧册有关，但不知道详情。
主角知道柳娘会删去旧曲地名。
主角已经触发裂钟记忆，但没有获得任何现实能力。
```

## 5. 文本禁忌

ACT01 开头不要再写：

```text
你不知道自己是谁。
你不知道这些人是谁。
宋地流民忽然出现。
韩宁忽然神秘登场。
裂钟给了你某种提示能力。
```

ACT01 应该写成：

```text
你知道自己是谁。
你知道眼前的人是谁。
你知道他们为什么害怕说旧里。
你刚刚听见了无法解释的裂钟。
但现在，车下的孩子、泥里的湿简、棚下混乱的人群，正在逼你选择。
```

## 6. 到 ACT02 的远期连接

ACT01 的第一选择应当影响 ACT02《旧礼无声》中：

| ACT01 偏向 | ACT02 可回响 |
|---|---|
| 先救孩子 | 旧渡认为主角心软可靠，但记录缺口更大 |
| 先抢湿简 | 韩宁更愿意靠近主角，但禾安会记住那一刻的延误 |
| 先互认 | 口述系统更强，但官档和救治两边都有遗憾 |

这三条都不应导向“正确路线”。

它们只应导向不同的亏欠、信任和记录形态。

## 7. 过渡总结

序章到 ACT01 的交接主题是：

```text
你刚刚写下自己的名字。
现在，你要决定先救一条命，先留一个名，还是先让活着的人彼此记住彼此。
```

这就是《山河无名》第一组真正的选择。
