## 2. 序章因果纪律

### 2.1 不能立刻回收的大坑

以下内容不能在序章或 ACT01 立即解释：

```text
裂钟到底是什么。
苏醒者为什么听见裂钟。
韩宁父亲到底做过什么。
辛衡是否曾删名。
主角父亲是否卷入官粮旧案。
```

这些只允许通过动作、停顿、旧物、话语回避来埋线。

### 2.2 可以立即形成的近因

序章可以立刻形成以下近因：

```text
玩家写下本世姓名。
玩家知道父亲随官运粮未归。
玩家知道宋亡流民正在抵达旧渡。
玩家知道隐名风险不等于故弄玄虚。
玩家知道韩宁与残简有关。
玩家知道柳娘会在地名处停顿。
玩家知道禾安会计算代价。
玩家听见裂钟并产生异常。
```

### 2.3 ACT01 必须接住的因

ACT01 不应重新解释序章，而应直接用序章结果制造压力：

```text
孩子被压在车下 → 接住禾安“今晚别死在这儿就行”。
湿简散在泥里 → 接住辛衡、韩宁与旧册线。
流民互认混乱 → 接住隐名规则。
主角手里有空木牍 → 接住“写自己的名字”与“写别人的名字”。
裂钟余响未散 → 接住苏醒者异常，但不提供超自然解法。
```

## 3. 因果写作要求

序章的因果不能像任务提示。

不要写：

```text
你获得任务：调查韩宁父亲旧册。
```

要写：

```text
韩宁的母亲听见父名时，手指一下按住袖中的木片。
辛衡看见那截木片，笔尖停在半空。
```

不要写：

```text
禾安是现实但善良的人。
```

要写：

```text
禾安把米袋倒过来抖了抖。
袋底落下一点碎米。
“别看我。就这么多。”
她还是倒进锅里。
```

## 4. 序章结束状态

序章结束时，玩家应持有以下心理状态：

```text
我知道我这一世是谁。
我有一个未归父亲和一直等待的母亲。
我认识辛衡与禾安。
我知道宋亡流民不是抽象背景。
我知道名字、旧里和名册都可能害人。
我对韩宁、柳娘和旧册产生疑问。
我听见了裂钟，但它没有帮我解决眼前危机。
我必须先看眼前的人。
```
