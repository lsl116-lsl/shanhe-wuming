# 序章《雨来之前》动画化叙事与轻交互规格 V0.1

> 文档状态：正式序章演出制作规则  
> 适用范围：序章《雨来之前》网页重制、Godot 正式版序章、Codex 动画化拆分任务  
> 核心原则：序章不是高频选择题关卡，而是一段让玩家进入第一世人生的开场动画化叙事。

## 1. 定位修正

当前可玩序章可以视为：

```text
骨架版
```

它解决的是：

```text
剧情顺序
因果入口
选择结构
数据验证
进入 ACT01
```

正式序章应当升级为：

```text
血肉版
```

它要解决的是：

```text
人物丰满
镜头节奏
动画演出
场景生活感
玩家代入
情绪沉淀
```

正式序章不是“剧情简介 + 连续选择题”。

它应该像一段真正的开场动画 / 章节序幕，把玩家慢慢带进旧渡、带进主角这一世、带进辛衡、禾安、韩宁、柳娘和宋亡流民身边。

## 2. 核心制作原则

序章制作必须遵守：

```text
先让玩家沉进去。
再让玩家看见问题。
最后才让玩家承担选择。
```

序章负责让玩家相信这个世界是真的，不是负责考玩家。

因此：

```text
序章中大部分内容应通过动画、镜头、人物走位、环境互动和少量轻操作呈现。
玩家只在真正产生不可逆代价的地方做选择。
人物自己的行动不能全部交给玩家决定。
角色必须通过自己的动作、停顿和选择变得像活人。
```

## 3. 节奏比例

正式序章推荐比例：

```text
70% 叙事演出
20% 轻探索 / 调查 / 对话
10% 关键选择
```

这不是严格时长比例，而是制作倾向。

序章不应频繁弹出选择框。

选择应当很少，但每一次都必须有明确代价。

## 4. 选择出现规则

序章里不要为了交互而交互。

不推荐：

```text
每隔几句就让玩家选一句话。
把人物自己的行动交给玩家决定。
把生活化片段做成伪选择。
```

推荐：

```text
人物自己行动，玩家观察和感受。
玩家通过轻探索理解人物和环境。
只有当某个决定会造成不可逆代价时，才出现关键选择。
```

序章真正的重大选择，应集中在结尾翻车现场：

```text
先救车下的孩子。
先抢泥水里的湿简。
先让还活着的人彼此认出彼此。
```

此前可以有轻交互，但不应频繁分支。

## 5. 轻交互类型

轻交互不负责制造大分支，而负责让玩家代入。

允许的轻交互包括：

```text
按住 E 写下本世姓名。
走到母亲身边，查看半袋粟米或父亲旧笔盒。
走到灶房，听见禾安催早饭。
靠近渡口，听船主说宋亡。
靠近韩宁，观察他按住袖口。
靠近柳娘，听旧曲在地名处停住。
帮禾安端水。
查看临时名册上的空白。
走向旧礼器库，触碰裂钟。
```

这些交互不应立即造成重大路线锁定。

它们的作用是：

```text
让玩家知道自己在哪里。
让玩家知道身边的人是谁。
让玩家看见人物自己的动作和压力。
让玩家逐步理解名与籍、隐名、宋亡、旧渡和裂钟。
```

## 6. 动画化叙事段落规划

### 一、洛水旧渡的早晨

表现方式：主要为动画演出。

镜头建议：

```text
河雾。
木船。
木缆轻响。
主角家门口。
你的母亲洗木盆。
你的母亲数米、数柴、数布。
你的母亲望向河道尽头。
```

玩家此处不需要重大选择。

最多允许轻交互：

```text
查看半袋粟米。
查看父亲留下的旧笔盒。
走到门口看河道尽头。
```

目的：

```text
让玩家知道：这是我家，这是我的母亲，这里有人没回来。
```

### 二、在渡册上落名

表现方式：教学式剧情 + 仪式性交互。

建议交互：

```text
【按住 E】写下名字
```

该交互不是选择，而是仪式。

目的：

```text
让玩家感觉自己第一次把自己写进这一世。
```

写名后可触发轻微异常：

```text
更长的案。
更暗的灯。
更冷的水。
陌生手按住名册。
```

但不要解释苏醒机制，更不能把画面导向寻找真名或前世身份。

### 三、禾安登场

表现方式：角色生活化演出。

内容重点：

```text
禾安抱柴进来。
怼主角早饭要冷了。
把粥放下。
嘴上说是主角母亲让端的。
知道主角家里的事，但不拿这些事安慰主角。
```

不要做成恋爱互动。

不要让玩家选择“是否和禾安亲近”。

目的：

```text
让玩家看见禾安和主角是旧渡共同长大的同龄伙伴。
熟悉、嘴硬、生活化，但不是恋爱线。
```

### 四、宋亡消息到来

表现方式：场景调度 + 轻探索。

镜头建议：

```text
东来商船靠岸。
船主喊“宋地乱了”。
旧渡人陆续停下手里的活。
禾安跑回灶房数水瓮和米袋。
辛衡推开木牍。
```

玩家可移动到不同人旁边听碎片：

```text
船主：宋地乱了。
旧渡人：宋也亡了。
禾安：二十三户？水要烧到后半夜。
辛衡：他们不肯说旧里？
```

目的：

```text
让玩家听见历史不是地图变色，而是进入旧渡的一群人。
```

### 五、韩宁和柳娘登场

表现方式：半动画 + 轻观察。

玩家可轻交互：

```text
靠近韩宁，看见他按住袖口。
靠近韩宁的母亲，看见她阻止追问旧里。
靠近辛衡，看见他停笔。
靠近柳娘，听见旧曲停在地名处。
查看临时名册上的空白。
```

此处不要让玩家立刻决定“问不问旧里”。

目的：

```text
让玩家慢慢理解：韩宁不是神秘 NPC，柳娘不是背景戏子，辛衡不是解释机器。
每个人都有自己不敢说完的东西。
```

### 六、碎米和雨来之前

表现方式：人物动画演出。

重点动作：

```text
禾安蹲下。
倒米袋。
袋底只落一点碎米。
她停一下。
看主角。
说：“别看我。就这么多。”
然后还是倒进锅里。
```

这不应做成玩家选择。

因为这是禾安自己的行动。

目的：

```text
让玩家看见救人不是廉价善良，是从明早饭里抠出来的一口活路。
```

### 七、裂钟

表现方式：主动移动点 + 动画演出。

玩家可以控制主角走向旧礼器库。

进入旧库并触碰裂钟后，转为动画：

```text
暗库。
破鼎。
裂钟。
触碰。
水底钟声。
王东迁残梦。
名字被刮去。
“这不是你第一次看见山河改色。”
```

这里不做选择。

目的：

```text
裂钟不是玩家决策，而是命运和记忆第一次打开缝隙。
```

### 八、翻车现场

表现方式：眼前代价系统 + 第一次重大选择。

这是序章第一个真正不可逆选择点。

玩家先看见：

```text
车下孩子。
泥水湿简。
棚下人群。
禾安喊救人。
韩宁扑向湿简。
柳娘喊互认。
辛衡递来空木牍。
```

然后进入可移动场景。

玩家靠近不同方向，看到眼前代价。

最后按互动键确认：

```text
先救车下的孩子。
先抢泥水里的湿简。
先让还活着的人彼此认出彼此。
```

目的：

```text
玩家不是在选 A/B/C，而是在旧渡雨里先跑向一个人、一片正在烂掉的名籍，或一群快要失散的活人。
```

## 7. 正式序章玩家体验目标

玩家进入游戏后，不应立刻觉得“我要做任务”。

玩家应先觉得：

```text
我醒在洛水边。
这里有雾。
有船。
有一个一直等父亲回来的母亲。
有一个话不多但看得很深的辛衡。
有一个嘴硬、现实、从小认识我的禾安。
有一群说不清来处的宋地流民。
有一个按着木片不肯说旧里的韩宁。
有一首唱到地名处停住的旧曲。
有一口在水底响起的裂钟。
```

等这些都成立了，翻车那一刻玩家才会真的紧张。

## 8. Codex 制作要求

后续让 Codex 重制序章时，必须遵守：

```text
不得把序章做成连续选择题。
不得删减主要人物登场和生活化动作。
不得把禾安、辛衡、韩宁、柳娘写成纯功能 NPC。
不得把人物自己的关键动作全部交给玩家决定。
不得让玩家在不了解现场的情况下承担后果。
```

应当优先实现：

```text
镜头调度。
角色入场。
环境物件互动。
少量轻探索。
关键选择延后。
翻车现场眼前代价系统。
```

## 9. Codex 可执行任务模板

后续可直接给 Codex 的任务说明：

```text
请先阅读 AGENTS.md、docs/14_可移动探索与眼前代价系统_V0.1.md，以及 docs/chapters/PROLOGUE_雨来之前/ 下全部文件。

重点阅读 docs/chapters/PROLOGUE_雨来之前/07_动画化叙事与轻交互规格_V0.1.md。

目标：把当前可玩序章从“骨架版剧情选择”升级为“动画化叙事 + 轻探索 + 少量关键选择”的正式序章原型。

要求：
1. 保持现有 JSON 内容与运行时分离，不把剧情写死进 UI。
2. 序章前 70% 以镜头、角色调度、环境互动和轻探索为主，不频繁弹选择题。
3. 轻交互只用于代入，不锁死重大分支。
4. 真正重大选择集中在翻车现场。
5. 翻车现场必须实现“移动负责让玩家看见，互动负责让玩家承担”。
6. 修改后运行 pnpm test。
```

## 10. 最终标准

正式序章成功的标准不是“玩家做了很多选择”。

而是玩家在第一次重大选择前，已经相信：

```text
这个旧渡是真的。
这些人认识我。
这些人不是背景。
宋亡不是地图变色。
名与籍不是概念，而是会牵出活人的线。
裂钟不是能力，而是无法解释的记忆裂口。
我现在跑向哪里，都不是答题，而是在承担这一世第一笔亏欠。
```
