# 序章《雨来之前》人物关系表 V0.1

> 人物原则：不按好坏分类。每个人都有自己的来处、欲望、恐惧、底线和不得已。文本不替玩家判断。

## 1. 主角 / 苏醒者本世

| 字段 | 内容 |
|---|---|
| 本世身份 | 洛水旧渡十岁孩童，能辨简单姓名、数目和渡册 |
| 已知关系 | 你的母亲、未归的父亲、辛衡、禾安 |
| 核心状态 | 清楚知道本世姓名，但对裂钟和陌生残梦无法解释 |
| 想要什么 | 想写清自己的名字，也想弄懂父亲未归和裂钟异常 |
| 害怕什么 | 害怕别人被写错、被漏写，也害怕自己不是自己以为的那个人 |
| 记忆点 | 写名字时的恍惚；掌心青铜锈；手里的空木牍 |
| 序章作用 | 让玩家从本世生活进入历史压力，而不是从系统视角进入选择题 |

## 2. 你的母亲

| 字段 | 内容 |
|---|---|
| 身份 | 旧渡普通妇人，独自维持家计并等待未归丈夫 |
| 想要什么 | 家还能撑下去；你的父亲还有回来的可能 |
| 害怕什么 | 承认没有消息就是消息；旧渡再被新的事拖垮 |
| 相信什么 | 路还在，人就还有可能回来 |
| 说不出口的事 | 她可能知道等待不能当饭吃，但不愿让这个家最后一点完整塌掉 |
| 记忆点 | 数米、数柴、数布；望河道尽头；不说等，却一直看 |
| 让玩家可能喜欢的地方 | 安静、坚韧，把本世生活钉住 |
| 让玩家可能不舒服的地方 | 她的等待可能让主角也被困在父亲未归这件事里 |
| 可能种下的因 | 父亲官粮线、旧仓线、主角私人追索动机 |

## 3. 你的父亲

| 字段 | 内容 |
|---|---|
| 身份 | 随官运粮后未归的人，序章不登场 |
| 想要什么 | 暂不揭示 |
| 害怕什么 | 暂不揭示 |
| 相信什么 | 暂不揭示 |
| 说不出口的事 | 他未归的原因不能在序章说明，后续可能与官粮、旧仓、记录或旧渡路线有关 |
| 记忆点 | 新笔承诺；官粮车队；河道尽头 |
| 让玩家可能喜欢的地方 | 留下私人牵挂，使主角不是漂浮的苏醒者 |
| 让玩家可能不舒服的地方 | 后续不一定只是单纯受害者，需要保留复杂性 |
| 可能种下的因 | 官粮旧案、旧仓放粮、辛衡隐瞒、主角家庭因果 |

## 4. 辛衡

| 字段 | 内容 |
|---|---|
| 身份 | 旧渡识字先生，处理渡册与临时名册的人 |
| 想要什么 | 让该被记住的人不被省掉，也让活人不要被名字害死 |
| 害怕什么 | 自己写过、删过、隐过的名字最终变成还不清的债 |
| 相信什么 | 写字的人不能只想着字，要想着字后面站着谁 |
| 说不出口的事 | 他可能知道旧册、删名和官粮旧事，但序章不说透 |
| 记忆点 | 敲案、停笔、看木牍；说话慢，每句都有重量 |
| 让玩家可能喜欢的地方 | 他懂记录的重量，愿意教主角承担 |
| 让玩家可能不舒服的地方 | 他总是有所保留，不把旧事一次说清 |
| 可能种下的因 | 无名录、删名旧案、韩宁旧册、主角写名启蒙 |

## 5. 禾安

| 字段 | 内容 |
|---|---|
| 身份 | 旧渡长大的邻家伙伴，熟悉灶、水、柴、米和旧渡日常 |
| 与主角关系 | 从小一起在旧渡长大的同龄伙伴，像本世生活里的熟人锚点；不是恋爱关系，也不发展恋爱线 |
| 叙事功能 | 把主角从裂钟、名册和抽象问题拉回灶火、米袋、伤者和眼前的人 |
| 想要什么 | 旧渡和眼前这些人都能撑过这一夜 |
| 害怕什么 | 外来人救了，本地人也被拖垮；救人的代价最后落在旧渡各户身上 |
| 相信什么 | 人先活过今晚，明早的账明早再算 |
| 说不出口的事 | 她也怕饿，也怕旧渡被牵连，但不愿显得冷血 |
| 记忆点 | 数水瓮、数米袋、倒碎米、拨灶火；嘴上现实，手上不慢 |
| 让玩家可能喜欢的地方 | 不讲大义，但会做事；熟悉主角，却不围着主角转 |
| 让玩家可能不舒服的地方 | 她会把救人的代价算清楚，不让玩家沉浸在廉价善良里 |
| 可能种下的因 | 旧渡存粮、粮债、本地人与流民的后续关系 |

## 6. 韩宁

| 字段 | 内容 |
|---|---|
| 身份 | 宋地流民少年，愿意说出现名，不愿说旧里 |
| 想要什么 | 让母亲和妹妹活下去，也保护父亲留下的残简 |
| 害怕什么 | 旧里、父名和残简被对上，牵连还活着的人 |
| 相信什么 | 有些名字不能给陌生人 |
| 说不出口的事 | 韩宁的父亲和旧册有关；那包残简可能不是普通身份证明 |
| 记忆点 | 听见旧里、父名时按住袖中木片；看人时像被逼到墙角的兽 |
| 让玩家可能喜欢的地方 | 倔强，护着家人，不轻易求饶 |
| 让玩家可能不舒服的地方 | 他隐瞒信息，让旧渡也一起承担风险 |
| 可能种下的因 | 旧臣遗孤、旧册、无名录、后世家族线 |

## 7. 韩宁的母亲

| 字段 | 内容 |
|---|---|
| 身份 | 宋地流民妇人，保护韩宁和残简 |
| 想要什么 | 孩子活下去；残简不被夺走；旧里不被追索 |
| 害怕什么 | 韩宁父亲的旧册旧事被人重新串起 |
| 相信什么 | 有些话不说，是为了让人活 |
| 说不出口的事 | 她知道的比韩宁更多，但序章只表现为阻止追问 |
| 记忆点 | 听见追问父名时下跪；守在韩宁身旁；先按住木片 |
| 让玩家可能喜欢的地方 | 护子，坚决，能立刻判断危险 |
| 让玩家可能不舒服的地方 | 她阻断信息，使辛衡和旧渡都难以完整登记 |
| 可能种下的因 | 韩宁父亲旧册线、残简无法合并、后续旧里追索 |

## 8. 柳娘

| 字段 | 内容 |
|---|---|
| 身份 | 跟流民同行的戏班班主 |
| 想要什么 | 让今晚还活着的人不要被恐惧压垮 |
| 害怕什么 | 一句地名唱出口，会暴露来处，牵连活人 |
| 相信什么 | 戏能安人，也能害人；唱与不唱都有代价 |
| 说不出口的事 | 她也知道删去地名像是再次抹去故乡 |
| 记忆点 | 唱到地名处停顿；戏箱垫在漏风处；发簪插得很正 |
| 让玩家可能喜欢的地方 | 有分寸，懂人心，有风骨 |
| 让玩家可能不舒服的地方 | 她为了保护活人，主动让旧曲残缺 |
| 可能种下的因 | 亡国旧曲、后世禁曲、戏台回响 |

## 9. 船主

|---|---|

| 想要什么 | 把船和人带过这一段路，不被任何一方关验扣住 |

| 可能种下的因 | 宋亡消息入口、二十三户流民、旧里不能写规则 |

## 10. 帮忙登记的渡户

| 字段 | 内容 |
|---|---|
| 身份 | 旧渡普通人，帮辛衡登记，但不完全理解隐名风险 |
| 想要什么 | 把事情问清楚，免得旧渡担责 |
| 害怕什么 | 旧渡收留不明来人后被牵连 |
| 相信什么 | 问清楚才好处理 |

## 11. 关系写作禁区

序章及后续第一章写禾安时，明确禁止：

```text
把禾安写成恋爱对象。
把禾安写成女主候选。
用暧昧推进她和主角的关系。
让她的行动动机围绕“喜欢主角”。
```

禾安和主角的关系应当是：

```text
旧渡共同长大的同龄伙伴。
熟悉、嘴硬、互相知道对方家里的事。
她会喊主角帮忙，也会怼主角发呆。
她的核心价值不是恋爱陪伴，而是现实锚点。
```
