# 序章《雨来之前》定位与边界 V0.1

## 1. 序章定位

序章《雨来之前》不是第一章八幕结构的一部分。

它位于第一章 ACT01 之前，负责让玩家在进入第一个高压选择前，先明确：

```text
我这一世是谁。
我住在哪里。
我身边有哪些具体的人。
宋亡为什么会来到旧渡。
名字、旧里、故邑和名册为什么危险。
裂钟为什么是唯一超出本世经验的异常。
```

序章的核心任务不是制造复杂分支，而是建立玩家的情感立足点。

玩家不能一上来像一个漂浮的系统视角替陌生人做选择。玩家必须先成为洛水旧渡里一个十岁的孩子，有母亲、有未归的父亲、有辛衡先生、有禾安、有旧渡生活，然后再被宋亡流民和裂钟异常推入第一章。

## 2. 本世身份边界

序章必须明确主角这一世的现实身份：

```text
年龄：十岁
居处：洛水旧渡
家庭：你的父亲随官运粮后未归；你的母亲在旧渡维生并等待
关系：辛衡是识字先生；禾安是从小一起长大的邻家伙伴
能力：能辨简单姓名、数目和渡册，不具备超时代知识
```

主角不是全知穿越者。

主角知道本世姓名，也知道本世生活，但不知道裂钟记忆从何而来。

## 3. 史实锚点

序章使用前 286 年宋亡作为现实入口。

宋亡不以宏大战争场面呈现，而是通过东来商船、关验变化、二十三户宋地流民、旧里隐名和旧册风险进入旧渡。

重点不是让玩家背诵历史，而是让玩家理解：

```text
一个国家的灭亡，会以船、病人、孩子、湿简、米袋和名册的形式落到普通人面前。
```

## 4. 隐名规则

序章必须讲清楚：

不是不能说“宋地来人”。

危险的是说到能被追索的程度：

```text
某邑
某里
某户
旧姓
父名
田属
债役
仍在原地的亲属
```

这些信息一旦写进册子，就可能被旧主、新主、债主、豪强或逃散旧吏用来追人、追田、追债、追役、追证据。

因此隐名不是故弄玄虚，而是乱世中现实的生存规则。

## 5. 人物边界

序章人物必须遵守 `docs/13_人物塑造规则_V0.1.md`。

- 禾安不能写成圣母。她嘴上现实，手上不慢，知道代价，也见不得人死在眼前。
- 辛衡不能写成全知导师。他懂记录，也害怕记录。他有旧事，但序章不说透。
- 韩宁不能写成单纯可怜人。他想被承认，又不敢说旧里，因为残简和父辈旧册会牵连活人。
- 柳娘不能写成装饰性戏子。她唱旧曲安人，也在地名处停顿。
- 主角的母亲不需要大量台词。她望向河道尽头，玩家就能明白她在等谁。
- 主角的父亲暂时不登场，只留下官粮、未归和新笔承诺。

## 6. 序章不能提前说透的内容

序章只能埋线，不能揭底。

不能直接说透：

```text
韩宁的父亲到底做过什么。
那些残简为什么不能合在一起。
辛衡是否曾经删过名字。
主角的父亲是否卷入旧仓或官粮旧案。
裂钟到底是什么。
苏醒机制为何出现，以及它为何总让不同历史位置的经验短暂重叠。
```

序章只允许让玩家感觉：

```text
这些事互相有关。
但暂时还看不出会缠成什么。
```

## 7. 交给 ACT01 的结果

序章结束时，必须自然进入 ACT01《雨后流民》的第一组高压选择：

```text
车翻了。
孩子被压在车辕下。
湿简散在泥水里。
流民需要互认。
主角手里有空木牍。
裂钟异常尚未解释。
```

ACT01 的第一选择应当围绕：

```text
先救车下的孩子；
先抢泥水里的湿简；
还是先让还活着的人彼此认出彼此。
```

这三个选择不代表善恶，而代表救命、留证和共同见证三种代价。
