# 序章《雨来之前》章节包索引

> 内容位置：第一章《礼崩之世》之前。  
> 功能定位：建立本世身份、旧渡生活、主角家庭、宋亡流民、隐名风险、韩宁旧册悬念和裂钟异常。  
> 注意：序章不计入第一章八幕结构，但它是玩家进入第一章 ACT01 的情感与信息入口。  
> 制作方向：正式序章应按“动画化叙事 + 轻探索 + 少量关键选择”制作，而不是高频选择题关卡。

## 文件结构

```text
PROLOGUE_雨来之前/
├── README.md

```

## 使用顺序

1. 先读 `00_序章定位与边界_V0.1.md`，确认序章不承担八幕主线，只负责让玩家落地。
2. 再读 `01_主线大纲_V0.1.md`，确认序章十一段剧情推进。
3. 再读 `02`—`04`，确定人物、伏笔、因果和记忆碎片。
4. 以 `05_故事剧本_V0.1.md` 作为文本打磨基础。
5. 用 `06_至ACT01_雨后流民_过渡文_V0.1.md` 连接到第一章 ACT01 的第一组高压选择。
6. 制作可玩正式版序章前，必须读 `07_动画化叙事与轻交互规格_V0.1.md`，确认动画化叙事、轻探索和关键选择节奏。

## 与第一章的关系

序章交给第一章 ACT01 的内容包括：

```text
玩家本世姓名
你的母亲与未归父亲
辛衡与禾安的前置关系
宋亡消息
二十三户宋地流民
韩宁现名与残简
柳娘旧曲停顿
隐名规则 / 名与籍
裂钟异常
第一辆/最后一辆车翻倒后的即时选择压力
```

序章结束时，玩家必须已经理解：

```text
我这一世是谁。
我在旧渡有牵挂。
名是称呼，籍是位置。
入册，是被承认，也是被追索。
宋亡不是抽象历史，而是眼前这些人的雨夜。
裂钟不是现实问题的解法，只是无法解释的异常。
```
