## 标准文件

### 序章章节包

序章独立于第一章八幕结构，采用：

```text
00_序章定位与边界_V0.1.md
01_主线大纲_V0.1.md
02_人物关系表_V0.1.md
03_因果与伏笔表_V0.1.md
04_记忆碎片表_V0.1.md
05_故事剧本_V0.1.md
06_至ACT01_雨后流民_过渡文_V0.1.md
07_动画化叙事与轻交互规格_V0.1.md
```

序章正式可玩版必须按 `07_动画化叙事与轻交互规格_V0.1.md` 执行：动画化叙事为主，轻探索为辅，关键选择只在真正有不可逆代价时出现。

### 前七章章节包

前七章统一采用：

```text
00_章节定位与史实边界_V0.1.md
01_主线大纲_V0.1.md
02_人物关系表_V0.1.md
03_职业线嵌入表_V0.1.md
04_因果节点表_V0.1.md
05_记忆碎片表_V0.1.md
06_故事剧本_V0.1.md
07_至下一章衔接过渡文_V0.1.md
```

第一章额外保留：

```text
README.md
08_名籍与人生主线架构_V0.1.md
09_关键人物星座原型_V0.1.md
12_ACT01_雨后流民详细剧本_V0.1.md
13_长平后归旧渡共用主线_V0.1.md
```

`README.md` 是第一章当前口径与阅读顺序入口。

`08` 用于统一“名与籍 / 入册 / 身籍”的表达，避免把第一章核心误读成单纯“写完整姓名”。

`09` 用于统一第一章关键人物的底层人格发动机、行动方式、阴影和动画关键词。星座只作内部原型，不在战国剧情中直接出现。

`12` 用于 ACT01《雨后流民》的详细可制作剧本，包含故事流程、分场剧情、人物行动、对话样例、选择项、轻调查、变量和 ACT02 接口。

`13` 用于所有职业线共用的“长平后归旧渡”主线节点，把长平伤口重新压回禾安、旧渡、童年、季良死讯、小时候一起喝粥的碗和无名录最终去向。

## 第一章当前职业线口径

第一章当前采用九条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
隐士。
```

“农人”不再作为独立职业线。

土地、粮水、田亩、空户、旧渡、灶火、没有米下锅和禾安，改为所有职业共同面对的现实地基。

已删除的第一章中间文档：

```text
10_主角立身与职业成形规则_V0.1.md
11_ACT年龄段路线交织与关键节点_V0.1.md
```

删除原因：内容已经归并进 `01 / 03 / 04 / 06 / 13`，继续保留会造成重复和旧口径冲突。

终章把职业嵌入改为全职业汇流、因果节点改为全局回收，并以开放式尾声代替下一章过渡。

## 使用顺序

1. 序章先读 `PROLOGUE_雨来之前/README.md`、`00` 和 `01`，确认本世身份、宋亡流民、隐名规则和裂钟异常。
2. 制作正式可玩序章前，必须读 `PROLOGUE_雨来之前/07_动画化叙事与轻交互规格_V0.1.md`，确认“动画化叙事 + 轻探索 + 少量关键选择”的节奏。
3. 第一章先读 `CH01_礼崩之世/README.md`，确认当前九职业口径、旧渡现实地基、长平后归旧渡和禾安粥碗节点。
4. 再读第一章 `00`、`08`、`01`、`06`，确认历史边界、名籍母题、完整主线和故事流向。
5. 再读第一章 `03`、`02`、`04`、`05`、`09`，确认职业、人物、因果、记忆和人物原型。
6. 制作 ACT01《雨后流民》时，继续读 `CH01_礼崩之世/12_ACT01_雨后流民详细剧本_V0.1.md`。
7. 制作长平后或 ACT08 时，必须读 `CH01_礼崩之世/13_长平后归旧渡共用主线_V0.1.md`。
8. 后续章节先读目标章节的 `README`、`00` 和 `01`，确认历史边界与固定历史结果。
9. 以故事剧本作为可制作文本基础，用过渡文生成章节或 ACT 之间的动态交接。

统一制作标准见 [`../09_章节包制作规范_V0.1.md`](../09_章节包制作规范_V0.1.md)。
