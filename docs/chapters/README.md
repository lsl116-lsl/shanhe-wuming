## 标准文件

前七章统一采用：

```text
00_章节定位与史实边界_V0.1.md
01_主线大纲_V0.1.md
02_人物关系表_V0.1.md
03_职业线嵌入表_V0.1.md
04_因果节点表_V0.1.md
05_记忆碎片表_V0.1.md
06_故事剧本_V0.1.md
07_至下一章衔接过渡文_V0.1.md
```

终章把职业嵌入改为全职业汇流、因果节点改为全局回收，并以开放式尾声代替下一章过渡。

## 使用顺序

1. 先读 `00` 和 `01`，确认历史边界与固定历史结果。
2. 再读 `02`—`05`，确定人物、职业、因果和记忆状态。
3. 以 `06` 作为可制作剧本基础。
4. 用 `07` 按主职业、人物命运、材料完整度和记录冲突动态生成跨章交接。

统一制作标准见 [`../09_章节包制作规范_V0.1.md`](../09_章节包制作规范_V0.1.md)。
