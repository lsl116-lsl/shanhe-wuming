## 标准文件

### 序章章节包

序章独立于第一章八幕结构，采用：

```text
00_序章定位与边界_V0.1.md
01_主线大纲_V0.1.md
02_人物关系表_V0.1.md
03_因果与伏笔表_V0.1.md
04_记忆碎片表_V0.1.md
05_故事剧本_V0.1.md
06_至ACT01_雨后流民_过渡文_V0.1.md
07_动画化叙事与轻交互规格_V0.1.md
```

序章正式可玩版必须按 `07_动画化叙事与轻交互规格_V0.1.md` 执行：动画化叙事为主，轻探索为辅，关键选择只在真正有不可逆代价时出现。

### 前七章章节包

前七章统一采用：

```text
00_章节定位与史实边界_V0.1.md
01_主线大纲_V0.1.md
02_人物关系表_V0.1.md
03_职业线嵌入表_V0.1.md
04_因果节点表_V0.1.md
05_记忆碎片表_V0.1.md
06_故事剧本_V0.1.md
07_至下一章衔接过渡文_V0.1.md
```

第一章额外增加：

```text
08_名籍与人生主线架构_V0.1.md
09_关键人物星座原型_V0.1.md
```

`08` 用于统一“名与籍 / 入册 / 身籍”的表达，避免把第一章核心误读成单纯“写完整姓名”。

`09` 用于统一第一章关键人物的底层人格发动机、行动方式、阴影和动画关键词。星座只作内部原型，不在战国剧情中直接出现。

终章把职业嵌入改为全职业汇流、因果节点改为全局回收，并以开放式尾声代替下一章过渡。

## 使用顺序

1. 序章先读 `PROLOGUE_雨来之前/README.md`、`00` 和 `01`，确认本世身份、宋亡流民、隐名规则和裂钟异常。
2. 制作正式可玩序章前，必须读 `PROLOGUE_雨来之前/07_动画化叙事与轻交互规格_V0.1.md`，确认“动画化叙事 + 轻探索 + 少量关键选择”的节奏。
3. 第一章先读 `CH01_礼崩之世/08_名籍与人生主线架构_V0.1.md`，再读 `CH01_礼崩之世/09_关键人物星座原型_V0.1.md`，确认“名与籍”母题与关键人物人格原型。
4. 再读第一章 `00` 和 `01`，确认历史边界与固定历史结果。
5. 后续章节先读 `00` 和 `01`，确认历史边界与固定历史结果。
6. 再读人物、职业、因果和记忆相关文件，确定人物状态与跨章材料。
7. 以故事剧本作为可制作文本基础。
8. 用过渡文生成章节或 ACT 之间的动态交接。

统一制作标准见 [`../09_章节包制作规范_V0.1.md`](../09_章节包制作规范_V0.1.md)。
