## 1. 组合推断

| 组合 | 得出 | 排除 |
|---|---|---|
| M01 + M04 + M06 | 世界变化由航路、制度、翻译与劳动共同进入 | “一个开眼者唤醒全民” |
| M02 + M05 + M08 | 国难、内乱与家庭代价不可分割 | “历史只有外部冲突” |
| M07 + M09 + M10 | 新主体在工场、女性组织和公共表达中形成 | “近代化只是官办机器史” |
| M03 + M11 + M12 | 苏醒者同时记得互相矛盾的位置 | 单一灵魂转世 |

## 2. 控制规则

- 记忆不直接冒用可识别历史名人第一视角。
- 外国人、官员、商人、农民、士兵等经验可以并置，但不能抹平权力差异。
- M12 只让玩家说出“我不止是一个人”，终极答案留给终章。
