## 4. 收敛与非收敛

- 收敛：所有职业都经历条约落实、内外战争压力、船政 / 工场新火与 1895 的危机判断。
- 不收敛：每条线的亲密人物、制度位置、高潮场景、必失项和交接材料保持独立。
- 未选职业由对应 NPC 推进简版命运；他们可能失败、妥协或取得局部成果，不能冻结。
- 高技能只能减少误差与浪费，不能取消不平等条约、财政约束、战争结果或政治结构。
