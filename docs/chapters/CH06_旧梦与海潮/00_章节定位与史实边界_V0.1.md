# 第六章《旧梦与海潮》章节定位与史实边界 V0.1

> 推荐主交互窗口：约 1835—1895 年
> 主空间：福州及闽江上下游、五口通商后的港区、茶山、炮台、船坞与相连内陆家户
> 章节责任：表现一个旧帝国面对工业化、全球贸易、殖民扩张和内部危机时的结构性失配；回答为何局部拥有知识、技术和能人，仍不足以组织整个社会走向未来。

## 1. 核心问题

```text
旧制度面对新世界时，为何逐渐失去组织未来的能力？
学习新的技术，是否必须接受强者写下的秩序？
战争、赔款、贸易和改革试错的成本，最终落在谁身上？
```

## 2. 史实锚点

- 1842 年《南京条约》后，福州成为五个通商口岸之一；条约不仅是外交文本，还改变港口贸易、税、城市空间和普通家庭生计。
- 鸦片贸易、禁烟与战争不可写成单一人物的道德戏。帝国贸易结构、白银、走私网络、成瘾者家庭、经办者和战争暴力共同作用。
- 太平天国战争持续十余年并波及多省；地方军事化、团练、军需、捐输、赈济与战后治理改变基层权力结构。
- 1866 年福建船政创办，关联船厂、学堂、工程、海军和技术人才培养；它证明晚清并非无人学习、无人制造，也暴露财政、制度、军政协调和长期工业体系的限制。
- 1895 年只作为本章晚年判断的历史门槛：局部器物改革没有自动转化为足以承担新时代的整体制度能力。

## 3. 史实边界

### 可以虚构

- 港口家庭、工匠、茶农、商人、艺人、基层官吏、士兵和船政工人。
- 一张由宋元海图多次续绘而来的民间图、一册火器失败工记、旧戏异本。
- 具体货栈、茶行、义渡、炮台小队、船坞工组和地方自救册。

### 不可改写

- 鸦片战争及不平等条约造成的主权损害和社会冲击。
- 太平天国战争、第二次鸦片战争与晚清内外交困的基本结果。
- 船政及早期近代工业、教育的历史存在。
- 1895 年前后旧制度危机进一步显露的方向。

### 禁止

- 不把战争归因于“闭关挨打”四字，也不淡化殖民侵略和不平等条约。
- 不把所有外国人写成同一张脸；个人可善良、贪婪、矛盾，但条约特权与武力结构不能被私人友谊洗白。
- 不把成瘾者写成懒惰笑料，不把禁烟简化成抓坏人。
- 不把太平天国战争只当作主角升级背景，要写平民参战、逃难、被征与互相伤害。
- 不让主角发明一艘船、一本书或一套改革方案就“提前救国”。
- 不让少数名臣、翻译者或工程师独占“开眼看世界”；水手、商人、工匠、茶农早已在接触变化。
