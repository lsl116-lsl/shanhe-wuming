# 第六章至第七章衔接过渡文《汽笛越过戏台》V0.1

## 1. 固定桥

旧戏唱了几十年，每次都在问谁能扶住将倾的山河。后来，戏台外的声音越来越多：船坞下工的铃、夜学翻书、报纸叫卖、铁路汽笛、乡民议事和士兵操练。

海图没有消失，它被铁路和电报线穿过；火器工记没有变成救国秘方，它被工人拿来比较事故；条约副本也没有停在签署那天，它继续出现在税、地、厂、港和一代人的愤怒里。

到了 1905 年前后，一张新桌子在旧戏台后台支起。桌上本不该属于同一故事的东西开始彼此认出：

- 条约地方执行副本；
- 船坞工资与伤亡名册；
- 海外来信和译报；
- 乡民自救册；
- 女工夜学课本；
- 被禁演又被重抄的旧戏新词。

它们没有自动组成“人民”。它们只让分散的人第一次看见：自己承受的问题与别人相连。

## 3. 人物分支模块

- **柳素**若建立家属会：她的账成为女性组织最早教材；若迁离，账由阿禾在异乡重抄；若旧栈覆灭，只剩一句“若干是谁家的称呼”。
- **梁七**若成为轮机工：船工经验进入技术课；若葬身，事故报告与家书人数冲突；若返乡，他把工场协作带进民船坊。
- **阿禾**若进入公共写作：第七章少年读到她署名课本；若退学，她的夜学仍留下多人笔迹；若遭压制，新一代先看到被裁掉的作者栏。
- **方识**与**格雷**的合作若公开平等边界，留下可复核术语；若用私人友情掩盖特权，后世先学会的是崇外或排外二选一。
- **周勇**与**茶娘**的关系决定第七章士兵、乡民初始互信；曾经的误伤必须进入名单，不可用共同目标洗掉。
- **苏棠**与**玉霜**若合作，当事人能同时保有隐私和声音；若决裂，医册只有编号，戏台只有夸张姓名。
- **何岚、罗机、陈录**分别交出资本、工艺、记录的权力问题；至少一份材料会控诉另一份的自我美化。

## 4. 记录冲突

### A. 谁带来了新知识

> 官办报告写主持者，外文合同写技术员，工册写师傅，学徒本写每一次拆装，水手说那条潮汐经验早在图纸之前。没有一项单独虚假，也没有一项足够完整。

### B. 改革为何受挫

> 有人归罪设备，有人归罪用人，有人归罪财政，有人归罪制度；工资册补上一句：工人连续欠薪三月。完整答案必须容纳这些层次，而不是选一个坏人。

### C. 谁在组织谁

> 官署说公局安民，乡民册说他们先自行分粮；商会说自己保航，船工合约说拒绝开船才换来安全；戏班说启发了观众，台下的改词本说观众早有自己的话。

## 5. 时间推进

```text
1895：危机判断与公共材料汇流
1898—1904：改制、报刊、学堂、商会与新组织不断试验
1905：废科举与新式教育门槛；一代少年进入新的公共空间
```

## 6. 第七章开场正文

【1905 年，一座连接学堂、码头、工场与乡路的城市】

少年在夜学点名册上发现三个重名：一个是船坞工人，一个是退伍兵，一个是从茶山来的脚夫。旧吏想删掉两个，女教员却在名字后添上工种、家乡和“本人自述”。

窗外，铁路汽笛越过旧戏台。台上正唱忠臣救国，后台工人把一句新词写在布景背面：

> “山河若要重写，不能还只等一个人的名字。”

桌上条约副本被雨打湿，字迹向船坞名册渗去。苏醒者触碰纸页，记忆不再来自遥远前世，而与教室里同时伸手按纸的人重合。

第七章《山河重铸》，开始。

## 7. 拼装顺序与验收

```text
固定桥
→ 主职业模块
→ 两名高影响人物
→ 一名关系破裂人物
→ 一组记录冲突
→ 时间推进
→ 第七章开场
```

- 必须同时保留一个局部改革成果和一个结构性未解问题。
- 必须出现工人、学生、士兵、乡民、女性组织者、商人、海外 / 翻译经验中的至少四类。
- 不得说这些人已经天然成为统一人民；第七章负责写他们如何建立联系、冲突、失败并形成共同主体。
- 不得把 1895—1905 写成只等待下一位英雄登场的空白。
