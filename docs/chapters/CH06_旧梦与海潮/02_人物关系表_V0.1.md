# 第六章《旧梦与海潮》人物关系表 V0.1

> 本章的人物不能被压成“守旧 / 开明”“中国 / 外国”“官 / 民”三组二元标签。每个人都在不平等的结构里拥有有限行动，也会因自保、野心、爱与恐惧伤害别人。

## 3. 角色主动性

- 阿禾即使未进入主职业，也会建立夜学；玩家只影响其规模、课程和安全。
- 梁七即使玩家拒绝新机器，也会尝试轮机；失败可能使他更开放或更排斥。
- 柳素不会因高亲密度无条件支持玩家抵押家庭资源。
- 格雷可以成为可靠同事，但不会替代本地工匠主导技术线，也不能以“好外国人”抹去条约结构。
- 何岚若认为玩家持续破坏信用，会独立撤资；她不是无限钱包。
- 茶娘在难民压力下可能做排外选择，必须通过共同规则而非说服检定解决。

## 4. 立体度验收

每名核心人物必须拥有：一个私人愿望、一个结构位置、一次自主选择、一次合理伤人、一次关系无法完全修复的后果。阵营标签不得替代人物弧光。
