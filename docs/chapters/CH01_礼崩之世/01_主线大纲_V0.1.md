# 第一章《礼崩之世》主线大纲 V0.2

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：根据 `08`、`10`、`11` 重整后的主线大纲  
> 叙事范围：战国晚期，约前 286 年至前 221 年  
> 人生范围：主角从 10 岁到约 75 岁，一章走完一段完整人生  
> 核心原则：主角必须立住，但不能被职业锁死；职业由一次次选择自然成形，路线分开后必须在历史伤口处交织回来。

## 1. 本章一句话

第一章写的是：

```text
一个在洛水旧渡长大的孩子，十岁时第一次写下自己的名字，也第一次看见别人的名与籍散在泥里。
他在之后六十五年里，被旧礼、新法、百家、商路、战争和统一一步步推向不同人生位置。
不管他成为医者、吏官、商贾、武将、戏子、农人、工匠、谋士、仕官或隐士，他最终都必须回答：一个人如何被时代写进秩序，又如何在秩序里保住自己不是数字。
```

## 2. 本章不能改变的历史结果

玩家不能改变：

```text
宋亡。
旧礼继续失效。
新法继续进入乡里。
上党风云与长平发生。
周亡。
秦统一。
```

玩家能改变：

```text
哪些人活下来。
哪些人被记住。
哪些人被牵连。
哪些 NPC 信任、疏远、离开、失踪或反向行动。
主角最终被哪一种职业责任磨成这一世的人。
无名录以何种形态进入第二章。
```

## 3. 主角固定主轴

不管职业如何变化，主角始终固定为：

```text
洛水旧渡长大的孩子。
十岁写下本世姓名。
父亲随官运粮后未归。
母亲一直望向河道尽头。
辛衡教他识字和理解名籍。
禾安把他拉回灶火、粮水、伤者和眼前的人。
韩宁和柳娘让他第一次理解隐名、旧里、旧曲和追索。
裂钟让他接触无法解释的前世回响。
```

主角的人格主轴：

```text
会称量。
会看见两边都有人。
害怕落错一笔。
记得那些被省掉的人。
会在犹豫之后承担选择。
```

他不是全知穿越者，不知道秦会统一，也不知道长平会怎样发生。他只能在这一世眼前的人身上，一层层理解历史。

## 4. 本章核心母题：名与籍

第一章不能再被理解成“把姓名写完整”。

本章核心是：

```text
名是称呼，籍是位置。
入册，是被承认，也是被追索。
```

每一幕都必须让主角对“名与籍”的理解加深一次：

| 阶段 | 主角理解 |
|---|---|
| 10 岁 | 写下姓名，是把自己放进这一世；但别人的名与籍可能正在泥里烂掉。 |
| 11—15 岁 | 救下来不等于结束，活人需要粮、水、棚位、承认和不被追索。 |
| 16—20 岁 | 旧称呼被重写为户、伍、什，新法让人获得位置，也让人被计算。 |
| 20—30 岁 | 不同学说和职业都能解释一部分痛苦，但没有一种能免除代价。 |
| 31—36 岁 | 名籍进入战争后，变成兵额、粮道、征发和死伤册。 |
| 37—50 岁 | 记录有罪，沉默也有罪；无名录开始成形。 |
| 50—65 岁 | 旧礼最后的象征崩塌，新秩序更能管理人，也更能追索人。 |
| 75 岁 | 天下有了一个名字，但一个人的名、籍和身后那一户活人仍无处安放。 |

## 6. ACT01：裂钟之梦 / 雨后流民

### 时间与地点

```text
前 286 年，主角 10 岁。
洛水旧渡、旧礼器库、渡口雨棚。
```

### 固定事件

```text
主角写下本世姓名。
母亲望向河道尽头。
辛衡解释名与籍的重量。
禾安以热水、柴、米和伤者把主角拉回现实。
宋亡流民抵达。
韩宁拒绝说旧里。
柳娘旧曲唱到地名处停住。
裂钟第一次响起。
雨夜翻车。
```

### 第一笔亏欠

翻车现场三方向：

```text
先救车下孩子。
先抢泥水湿简。
先让活人互认。
```

该选择只种倾向，不锁职业。

NPC 会自主行动：禾安救人，韩宁扑简，柳娘喊名，辛衡观察主角如何落下第一笔因果。

### 结尾状态

```text
玩家知道：救下来只是开始。
主角知道：别人的名与籍不是姓名问题，而是活人身后的网。
旧渡知道：收留流民会带来粮、水、责任和追索。
```

## 7. ACT02：旧礼无声 / 旧仓与旧册

### 时间与地点

```text
主角 11—15 岁。
旧渡、旧仓、流民棚区、辛衡书案、主角家。
```

### 固定事件

```text
流民暂住旧渡。
旧仓放粮与登记冲突出现。
旧渡本地户与流民的粮、水、棚位矛盾加深。
临时名册决定谁能领粮，也决定谁可能被追索。
父亲官粮线露出第一处裂缝。
辛衡旧册不再只是工具，而是债。
```

### 主角理解

```text
人救下来以后，还要活下去。
活下去需要位置。
有位置就可能被承认，也可能被找到。
```

### 关键节点：旧仓放粮

必须让玩家看见：

```text
不开仓，流民可能熬不过去。
开仓，旧渡本地户明早可能也断粮。
登记完整，发粮更有序，也可能让人被追索。
登记模糊，暂时护人，也可能让后续分粮失控。
```

### 路线积累

救治、记录、粮路、器物、乡土、言说、仕途、隐退、谋划等倾向继续累积。

父亲官粮线只露裂缝，不说透。

## 8. ACT03：旧国被重写 / 新法入乡

### 时间与地点

```text
主角 16—20 岁。
旧渡、乡里、县署外围、重新编户现场。
```

### 固定事件

```text
旧渡被重新编户。
旧称呼变成户、伍、什。
新法木牌钉入乡里。
田、役、债、罚、连坐进入日常。
公孙砚正式出现。
```

### 主角理解

```text
旧礼救不了旧渡。
新法不是单纯恶物。
新法能给人位置，也能让人变得可追索、可征发、可计算。
```

### 第一次职业邀请

不弹职业菜单，而由 NPC 和事件自然推来：

```text
县署、医棚、工坊、商路、乡里、学舍、迁民队、山中见证等入口开始出现。
```

## 9. ACT04：新法如刀 / 选择一双手

### 时间与地点

```text
主角 20—25 岁。
县署、旧渡、乡里、商路、学舍、工坊、医棚等职业分支场景。
```

### 固定事件

```text
主角开始半离开旧渡。
职业方向真正显形。
辛衡病重。
辛衡交托旧册、旧笔和未完成名单。
禾安不再只是童年伙伴，而成为旧渡现实压力的独立承担者。
```

### 核心规则

职业显形靠责任，而不是菜单。

```text
有人夜里敲门请你看伤。
有人让你补旧册缺口。
有人邀你走商路。
有人请你修车、桥、仓。
有人让你参与田亩和空户分配。
有人请你护送粮道或迁民队。
有人让你记录旧曲和口述。
有人让你进入新法执行现场。
有人让你保存见证而不入官档。
```

## 10. ACT05：百家灯火 / 辛衡老死

### 时间与地点

```text
主角 25—30 岁。
洛邑、学舍、商路、旧渡回望、辛衡病榻。
```

### 固定事件

```text
主角接触百家争鸣和不同人生答案。
荀白、申不疑、青缗等人物加深。
辛衡老死。
```

### 辛衡老死

辛衡的死要安静、有重量：

```text
雨停后的早晨。
书案上墨已经干了。
辛衡没有来开门。
案上留下半片未刮平的木牍。
木牍上没有遗言，只有几个没写完的名字。
```

意义：主角失去第一个教他“字后面站着人”的人。从此他必须自己决定哪些字该落、哪些字该空、哪些字只能换一种方式留下。

### 主角理解

```text
每一种学说都能解释一部分痛苦。
但没有一种学说能替具体的人承担全部代价。
```

## 11. ACT06：合纵连横 / 战争前夜

### 时间与地点

```text
主角 31—35 岁。
列国边境、商路、粮道、学舍、军役登记处、乡里征发现场。
```

### 固定事件

```text
合纵连横不断变化。
盟书、地图、粮道、征发和军籍连成战争机器。
上党风云逼近。
主角所在职业线被不同方式卷入。
```

### 关键节点：战前名单

必须出现一份战前名单：

```text
有的人名字完整，马上被征。
有的人名籍残缺，无法领粮。
有的人被写作逃亡。
有的人已经死了，却还在名册上。
有的人活着，却不敢出现。
```

主角理解：名籍已经从救济工具变成战争入口。

## 12. ACT07：长平血雾

### 时间与地点

```text
主角约 36 岁。
长平大战及其周边粮道、医棚、军籍、迁民、口述现场。
```

### 固定事件

```text
长平发生。
大量军籍、粮籍、死伤册失效。
活人与死人在记录中混杂。
重要 NPC 或职业线关键 NPC 死亡、失踪或留下不可逆创伤。
主角第一次真正看见一整代人被压成数字。
```

### 不可逆损失版本

根据路线不同，可触发：

```text
军旅相关 NPC 战死。
韩宁失踪、战死或被迫暴露旧籍。
柳娘戏班折损，她开始在“人名”处停住。
禾安旧渡线重创，她仍伸手，但不再相信一定够快。
公孙砚制度线受创，看见冷秩序也装不下这场死亡。
```

不得设计全员完美存活路线。

### 主角理解

```text
名字写得再整齐，也接不住所有死人。
不写，又会让他们彻底散掉。
```

这是无名录真正成形的节点。

## 13. ACT08：天下将一

### 时间与地点

```text
主角 37—75 岁。
长平余波、周亡、新秩序推进、秦统一、洛水旧渡回望。
```

### 固定事件

```text
幸存者回不去原来的家。
失踪者无法被确认为亡。
无名录逐渐成形。
周亡，旧礼最后象征崩塌。
秦统一，天下归一。
主角决定无名录去向。
```

### 无名录来源

不同职业提供不同材料：

```text
医者：伤者口供和临终姓名。
吏官：残缺名册、错籍和空籍。
商贾：路上见闻、关验记录、失踪名单。
武将：征发记录、阵前名单、战后无人认领者。
戏子：旧曲、口述、人名停顿。
农人：空户、田亩、迁民、无人收成的地。
工匠：车辙、器物、桥仓位置、裂钟物证。
谋士：盟书背后的代价。
仕官：制度档案中的缺口和删改痕迹。
隐士：不入官档的私人见证。
```

### 最终去向

```text
交给官档。
藏入民间。
托给旧曲和口述。
拆成数份。
埋回洛水与裂钟之间。
```

结尾问题：

```text
天下终于有了一个名字。
可一个人呢？
他的名，他的籍，他身后那一户活人，又该写在哪里？
```

## 14. 本章结束状态

第一章结尾时，玩家应当感觉：

```text
我不是选了一个职业。
我是一路这样选择，才活成了这个人。
```

主角带入第二章的不是职业称号，而是：

```text
无名录的形态。
裂钟的回响。
记录与沉默的亏欠。
一生中被他留下、错过、害到、保护过的人。
```
