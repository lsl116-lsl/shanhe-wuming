# 第一章《礼崩之世》主线大纲 V0.4

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：当前第一章主线总纲，八职业口径  
> 叙事范围：战国晚期，约前 286 年至前 221 年  
> 人生范围：主角从 10 岁到约 75 岁，一章走完一段完整人生  
> 核心原则：主角必须立住，职业由选择自然成形；路线分开后必须在长平、旧渡、粥碗和无名录处交织回来。

## 1. 本章一句话

第一章写的是：

```text
一个在洛水旧渡长大的孩子，十岁时第一次写下自己的名字，也第一次看见别人的名与籍散在泥里。
他在之后六十五年里，被旧礼、新法、百家、商路、战争和统一一步步推向不同人生位置。
中年时，他在长平看见无数人被压成数字。
长平后，他回到旧渡，面对禾安问丈夫阿梁的消息，却说不出口。
晚年秦统一前后，他再回旧渡，发现禾安已逝，只留下小时候一起喝过稀粥的碗。
他终于决定无名录的去向，不是为了消除亏欠，而是为了让那些没被说出口的人不至于彻底无名。
```

## 2. 当前职业线口径

第一章保留八条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”和“隐士”不再作为独立职业线。

```text
乡土地基：土地、粮水、田亩、空户、旧渡、灶火、没有米下锅和禾安。
隐退倾向：少介入、私藏见证、不入官档、晚年姿态。
```

## 3. 本章不能改变的历史结果

玩家不能改变：

```text
宋亡。
旧礼继续失效。
新法继续进入乡里。
上党风云与长平发生。
周亡。
秦统一。
```

玩家能改变：

```text
哪些人活下来。
哪些人被记住。
哪些人被牵连。
哪些 NPC 信任、疏远、离开、失踪或反向行动。
主角最终被哪一种职业责任磨成这一世的人。
无名录以何种形态进入第二章。
```

## 4. 主角固定主轴

不管职业如何变化，主角始终固定为：

```text
洛水旧渡长大的孩子。
十岁写下本世姓名。
父亲随官运粮后未归。
母亲一直望向河道尽头。
辛衡老伯教他识字和理解名籍。
禾安把他拉回灶火、粮水、伤者和眼前的人。
韩宁和柳娘让他第一次理解隐名、旧里、旧曲和追索。
裂钟让他接触无法解释的前世回响。
```

主角的人格主轴：

```text
会称量。
会看见两边都有人。
害怕落错一笔。
记得那些被省掉的人。
会在犹豫之后承担选择。
```

他不是全知穿越者，不知道秦会统一，也不知道长平会怎样发生。他只能在这一世眼前的人身上，一层层理解历史。

## 5. 本章核心母题：名与籍

第一章核心是：

```text
名是称呼，籍是位置。
入册，是被承认，也是被追索。
```

每一幕都必须让主角对“名与籍”的理解加深一次：

| 阶段 | 主角理解 |
|---|---|
| 10 岁 | 写下姓名，是把自己放进这一世；但别人的名与籍可能正在泥里烂掉。 |
| 11—15 岁 | 救下来不等于结束，活人需要粮、水、棚位、承认和不被追索。 |
| 16—20 岁 | 旧称呼被重写为户、伍、什，新法让人获得位置，也让人被计算。 |
| 20—30 岁 | 不同学说和职业都能解释一部分痛苦，但没有一种能免除代价。 |
| 31—36 岁 | 名籍进入战争后，变成兵额、粮道、征发和死伤册。 |
| 37—40 岁 | 主角回旧渡，看见死伤册上的一个名字变成禾安问出口的一句话。 |
| 40—75 岁 | 记录有罪，沉默也有罪；无名录不断成形，但主角一直没有再回旧渡。 |
| 75 岁 | 天下有了一个名字，但一个人的名、籍、死讯和身后活人仍无处安放。 |

| ACT | 标题 | 年龄段 | 核心历史 / 人生节点 | 主线功能 |

## 7. ACT 关键流向

### ACT01：裂钟之梦 / 雨后流民

固定事件：

```text
主角写下本世姓名。
宋亡流民抵达。
韩宁拒绝说旧里。
柳娘旧曲唱到地名处停住。
裂钟第一次响起。
雨夜翻车。
禾安把一锅粥熬得像水，旧碗第一次出现。
```

翻车现场三方向：

```text
先救车下孩子。
先抢泥水湿简。
先让活人互认。
```

该选择只种倾向，不锁职业。

### ACT02：旧礼无声 / 旧仓与旧册

旧仓放粮不能写成善恶选择。必须让玩家看见：

```text
不开仓，流民可能熬不过去。
开仓，旧渡本地户明早可能也断粮。
登记完整，发粮更有序，也可能让人被追索。
登记模糊，暂时护人，也可能让后续分粮失控。
```

### ACT03：旧国被重写 / 新法入乡

旧渡被重新编户。新法给人位置，也让人被计算。

公孙砚正式出现。禾安不参与宏大辩论，只问粮、水、役落到谁家。

### ACT04：新法如刀 / 选择一双手

职业显形靠责任，不靠菜单。

```text
有人夜里请主角看伤。
有人让主角补旧册缺口。
有人邀主角走商路。
有人请主角修车、桥、仓。
有人让主角护送迁民队。
有人让主角记录旧曲和口述。
有人让主角进入新法执行现场。
有人让主角保存不入官档的见证。
```

辛衡老伯病重并交托旧册、旧笔和未完成名单。

### ACT05：百家灯火 / 辛衡老伯老死

荀白、申不疑、青缗等人物加深。辛衡老伯老死。

主角发现：

```text
每一种学说都能解释一部分痛苦。
但没有一种学说能替具体的人承担全部代价。
```

### ACT06：合纵连横 / 战争前夜

必须出现战前名单：

```text
有的人名字完整，马上被征。
有的人名籍残缺，无法领粮。
有的人被写作逃亡。
有的人已经死了，却还在名册上。
有的人活着，却不敢出现。
```

梁成在此阶段被征。禾安日常称他“阿梁”。他不是英雄，而是旧渡普通丁壮。重点是：他正因为有名、有籍、有户，所以被征发准确找到。

### ACT07：长平血雾

长平发生。八职业从不同入口进入同一历史伤口。

主角领悟：

```text
名字写得再整齐，也接不住所有死人。
不写，又会让他们彻底散掉。
```

### ACT07 后：归旧渡

主角回旧渡，见到已经成家的禾安。

禾安问：

```text
阿梁。旧渡梁氏，去年随征走的。
你路上，听过没有？
```

主角知道或高度怀疑梁成已经死了，但说不出口，只能说：

```text
我……去查查看。
```

两人聊到小时候的流民、韩宁、没米下锅和那只旧碗。

主角此后直到晚年都没有再回旧渡。

### ACT08：天下将一

秦统一。主角约 75 岁。

主角决定无名录去向前，终于回旧渡。

禾安早已离世。她没有等主角回来，也没有把自己活成主角的遗憾。

她留下：

```text
那只小时候一起喝过稀粥的碗。
倒扣过很多次的旧锅。
补过的热水桶。
一块刻着“梁”字的旧木片。
```

有人转述：

```text
她后来不问了。
只说，没消息的人，也得留一口饭。
```

这只碗成为无名录最终决定前的最后一根针。

## 8. 无名录五种去向

最终选择可根据职业线和 NPC 关系出现不同选项。

```text
交给官档：秩序承认，但可能被删改或追索。
藏入民间：保护活人，但难以被后世正式承认。
托给旧曲和口述：有温度，但可能失真。
拆成数份：减少一次性毁灭风险，但完整性降低。
埋回洛水与裂钟之间：保留神秘回响，但等同把答案交给未来。
```

无论选择哪一种，都不能消除主角亏欠。

## 9. 本章结束状态

第一章结尾时，玩家应当感觉：

```text
我不是选了一个职业。
我是一路这样选择，才活成了这个人。
```

主角带入第二章的不是职业称号，而是：

```text
无名录的形态。
裂钟的回响。
记录与沉默的亏欠。
一生中被他留下、错过、害到、保护过的人。
禾安留下的粥碗所代表的旧渡现实地基。
```
