# 第一章《礼崩之世》名籍与人生主线架构 V0.1

> 文档目的：修正第一章核心表达，避免把“名字”误解为单纯姓名。第一章真正写的是“名与籍”：一个人如何被社会承认，又如何被秩序追索。  
> 适用范围：第一章主线、序章衔接、ACT01—ACT08、人物台词、因果节点、记录系统。

## 1. 核心修正

后续不再把第一章核心概括为“把名字写全”。

这个说法容易让玩家误解成：

```text
把姓名两个字写完整。
```

第一章真正要写的是：

```text
一个人被写进社会秩序里的完整位置。
```

也就是：

```text
他叫什么；
他从哪一邑哪一里来；
他是谁家的孩子；
他的父母是谁；
他的妻儿是谁；
他家还有谁留在原地；
他名下有没有田；
他欠不欠债；
他有没有役；
谁能顺着这条记录找到他和他身后的人。
```

因此，第一章后续应统一使用以下概念：

```text
名：别人怎么叫你。
籍：官府怎么找到你。
入册：一个人被秩序承认，也被秩序牵住。
写全身籍：不只是写姓名，而是写出故里、父母、亲属、田亩、债役和可追索关系。
```

最简短的剧情表达是：

```text
名是称呼，籍是位置。
```

或者：

```text
名字只是线头。
一入册，后面牵着的就是一户人。
```

## 2. 第一章真正的问题

旧表述：

```text
人的名字，到底应该怎样被留下？
```

修正为：

```text
一个人被写进册子时，留下的是他自己，还是他身后整张网？
```

更适合作为第一章前半段母题的是：

```text
入册，是被承认，也是被追索。
```

第一章不是只问“谁叫什么”，而是问：

```text
谁有资格被承认？
谁会因为被承认而被找到？
谁被写成一户？
谁被写成一役？
谁被写成一个数字？
谁被从社会位置中抹去？
```

## 3. 对韩宁线的修正

韩宁不怕说出“韩宁”这个现名。

他真正怕的是：

```text
韩宁这个名字后面的身籍被写全。
```

一旦写全，别人就能顺着这条线找到：

```text
韩宁的旧邑；
韩宁的旧里；
韩宁的父亲；
韩宁的母亲；
韩宁的妹妹；
韩宁父亲管过的旧册；
仍留在原地的人；
曾经替他们开门、藏粮、改名的人。
```

所以韩宁的核心矛盾不是“愿不愿意说名字”，而是：

```text
他需要被承认，才能领水、领粮、被救济、被安置；
但他又不能被完整入册，因为完整入册会把他身后的人一并暴露。
```

## 4. 对辛衡线的修正

辛衡不是单纯教主角“写名字”的先生。

他教主角的是：

```text
字落入册，才开始变重。
```

辛衡以后解释时应避免空泛说“名字会害人”，改成更清楚的表达：

```text
名字本身不害人。
害人的是名字后面连着的籍。
```

或：

```text
官府问的不是你叫什么。
官府问的是你是哪一里的人，是谁家的子，名下有没有田，身后还有谁。
这些一写进册子，找的就不只是你一个人了。
```

辛衡的停笔不只是因为“这个名字该不该写”，而是因为：

```text
这条身籍一旦写全，会有多少活人被牵出来。
```

## 5. 对主角成长线的修正

第一章主角不是从“想把名字写清楚”成长为“记录者”。

更准确的成长线是：

```text
10岁：他以为写下姓名，就是知道自己是谁。

15岁：他发现入册不只是姓名，而是一个人在社会中的位置。

25岁：他发现身籍能救人，也能让官府、债主和军役找到人。

36岁：他在长平发现，战争会把一整户、一整里、一整伍的人都压成数字。

75岁：他不再相信存在一种完全无害的记录方式，但仍不愿让无名者彻底消失。
```

主角最终成长为：

```text
一个知道记录有罪、沉默也有罪的人。

他不再轻易说“把名字写下来就能救人”。

他只知道：不写，有些人永远不会被承认；写全，有些活人会被顺着册子找到。
```

## 6. 第一章年龄与阶段架构

| 阶段 | 年龄 | 历史 / 剧情核心 | “名与籍”在此阶段的含义 |
|---|---:|---|---|
| 序章《雨来之前》 | 10 | 写下本世姓名，宋亡消息到来 | 名字先让主角落地，但韩宁让主角看见姓名后面还有身籍 |
| ACT01《裂钟之梦》 | 10 | 翻车、湿简、救人、互认 | 湿简里散落的不只是名字，而是来处、亲属和能否被安置的凭证 |
| ACT02《旧礼无声》 | 11—12 | 旧仓、旧册、隐名后果 | 不入册可能无粮，入册可能被追索 |
| ACT03《旧国被重写》 | 15—18 | 新籍、新法、旧渡改编 | 旧国身籍被新政权重写，人从旧称呼变成新户口 |
| ACT04《新法如刀》 | 18—25 | 新法进入乡里，职业入口展开 | 身籍开始连接授田、连坐、征发和军功 |
| ACT05《百家灯火》 | 25—32 | 游学、辩论、列国道路 | 学说不再只是道理，它们都要落到人如何被编户、治理和救济 |
| ACT06《合纵连横》 | 32—35 | 盟书、粮道、战争逼近 | 地图和数字把一户户人变成军粮、兵额和徭役 |
| ACT07《长平血雾》 | 35—36 | 长平大战与无名者 | 大量身籍断裂，死者、失踪者、逃亡者不再能被完整确认 |
| ACT08《天下将一》 | 37—75 | 战后余生、周亡、秦统一 | 天下归一以后，名籍更统一，也更能追索每一个人 |

## 7. 第一章最终问题

第一章最终不要只问：

```text
这些名字有没有留下？
```

而要问：

```text
这些人，是否还被当作一个具体的人留下？
```

秦统一之后，天下会拥有更统一的法令、道路、文字、度量衡和户籍。

这既是乱世结束的一部分，也是下一章问题的开始：

```text
统一以后，人真的安定了吗？

当天下终于有了一个名字，一个普通人还能不能保住自己的位置？
```

## 8. 术语替换规则

后续修订时，优先按下表替换：

| 原说法 | 建议替换 |
|---|---|
| 把名字写全 | 写全身籍 / 写进完整册籍 / 把这个人连同来处一起写进去 |
| 名字会害人 | 名字后面连着的籍会害人 / 入册会牵出身后的人 |
| 名字被留下 | 名与籍被留下 / 这个人被承认为某一户、某一里的人 |
| 名字被抹去 | 身籍断裂 / 从册子和关系网里被抹掉 |
| 记住名字 | 记住他是谁、从哪里来、身后还有谁 |

## 9. 剧情台词范式

辛衡可用：

```text
“名是称呼，籍是位置。”

“你在渡口喊一声韩宁，来的是一个人。”

“可你在册上写全韩宁的身籍，找来的就可能是官差、债主、旧主，也可能是一把刀。”
```

韩宁可用：

```text
“韩宁这个名，我可以说。”

“可你若问我是哪个里的人，问我父亲是谁，问我家还剩谁——那就不是问我一个人了。”
```

禾安可用：

```text
“写不写我不懂。”

“我只知道，册子上多一户，明早就多一张嘴；册子上少一户，今晚就少一个能领水的人。”
```

主角暮年可用：

```text
年轻时，我以为人要有名。

后来才知道，人还要有籍。

再后来才知道，有名有籍，也未必能保住一个人。
```

## 10. 第一章结尾的修正表达

原结尾方向：

```text
天下终于有了一个名字。
可人呢？
```

可保留，但要在前文铺垫“名与籍”。最终可以升级为：

```text
天下终于有了一个名字。

可一个人呢？

他的名，他的籍，他身后那一户活人，又该写在哪里？
```
