# 第一章《礼崩之世》故事剧本 V0.4

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 剧本题名：《钟裂于洛水》  
> 文档状态：当前第一章完整故事流向，八职业口径  
> 剧本定位：从 10 岁到 75 岁的一段完整人生；根据玩家选择形成八条职业线，并在长平、归旧渡、无名录、秦统一处汇总。

## 1. 剧本总原则

第一章不是职业副本集合。

第一章写的是：

```text
同一个主角，从洛水旧渡十岁写名开始，被一次次选择磨出不同人生位置。
```

玩家不是开局选择职业。

玩家是在一路处理问题后，回头发现：

```text
原来我这一世，是这样活成这个人的。
```

第一章保留八条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”改为乡土地基，“隐士”改为隐退倾向。

```text
乡土地基：旧渡、禾安、粮水、田亩、空户、灶火、没有米下锅、粥碗。
隐退倾向：少介入、私藏见证、不入官档、晚年去向。
```

## 2. 完整故事主线

### 2.1 十岁：名字落进雨里

前 286 年，主角十岁，在洛水旧渡写下本世姓名。

父亲早一年随官车运粮后未归。官册里没有写“亡”，也没有写“逃”。母亲每日数米、数柴、补衣、烧水，偶尔望向河道尽头，却从不说自己在等。

辛衡老伯教主角识字。他告诉主角：

```text
名不是只给人叫的。
名一落进册里，后面就会连出籍。
籍后面有旧里、父母、田亩、债役、粮、罪，还有人会顺着找。
```

禾安抱柴进来，打断主角发呆：

```text
字写完没有？写完就来端水。
人饿着，字不能下锅。
```

当晚，宋亡消息随雨水抵达旧渡。二十三户宋地流民逃来。韩宁袖中藏着木片，不愿说旧里。柳娘带着破戏箱，用旧曲安住孩子，却在唱到地名处停住。

旧礼器库里的裂钟发出不该有的响。

渡口外，最后一辆流民车翻进泥里。

车下压着孩子和老人。泥里散着湿简。人群将散。禾安第一个冲出去，韩宁扑进泥里找湿简，柳娘喊人互认，辛衡老伯撑着木牍试图分辨谁还活着。

主角手里一边是空木牍，一边是热水。

他第一次必须选择先做什么：

```text
先救车下孩子。
先抢泥水湿简。
先让活人互认。
```

无论选择什么，都有人因此得救，也有人因此被耽误。

雨停一阵后，辛衡老伯问：

```text
这一笔，你先落在哪儿了？
```

那一夜，旧礼器库变成临时医棚。旧鼎、残钟、礼器被推到墙边，给伤者让出地方。辛衡老伯摆案，要记今晚还活着的人。流民不愿说旧里，本地户担心不登记就分不清粮和责任。

禾安把一锅粥熬得像水。那只旧碗第一次出现。它可能被主角和禾安分过一口，也可能被递给车下孩子、韩宁母亲或某个流民老人。

到天亮时，辛衡老伯合上临时册。禾安把空锅倒扣。韩宁按紧袖口。柳娘停在一句没唱完的旧曲上。

主角第一次知道：

```text
人还没有救完，名字已经开始伤人。
```

### 2.2 十一到十五岁：救下来以后

流民没有因为被拖进旧礼器库就安全。

他们要吃饭，要避雨，要领粮，要找失散的人，也要躲开可能追来的官府和旧主。

旧仓成了第一场真正冲突。

```text
不开仓，流民熬不过去。
开仓，本地户明日可能断粮。
写全名册，粮能分得清楚，但人也可能被追索。
写得模糊，能暂时护人，却会让分粮和寻亲失控。
```

禾安每天都在算米、柴、水、棚位。她不是只会救人，她知道善良要有米下锅。

父亲官粮线也露出第一处裂缝。主角在旧仓木牌上看见像父亲车队的记号。母亲听见车队名时，手里的米勺停住。辛衡老伯看见旧粮符后把木牍收进袖中。

主角第一次感觉到：

```text
有些空白不是没有字，是有人不敢写。
```

### 2.3 十六到二十岁：旧渡被重新写过

新法入乡，旧渡被重新编户。

从前人们叫“河东那家”“辛衡老伯案边那个孩子”“禾安家灶边”，现在要写成户、伍、什。门上钉新木牌，田亩、役责、罚则、连坐一并落下。

公孙砚来到旧渡。他不是反派。他真心相信：

```text
没有户籍，粮发不下去。
没有法度，乱世停不住。
没有征发，边地守不住。
没有一套冷的东西，死的人会更多。
```

禾安只问：

```text
这一户写上去，明年多出几日役？
那一户男人没回来，田算谁种？
你们钉木牌，粮会跟着来吗？
```

主角在这里看见新法的两面：它让人被承认，也让人被计算、被追索、被征发。

职业邀请开始出现。公孙砚让主角去县署看看；老医者让主角夜里守伤者；青缗递给他关验木牌；工匠鲁砚让他扶住车轴；柳娘让他听不能唱全的旧曲；南郭生告诉他，有些东西不入官档，也不该消失。

主角还没有选择职业。但别人已经开始因为他过去做过的事，把不同责任递到他手里。

### 2.4 二十到二十五岁：一双手

主角开始半离开旧渡。

职业不是菜单，而是某天有人来敲门：

```text
有人抱着伤者来找他。
有人把旧册缺口推到他面前。
有人让他走一趟断粮路。
有人让他扶住快塌的桥梁。
有人请他护送迁民队。
有人让他学会把危险地名藏进节拍。
有人让他在几方之间转圜。
有人让他进入新法执行现场。
有人把不入官档的见证交给他。
```

同一时期，辛衡老伯病重。他咳得写不稳字，墨在木牍上晕开。他把旧笔、残册和一份未完成名单交给主角。

```text
我老了。
有些名字等不到我写了。
```

主角问哪些该写。

辛衡老伯说：

```text
我若知道，就不会欠这么多。
```

禾安也在这一段彻底从童年伙伴变成独立活着的人。她开始真正撑旧渡的现实压力。她不等主角，不围着主角转。她继续数米、数柴、数人。

### 2.5 二十五到三十岁：百家灯火，辛衡老伯老死

主角进入更大的世界。

荀白喜欢发问，能把旧礼、新法、仁义、功利都拿出来辩。申不疑看问题像看结构，相信天下必须被重新安排。青缗让主角看见，粮、盐、药、布、关验和消息，往往比道理更早决定一个人能不能活到明天。

主角不是听完百家就懂了。他只是越来越清楚：

```text
每一种学说都能解释一部分痛苦。
但没有一种学说能替具体的人承担全部代价。
```

然后，辛衡老伯死了。

雨刚停。书案上墨已经干了。辛衡老伯没有来开门。主角推门进去，看见半片未刮平的木牍，木牍上没有遗言，只有几个没写完的人名。

从这一天起，主角不能再把“写不写”推给辛衡老伯。

### 2.6 三十一到三十五岁：战争前夜

上党风云逼近。合纵连横反复变化。盟书、地图、粮道、征发、军籍开始连成战争机器。

必须出现一份战前名单。

名单上：

```text
有人名字完整，所以马上被征。
有人名籍残缺，所以领不到粮。
有人被写作逃亡。
有人已经死了，却还在册上。
有人活着，却不敢出现。
```

梁成在此阶段被征。禾安日常称他“阿梁”。

他不是英雄，不是名将，只是旧渡普通丁壮。重点是：

```text
他不是因为无名而被征。
他正是因为有名、有籍、有户，所以被征发准确找到。
```

主角终于明白：

```text
名籍已经从救济工具，变成战争入口。
```

### 2.7 三十六岁：长平血雾

长平发生。

这一幕必须从主角职业入口进入。

医者线里，主角在医棚里救人，最后仍发现救不完。吏官线里，死伤册越来越厚，错名、残名、空格越来越多。商贾线里，粮道断裂，关验失效。武将线里，主角认识的军旅青年或梁成所在伍被吞没。戏子线里，柳娘或戏班在战后喊名，从前唱到地名处停住，如今唱到人名处停住。工匠线里，主角发现车、桥、仓、器物都被战争使用。谋士线里，曾经的盟书和调停回头压死人。仕官线里，公孙砚发现官档装不下这一场死亡。

长平之后，主角站在白骨、断简、湿衣、死伤册、旧曲和无人认领者之间。

他终于明白：

```text
名字写得再整齐，也接不住所有死人。
不写，又会让他们彻底散掉。
```

无名录从这里真正开始。

### 2.8 长平之后：主角回到旧渡

长平之后数年，主角带着各自职业线上的材料回到旧渡。

旧渡已经变了。旧雨棚还在，但换过梁。旧仓门上多了新木牌。辛衡老伯旧案积灰。当年翻车的泥地变成硬路，可雨后仍能看出车辙。

主角看见禾安。

她不是站在渡口等他。她正在过日子。她倒空锅，补灶口，数粮袋，把柴往干处移，还给一个孩子分半碗粥。

她抬头看见主角，第一句话是：

```text
你倒还认得路。
```

她看他身上的尘，看他手里的册，看他袋里那些东西，问：

```text
从那边回来的？
```

“那边”不必明说。

主角点头。

禾安把一只破碗翻过来，说：

```text
那正好。
我问你个人。
```

她问：

```text
阿梁。旧渡梁氏，去年随征走的。
你路上，听过没有？
```

主角知道，或者几乎确定，梁成已经死了。

不同职业线里，主角知道这件事的方式不同：医者听过临终口音；吏官见过死伤册残名；商贾带回关验残片；武将可能与梁成同伍；戏子听过战后唱名；工匠拾到刻名器物；谋士知道某份调令牵动其伍；仕官见过官档。

主角说不出口。

他只能说：

```text
我……去查查看。
```

禾安可能已经听出什么，却不逼问。

```text
你小时候说谎，耳朵会红。
现在倒不红了。
```

她没有继续问阿梁，转而聊起小时候。她说起雨夜翻车，说起韩宁，说起柳娘喊名，说起没有米下锅。

她从灶边摸出一只旧碗。碗边有缺口，碗底有旧灶火熏出的黑痕。

```text
那晚就是这只。
熬得跟水一样。
你还问够不够。
哪有什么够不够。只是看谁先倒下。
```

主角从这只碗想到长平粮道，从旧渡小饿想到长平大死。

他离开时，禾安只说：

```text
查到了，托人带句话。
别亲自跑。你也不是十岁了。
```

主角走出旧渡，听见锅盖在身后轻轻一响。

那声音比长平的鼓声小得多，却压得他更久。

此后直到晚年，主角都没有再回旧渡。

真实原因只有一个：

```text
他不知道怎么把禾安丈夫战死的消息讲给禾安。
```

这不是简单懦弱，而是“记录与沉默”在主角自己身上的反噬。

### 2.9 七十五岁：天下有名

前 221 年，秦统一。

主角七十五岁。

天下终于有了一个名字。

主角必须决定无名录的去向。

在做决定前，他终于回旧渡。

旧渡比记忆里更小。旧仓还在，但门换了。旧礼器库破了半边。辛衡老伯旧案已无人知道原来放在哪里。灶边有人换过新泥。

主角寻找禾安。

他没有见到她。

禾安早已离世。

她没有等主角回来。她照常过完自己的一生。她撑过旧渡，送走许多人，养大孩子，或者照看别人的孩子。她继续数米、数柴、数水，继续把没消息的人也留一口饭。她没有把自己活成主角的遗憾。

主角见到她留下的东西。

```text
一口倒扣过很多次的旧锅。
一只补过的热水桶。
一包种子。
一块刻着“梁”字的旧木片。
以及那只小时候一起喝过稀粥的碗。
```

有人转述禾安的话：

```text
她后来不问了。
只说，没消息的人，也得留一口饭。
```

主角翻过那只碗。

碗里没有粥，也没有字。

但他想起那一夜两个人蹲在灶边，一人喝过一口。

他终于明白，无名录不是为了让他无愧，也不是为了把所有死讯都送到每个人面前。

```text
它是为了让那些没有被送达、没有被承认、没有被说出口的人，不至于彻底散掉。
```

主角终于做出决定。

他可以把一部分无名录交给官档，让制度至少承认这些人曾经存在。也可以藏入民间，保护还活着的人。可以托给旧曲和口述，让不能写全的人在声音里留下。可以拆散，交给路、桥、伤簿、私记。也可以把最核心的一部分埋回洛水与裂钟之间，交给未来。

无论选择哪一种，都不是完美结局。

主角的亏欠不会消失。

可他终于不再因为写不全就不写。

也不再因为说不出口，就让他们彻底散掉。

洛水边，裂钟再次响起。

主角听见一句清晰回声：

```text
这不是你第一次看见山河改色。
```

第一章结束。

## 3. 八职业线如何嵌进完整故事

### 3.1 医者线：救命之后

主角最早从伤者开始。他救下雨夜孩子，守过旧渡医棚，跟老医者学草药和清创。长平后，他从医棚带回梁成的临终口音，因此知道禾安丈夫已死，却说不出口。晚年无名录里，医者线提供伤簿、临终姓名和身体旧伤标记。

核心：

```text
救命不是结束，活下去还要有位置。
```

### 3.2 吏官 / 记录线：空格

主角继承辛衡老伯旧册，最懂空格的重量。他在死伤册上见到梁成的残名，回旧渡时面对禾安的询问，说不出“册上有他”。晚年无名录里，吏官线提供残缺名册、错籍、空籍和删改痕迹。

核心：

```text
记录不是中性的，写字的人也在承担因果。
```

### 3.3 商贾线：路不断

主角随青缗走商路，看见粮、药、布、关验如何决定生死。长平后，他从断粮道上带回梁成的关验残片。他知道路把人带走，也没能把消息带回。晚年无名录里，商贾线提供路上见闻和失踪名单。

核心：

```text
路断了，人连选择都没有。
```

### 3.4 武将线：阵前名单

主角从护送迁民走向军旅。他可能与梁成同伍，或亲眼见过梁成战死。回旧渡时，他最知道答案，却最说不出口。晚年无名录里，武将线提供阵前名单、征发记录和无人认领者。

核心：

```text
战争不是战场一瞬，而是无数户人被提前写进刀口。
```

### 3.5 戏子线：不敢唱全的旧曲

主角随柳娘学会喊名和口述。长平后，他在战后旧曲里听过阿梁的名字，却无法把那一声唱回禾安面前。晚年无名录里，戏子线把无法写全的人托给旧曲和口述。

核心：

```text
记住一个人，不一定靠官册，也可能靠不敢唱全的旧曲。
```

### 3.6 工匠线：车辙

主角从车、桥、仓、木牌看见时代。他可能从战场车辙旁拾到刻着梁成名记的器物。回旧渡时，那件东西就在他袋中，却拿不出来。晚年无名录里，工匠线提供车辙、器物、桥仓位置和裂钟物证。

核心：

```text
器物没有善恶，但人会把器物放进不同秩序里。
```

### 3.7 谋士线：盟书背后

主角擅长调停、联络、转圜。可长平后他发现自己的话也可能把人推向征发。梁成所在伍的覆灭，也许与某份调令或粮道安排有关。回旧渡时，他面对禾安，不只说不出口，还带着“我也在其中”的亏欠。

核心：

```text
聪明不是答案，聪明也会制造代价。
```

### 3.8 仕官线：木牌

主角进入制度，看见新法如何运行。梁成的死亡或失踪早在官档里，但没有送到禾安手上。主角回旧渡时，最痛的是：制度知道，却没有让该知道的人知道。晚年他是否把无名录交官档，会成为最尖锐的选择。

核心：

```text
治理天下时，最容易看不见一个人的脸。
```

## 4. 乡土地基与隐退倾向

### 4.1 乡土地基

乡土地基贯穿全章：

```text
ACT01：没有米下锅，一只旧碗分过稀粥。
ACT02：旧仓放粮，本地户与流民都要活。
ACT03：田亩、户籍、赋役和连坐落到旧渡。
ACT04：禾安独自承担旧渡压力，不等主角。
ACT06：丁壮被征，灶边少了一双手。
ACT07：梁成被长平吞掉。
ACT08：禾安已逝，只留下那只粥碗。
```

共同底色：

```text
天下怎么改名，地还是要种。
可种地的人、烧灶的人、分粥的人，也会被名籍、征发和战争带走。
```

### 4.2 隐退倾向

隐退不是职业，而是所有职业都可能走向的姿态：

```text
医者可以私藏伤簿。
吏官可以带走残册。
戏子可以只传半支旧曲。
工匠可以藏起裂钟残片。
谋士可以停止游说，只留下被牵动的人名。
仕官可以保存官档里不能公开的缺口。
```

隐退倾向的主题：

```text
不入官档不是无罪。
不公开也不是消失。
不选择，也会留下或错过见证。
```

## 5. 剧本写作禁忌

```text
不要把职业写成开局选择菜单。
不要让八职业变成八个互不相干副本。
不要把农人重新拆成独立职业线。
不要把隐士重新拆成独立职业线。
不要让旧渡现实压力只属于某一职业。
不要让 NPC 只等主角触发。
不要让禾安变成恋爱线或主角遗憾附属物。
不要让辛衡老伯之死变成廉价催泪。
不要让长平只是背景数字。
不要允许全员完美存活。
不要让禾安粥碗变成神秘法器。
不要让无名录只有一种正确去向。
```

## 6. 一句话总结

```text
主角十岁时第一次替别人的名字承担后果；
中年在长平看见无数人被压成数字；
长平后回旧渡，面对禾安问阿梁消息，却说不出口；
晚年再回旧渡时，禾安已逝，只留下小时候一起喝粥的碗；
他终于决定无名录的去向，不是为了消除亏欠，而是为了让那些没被说出口的人不至于彻底无名。
```
