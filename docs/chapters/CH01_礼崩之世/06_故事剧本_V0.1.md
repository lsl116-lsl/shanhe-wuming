# 第一章《礼崩之世》故事剧本 V0.2

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 剧本题名：《钟裂于洛水》  
> 文档状态：根据 `01`、`02`、`03`、`04`、`10`、`11` 重整后的故事剧本骨架  
> 剧本定位：从 10 岁到 75 岁的一段完整人生；根据玩家选择形成十职业独立故事线，并在长平、无名录、秦统一处汇总。

## 1. 剧本总原则

第一章不是十个职业副本。

第一章写的是：

```text
同一个主角，从洛水旧渡十岁写名开始，被一次次选择磨出不同人生位置。
```

玩家不是开局选择职业。

玩家是在一路处理问题后，回头发现：

```text
原来我这一世，是这样活成这个人的。
```

## 2. 剧本结构

本剧本分三层：

```text
共享人生主线：所有玩家都经历的年龄段和历史伤口。
职业独立线：玩家因选择形成的不同人生位置和专属责任。
汇总节点：不同职业线在旧仓、新法、长平、无名录、秦统一处重新交织。
```

主角年龄跨度：

```text
前 286 年：主角 10 岁。
前 221 年：秦统一，主角约 75 岁。
```

## 3. 共享主线剧本骨架

### 3.1 十岁：旧渡落地

```text
时间：前 286 年。
地点：洛水旧渡。
对应：序章 + ACT01。
```

固定戏剧事件：

```text
主角写下本世姓名。
母亲望向河道尽头。
辛衡解释名与籍。
禾安端水、抱柴、催主角别发呆。
宋亡流民抵达。
韩宁拒绝说旧里。
柳娘旧曲唱到地名处停住。
裂钟第一次响。
雨夜翻车。
```

第一场重大选择：

```text
先救车下孩子。
先抢泥水湿简。
先让活人互认。
```

剧本要求：

```text
该选择只种下初始倾向，不锁职业。
禾安、韩宁、柳娘都要按自己的逻辑行动，不等待主角。
辛衡不替玩家选择，只观察主角第一笔因果。
```

结尾落点：

```text
主角第一次明白：别人的名与籍不是姓名问题，而是活人身后的网。
```

### 3.2 十一至十五岁：旧仓与旧册

```text
对应：ACT02。
地点：旧仓、流民棚区、旧渡本地户、辛衡书案。
```

固定戏剧事件：

```text
流民暂住旧渡。
旧仓是否放粮成为争议。
本地人与流民争水、争棚、争粮。
临时名册开始决定谁能领粮，也决定谁可能被追索。
父亲官粮线露出第一处裂缝。
```

核心冲突：

```text
不开仓，流民熬不过去。
开仓，本地户明早可能断粮。
写全，发粮更有序，也更容易追索。
写虚，暂时护人，也可能让后续失控。
```

剧本落点：

```text
主角发现：救下来不是结束。活下去需要位置，而位置会带来承认和追索。
```

### 3.3 十六至二十岁：新法入乡

```text
对应：ACT03。
地点：旧渡、乡里、县署外围、重新编户现场。
```

固定戏剧事件：

```text
旧渡重新编户。
新法木牌钉入乡里。
旧称呼被改写成户、伍、什。
田、役、债、罚、连坐进入日常。
公孙砚正式出现。
```

职业邀请开始出现：

```text
县署请主角协助旧册。
医者请主角夜里看伤。
青缗邀请主角走一趟商路。
工匠让主角搭手修车桥仓。
乡里让主角参与田亩安置。
荀白或柳娘让主角进入言说与口述线。
南郭生让主角看见不入局的见证方式。
```

剧本落点：

```text
主角明白：旧礼救不了旧渡，新法也不是单纯恶物。它给人位置，也让人被计算。
```

### 3.4 二十至二十五岁：选择一双手

```text
对应：ACT04。
地点：县署、医棚、工坊、商路、乡里、学舍、旧渡。
```

固定戏剧事件：

```text
主角半离开旧渡。
职业责任真正显形。
辛衡病重。
辛衡交托旧册、旧笔和未完成名单。
禾安成为旧渡现实压力的独立承担者。
```

剧本要求：

```text
职业显形靠责任，不靠菜单。
每条职业线至少有一个“有人来请你帮忙”的场景。
主角可以被邀请，也可以被拒绝。
NPC 根据此前选择调整信任和距离。
```

### 3.5 二十五至三十岁：百家灯火与辛衡老死

```text
对应：ACT05。
地点：洛邑、学舍、商路、旧渡回望、辛衡病榻。
```

固定戏剧事件：

```text
荀白登场或关系加深。
申不疑登场或关系加深。
青缗商路线加深。
辛衡老死。
```

辛衡死亡场景建议：

```text
雨停后的早晨。
书案上墨已经干了。
辛衡没有来开门。
案上留着半片未刮平的木牍。
木牍上没有遗言，只有几个没写完的名字。
```

剧本落点：

```text
主角失去第一个教他“字后面站着人”的人。
从此他必须自己决定哪些字该落，哪些字该空，哪些字只能换一种方式留下。
```

### 3.6 三十一至三十五岁：战争前夜

```text
对应：ACT06。
地点：边境、商路、粮道、学舍、军役登记处、乡里征发现场。
```

固定戏剧事件：

```text
合纵连横变化。
上党风云逼近。
盟书、地图、粮道、征发、军籍连成战争机器。
主角所在职业线从不同入口卷入。
```

必须出现战前名单：

```text
有人名字完整，马上被征。
有人名籍残缺，无法领粮。
有人被写作逃亡。
有人已经死了，却还在名册上。
有人活着，却不敢出现。
```

剧本落点：

```text
名籍从救济工具变成战争入口。
```

### 3.7 三十六岁：长平血雾

```text
对应：ACT07。
历史节点：长平大战。
```

固定戏剧事件：

```text
长平发生。
军籍、粮籍、死伤册失效。
活人与死人在记录中混杂。
重要 NPC 或职业线关键 NPC 死亡、失踪或留下不可逆创伤。
主角第一次真正看见一整代人被压成数字。
```

不同路线可触发不同不可逆损失：

```text
军旅青年战死。
韩宁失踪、战死或旧籍暴露。
柳娘戏班折损。
禾安旧渡 / 迁民线重创。
公孙砚制度线受创。
青缗在保路、保货、保人之间做出不可逆选择。
荀白第一次说不出话。
```

剧本禁忌：

```text
不能全员完美存活。
不能把长平写成背景数字。
不能让玩家靠选对答案避免历史伤口。
```

剧本落点：

```text
名字写得再整齐，也接不住所有死人。
不写，又会让他们彻底散掉。
```

### 3.8 三十七至七十五岁：天下将一

```text
对应：ACT08。
历史节点：长平余波、周亡、秦统一。
```

固定戏剧事件：

```text
幸存者回不去原来的家。
失踪者无法被确认为亡。
无名录逐渐成形。
周亡，旧礼最后象征崩塌。
秦统一，天下归一。
主角决定无名录去向。
```

最终问题：

```text
天下终于有了一个名字。
可一个人呢？
他的名，他的籍，他身后那一户活人，又该写在哪里？
```

## 4. 十职业独立故事线

以下每条职业线都必须有独立故事线，但不得脱离共享主线。

### 4.1 医者线：救命之后

独立线核心：

```text
主角反复优先救伤、找药、看护病人，逐渐被医者线吸纳。
```

关键剧情：

```text
ACT02：夜里照看旧渡棚区伤者。
ACT03：迁民中疫病和伤口处理。
ACT04：老医者请主角独自守一夜。
ACT05：辛衡老死，主角第一次面对“老死不是失败”。
ACT06：征发前病人被写入兵籍。
ACT07：长平后医棚救不完人。
ACT08：伤者口供成为无名录材料。
```

最终领悟：

```text
救命不是结束，活下去还要有位置。
```

### 4.2 吏官 / 记录线：落笔的人

关键剧情：

```text
ACT02：整理湿简和临时名册。
ACT03：看到新法编户如何改变旧渡。
ACT04：辛衡交托旧册。
ACT05：辛衡老死，主角继承未完成名单。
ACT06：战前名单让主角看见名籍进入征发。
ACT07：死伤册失效。
ACT08：残缺名册和删改痕迹进入无名录。
```

最终领悟：

```text
记录不是中性的，写字的人也在承担因果。
```

### 4.3 商贾线：路不断，人还有选择

关键剧情：

```text
ACT03：主角关注粮水、关验和路，青缗注意到他。
ACT04：第一次随青缗走商路。
ACT05：商路消息与百家问议交叉。
ACT06：商路被军需吞并。
ACT07：青缗必须在保路、保货、保人之间选。
ACT08：路上见闻和失踪名单进入无名录。
```

最终领悟：

```text
乱世里活路常不干净，但路断了人连选择都没有。
```

### 4.4 武将线：被提前写进刀口

关键剧情：

```text
ACT03：护送迁民或旧渡粮车。
ACT04：守路、护送、冲突升级。
ACT05：与退伍老卒或军旅青年建立关系。
ACT06：战前征发和粮道守护。
ACT07：长平战死节点发生。
ACT08：征发记录和无人认领者进入无名录。
```

最终领悟：

```text
战争不是战场一瞬，而是无数户人被提前写进刀口。
```

### 4.5 戏子线：不敢唱全的旧曲

关键剧情：

```text
ACT01：柳娘旧曲停在地名处。
ACT02：喊名互认、安住孩子。
ACT04：主角学习口述和节拍如何记人。
ACT05：旧曲与百家语言形成对照。
ACT07：戏班折损，柳娘开始在人名处停住。
ACT08：旧曲成为无名录的民间形态。
```

最终领悟：

```text
记住一个人，不一定靠官册，也可能靠不敢唱全的旧曲。
```

### 4.6 农人线：地还要种

关键剧情：

```text
ACT02：旧仓和本地户粮水冲突。
ACT03：新法授田、编户、役责落到旧渡人身上。
ACT04：禾安承担旧渡现实压力。
ACT06：丁壮被征，田亩空缺。
ACT07：旧渡或迁民线重创。
ACT08：空户、田亩和无人收成的地进入无名录。
```

最终领悟：

```text
天下怎么改名，地还是要种；种地的人未必保得住位置。
```

### 4.7 工匠线：器物被时代使用

关键剧情：

```text
ACT02：修车、棚、仓门。
ACT03：新法入乡后修路、修仓、修桥。
ACT04：工匠锚点交给主角真正的工具。
ACT06：车桥仓被军需征用。
ACT07：器物成为战争机器的一部分。
ACT08：车辙、器物、桥仓位置和裂钟物证进入无名录。
```

最终领悟：

```text
器物没有善恶，但人会把器物放进不同秩序里。
```

### 4.8 谋士线：聪明也有代价

关键剧情：

```text
ACT02：调停旧渡人与流民冲突。
ACT03：在县署、乡里和流民之间转圜。
ACT05：百家问议中学习把复杂话说成可执行方案。
ACT06：盟书和游说卷入战争前夜。
ACT07：计策和盟书的失败造成具体人死亡。
ACT08：盟书背后的代价进入无名录。
```

最终领悟：

```text
聪明不是答案，聪明也会制造代价。
```

### 4.9 仕官线：看不见脸的治理

关键剧情：

```text
ACT03：公孙砚让主角看见新法执行现场。
ACT04：主角进入县署或制度现场。
ACT05：申不疑带来制度重构思想。
ACT06：制度进入战争状态。
ACT07：官档和军籍装不下海量死亡。
ACT08：主角决定是否把无名录交给官档。
```

最终领悟：

```text
治理天下时，最容易看不见一个人的脸。
```

### 4.10 隐士线：旁观也不是无罪

关键剧情：

```text
ACT02：主角保存见证但少介入。
ACT03：避开官署和显性权力。
ACT04：隐士锚点教他如何保存不入官档的材料。
ACT05：辛衡死后，主角选择是否只保留私人见证。
ACT06：战争前夜要求旁观者沉默或作证。
ACT07：长平后发现旁观也不能无亏欠。
ACT08：私人见证成为无名录的一种形态。
```

最终领悟：

```text
不选择，也是一种选择。
```

## 5. 汇总节点剧本要求

### 5.1 旧仓汇总

所有职业线都必须在旧仓 / 粮水 / 名册冲突处留下第一层痕迹。

### 5.2 新法汇总

所有职业线都必须看到新法如何进入旧渡，只是入口不同：

```text
医者看伤者如何被编户。
吏官看名册如何重写。
商贾看关验和道路如何改变。
农人看田亩和役责如何落下。
工匠看木牌、仓桥和工具如何被征用。
```

### 5.3 长平汇总

所有职业线必须在长平处交汇。

不同职业看见不同入口，但共同看见：

```text
一整代人被压成数字。
```

### 5.4 无名录汇总

每条职业线都必须把自己的材料交给无名录。

无名录不是单一书册，而可以是：

```text
官档。
民间藏本。
旧曲口述。
拆散的材料。
洛水与裂钟之间的埋藏物。
```

## 6. 剧本写作禁忌

```text
不要把职业写成开局选择菜单。
不要让十职业变成十个互不相干副本。
不要让 NPC 只等主角触发。
不要让禾安变成恋爱线。
不要让辛衡之死变成廉价催泪。
不要让长平只是背景数字。
不要允许全员完美存活。
不要让无名录只有一种正确去向。
```

## 7. 下一步扩写方式

正式扩写时，每个 ACT 应继续拆成：

```text
共享场景。
职业入口场景。
NPC 自主行动场景。
关键选择。
即时结果。
后续回收。
本 ACT 结尾状态。
```

每条职业线也要拆成：

```text
职业显形场景。
职业专属 NPC。
职业专属工具。
职业第一次亏欠。
长平回收。
无名录贡献。
75 岁暮年回望。
```
