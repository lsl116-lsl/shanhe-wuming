# 第一章《礼崩之世》故事剧本 V0.1

> 目录归属：`docs/chapters/CH01_礼崩之世/`
>
> 剧本定位：可制作的分场剧本；锁定场景目标、人物行动、关键选择、职业独立故事和状态落点，正式对白可在本文件基础上继续扩写。
>
> 剧本题名：《钟裂于洛水》

## 1. 本章戏剧核心

苏醒者从一枚只剩半个名字的残简开始，花一生尝试回答：

> 当旧秩序已经无法保护人，新秩序又首先把人写成数字时，一个普通人还能怎样保住自己和别人的名字？

玩家的性格不是开场问卷决定，而由反复行动显现：

```text
遇到危险时先救人还是先留证
面对制度时服从、规避、改良还是公开承担反对
面对故人时守约、说真话、替其决定还是允许其拒绝
面对历史时争取署名、匿名保存还是让众人共同维护
```

## 2. 核心人物语言与行动

| 人物 | 语言特征 | 不说出口的东西 | 玩家缺席时的固定行动 |
|---|---|---|---|
| 季伯 | 短句；常用“这一笔”；先问名字再问立场 | 他曾按命令删过一批人的籍 | 私下保留第一次流民名册 |
| 禾安 | 以田、井、季节和劳力说话；不接空泛大词 | 她怕自己只能靠别人记住 | 组织妇孺和老人共同播种、运粮与寻人 |
| 韩宁 | 说话克制；记日期和原话；最恨别人替父亲辩护 | 她并不确定父亲是否也曾害过人 | 独自寻找父亲暗册并质问旧国遗民 |
| 青缗 | 先算车、路、日程；说笑掩饰风险 | 他曾为保商队放弃一车饥民 | 建立一套只给同行看的沿途失踪记号 |
| 荀白 | 喜欢追问前提；承认自己会改主意 | 他渴望自己的话被主君采用 | 抄录互相冲突的证言而不强行合并 |
| 申不疑 | 句式整齐；先谈可执行性；极少提高嗓门 | 他怕自己重回无权无粮的童年 | 把玩家处理隐丁案的方法上报为治策 |
| 柳娘 | 不直接回答危险问题；用半句旧歌代替 | 她忘了一部分原词，却不肯承认 | 把死者姓名编进节拍，交给阿檀 |
| 公孙砚 | 精确到户、日和数量；不接受含糊承诺 | 他知道一次依法执行害死过无辜者 | 保存一份带执行批注的新法副本 |
| 屠申 | 少谈大道理；只记得同伍吃什么、怕什么 | 他服从过一项终身不愿说明的命令 | 把同伍托付分别交还家属 |
| 苏离 | 擅长把复杂话改成一句能打动主君的话 | 他知道被删去的人名会变成代价 | 使用玩家治策游说，并留下删改痕迹 |

## 3. 共享序章

### CH01-ACT01-SC001 雨后流民

```text
时间：前 286 年
地点：洛水渡口
人物：少年苏醒者、季伯、禾安、韩宁、柳娘、流民
现实目标：在天黑前安置病者、辨认死者并清点可用粮物
```

视觉开场：雨水从车辙流入洛水，一枚写着半个姓名的残简卡在泥里。

季伯要求先把还能说话的人叫到案前。禾安抢过空陶罐去汲热水，韩宁则跪在泥里翻找湿简。三个行动都合理，却争夺同一批人手和最后一点光。

关键选择：

1. **跟禾安抬病者进旧库**
   - 病者生还率提高。
   - 两名死者来不及确认姓名。
   - 禾安形成 `shared_debt: rain_rescue`。
2. **替季伯抢救湿简**
   - 半名残简信息提高。
   - 韩宁误以为玩家知道父亲线索。
   - 眼前病者由柳娘照看，留下治疗亏欠。
3. **让流民彼此点名**
   - 形成最完整临时名册。
   - 一名逃亡者暴露假名并连夜离开。
   - 激活“记录也会伤人”的第一证据。

关键对白：

> 季伯：“先写名。人若没了，总得让后来人知道少的是谁。”
>
> 禾安：“人还没没。你先把手伸过来。”
>
> 韩宁：“若只能救一样，先救字。活人还会再说，死人不会。”

状态落点：`SW-CH01-002`、`SW-CH01-004`，并形成玩家第一项性格事实。

### CH01-ACT01-SC002 无人敲钟

夜里，旧礼器库漏雨。苏醒者在无人靠近时听到裂钟短响，并看见水从梦中钟缝流出。现实中，韩宁正试图从他手里取走半名残简。

玩家可以立即交出、要求共同辨认，或暂时藏起。韩宁不会因交出就完全信任，也不会因藏起就成为敌人；她判断的是玩家是否承认这枚简可能关系到活人的安全。

### CH01-ACT01-SC003 没有国名的歌

柳娘为死者唱旧曲，却删去国名。旧国遗民要求补回国名，流民中另一群人担心因此被辨认。

玩家不选择“爱国或不爱国”，而选择：

- 今夜是否唱出死者姓名。
- 是否允许假名者保持沉默。
- 由谁保管临时名册。

本幕结束时，裂钟被抬到告祭中央，却发不出完整声音。

## 4. 共享成长段

### CH01-ACT02-SC001 仓中有粮

数年旱情后，旧仓仍有祭粮，流民却因名不在籍无法领取。禾安一家已经拆了最后一件旧农具换种。

季伯带玩家按旧礼请粮；青缗提出先借粮；新署文书则允许流民重新编户后领粮。

选择改变：

- 当季死亡和播种人数。
- 债务归属。
- 新籍接受度。
- 禾安是否认为玩家“把来年也算进去了”。

### CH01-ACT02-SC002 被划去的人

新名册完成后，玩家发现第一次名册上的人被划去：

- 有人已经死亡。
- 有人换名入籍。
- 有人因逃债被青缗隐藏。
- 有人被旧族担保者故意排除。

季伯第一次承认：他年轻时也曾照命令划去姓名。

玩家可以追问、安慰、指责或要求看旧册。无论选择如何，季伯当夜开始抄一份不交官署的副本。

### CH01-ACT03-SC001 三个姓名

在几经易手的边邑，同一户在三套旧籍上有三个姓氏。韩宁找到父亲笔迹，却发现父亲也修改过姓名。

韩宁的私人目标是证明父亲不是叛臣；流民的现实目标是避免旧名暴露；申不疑要用赦免换取全部旧档。

主要选择：

- 交出原册换取公开赦免。
- 制作明暗两册。
- 保护新名，封存旧名。
- 毁去可用于追索活人的部分，另记死者。

韩宁根据选择形成 `trust`、`rift` 或 `shared_debt`，但固定行动是继续查父亲曾经删过谁。

### CH01-ACT03-SC002 选择一双手

玩家不是从菜单选择职业。十名锚点人物分别提出一项必须在当天完成的工作：

| 入口 | 当日行动 | 玩家被吸引出的性格 |
|---|---|---|
| 隐士 | 夜送一户假名者上山 | 愿否承担看不见的连带风险 |
| 仕官 | 替赦免文书找出可执行措辞 | 愿否进入自己不完全认同的制度 |
| 谋士 | 整理双方都不愿写下的交换条件 | 是否习惯替别人分配代价 |
| 武将 | 护送流民通过军卡 | 如何使用短时强制力 |
| 医者 | 为病者证明无法服役 | 是否为不确定诊断担责 |
| 戏子 | 把三户来处编成不暴露真名的歌 | 是否接受真相在传播中变形 |
| 商贾 | 在货单中藏人和旧简 | 是否让同行为自己的选择冒险 |
| 工匠 | 在车轴暗格中藏一卷旧籍 | 如何面对器物用途失控 |
| 吏官 | 抄写一份明册和一份暗册 | 是否愿意让自己的笔迹成为证据 |
| 农人 | 留在争议田界上完成抢种 | 是否把一处土地当作新的故乡 |

完成行动后主职业锁定；其他锚点人物继续作为 NPC 行动。

## 5. 十条职业独立主线

以下每条线由四个核心场景构成。正式制作时可在场景之间插入共享人物场景和日常生活。

### 5.1 隐士线《山中无籍》

关系核心：南郭生、韩宁、禾安。

路线欲望：建立一处不问旧名也能活下去的山中聚落。

性格盲点：把“不进入制度”误认为“不必为制度后果负责”。

#### R01-SC01 藏下一个人

玩家带隐丁石牯入山。山民愿意藏他，但要求他不得再下山见家人。玩家可隐瞒这一条件、如实说明，或放弃藏匿去与公孙砚谈缓役。

#### R01-SC02 邻户受罚

山下同伍因石牯失踪被加役，禾安前来质问。南郭生拒绝交人，理由是山中规矩一破，再无人敢来。

高潮选择不是“交或不交”，而是由谁承担补缺：

- 玩家下山代役。
- 暴露一条山路换取整伍缓期。
- 让石牯自己决定是否归案。
- 拒绝交易，让聚落共同承受封山。

#### R01-SC03 地图外的路

ACT06，玩家发现盟书粮道图没有画出逃生山路。开放此路能救上党百姓，也会暴露聚落。

#### R01-SC04 七日之门

长平余波中，逃兵、伤者、百姓和追捕者同时抵达。山粮只够再开门七日。玩家必须制定接纳规则并亲自拒绝一批人。

专属高潮：建立带保护期限的假名册，区分生还、逃亡和失踪。

不可逆代价：聚落曝光、邻户加役或一批求助者被拒。

路线结局：守山人、下山证人、被逐者或带徒远迁者。

### 5.2 仕官线《一纸缓令》

关系核心：申不疑、公孙砚、荀白。

路线欲望：证明制度可以因具体的人而改变。

性格盲点：相信只要留在位置上，下一次一定来得及改。

#### R02-SC01 先执行

玩家获得处理隐丁案的有限权限。申不疑要求先登记再申请缓役；公孙砚允许玩家提出一项可复制的例外。

#### R02-SC02 被复制的漏洞

玩家设计的缓役条款被地方豪强用于保护家仆，真正贫户反而失去名额。玩家必须公开撤销、收紧条件或接受不完美规则。

#### R02-SC03 谁在盟书上签字

玩家参与盟书担保。荀白要求写明粮役承担县邑；申不疑认为写得越清楚越难成盟。

#### R02-SC04 开仓署名

长平前后，玩家可合法开一仓、延一县征发或批准一批撤离文书，只能选择其一。每份命令必须署名，不能把责任留给无名小吏。

专属高潮：在失败的救援链上保存所有知情、签署和驳回时间。

不可逆代价：失官、被罪，或保住职位却留下明确未救之人。

路线结局：能臣、罢官者、受罪者或退居地方的制度见证者。

### 5.3 谋士线《空言有债》

关系核心：苏离、申不疑、韩宁。

路线欲望：用看清大势的能力阻止更坏结果。

性格盲点：认为只要总结果更好，代价分配可以以后补偿。

#### R03-SC01 可用的话

苏离教玩家删去治策里“不利于主君听懂”的姓名。删得越少，越可能无人采用；删得越多，越可能成为有效征发方案。

#### R03-SC02 三份推演

玩家为三方分别推演粮道。每份都成立，却把风险压向不同县邑。韩宁要求在每份末尾写明“谁先饿”。

#### R03-SC03 说服成功

玩家成功促成一项盟约，随后看见自己的原话被改成更大征发。苏离承认删改，却问：“若不改，他们连第一句也不会听。”

#### R03-SC04 送出哪封警告

大战前只能安全送出一封警告：粮道、撤离、换将传闻或投降风险。每封都能救一批人，也会让另一批人失去准备。

专属高潮：保留原稿、删改稿和执行稿，第一次让策略责任可追溯。

不可逆代价：玩家的成功主张成为伤亡链的一部分。

路线结局：名士、失意门客、匿名抄手或公开认责者。

### 5.4 武将线《同伍旧约》

关系核心：屠申、魏梁、禾安。

路线欲望：让同伍所有人一起回家。

性格盲点：把保护袍泽放在所有陌生人之前。

#### R04-SC01 军功田

魏梁凭军功获得田地，原耕户却被迁走。玩家决定帮助魏梁接田、促成共耕或要求他放弃军功所得。任何选择都改变两户生计。

#### R04-SC02 缺额

隐丁未归，玩家同伍必须补一人。玩家可带走当事人、抽邻户、由自己承担危险勤务或伪报伤病。

#### R04-SC03 护使还是护民

上党路上，玩家的命令是护使者，山道另一侧却有百姓撤离。分兵会让两边都更危险。

#### R04-SC04 最后点名

长平断粮后，同伍面临突围、留守、投降和护送伤者。玩家无法让所有人同选，也不能让反对者变成懦夫。

专属高潮：在军册之外完成最后点名，区分战死、失踪、投降后失踪与逃亡。

不可逆代价：屠申、魏梁或同伍至少一组关系永久失去。

路线结局：伤残归乡、受赏背债、拒命受罪或无名失踪。

### 5.5 医者线《先救谁》

关系核心：小蓟、禾安、屠申。

路线欲望：不让任何人因身份低微而排在救治之后。

性格盲点：把不能放弃任何人变成对自己和同伴的残酷要求。

#### R05-SC01 病证

石牯确有旧伤，却仍能服轻役。玩家开的字决定他去留，也决定邻户是否补缺。

#### R05-SC02 一包药

同一包药可给禾安病母、军中伤卒或聚落疫病。小蓟拒绝“平均分”，因为剂量不足会三边都无效。

#### R05-SC03 药路

军方征走药材。玩家可藏药、交药、以假劣药替换或随军监督使用。每种做法都改变后方疫情和前线生还。

#### R05-SC04 伤营天亮

长平伤营在天亮前必须撤离。玩家确定救治和运输顺序，并决定是否用有限时间记录无法带走者的姓名。

专属高潮：以身体特征、旧伤和最后语言补足无名者身份。

不可逆代价：至少一名可救者因排序等待过久；玩家可能永久伤病。

路线结局：军医、乡医、携簿行医者或因伤停手的教徒者。

### 5.6 戏子线《旧曲改词》

关系核心：柳娘、阿檀、韩宁。

路线欲望：让不识字的人也能把死者名字带走。

性格盲点：相信传播得够广就能抵抗所有歪曲。

#### R06-SC01 三种旧曲

柳娘、韩宁和旧国遗民记得三种不同原词。玩家必须选择以谁的版本为底，或承认没有唯一原版。

#### R06-SC02 替法令开口

玩家受命向乡民唱解木牌条文。解释得越清楚，百姓越能避错，也越方便官署执行。

#### R06-SC03 盟誓之歌

苏离要求写振军词；柳娘要求暗藏撤离警告；阿檀只想让同行领到粮。三种目标不能完全兼得。

#### R06-SC04 一口气能唱几人

长平余波中，玩家以节拍唱未归者姓名。唱真名会暴露逃兵家属，唱绰号又可能永远无法核验。

专属高潮：将亡国旧曲从悼一国改成悼亡者、失踪者和仍在等待的人。

不可逆代价：原词失去、同行受禁、假名者暴露或歌曲被权力征用。

路线结局：宫廷乐人、民间禁曲传人、失声者或无名教唱者。

### 5.7 商贾线《无法结清的账》

关系核心：青缗、禾安、鲁砚。

路线欲望：让道路一直通，让货最终到需要的人手里。

性格盲点：习惯把不能计价的东西延后处理。

#### R07-SC01 货单里的人

玩家在货车中藏人和旧简。同行必须共同承担查验风险，青缗要求玩家先问他们，而不是独自做英雄。

#### R07-SC02 赎一户

玩家能筹够一户赎役的钱。借债会抬高全村未来负担，拒绝则当事人被征。

#### R07-SC03 被征用的商路

青缗的路图成为军粮依据。玩家可更改一处仓点、延迟一队粮车或公开拒绝；每项都影响军队与乡里。

#### R07-SC04 最后一车粮

粮车可送伤营、被围军卒、逃难百姓或维持下一次运输的车队。散尽货物不是无代价的善举。

专属高潮：用关卡戳记、车号和债契重建失踪运输者的最后路线。

不可逆代价：商队破产、饥者死亡、军需断裂或青缗决裂。

路线结局：富而负债者、破产救援者、官运承包者或沿路寻名者。

### 5.8 工匠线《木尺两用》

关系核心：鲁砚、公孙砚、阿檀。

路线欲望：造出真正让普通人生活变好的器物。

性格盲点：以为器物用途失控就与造器者无关。

#### R08-SC01 暗格

玩家在粮车轴中藏旧简，却使车轴承重下降。继续使用会威胁整队安全。

#### R08-SC02 同一把尺

同一把木尺可量田、公平分粮，也可快速核定征发。鲁砚要求玩家决定是否留下改进刻度。

#### R08-SC03 修桥还是拆桥

修桥能让百姓撤离，也让军粮更快通过；拆桥可拖慢追兵，也会截断伤者。

#### R08-SC04 墓标与军械

长平之后，作坊材料只够赶制军械、伤车或墓标之一。玩家可以转用材料，但同坊者将替玩家受罚。

专属高潮：通过工坊记号、车号、兵器痕迹和墓标连接无名者去向。

不可逆代价：同坊受罚、撤离受阻、器物被用于杀戮或墓地失去标记。

路线结局：官营匠人、乡间水工、断指退匠者或藏器守录者。

### 5.9 吏官线《明册暗册》

关系核心：季伯、孟简、公孙砚。

路线欲望：让官册至少不要说谎。

性格盲点：相信写下真实就等于保护了真实。

#### R09-SC01 第一处留白

玩家在逃籍者栏留下空白。孟简提醒：空白比假字更容易引来复查。

#### R09-SC02 一个字的缺额

隐丁可被写成病、亡、逃或在。每个字都把责任推向不同的人，没有“无后果假字”。

#### R09-SC03 问议删节

玩家负责记录百家问议。署名能增加证言效力，也会暴露说话者；匿名能保护人，却方便后来者夺走经验。

#### R09-SC04 销毁命令

长平后，军册、伤簿和处置记录被要求统一重抄并销毁底稿。孟简准备服从，季伯旧笔迹提醒玩家底稿中的划改本身就是证据。

专属高潮：建立官册与私录逐项差异，形成《无名录》文字底本。

不可逆代价：玩家、孟简或季伯遗稿至少一方暴露；真名也可能连累家属。

路线结局：官档书吏、被罪改册者、双册守护者或匿名抄写者。

### 5.10 农人线《田亩未归》

关系核心：禾安、魏梁、青缗。

路线欲望：让家人拥有一块不再因国名变化而被夺走的田。

性格盲点：为了守住本户，可能把外来者当成新的威胁。

#### R10-SC01 谁的田

玩家与禾安抢种一块争议田。旧耕户、新授户和逃亡后归来的原户都能提出合理来历。

#### R10-SC02 五家一伍

隐丁案使同伍加役。乡里有人主张告发，有人主张共同替役，也有人要求驱逐所有流民。

#### R10-SC03 粮从田里来

盟书数字要求的军粮超过真实余粮。玩家可交种粮、藏粮、借粮或带乡民逃走；代价延伸到下一季。

#### R10-SC04 守田还是寻人

长平之后，禾安必须在守住田契、寻找失踪家人和护送遗属之间选一件。玩家只能陪她完成一件，其余由其他人物承担并可能失败。

专属高潮：用井名、田界、小地名和亲属称呼补足官册无法辨认的人。

不可逆代价：失田、失亲、全伍受罚或新一批流民被排斥。

路线结局：重建聚落者、军功田户、失地迁徙者或携种寻乡者。

## 6. 百家问议共享场

### CH01-ACT05-SC001 一户得田又失子

十职业携带不同证据进入同一场问议。玩家不能发表全知演说，只能提交主职业真正掌握的材料。

| 职业 | 能提交 | 无法证明 |
|---|---|---|
| 隐士 | 逃籍者实际去向 | 官署完整命令 |
| 仕官 | 政策与执行批文 | 所有基层隐瞒 |
| 谋士 | 多方推演与删改链 | 每户实际承受 |
| 武将 | 军功和卒伍伤亡 | 外交全貌 |
| 医者 | 身体、伤病和死亡时间 | 决策者真实动机 |
| 戏子 | 口述和传播版本 | 传闻全部真伪 |
| 商贾 | 粮价、路线和债 | 没有购买力者的全部需要 |
| 工匠 | 器物用途和工程限制 | 器物最终使用命令 |
| 吏官 | 案卷划改和时间链 | 案卷未记录的人生 |
| 农人 | 收成、役期和家庭变化 | 高层决策过程 |

苏离随后删去人名，只留可用于盟约的数字。这个动作固定发生；玩家改变的是是否保存原稿、公开反对、参与删改或另行传播。

## 7. 长平共同危机

ACT07 不做成一条相同战场线，而做成十个同时发生、互相传递资源和消息的位置。

```text
谋士的警告
→ 仕官的撤离与开仓文书
→ 吏官转为征发名额
→ 商贾和工匠组织车、桥与粮
→ 农人交粮、藏粮或迁徙
→ 武将接收被截断的命令
→ 医者处理身体后果
→ 戏子传播寻人信息
→ 隐士接住制度外逃生者
```

玩家只控制一环。其他九环由对应 NPC 根据此前关系和状态行动。

### CH01-ACT07-SC-FINAL 坑边点名

所有路线最终通过一项“点名行为”汇流：

- 前线点同伍。
- 伤营点伤者。
- 官署对军册。
- 山中记假名。
- 乡里点未归者。
- 商路点失踪车夫。
- 工坊对车号与墓标。
- 乐人用节拍记名。
- 谋士对照原稿与执行结果。
- 仕官保存签署、驳回和迟到的命令。

固定事实：大战结果不变，大量人无法归来。

可变事实：

- 哪些人活着。
- 哪些人仍被列为死亡、逃亡或失踪。
- 哪些家属获得消息。
- 哪份命令和证言留下。
- 谁承担玩家选择造成的亏欠。

《无名录》不是一人在坑边灵感突发写成，而是十类材料汇流后的共同记录。

## 8. 晚年与结局

### CH01-ACT08-SC001 季伯最后一笔

季伯临终或遗稿中承认：记录既能救人，也曾替权力把人删去。他不要求玩家原谅，只把第一次流民名册交出。

若季伯已提前死亡，则由孟简、韩宁或玩家发现遗稿；内容不变，理解者不同。

### CH01-ACT08-SC002 韩宁的答案

韩宁最终确认父亲既救过人，也曾为了保全更多暗册而放弃公开营救一户。她拒绝“忠臣”或“叛臣”的单一结论。

玩家可以：

- 为父亲恢复姓名。
- 只公开被他救下与放弃的人。
- 尊重韩宁暂不公开。
- 把互相矛盾版本并列保存。

这项选择决定后世看到英雄故事、责任记录、私人沉默或冲突档案。

### CH01-ACT08-SC003 无名录去向

四种主去向：

```text
ARCHIVE      交入官藏
DISTRIBUTED  分给家属与行旅
BELL_CACHE   藏入裂钟旧库
SONG         托付乐人和旧曲
```

主职业提供优先建议，但玩家仍可选择其他合法去向。选择时必须展示：

- 保存概率。
- 活人暴露风险。
- 被重写概率。
- 能否被普通人接触。

### CH01-ACT08-SC004 天下将一

多年后，苏醒者暮年听闻天下统一。故人已经散落为官、民、行旅、伤者、失踪者和后人。

最终画面不是地图变成一种颜色，而是同一种格式的新木牌被送往不同道路。

苏醒者听见：

> 这不是你第一次看见山河改色。

他回望许多双手：写简、种田、抬伤者、推粮车、埋葬、改词、开仓、藏人。没有一双手足以代表全部，却都带来同一种无法解释的熟悉。

## 9. 职业结局块

| 职业 | 高责任结局 | 低责任结局 | 非成败结局 |
|---|---|---|---|
| 隐士 | 聚落共同承担并保存假名册 | 独善其身导致邻户背债 | 下山作证或守山沉默 |
| 仕官 | 署名留下权限与失败责任 | 用职位掩盖执行代价 | 罢官但制度改良部分存续 |
| 谋士 | 保存删改链并公开认责 | 让成功说辞夺走经历者声音 | 匿名留稿，个人名声消失 |
| 武将 | 保护同伍并留下处置证言 | 只保袍泽而牺牲无名者 | 生还背债或拒命受罪 |
| 医者 | 伤簿兼顾隐私与辨认 | 以救人之名隐瞒排序代价 | 失去行医能力但留下医方 |
| 戏子 | 旧曲成为共同寻名工具 | 为传播牺牲真名与安全 | 原曲失去，民间版本活下 |
| 商贾 | 道路持续且账册写明人命 | 只保生意或一次散尽后断路 | 破产但同行网络延续 |
| 工匠 | 工记揭示器物责任链 | 以“不知用途”逃避责任 | 器物失去，刻记和技艺留下 |
| 吏官 | 官册私录并列可核验 | 真名公开连累活人或全部销毁 | 被罪后由同僚续抄 |
| 农人 | 守住共同体且接纳后来者 | 为保本户排斥新流民 | 失田迁徙但带走地名与种子 |

结局评价不显示金、银、铜。结算页展示：

```text
你成为了怎样的人
谁因你活下来
谁替你承担了代价
你不知道谁后来怎样
官档怎样写
故人怎样记
哪一件东西离开了这一世
```
