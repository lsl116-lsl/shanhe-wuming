# 第一章《礼崩之世》因果节点表 V0.3

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：当前第一章因果总表，九职业口径  
> 用途：登记第一章主线、九职业线、旧渡现实地基、NPC 自主行动、关键死亡 / 离场和无名录回收节点。

## 1. 因果不是奖惩

本项目的因果定义是：

```text
选择会进入人物、制度、文字、地点与后世，并继续生长。
```

因果节点不记录善恶值，而记录：

```text
玩家做了什么。
谁从中受益。
谁替这个选择承担代价。
谁因此信任、疏远、离开或反向行动。
哪一种版本进入官档。
哪一种版本进入民间。
哪件物、哪段文字、哪个地点、哪个人把它带向后世。
```

## 2. 节点类型

| 类型 | 说明 | 示例 |
|---|---|---|
| 骨架节点 | 无论路线都出现，玩家改变其形态和意义 | 裂钟、长平、秦统一 |
| 倾向节点 | 记录玩家反复优先处理的对象，用于职业显形 | 救治、记录、粮路、器物等 |
| 关系节点 | 改变 NPC 信任、距离、秘密透露和主动行动 | 禾安信任、韩宁后撤、辛衡交托深浅 |
| 分支节点 | 玩家做出互斥处理方式 | 翻车第一笔亏欠、旧仓放粮、无名录去向 |
| 聚合节点 | 汇总多条路线材料 | 无名录、战前名单、长平余波、归旧渡 |
| 死亡 / 离场节点 | 关键人物老死、失踪、战死、疏远或独自行动 | 辛衡老死、季良战死、韩宁失踪、禾安已逝 |
| 路由节点 | 决定下一章从哪一种载体进入 | 无名录交官档 / 民间 / 旧曲 / 拆分 / 埋回洛水 |

## 3. 倾向节点

系统内部可以记录：

```text
record_tendency：记录倾向。
healing_tendency：救治倾向。
route_tendency：粮路倾向。
craft_tendency：器物倾向。
field_tendency：乡土倾向。
military_tendency：军旅倾向。
speech_tendency：言说倾向。
official_tendency：仕途倾向。
withdraw_tendency：隐退倾向。
strategy_tendency：谋划倾向。
```

这些倾向只决定职业显形和剧情入口，不用于善恶评价。

其中 `field_tendency` 不导向独立“农人”职业，而是影响：

```text
禾安信任。
旧仓放粮压力。
旧渡本地户态度。
长平后归旧渡节点。
无名录民间 / 旧渡 / 粥碗回收权重。
```

## 5. NPC 关系因果

### 5.1 禾安

```text
如果主角多次先救人、做现实杂务：禾安信任上升，透露旧渡真实粮水压力。
如果主角多次为记录延误救治：禾安不会简单否定主角，但会记住那一刻的冷。
如果主角长期离开旧渡：禾安会自己承担旧渡压力，不会停在原地等主角。
长平后：禾安问季良消息，主角知道或高度怀疑答案，却说不出口。
晚年：禾安已逝，粥碗成为主角无法逃避的遗物。
```

### 5.2 韩宁

```text
如果主角保护隐名风险：韩宁逐步透露残简和父亲线索。
如果主角急于写全旧里：韩宁后撤，甚至独自行动。
如果韩宁线较深：长平前后可触发失踪、战死、旧籍暴露或关键证人结局。
无论生死：韩宁的“真话会牵出活人”必须进入无名录。
```

### 5.3 辛衡

```text
如果主角理解记录两面性：辛衡交托更深旧册。
如果主角只把记录当正确答案：辛衡保留更多。
辛衡死亡固定发生在 ACT05 前后，不由玩家撤销。
辛衡死后：旧笔、旧册和未完成名单继续影响无名录。
```

### 5.4 柳娘

```text
如果主角重视互认和口述：柳娘让旧曲成为无名录的一种形态。
如果主角只信官册：柳娘仍唱，但不交出最深停顿。
长平后：柳娘或戏班必须出现折损、创伤或旧曲变形。
```

### 5.5 公孙砚

```text
如果主角理解制度必要性：公孙砚邀请主角进入新法执行现场。
如果主角只指责新法冷酷：公孙砚视主角为不懂乱世。
长平后：公孙砚必须面对官档与军籍装不下海量死亡的极限。
```

## 6. 职业因果节点

| 职业线 | 种因 | 长平回收 | 归旧渡回收 | 无名录贡献 |
|---|---|---|---|---|
| 医者 | 反复先救伤者、看护病人 | 救不完的伤者和无人认领者 | 可能从临终口供知道季良死讯 | 伤者口供、临终姓名、旧伤标记 |
| 吏官 / 记录 | 反复整理木牍、口供、旧册 | 死伤册失效、错籍空籍爆发 | 可能在死伤册上见过季良残名 | 残缺名册、删改痕迹 |
| 商贾 | 反复关注粮路、关验、交换 | 商路被军需吞并 | 可能带回季良关验残片 | 路上见闻、失踪名单 |
| 武将 | 反复护送、守路、关注征发 | 战死、失踪、征发名单破碎 | 可能与季良同伍或听见同伍证言 | 阵前名单、无人认领者 |
| 戏子 | 反复重视口述、喊名、旧曲 | 人名处停顿，戏班折损 | 可能在战后唱名里听过季良 | 旧曲、口述、人名停顿 |
| 工匠 | 反复关注车、桥、仓、器物 | 器物被战争使用 | 可能拾到刻着季良名记的器物 | 车辙、器物、桥仓位置 |
| 谋士 | 反复联络、劝说、布局 | 盟书失败，聪明制造代价 | 某份调令或粮道安排可能牵动季良所在伍 | 盟书背后被牵动的人 |
| 仕官 | 反复关注官署、制度、法令 | 制度效率进入战争后的冷 | 官档已有季良死亡 / 失踪记录却未送达禾安 | 官档缺口、执行记录 |
| 隐士 | 反复保存见证、少介入 | 旁观也无法无罪 | 可能保存了不入官档的季良证言 | 私人见证、不入官档材料 |

## 7. 无名录去向节点

最终路由：

```text
A. 交给官档：秩序承认，但可能删改和追索。
B. 藏入民间：保护活人，但难以正式承认。
C. 托给旧曲和口述：有温度，但可能失真。
D. 拆成数份：降低毁灭风险，但完整性降低。
E. 埋回洛水与裂钟之间：交给未来，带入更强裂钟回响。
```

去向由以下因素影响：

```text
主角职业线。
辛衡交托深浅。
韩宁是否存活 / 失踪 / 旧籍暴露。
柳娘口述线深浅。
公孙砚是否承认官档局限。
禾安与季良线的处理。
长平损失版本。
粥碗是否被纳入最终无名录载体。
```

## 8. 设计禁忌

```text
不要把因果写成奖励惩罚。
不要让善意选择必然得到好结果。
不要让冷酷制度选择必然是坏结果。
不要让玩家救下所有关键人物。
不要让 NPC 死亡完全由玩家是否选对决定。
不要让职业倾向成为善恶数值。
不要把农人作为独立职业线恢复。
不要让长平变成可完美通关的谜题。
不要让粥碗变成赎罪成功道具或神秘法器。
```
