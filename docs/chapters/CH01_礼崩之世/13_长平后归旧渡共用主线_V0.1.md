# 第一章《礼崩之世》长平后归旧渡共用主线 V0.1

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：所有职业线共用主线节点  
> 适用范围：ACT07 长平之后、ACT08 无名录去向之前  
> 核心作用：把长平的时代伤口重新压回旧渡、禾安、童年和主角个人亏欠上。

## 1. 核心判断

这个节点必须成为所有职业线的共同主线。

原因：

```text
长平如果只停留在战场、医棚、死伤册、粮道和官档里，它会太大。
大到玩家知道它惨，却未必真正被一个人刺中。
```

主角长平之后回旧渡见禾安，就是把“一整代人被压成数字”重新变成一个具体问题：

```text
你知道某个人已经死了。
而他的妻子，正站在你面前，问你有没有他的消息。
```

这个节点要让主角第一次真正体会：

```text
不只是写不下所有死人。
有些死讯，他也说不出口。
```

## 2. 节点位置

建议放在：

```text
ACT07《长平血雾》结束后。
ACT08《天下将一》前半，无名录尚未最终定形之前。
```

时间：

```text
主角约 37—40 岁。
长平之后数年内。
```

地点：

```text
洛水旧渡。
旧渡灶边。
旧仓外。
童年雨夜翻车旧地。
辛衡旧案或旧屋残处。
```

## 3. 所有职业线都必须经过此节点

无论主角此前是什么职业，都要回到旧渡。

不同职业回来的理由可以不同：

| 职业线 | 回旧渡理由 |
|---|---|
| 医者 | 带着伤者口供或战后病者名单，想查旧渡是否有人能认领。 |
| 吏官 / 记录 | 带着死伤册、失踪册或无人认领者名单，想补旧渡相关空格。 |
| 商贾 | 沿粮路或关验回旧渡，发现旧渡也被长平余波抽空。 |
| 武将 | 从战场或粮道归来，带着不能交还的同伍消息。 |
| 戏子 | 随柳娘旧曲或战后口述回到旧渡，想确认某个名字还能不能唱。 |
| 农人 | 回旧渡看田亩和旧户，发现丁壮被征后的空灶和空田。 |
| 工匠 | 因车辙、桥、仓或裂钟物证回旧渡。 |
| 谋士 | 因盟书、征发和旧渡人被牵动，回头确认自己的话造成了什么。 |
| 仕官 | 因官档核查、失踪者确认或征发册回旧渡。 |
| 隐士 | 因保存私人见证，最后仍无法避开旧渡这个原点。 |

但无论理由如何，回到旧渡后，都必须见到禾安。

## 4. 禾安状态

此时禾安已经不是童年伙伴。

她应当是：

```text
已经成家。
不再年轻。
仍然会算米、柴、水和明早够不够。
丈夫被征兵或随军役离开。
她没有离开旧渡，或者曾经迁徙后又回到旧渡附近。
她不再问大的天下，只问一个具体人的消息。
```

禾安的变化：

```text
小时候她怕晚伸一只手。
中年时她知道，有些手再快也伸不到战场。
她仍然现实、直接、嘴硬。
但她已经不再相信“先动起来”就一定能赶得上。
```

禁止写法：

```text
不要把禾安写成苦等主角的人。
不要把她写成主角错过的恋爱对象。
不要让她用凄美口吻责怪主角。
不要让她只承担催泪功能。
```

她首先是一个活过半生、撑过旧渡现实压力的人。

## 5. 禾安丈夫设定

禾安丈夫可以是虚构旧渡本地人，建议暂名：

```text
阿季 / 季良 / 旧渡季氏子
```

功能不是增加爱情三角，而是让“长平死伤册”落到旧渡一户人身上。

他的设定建议：

```text
不是英雄。
不是名将。
不是特别重要的人。
只是旧渡被征走的普通丁壮。
曾经帮禾安挑水、修灶、收柴。
可能在 ACT03—ACT06 的旧渡或农人线中有一次轻微登场。
名字完整，籍也完整，所以征发能准确找到他。
```

这点很重要：

```text
他不是因为无名而被征。
他正是因为有名、有籍、有户，所以被征。
```

这能反扣第一章母题。

## 6. 共享剧情流程

### SC01 长平之后的路

主角带着各职业线材料离开长平相关场景。

不同职业看到不同残余：

```text
医者带着伤者最后说出的旧渡口音。
吏官带着一份写着旧渡户名的死伤册。
商贾带着断掉的粮路和关验残片。
武将带着同伍托付。
戏子带着唱到一半的人名。
农人带着空田和征发消息。
工匠带着车辙和坏掉的器物。
谋士带着盟书删改痕迹。
仕官带着官档中无法确认的一项。
隐士带着无人愿意入官册的私人见证。
```

主角决定回旧渡。

旁白基调：

```text
你离开旧渡时，以为自己是去看天下。
后来才知道，天下每一次改色，都会绕回旧渡的一口锅、一眼井、一户门前。
```

### SC02 旧渡重见

旧渡已经变了。

画面建议：

```text
旧雨棚还在，但换过梁。
旧仓门上多了新木牌。
辛衡旧案不在原处，或已经积灰。
当年翻车的泥地变成硬路，但雨后仍能看出车辙。
旧礼器库仍在，里面不再挤满流民，却有空处更冷。
```

主角看见禾安。

她正在做很实际的事：

```text
倒空锅。
补灶口。
数粮袋。
给孩子分半碗粥。
把柴往干处移。
```

她不是等在那里。

她是在过日子。

### SC03 禾安认出主角

禾安看见主角，第一反应不应是煽情。

可以是：

> 禾安：“你倒还认得路。”

主角没有立刻回答。

禾安看他身上的尘、手里的册、袋里的物件。

> 禾安：“从那边回来的？”

这里的“那边”不必明说长平。

主角点头或沉默。

禾安继续做手上的活：

> 禾安：“那正好。”

她把一只破碗翻过来。

> 禾安：“我问你个人。”

### SC04 禾安问丈夫消息

禾安说出丈夫名字。

示例：

> 禾安：“季良。旧渡季氏，去年随征走的。你路上，听过没有？”

这句话要非常普通。

越普通越痛。

主角此时知道或高度怀疑：季良已经战死。

根据职业线，主角知道的方式不同：

| 职业线 | 主角知道的方式 |
|---|---|
| 医者 | 曾在医棚听到临终者报出“旧渡季良”。 |
| 吏官 | 死伤册上见过“旧渡季氏良”或近似残名。 |
| 商贾 | 粮道旁有人交给他一枚旧渡关验残片。 |
| 武将 | 曾与季良同伍或听同伍说其战死。 |
| 戏子 | 战后有人在旧曲节拍里喊过这个名。 |
| 农人 | 征发空户名单里已有季良名。 |
| 工匠 | 车辙旁拾到刻着季良名记的器物。 |
| 谋士 | 某份调兵 / 粮道安排间接导致其所在伍覆灭。 |
| 仕官 | 官档已有死亡或失踪记录，但未能送达家属。 |
| 隐士 | 私人见证中有人托主角带过话，但主角一直未确定。 |

主角不能说出口。

他的回答建议固定为：

> 主角：“我……去查查看。”

或者更克制：

> 主角：“我查过些册。还没对上。”

禾安看着他。

她可能已经听出什么，但不逼问。

> 禾安：“你小时候说谎，耳朵会红。”

停顿。

> 禾安：“现在倒不红了。”

这句要非常轻，不要像指责。

## 7. 回忆旧渡童年

禾安没有继续追问丈夫。

两个人聊到小时候。

### 7.1 聊雨夜流民

禾安：

> “你还记得那晚吗？车翻了，你站着看孩子，又看那些烂木片。”

如果 ACT01 主角先救孩子：

> 禾安：“那晚你先来抬车。我那时候还以为，你这人不算太慢。”

如果 ACT01 主角先抢湿简：

> 禾安：“那晚你先扑那些简。我气得想骂你。后来才知道，有些木片后面也站着活人。”

如果 ACT01 主角先互认：

> 禾安：“那晚你跟着柳娘喊人。嗓子都劈了，还非要喊到有人答应。”

### 7.2 聊韩宁

禾安：

> “那个不肯说旧里的孩子，后来你还见过吗？”

主角可以根据韩宁线状态回答：

```text
韩宁存活：见过，但不能说太多。
韩宁失踪：见过一回，后来断了消息。
韩宁战死：知道结局，但说得很轻。
韩宁旧籍暴露：沉默更久。
```

主角的回答不能爽快。

因为韩宁也代表“真话会牵出活人”。

禾安：

> “那时候我只记得没米下锅。”

她看着灶。

> “后来才知道，她怕的东西，比没米还难熬。”

### 7.3 聊没有米下锅

禾安说：

> “你还记得那锅粥吗？”

主角：

> “记得。”

禾安：

> “熬得跟水一样。你还问够不够。”

她笑一下。

> “哪有什么够不够。只是看谁先倒下。”

这段必须把童年和长平连起来。

主角从一锅粥想到战场粮道，从旧渡小饿想到长平大死。

## 8. 主角离开旧渡

主角没有告诉禾安丈夫的死讯。

离开前，禾安没有求他留下。

她只说：

> 禾安：“查到了，托人带句话。”

主角点头。

禾安把灶里的火拨亮一点。

> 禾安：“别亲自跑。你也不是十岁了。”

这句反而成为主角后来不敢回来的理由之一。

主角独自离开。

旁白：

```text
你走出旧渡时，听见锅盖在身后轻轻一响。
那声音比长平的鼓声小得多。
却压得你更久。
```

## 9. 长久不归

此后直到晚年，主角都没有再回旧渡。

表面理由可以因职业不同而不同：

```text
医者：还有太多伤者。
吏官：还没查清册。
商贾：路总在远处断。
武将：不敢带回同伍死讯。
戏子：不敢把那个人名唱回去。
农人：不敢看空灶。
工匠：不敢修回那条通往旧渡的路。
谋士：不敢承认自己的话也把人推向那里。
仕官：官档一直没有正式确认。
隐士：保存见证的人，自己也在逃避见证。
```

真实原因只有一个：

```text
他不知道怎么把禾安丈夫战死的消息讲给禾安。
```

这不是软弱的逃避，而是第一章“记录与沉默”主题在主角自己身上的反噬。

```text
他知道不说是亏欠。
他说不出口也是亏欠。
```

## 10. 晚年回旧渡

到 ACT08 末尾，主角约 75 岁。

此时他必须决定无名录去向。

他终于回旧渡。

旧渡更安静。

画面建议：

```text
旧仓还在，但门换了。
旧礼器库破了半边。
辛衡旧案已无人知道原来放在哪里。
当年翻车那条路已经不再明显。
灶边有人换过新泥。
```

主角寻找禾安。

他发现禾安早已离世。

不要让禾安临终等他。

要写成：

```text
她照常过完自己的一生。
她撑过旧渡，送走许多人，养大孩子或照看别人的孩子。
她没有等主角回来才结束。
```

这很重要。

禾安不是主角遗憾的附属物。

她有完整人生。

## 11. 禾安留下的东西

主角没有见到禾安本人，但可以见到她留下的东西。

建议物件：

```text
倒扣过很多次的旧锅。
一包种子。
一块刻着“季”字的旧木片。
一只补过的热水桶。
一段别人转述的口头话。
```

可选口头话：

> “她走前说，那个人若还回来，就让他别查了。”

或者更克制：

> “她后来不问了。只说，没消息的人，也得留一口饭。”

这个点非常好：

```text
禾安最后可能已经知道丈夫死了。
但她没有等主角告诉她。
她用自己的方式把空位留了一生。
```

## 12. 主角的最终决定

主角面对无名录去向时，旧渡与禾安成为最后一根针。

他终于明白：

```text
无名录不是为了把所有死讯送到每个人面前。
也不是为了替活人抹掉痛苦。
它是为了让那些没有被送达、没有被承认、没有被说出口的人，不至于彻底散掉。
```

因此无名录最终去向可以根据玩家选择不同变化，但都必须被禾安节点影响。

### 12.1 交给官档

主角决定：

```text
如果没有官档，禾安丈夫这样的普通丁壮永远不会被制度承认。
```

但他必须接受：

```text
官档会删改，会分类，会把人再次变成户、役、亡、失。
```

### 12.2 藏入民间

主角决定：

```text
有些消息不该由官府先知道。
活人需要留下空位，也需要自己选择何时知道。
```

但他必须接受：

```text
民间藏本会残缺，会散，会被遗忘。
```

### 12.3 托给旧曲和口述

主角决定：

```text
禾安没有等到正式死讯，但旧渡的人会用饭、灶、歌和口头话记住那个人。
```

但他必须接受：

```text
口述会变形，名字可能不完整。
```

### 12.4 拆成数份

主角决定：

```text
没有一种记录方式配独自承担全部无名者。
```

于是官档、民间、旧曲、物证、私藏各得一部分。

代价：

```text
后世难以拼回完整真相。
```

### 12.5 埋回洛水与裂钟之间

主角决定：

```text
有些答案只能交给后来的人。
```

禾安的旧锅、季良的残名、韩宁的残简、辛衡的空格、柳娘的旧曲，都成为埋藏物或回声的一部分。

代价：

```text
这一代人可能永远得不到正式承认。
```

## 13. 这个节点的主题作用

该节点完成三次回扣。

### 13.1 回扣 ACT01

ACT01 是：

```text
没有米下锅。
救人、留证、互认、分粮互相冲突。
```

长平后旧渡是：

```text
有些人被征走，有些人没消息，有些锅仍然要烧。
```

### 13.2 回扣韩宁

韩宁说过：

```text
写全了，就会有人顺着找。
```

禾安丈夫则是另一面：

```text
写全了，也可能让征发准确找到你。
但不写，死后又无人承认。
```

### 13.3 回扣无名录

主角一直在问写不写。

禾安节点让他知道：

```text
真正难的不是写不写。
而是你能不能把写下来的死讯，交给还活着的人。
```

## 14. 设计禁忌

```text
不要把禾安写成主角错过的爱情遗憾。
不要让禾安等主角一生。
不要让主角不说死讯被写成简单懦弱。
不要让丈夫战死成为纯催泪工具。
不要让晚年回旧渡变成赎罪成功。
不要让无名录决定消除主角亏欠。
```

## 15. 一句话总结

```text
长平让主角看见无数人死去。
旧渡让主角面对一个他说不出口的死讯。
无名录不是为了让他无愧，而是为了让那些没有被说出口的人，不至于彻底无名。
```
