## 1. 过渡必须完成的任务

这段过渡不是普通时间字幕。它必须同时完成：

1. 让第一章的“天下将一”变成第二章的“天下已一”。
2. 让新法木牌从争论对象变成帝国日常。
3. 让《无名录》的去向产生真实差异。
4. 让第一章的老人完成本世，让第二章的少年拥有完全不同的人生。
5. 让裂钟触发熟悉感，却不证明两世属于单一灵魂履历。
6. 把问题从“统一是否值得”推进到“统一以后，人真的安定了吗”。

## 2. 时间与地点

| 项目 | 设计 |
|---|---|
| 第一章结束 | 前 221 年前后，暮年苏醒者完成《无名录》交接并离世 |

| 新身份 | 约十三岁的编户少年；本世姓名、家庭细节可由玩家确定 |
| 共同现实压力 | 家庭被召至官署核定户、田与役，统一书写与制度第一次直接落到新一世姓名上 |

选择同一空间不是为了让苏醒者拥有固定家族，而是让地点本身成为时间见证：

```text
周的旧礼器库
→ 战国流民暂居地
→ 秦三川郡下的官署与郡库
```

山河没有移动，命名山河的制度已经改变。

## 3. 推荐完整过渡文：裂钟藏册线

### 《钟声入简》

天下终于只剩下一个国名。

消息传到洛水边时，没有雷声，也没有天光骤变。

只是官道上的车更多了。旧城门上的字被重新描过，商旅携带的量器要拿去比校，路旁不再有人争论该尊哪一位王。年轻人说，乱世总算结束；老人却先问，明年的役书会从哪里来。

你已经很老了。

老到禾安说起某一年旱情时，你要想很久，才能记起那是旧仓开门以前，还是长平落雨以后。老到青缗账册上的数字换过几轮写法，柳娘的曲子也只剩后辈还能唱全。老到别人提起当年列国，你先想起的不是旗号，而是那些跟着旗号走了、再也没有回来的人。

《无名录》摊在膝上。

它从来不像一部完整的书。

有的简上是姓名，有的只有乡里；有的写着“亡”，旁边却被另一只手补了“未归”；有一枚简只刻着衣襟的颜色和左臂旧伤；还有许多空格，空得叫人不敢久看。

你没有把那些空格填成数字。

裂钟仍在旧库里。

钟身比少年时更暗，裂纹里积着洗不净的尘。你把《无名录》分成数束，用旧布包好，藏进钟后的木匣。木匣合上以前，一枚半名残简从指间滑落。那上面的故邑与户属早已被刮去，剩下的半个名字也没有人能认全。

你把它放回去。

“不知道名字，”你低声说，“不等于他没有名字。”

无人回答。

洛水在库外流。水声穿过钟身裂纹，像许多年前那个没有说完的梦。

你看见许多双手。

写简的手，种田的手，推粮车的手，缝伤口的手，刻木尺的手，埋葬死者的手。它们不属于同一个人，也没有一只手佩着王者的冠饰。

你终于把木匣合上。

钟没有响。

可那一夜，你听清了声音：

> 这不是你第一次看见山河改色。

你没有想起一个更古老的姓名。

你只是忽然明白，自己寻找了几十年的东西，也许从来不属于一个人。

天亮以前，你在本世最后一次睡去。

---

三年后。

秦三川郡，洛水北岸。

你被木牍相击的声音惊醒。

不是钟。

官署院中，两个小吏正在清点从旧库移来的器物。木牍一枚枚碰在案上，声音干脆、整齐。有人在廊下高声报数，有人把旧简按新的字形重抄。认不出的字放到左边，无法核定的姓名放到更远的一边。

你低头看见自己的手。

这是一双少年的手，指节没有旧伤，掌心只有昨日帮家里搬粮留下的红痕。你知道自己今年十三岁，知道母亲清晨催你来官署，知道家中有几亩田、欠过谁一袋粟，也知道今日为何要来。

官署要重新核定你家的户、田和役。

这些本世记忆完整而真实。你不是闯入这段人生的客人。

可你仍记得水从裂纹里涌出的声音。

“下一户。”

案后的吏抬起头。

你的母亲把你往前推了一步。她报出家中人数，报出田亩，也报出你本世的姓名。

吏把那个名字写在新简上。

笔尖落下时，你胸口忽然一紧。

上一世，你花了几十年替别人留下名字。

这一世，你的名字刚刚被写下，就已经和田、税、役连在一起。

院门外传来沉重的拖响。

几名役夫把一口旧钟抬进来。钟身开裂，已不能用于礼乐。领头的人照着器物清单念道：

“旧钟一，残，不堪用。”

小吏在简上写了一个数。

役夫放下钟时，木架歪了一下。钟后的旧匣摔在地上，盖板裂开，几束发黑的竹简滚进日光。

院中忽然安静。

你没有见过那些简。

可你的手已经先一步伸了出去。

指尖碰到最旧的一枚时，明明干燥的竹面却像刚从水里捞起。你看见湿简、白骨、火光和许多没有固定面容的人。一个空格停在简尾，旁边刻着一道短痕。

不是删除。

更像有人不肯把“不知道”写成“从未存在”。

案后的吏皱起眉。

“旧国文字，姓名无验。”他说，“另置。待重抄。”

另一个人问：“抄不出的呢？”

“无验者不录。”

你抬起头。

院墙上贴着新颁的文字，字形整齐，笔画一致。官道从墙外伸向更远的郡县，量器、车轨、法令和役书都将沿着它通行。列国的关塞正在拆去，过去互不相通的地方第一次被写进同一套秩序。

这秩序强大、清楚，远胜那口已经发不出声音的旧钟。

可日光下，那些无法核定的名字仍旧残缺。

你的母亲在身后低声催促。今日若误了核籍，家里的事不会等你。小吏也已伸手，要把散简扫进“无验”的一堆。

你只有片刻可以决定：

- 把手中的残简交回去，请求逐枚重抄。
- 先藏下一枚，去寻找仍能辨认旧字的人。
- 询问这口裂钟来自哪里。
- 先完成本世核籍，记住散简被送往何处。

远处没有战鼓。

天下已经统一。

而你的第二段人生，就从一个将被删去的名字前开始。

## 4. 四种载体分支替换段

正式实现时，第 3 节“三年后”至“玩家看见第一枚旧简”的部分按 `SW-CH01-022` 替换。替换段结束后统一汇入：

> 案后的吏开始核定你家的户、田和役。

### A. ARCHIVE 官藏线

你在官署帮忙搬运待重抄的旧简。

旧简被分成三堆：字可辨者重抄，事可核者归档，姓名无验者另置。你在第三堆中看见辛衡的空格记号，也看见一行被新笔划去的旧字。

你不认识笔迹，却在笔锋停顿处感到无法解释的熟悉。

这一线的开场选择是：

- 按命重抄并删去无验姓名。
- 保留空格和旧笔迹。
- 私下制作新旧对照。
- 询问谁有权决定“无验”。

### B. DISTRIBUTED 家属与行旅线

你的母亲带来一枚家中保存多年的残简。

她需要用它证明一名未归者不是逃役者，否则旧债与新役将一并落到本户。残简上的姓名与官册写法不同，官吏不肯认。

你第一次意识到：同一个人可以在家中有一个名字，在官册中有另一个名字，也可以在制度里根本不存在。

这一线的开场选择是：

- 接受官册名字以换取眼前核准。
- 坚持旧名并寻找旁证。
- 隐去未归者与本户的关系。
- 请求保留“未归”，拒绝被改成“逃”或“亡”。

### C. BELL_CACHE 裂钟藏册线

使用第 3 节完整默认稿。

这一线把裂钟、无名录、郡库和统一书写集中在同一场景，适合作为首个原型的默认展示路径。

### D. SONG 乐人旧曲线

官署院外有人哼起一段旧曲。

曲子明说宋亡，每一句却把具体乡里或绰号藏在不同停顿里。官吏命乐人改词，因为旧词中有无法核定的人名，也有会把活人重新连回旧籍的故邑。

你明明第一次听见，却在下一处转调前先吸了一口气。

你不知道歌词，却知道旋律不该在那里停下。

这一线的开场选择是：

- 帮乐人记下被删歌词。
- 接受改词，让旋律先活下去。
- 把姓名改成只有家属听得懂的暗语。
- 询问自己为何提前知道下一处旋律。

## 5. 分支汇流后的共同开场

四条载体线在十五分钟内必须汇流到同一件事：

```text
新一世家庭被核定户、田与役
→ 玩家本世姓名第一次进入秦制文书
→ 第一章载体出现
→ 旧名字与新标准发生冲突
→ 玩家作出第二章第一个选择
```

第二章第一个选择不能决定“支持秦还是反对秦”，而应决定玩家如何处理：

- 统一书写的公共便利。
- 无法核验者被删除的风险。
- 本户现实的税役压力。
- 旧记录对活人可能造成的伤害。

## 6. 章节问题的正式交接

第一章的问题：

> 统一是否值得？

第一章给出的不是答案，而是一组事实：

- 旧礼确实已经失效。
- 新法确实能组织资源、打破部分旧特权。
- 新法也把家庭、土地和生命变成可征发的单位。
- 统一结束列国长期争战，却沿着白骨与名册来到。

第二章因此不再重复争论“要不要统一”，而从既成现实继续：

> 天下已经使用同一种制度组织道路、文字、田亩和人。
>
> 那么，统一以后，人真的安定了吗？
> 被写成同一种字的人，是否因此更有名字？

## 7. 主职业晚年插入块

以下模块插入默认稿“老人离世”之前。一次游玩只读取主职业和对应结局，不把十条路线全部朗读。

### ROUTE-HERMIT 隐士

> 山里最后一处藏名的洞壁被雨水冲平。你没有重刻所有真名，只留下辨认者和保护期限。你明白，有些名字暂时不被写下，不是因为它们不重要，而是因为写下它们的人还活在追索之中。

若聚落曝光，追加：

> 官差最终找到了山路。有人怪你开过门，有人怪你关门太迟。南郭生没有替你辩护，只把那份假名册分成三份，交给三个互不相识的人。

### ROUTE-OFFICIAL 仕官

> 你最后一次用印，不是升迁文书，而是为一批永远来不及撤走的人补写知情、驳回与迟到的时刻。官署不愿收这份责任链，你便把它夹进政令副本，让后来的重抄者必须先看见那些批注。

若保职，追加“印仍在手，旧友已不再相信你还会等到下一次”；若罢官，追加“印被收走，命令的副本却先一步离开”。

### ROUTE-STRATEGIST 谋士

> 后人记得一条被采用的策，却未必记得策中曾有姓名。你把原稿、删改稿和执行稿并排捆好，不再争哪一份最像你的本意，只写下每一次删改把风险移给了谁。

若公开认责，保留署名；若匿名留稿，署名栏留空，但保留笔迹旁证。

### ROUTE-SOLDIER 武将

> 你没能带所有同伍回来。暮年点名时，你仍会在一个名字后停很久：战死、失踪、投降后失踪和逃亡不是同一回事。军功簿只要一个字，你偏偏留下了四种可能。

若伤残归乡，载体为袍泽托物；若受罪或失踪，载体由屠申、魏梁或家属代交。

### ROUTE-HEALER 医者

> 伤簿上的人比军册上的多。你记得谁在天亮前还有呼吸，也记得谁因为你的排序等得太久。后来人只抄走医方，你便在药名旁留下身体特征，让一张方子仍能指回具体的人。

若玩家失去行医能力，追加“小蓟替你握笔，你负责逐个纠正名字”。

### ROUTE-PERFORMER 乐人

> 旧曲已经没有唯一原词。有人唱国名，有人唱乡里，有人只唱一串旁人听不懂的绰号。你没有把它改回所谓原样，只在每次停顿处留下谁曾在那里被唱起。

若成为禁曲，旋律暗传；若进入宫廷，民间原词由阿檀带走；若失声，由众人接唱。

### ROUTE-MERCHANT 商贾

> 有些账永远无法结清。你在最后一页划去利息，却没有划去欠债人的名字；又给已经死去的车夫补上一笔“货已送达”。青缗说这不合账法。你回答，人命本来就不合账法。

若商队破产，账簿分散在同行手中；若转入官运，私账与官账并列保存。

### ROUTE-ARTISAN 工匠

> 木尺磨短了，刻度仍在。你晚年不再问一件器物究竟算农具、军具还是藏物的匣子，只把谁造、谁领、谁改、最后用在何处刻进工记。裂钟若仍在，也只是一件经历过这些手的旧器。

若裂钟已熔，载体改为熔铸清单、拓记或铜料去向，不得恢复整钟。

### ROUTE-CLERK 吏官

> 明册里的人各有一个确定字，暗册里却满是“也许”“未归”和旁人的异议。你曾以为真相应当只有一版，暮年才明白，并列保存冲突有时比替所有人判定更诚实。

若玩家被罪，由孟简续抄；若仍在官署，必须同时留下销毁命令和未执行副本。

### ROUTE-FARMER 农人

> 田界改过，井名没有。禾安把每一户从哪条沟、哪棵树旁被征走记给孩子听。你留下的不是一张能证明所有权的地契，而是一包种子和一串只有当地人能辨认的小地名。

若失田迁徙，种子随行；若守住聚落，必须追加后来流民是否被接纳的结果。

## 8. 核心人物命运插入规则

过渡文至少选择两名与本存档关系最深、命运变化最大的核心人物，不按好感度机械排序。

| 人物 | 生还块 | 死亡 / 失踪块 | 决裂块 | 跨章痕迹 |
|---|---|---|---|---|
| 辛衡 | 暮年交出第一份名册并承认删名旧事 | 遗稿由孟简或玩家发现 | 不适用；他可拒绝玩家处理名册的方法 | 笔法、抄册习惯、第一份名册 |
| 禾安 | 守田、失田或携种迁徙，始终记得未归者 | 家人用井名和田界继续辨认她 | 因玩家转嫁徭役而不再往来 | 种子、地名、家庭口述 |
| 韩宁 | 并列保存父亲救人与放弃他人的记录 | 去向不明，只留查档批注 | 拒绝让玩家替父亲定论 | 暗册、父亲笔迹、责任争议 |
| 青缗 | 继续维持道路或转入官运 | 最后关卡戳记成为去向证据 | 因玩家牺牲同行或断路决裂 | 账簿、车号、道路记号 |
| 荀白 | 抄录冲突证言并继续游学 | 未完成问议由弟子续抄 | 认为玩家把复杂经验卖给权力 | 问议副本、无署名批注 |
| 申不疑 | 进入新秩序并保留执行批注 | 死于动乱或失去官位 | 承认彼此都曾让别人先付代价 | 治策、法令批注 |
| 柳娘 | 把曲交给阿檀或民间 | 旧曲在她死后出现多个版本 | 因玩家公开真名连累同行而拒唱 | 曲调、停顿、改词史 |
| 公孙砚 | 将新法执行经验带入秦制 | 只留下精确而无解释的批注 | 因改册或公开抗命将玩家列入案 | 木牌格式、官署文书 |
| 屠申 | 归还同伍托物并拒绝英雄叙述 | 军册写“亡”，私录写具体最后所见 | 因玩家拒命或服从造成同伍损失 | 托物、同伍点名 |
| 苏离 | 承认删改并保存其中一版 | 成名而原稿失传，或本人失踪 | 拒绝接受玩家事后把责任全推给他 | 盟书删改链 |

人物块不能把后人写成人格复制品。下一章只继承载体、处境、债务、传说或制度后果。

| 条件 | 插入内容 |
|---|---|
| 官档最完整 | 旧名被统一重写，无法核验者被删 |
| 私录最完整 | 保留具体姓名，但缺少合法印记 |
| 口述最完整 | 传播最广，姓名与事件次序已经变形 |
| 三者冲突 | 第二章玩家必须决定先相信哪一版，并保留反证 |
| 主载体毁损 | 只展示损毁记录和现实后果，不恢复原物 |

## 10. 过渡验收

- [x] 第一章老人完成本世，不把故人强行带入下一世。
- [x] 第二章少年拥有完整本世身份，不是失忆空壳。
- [x] 两世通过地点、制度、载体和记忆连接，不依赖血缘。
- [x] 四种《无名录》去向产生不同开场，但快速汇入同一主线。
- [x] 裂钟是现实物件与记忆入口，不是轮回法器。
- [x] 新法木牌转化为秦制日常。
- [x] 统一措施同时显示组织能力与删除风险，不做简单褒贬。
- [x] 第二章第一个选择处理具体户籍问题，不让玩家先选抽象政治立场。
- [x] 没有提前揭示苏醒者是人民共同回声。
- [x] 十条主职业均有可插入的晚年余波。
- [x] 核心人物按命运状态进入过渡，而非只出现固定名单。
- [x] 官档、私录和口述的冲突可以改变第二章第一个判断。
- [x] 主载体毁损时只保留痕迹和后果，不会完整复活。
