# 第一章《礼崩之世》ACT 年龄段路线交织与关键节点 V0.2

> 文档状态：第一章 ACT01—ACT08 细化骨架  
> 适用范围：第一章主线拆分、九职业线交织、旧渡现实地基、NPC 自主行动、关键死亡 / 离场 / 回响节点、Codex 剧情生成  
> 前置文档：`10_主角立身与职业成形规则_V0.1.md`  
> 核心原则：路线可以分开，但必须在长平、旧渡、禾安粥碗和无名录处交织回来。

## 1. 总体说明

本文件用于把第一章从“人生大方向”继续拆成 ACT01—ACT08 的可制作结构。

第一章主角人生跨度固定为：

```text
前 286 年：主角 10 岁。
前 221 年：秦统一，主角约 75 岁。
```

本章不是连续日常模拟，而是用关键年龄段串成完整人生。

第一章当前保留九条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
隐士。
```

“农人”不再作为独立职业线。土地、粮水、田亩、空户、旧渡、灶火、没有米下锅和禾安，转为所有职业共同面对的现实地基。

玩家选择会影响：

```text
职业倾向。
NPC 信任与距离。
某些人是否透露秘密。
某些人是否提前离开、失踪、被牵连或战死。
无名录最终形态。
```

玩家不能改变：

```text
宋亡。
长平。
周亡。
秦统一。
旧礼崩解与新秩序推进。
```

## 3. ACT01：裂钟之梦 / 雨后流民

```text
主角年龄：10 岁。
时间：前 286 年，宋亡消息抵达洛水旧渡。
地点：洛水旧渡。
```

固定事件：

```text
主角写下本世姓名。
母亲望向河道尽头。
辛衡解释名与籍的重量。
禾安以现实行动拉住主角。
宋亡流民抵达。
韩宁拒绝说旧里。
柳娘旧曲停在地名处。
裂钟第一次响起。
雨夜翻车。
```

翻车现场三方向：

```text
A. 先救车下孩子。
B. 先抢泥水湿简。
C. 先让活人互认。
```

该选择只影响初始职业倾向和 NPC 第一印象，不锁职业。

这一夜必须留下“小时候一起喝粥的碗”的来源：禾安把粥熬得像水，主角与禾安或流民共享这只旧碗。

## 4. ACT02：旧礼无声 / 旧仓与旧册

```text
主角年龄：11—15 岁。
地点：洛水旧渡、旧仓、临时棚区、辛衡书案。
```

固定事件：

```text
流民暂住旧渡。
粮、水、棚位、名册、旧里、旧债开始变成现实压力。
旧仓放粮与登记矛盾出现。
父亲官粮线第一次露出痕迹。
辛衡旧册和隐瞒开始有重量。
```

路线触发：

```text
反复救治伤者：医者入口加深。
反复整理口供和木牍：吏官 / 记录入口加深。
反复处理粮、水、棚位：旧渡现实地基加深，可影响禾安信任和后续归旧渡情绪。
反复修补车棚器物：工匠入口加深。
反复劝人、组织互认：戏子 / 谋士 / 言说入口加深。
```

## 5. ACT03：旧国被重写 / 新法入乡

```text
主角年龄：16—20 岁。
地点：旧渡、乡里、县署外围、重新编户现场。
```

固定事件：

```text
旧渡被重新编户。
新法木牌进入乡里。
旧称呼被改写为户、伍、什。
田、役、债、罚、连坐进入日常。
公孙砚第一次正式出现。
```

新法要同时呈现有用与刀口。

禾安只问粮、水、役落到谁家，不参与宏大辩论。

## 6. ACT04：新法如刀 / 选择一双手

```text
主角年龄：20—25 岁。
地点：县署、旧渡、商路、学舍、工坊、医棚等分支场景。
```

固定事件：

```text
主角开始半离开旧渡。
职业方向真正显形。
辛衡病重。
辛衡把未完成的旧册责任交给主角。
禾安开始不再只是童年伙伴，而是旧渡现实压力的独立承担者。
```

职业显形靠责任，不靠菜单。

“乡土倾向”在此阶段不形成独立职业线，而是影响旧渡、禾安、粮水和空户相关共用剧情。

## 7. ACT05：百家灯火 / 辛衡老死

```text
主角年龄：25—30 岁。
地点：洛邑、学舍、商路、旧渡回望、辛衡病榻。
```

固定事件：

```text
主角接触百家争鸣和不同人生答案。
荀白登场或加深。
申不疑制度重构思想登场或加深。
青缗商路与消息网络登场或加深。
辛衡老死。
```

辛衡之死安静、有重量。主角失去第一个教他“字后面站着人”的人。

## 8. ACT06：合纵连横 / 战争前夜

```text
主角年龄：31—35 岁。
地点：列国边境、商路、粮道、学舍、军役登记处、乡里征发现场。
```

固定事件：

```text
合纵连横不断变化。
盟书、地图、粮道、征发和军籍逐渐连成战争机器。
上党风云逼近。
主角所在职业线被不同方式卷入。
```

必须出现“战前名单”。

名单要让玩家看见：

```text
有的人名字完整，马上被征。
有的人名籍残缺，无法领粮。
有的人被写作逃亡。
有的人已经死了，却还在名册上。
有的人活着，却不敢出现。
```

禾安丈夫季良可以在此阶段被征。其重点不是英雄叙事，而是：他正因为有名、有籍、有户，所以被征发准确找到。

## 9. ACT07：长平血雾 / 不可逆战死节点

```text
主角年龄：36 岁左右。
历史节点：长平大战。
```

固定事件：

```text
长平发生。
大量军籍、粮籍、死伤册失效。
活人与死人在记录中混杂。
某些 NPC 战死、失踪或留下不可逆创伤。
主角第一次真正看见一整代人被压成数字。
```

九职业从不同入口进入长平。

不可逆损失包括：

```text
军旅相关 NPC 战死。
韩宁失踪、战死或被迫暴露旧籍。
柳娘戏班折损。
禾安旧渡线被抽空，季良战死或失踪。
公孙砚制度线受创。
青缗在保路、保货、保人之间做不可逆选择。
```

长平后的主角领悟：

```text
名字写得再整齐，也接不住所有死人。
不写，又会让他们彻底散掉。
```

这是无名录真正成形的节点。

## 10. ACT07 后 / ACT08 前：长平后归旧渡

所有职业线必须经过此节点。

主角回旧渡，见到已经成家的禾安。

禾安问丈夫季良消息：

```text
季良。旧渡季氏，去年随征走的。
你路上，听过没有？
```

主角知道或高度怀疑季良已经战死，但说不出口，只能说：

```text
我……去查查看。
```

禾安可能已经听出什么，但不逼问。

她说：

```text
你小时候说谎，耳朵会红。
现在倒不红了。
```

两人聊到小时候：雨夜流民、韩宁、没米下锅和那只旧碗。

禾安从灶边摸出那只碗：

```text
那晚就是这只。
熬得跟水一样。
你还问够不够。
哪有什么够不够。只是看谁先倒下。
```

主角离开旧渡后，直到晚年都没有再回去。

真实原因：

```text
他不知道怎么把禾安丈夫战死的消息讲给禾安。
```

## 11. ACT08：天下将一 / 无名录去向

```text
主角年龄：37—75 岁。
历史节点：长平余波、周亡、新秩序推进、秦统一。
```

ACT08 时间跨度大，应采用“暮年回望 + 关键节点跳切”的叙事方式。

固定事件：

```text
长平余波持续。
幸存者回不去原来的家。
失踪者无法被确认为亡。
无名录逐渐成形。
周亡，旧礼最后象征崩塌。
秦统一，天下归一。
主角决定无名录去向。
```

主角晚年回旧渡。

禾安已逝。

她没有等主角回来，也没有把自己活成主角的遗憾。

她留下：

```text
小时候一起喝过那锅稀粥的碗。
倒扣过很多次的旧锅。
补过的热水桶。
也许还有一块刻着“季”字的旧木片。
```

有人转述禾安的话：

```text
她后来不问了。
只说，没消息的人，也得留一口饭。
```

这只碗成为主角决定无名录去向前的最后一根针。

## 12. 无名录来源

九职业线为无名录提供不同材料：

```text
医者：伤者口供、临终姓名、身体上的旧伤标记。
吏官：残缺名册、死伤册、错籍与空籍。
商贾：路上见闻、关验记录、失踪名单。
武将：征发记录、阵前名单、战后无人认领者。
戏子：旧曲、口述、人名停顿。
工匠：车辙、器物、桥仓位置、裂钟相关物证。
谋士：盟书背后的代价、被计策牵动的人。
仕官：制度档案中的缺口和删改痕迹。
隐士：不入官档的私人见证。
旧渡现实地基：禾安粥碗、空户、田亩、旧锅、灶火、季良残名。
```

## 13. 无名录最终去向

最终选择可根据职业线和 NPC 关系出现不同选项。

```text
交给官档：秩序承认，但可能被删改或追索。
藏入民间：保护活人，但难以被后世正式承认。
托给旧曲和口述：有温度，但可能失真。
拆成数份：减少一次性毁灭风险，但完整性降低。
埋回洛水与裂钟之间：保留神秘回响，但等同把答案交给未来。
```

无论哪种选择，都不能消除主角亏欠。

## 14. 关键 NPC 生命周期草案

### 辛衡

```text
ACT01：教主角写名与理解名籍。
ACT02：旧册与旧仓压力出现，辛衡开始显出隐瞒。
ACT03：面对新法入乡，辛衡态度复杂。
ACT04：病重，交托旧册、旧笔和未完成名单。
ACT05：老死，留下未写完的人名和父亲官粮线索。
ACT06—ACT08：以笔、旧册、未完成名单和主角记忆回响。
```

### 禾安

```text
ACT01：现实锚点，先救眼前人，熬出那锅稀粥，碗第一次出现。
ACT02：处理旧渡粮、水、柴、棚位压力。
ACT03：面对新法入乡，先问代价落到谁家。
ACT04—ACT06：留守旧渡、参与迁徙、照顾伤者或与主角渐行渐远，但她不等主角。
ACT06—ACT07：丈夫季良被征，长平后战死或失踪。
ACT07 后：主角归旧渡，禾安问季良消息，主角说不出口。
ACT08：禾安已逝，留下小时候一起喝粥的碗。
```

禾安不应为主角停在原地。

### 韩宁

```text
ACT01：拒绝旧里，护住残简。
ACT02：根据主角选择，透露或隐藏残简细节。
ACT03：新法编户让他的旧籍风险加重。
ACT04—ACT05：可能离开、失踪、短暂同行或暗中保留线索。
ACT06—ACT07：残简线在战争前后重新浮出，可能导致失踪、战死或牵连。
ACT08：若存活，可成为无名录关键证人；若死亡 / 失踪，其残简成为无名录核心材料。
```

### 柳娘

```text
ACT01：旧曲停在地名处。
ACT02：用唱、喊名和戏箱安住流民。
ACT03—ACT05：口述线、戏子线、亡国旧曲加深。
ACT06—ACT07：长平前后，旧曲从安人变成记人。
ACT08：可让无名录以旧曲 / 口述形式进入民间。
```

### 公孙砚

```text
ACT03：新法入乡正式登场。
ACT04—ACT06：推动制度、编户、征发与治理。
ACT07：长平后看见制度面对海量死亡的失效或冷酷极限。
ACT08：可能坚持交官档，也可能承认官档装不下全部无名者。
```

## 15. 设计禁忌

```text
不要让辛衡突然死，只为了催泪。
不要让长平死亡只是背景数字。
不要让所有 NPC 都跟着主角走。
不要让职业线只换文本，不换责任入口。
不要让 NPC 的死亡完全由玩家是否选对决定。
不要让玩家可以救下所有重要人物。
不要让历史伤口变成可完美通关的谜题。
不要把农人重新作为独立职业线。
不要让禾安等主角一生。
不要让粥碗变成神秘法器。
```

## 16. 一句话总结

```text
第一章不是九条职业副本。
它是一段完整人生：少年种下第一笔亏欠，青年被选择磨出一双手，中年在长平看见所有答案破碎，长平后回旧渡却说不出一个死讯，晚年面对禾安留下的粥碗，终于决定如何把无名者交给后来的人。
```
