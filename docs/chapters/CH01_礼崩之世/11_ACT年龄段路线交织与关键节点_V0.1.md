# 第一章《礼崩之世》ACT 年龄段路线交织与关键节点 V0.1

> 文档状态：第一章 ACT01—ACT08 细化骨架  
> 适用范围：第一章主线拆分、职业线交织、NPC 自主行动、关键死亡 / 离场 / 回响节点、Codex 剧情生成  
> 前置文档：`10_主角立身与职业成形规则_V0.1.md`  
> 核心原则：路线可以分开，但必须在历史伤口处交织回来。

## 1. 总体说明

本文件用于把第一章从“人生大方向”继续拆成 ACT01—ACT08 的可制作结构。

第一章的主角人生跨度固定为：

```text
前 286 年：主角 10 岁。
前 221 年：秦统一，主角约 75 岁。
```

本章不是连续日常模拟，而是用关键年龄段串成完整人生。

玩家选择会影响：

```text
职业倾向。
NPC 信任与距离。
某些人是否透露秘密。
某些人是否提前离开、失踪、被牵连或战死。
无名录最终形态。
```

玩家不能改变：

```text
宋亡。
长平。
周亡。
秦统一。
旧礼崩解与新秩序推进。
```

## 3. ACT01：裂钟之梦 / 雨后流民

### 3.1 年龄与历史位置

```text
主角年龄：10 岁。
时间：前 286 年，宋亡消息抵达洛水旧渡。
地点：洛水旧渡。
```

### 3.2 固定事件

```text
主角写下本世姓名。
母亲望向河道尽头。
辛衡解释名与籍的重量。
禾安以现实行动拉住主角。
宋亡流民抵达。
韩宁拒绝说旧里。
柳娘旧曲停在地名处。
裂钟第一次响起。
雨夜翻车。
```

### 3.3 第一组可变选择

翻车现场三方向：

```text
A. 先救车下孩子。
B. 先抢泥水湿简。
C. 先让活人互认。
```

该选择影响：

```text
初始职业倾向。
禾安 / 韩宁 / 柳娘 / 辛衡对主角的第一印象。
后续 ACT01—ACT02 可获得的信息顺序。
```

不影响：

```text
职业最终锁定。
宋亡事实。
流民到来事实。
主角进入第一章事实。
```

### 3.4 NPC 自主逻辑

```text
禾安会优先救眼前人，即使主角不帮，她也会拖水桶、喊人、骂人。
韩宁会扑向湿简，即使主角不选湿简，他也会试图护住残简。
柳娘会组织人互认，即使主角不选互认，她也会用旧曲和喊名安住人群。
辛衡不会替玩家选择，他会看主角第一笔因果如何落下。
```

### 3.5 ACT01 结尾状态

```text
玩家知道：救下来只是开始。
主角知道：名与籍不是姓名问题，而是活人身后的网。
旧渡知道：收留流民会带来粮、水、责任和追索。
```

## 4. ACT02：旧礼无声 / 旧仓与旧册

### 4.1 年龄与历史位置

```text
主角年龄：11—15 岁。
地点：洛水旧渡、旧仓、临时棚区、辛衡书案。
```

### 4.2 固定事件

```text
流民暂住旧渡。
旧仓放粮问题出现。
本地人与流民之间的粮、水、棚位矛盾加剧。
临时名册开始决定谁能领粮、谁会被追索。
父亲官粮线露出第一处裂缝。
辛衡旧册不再只是工具，而是债。
```

### 4.3 路线分化方向

| 玩家反复优先处理 | 增强倾向 | 对应后续入口 |
|---|---|---|
| 草药、清创、夜里看护 | 救治 | 医者 |
| 湿简、口供、同行关系 | 记录 | 吏官 / 记录 |
| 粮水、棚位、本地户怨气 | 乡土 / 粮路 | 农人 / 商贾 |
| 车、棚、仓门、工具 | 器物 | 工匠 |
| 劝人、喊名、组织互认 | 言说 / 谋划 | 戏子 / 谋士 |
| 官署流程、担责、旧册 | 仕途 / 记录 | 仕官 / 吏官 |
| 保持距离、保存见证 | 隐退 | 隐士 |

### 4.4 关键节点：旧仓放粮

旧仓放粮不能写成简单善恶选择。

必须让玩家看见：

```text
不开仓，流民熬不过去。
开仓，旧渡本地户明早可能也断粮。
登记完整，可以发得更有序，也可能让人被追索。
登记模糊，可以暂时护人，也可能让后续分粮失控。
```

### 4.5 父亲官粮线第一处裂缝

可触发材料：

```text
旧仓木牌上有父亲随行官粮车队的记号。
母亲听见某个车队名时停住。
辛衡看见旧粮符后收起木牍。
某个渡户说：那批粮，不是早该过河了吗？
```

该线不应在 ACT02 说透。

### 4.6 NPC 动态

```text
禾安：若主角承担现实杂务，她会让主角知道旧渡真实存粮；若主角只顾记录，她会记住主角曾经晚伸手。
韩宁：若主角保护隐名，他可能透露残简边角；若主角逼问旧里，他会后退。
辛衡：若主角理解记录两面性，他会让主角看旧册；若主角只求正确，他会继续藏。
主角母亲：若主角追问父亲，她会沉默、转移话题，或在夜里看旧笔盒。
```

## 5. ACT03：旧国被重写 / 新法入乡

### 5.1 年龄与历史位置

```text
主角年龄：16—20 岁。
地点：旧渡、乡里、县署外围、重新编户现场。
```

### 5.2 固定事件

```text
旧渡被重新编户。
新法木牌进入乡里。
旧称呼被改写为户、伍、什。
田亩、赋役、债、罚、连坐进入日常。
公孙砚第一次正式出现。
```

### 5.3 主角理解推进

```text
旧礼保护不了旧渡。
新法不是单纯恶物。
新法能让人获得位置，也会让人更容易被追索、征发、计算。
```

### 5.4 路线触发

```text
愿意进入县署学习制度：仕官 / 吏官入口。
愿意留在乡里处理田亩安置：农人入口。
愿意跟着修路、修仓、修车：工匠入口。
愿意跟商路看关验和粮价：商贾入口。
愿意跟随医者救治迁民：医者入口。
愿意避开官署但保存见证：隐士入口。
愿意组织乡里与流民协商：谋士 / 言说入口。
```

### 5.5 NPC 自主逻辑

```text
公孙砚会按新法推进，不会因为主角不喜欢就停手。
辛衡会对新法保持复杂态度：他知道旧礼无力，也知道新法会追索活人。
禾安会先问粮、水、役落到谁家，不会沉迷制度争论。
韩宁会因旧籍风险对编户极度警惕。
```

### 5.6 关键节点：第一次职业邀请

ACT03 末尾可以出现第一次职业邀请，但不能锁死。

示例：

```text
公孙砚：你若真想知道一笔怎么落，就来县署看。
老医者：你手稳，夜里来替我看伤。
青缗：你总问路怎么走，不如跟我走一次。
工匠：你看车轴比看热闹仔细，来搭把手。
荀白：你总问两边都要死怎么办，那就来听听他们怎么辩。
```

## 6. ACT04：新法如刀 / 选择一双手

### 6.1 年龄与历史位置

```text
主角年龄：20—25 岁。
地点：县署、旧渡、乡里、商路、学舍、工坊、医棚等分支场景。
```

### 6.2 固定事件

```text
主角开始半离开旧渡。
职业方向真正显形。
辛衡病重。
辛衡把未完成的旧册责任交给主角。
禾安开始不再只是童年伙伴，而是旧渡现实压力的独立承担者。
```

### 6.3 关键节点：辛衡病重

辛衡病重必须成为主角人生第一次重大传承节点。

表现方式：

```text
辛衡咳到写不稳字。
笔尖在木牍上晕开。
他让主角把一片空木牍收好。
他说：我老了，有些名字等不到我写了。
```

辛衡不应把所有秘密一次说完。

他只交出：

```text
一部分旧册。
一支旧笔。
一个未完成的名单。
一句未说透的话。
```

### 6.4 辛衡是否立即死亡

ACT04 可以让辛衡病重但暂不死亡。

根据节奏推荐：

```text
ACT04：病重与交托。
ACT05 前后：老死。
```

这样辛衡的死亡不会只是剧情工具，而是让玩家先感到“他正在退出这一世”。

### 6.5 职业显形方式

职业显形应通过责任，而不是菜单。

```text
医者线：有人夜里来敲门，说一个登记不全的人快死了。
吏官线：辛衡旧册缺口必须有人补。
商贾线：青缗需要有人懂旧渡、懂名册、也懂路。
工匠线：旧桥 / 车 / 仓影响流民去留。
农人线：田亩与空户分配需要主角参与。
武将线：护送粮道或迁民队时第一次遇兵。
戏子线：柳娘让主角明白口述也能留人。
谋士线：不同势力都不肯担责，需要有人转圜。
仕官线：公孙砚让主角看见制度执行现场。
隐士线：主角选择不入局，但开始系统保存见证。
```

## 7. ACT05：百家灯火 / 辛衡老死

### 7.1 年龄与历史位置

```text
主角年龄：25—30 岁。
地点：洛邑、学舍、商路、旧渡回望、辛衡病榻。
```

### 7.2 固定事件

```text
主角接触百家争鸣和不同人生答案。
荀白登场或加深。
申不疑的制度重构思想登场或加深。
青缗的商路与消息网络登场或加深。
辛衡老死。
```

### 7.3 关键节点：辛衡老死

辛衡死亡不能写得煽情过度。

他的死应当安静、现实、有重量。

建议场景：

```text
雨停后的早晨。
书案上墨已经干了。
辛衡没有来开门。
案上留着半片未刮平的木牍。
木牍上没有遗言，只有几个没写完的名字。
```

辛衡临终或死后留下：

```text
旧册残卷。
父亲官粮线的一处线索。
关于韩宁残简的一句未完说明。
“字后面站着谁”的最终回响。
```

### 7.4 辛衡死亡的路线影响

```text
记录 / 吏官线：主角继承旧册责任最深。
医者线：主角可能因救不了辛衡第一次面对“老死不是失败”。
隐士线：主角可能只保存辛衡未完的笔记，不入官档。
戏子线：柳娘可能把辛衡未写完的人名转入口述。
仕官线：公孙砚可能认为旧册应归入新档。
```

### 7.5 百家灯火不是答案大会

ACT05 不能写成思想课堂。

它要让主角发现：

```text
每一种学说都能解释一部分痛苦。
但没有一种学说能替具体的人承担全部代价。
```

### 7.6 NPC 动态

```text
荀白会把问题点亮，但可能把痛苦变成论题。
申不疑会看见制度未来，但看不清具体人脸。
青缗会说活路常常不清白。
禾安如果仍在旧渡，会和主角距离拉开：她在过日子，主角在看天下。
韩宁可能在此阶段失踪、短暂出现，或通过残简留下线索。
```

## 8. ACT06：合纵连横 / 战争前夜

### 8.1 年龄与历史位置

```text
主角年龄：31—35 岁。
地点：列国边境、商路、粮道、学舍、军役登记处、乡里征发现场。
```

### 8.2 固定事件

```text
合纵连横不断变化。
盟书、地图、粮道、征发和军籍逐渐连成战争机器。
上党风云逼近。
主角所在职业线被不同方式卷入。
```

### 8.3 各职业进入战争前夜的入口

```text
医者：被请去看征发伤病和逃亡者。
吏官：整理兵籍、粮籍和失踪者。
商贾：商路被军需吞并，关验变严。
武将：护送、守路、征发逐渐升级。
戏子：旧曲和军中口述开始记录将死之人。
农人：田亩空缺、丁壮被征，收成无人管。
工匠：车、桥、仓、兵器维修被征用。
谋士：盟书和游说卷入更大博弈。
仕官：制度执行进入战争状态。
隐士：旁观者也被要求提供见证或沉默。
```

### 8.4 关键节点：战前名单

必须出现一份“战前名单”。

它不是普通军籍，而是本章主题压缩：

```text
有的人名字完整，马上被征。
有的人名籍残缺，无法领粮。
有的人被写作逃亡。
有的人已经死了，却还在名册上。
有的人活着，却不敢出现。
```

主角在此处应当理解：

```text
名籍已经从救济工具，变成战争入口。
```

### 8.5 NPC 动态

```text
公孙砚会认为战争状态更需要秩序。
申不疑会说旧秩序必须被更强结构替换。
荀白会试图辩，但语言开始失效。
青缗必须在保路、保货、保人之间选择。
禾安若在旧渡线，会面对丁壮被征和粮食被抽走。
韩宁若存活且靠近主角，可能因旧籍线再次被追索。
```

## 9. ACT07：长平血雾 / 不可逆战死节点

### 9.1 年龄与历史位置

```text
主角年龄：36 岁左右。
历史节点：长平大战。
```

如果后续确实需要虚构地点“长宁”，可将部分支线战死地改为“长宁”；但第一章主历史伤口仍建议以长平为核心。

### 9.2 固定事件

```text
长平发生。
大量军籍、粮籍、死伤册失效。
活人与死人在记录中混杂。
某些 NPC 战死、失踪或留下不可逆创伤。
主角第一次真正看见一整代人被压成数字。
```

### 9.3 必须发生的死亡 / 离场逻辑

ACT07 必须至少发生一种不可逆损失。

可根据路线不同触发不同版本。

#### 版本 A：武将 / 军旅相关 NPC 战死

建议设定：

```text
一名与主角在护送粮道、征发或守路中建立关系的青年 NPC 战死。
```

功能：

```text
让战争不是抽象历史，而是玩家曾经认识、曾经帮过或曾经拒绝过的人。
```

#### 版本 B：韩宁失踪或被迫暴露旧籍

如果韩宁线较深：

```text
韩宁为抢回残简、救母亲、或阻止旧籍被对上而失踪。
```

可选结果：

```text
韩宁战死。
韩宁失踪，不知生死。
韩宁活着，但旧籍暴露，牵连他一直想保护的人。
```

该节点要回收“他说真话会牵出活人”。

#### 版本 C：柳娘戏班折损

如果戏子 / 口述线较深：

```text
柳娘的戏班在战后救助、迁徙或军中口述中折损。
```

柳娘可以不死，但必须失去某个重要同伴或孩子。

回响：

```text
她不再只是唱到地名处停住。
她开始唱到人名处停住。
```

#### 版本 D：禾安旧渡线重创

如果禾安线较深：

```text
旧渡某户丁壮战死，或禾安承担的粮 / 水 / 伤者线彻底压垮旧渡一角。
```

禾安未必死亡。

更适合让她活下来并改变：

```text
她仍然先伸手，但不再相信伸手一定够快。
```

#### 版本 E：公孙砚制度线受创

如果仕官 / 新法线较深：

```text
公孙砚执行的名籍、军籍或粮籍在长平后失效。
```

他不一定死，但他必须看见自己相信的冷秩序也装不下这场死亡。

### 9.4 长平后的主角领悟

```text
名字写得再整齐，也接不住所有死人。
不写，又会让他们彻底散掉。
```

这是主角从“记录问题”走向“无名录”的真正节点。

## 10. ACT08：天下将一 / 无名录去向

### 10.1 年龄与历史位置

```text
主角年龄：37—75 岁。
历史节点：长平余波、周亡、新秩序推进、秦统一。
```

ACT08 时间跨度大，应采用“暮年回望 + 关键节点跳切”的叙事方式。

### 10.2 固定事件

```text
长平余波持续。
幸存者回不去原来的家。
失踪者无法被确认为亡。
无名录逐渐成形。
周亡，旧礼最后象征崩塌。
秦统一，天下归一。
主角决定无名录去向。
```

### 10.3 无名录的来源

不同职业线为无名录提供不同材料：

```text
医者：伤者口供、临终姓名、身体上的旧伤标记。
吏官：残缺名册、死伤册、错籍与空籍。
商贾：路上见闻、关验记录、失踪名单。
武将：征发记录、阵前名单、战后无人认领者。
戏子：旧曲、口述、人名停顿。
农人：空户、田亩、迁民、无人收成的地。
工匠：车辙、器物、桥仓位置、裂钟相关物证。
谋士：盟书背后的代价、被计策牵动的人。
仕官：制度档案中的缺口和删改痕迹。
隐士：不入官档的私人见证。
```

### 10.4 无名录最终去向

最终选择可根据职业线和 NPC 关系出现不同选项。

```text
交给官档：秩序承认，但可能被删改或追索。
藏入民间：保护活人，但难以被后世正式承认。
托给旧曲和口述：有温度，但可能失真。
拆成数份：减少一次性毁灭风险，但完整性降低。
埋回洛水与裂钟之间：保留神秘回响，但等同把答案交给未来。
```

### 10.5 暮年主角状态

无论职业如何，暮年主角都应回到同一句问题：

```text
天下终于有了一个名字。
可一个人呢？
他的名，他的籍，他身后那一户活人，又该写在哪里？
```

## 11. 关键 NPC 生命周期草案

### 11.1 辛衡

```text
ACT01：教主角写名与理解名籍。
ACT02：旧册与旧仓压力出现，辛衡开始显出隐瞒。
ACT03：面对新法入乡，辛衡态度复杂。
ACT04：病重，交托旧册、旧笔和未完成名单。
ACT05：老死，留下未写完的人名和父亲官粮线索。
ACT06—ACT08：以笔、旧册、未完成名单和主角记忆回响。
```

辛衡死亡意义：

```text
主角失去第一个教他“字后面站着人”的人。
从此主角必须自己决定：哪些字该落，哪些字该空，哪些字只能换一种方式留下。
```

### 11.2 禾安

```text
ACT01：现实锚点，先救眼前人。
ACT02：处理旧渡粮、水、柴、棚位压力。
ACT03：面对新法入乡，先问代价落到谁家。
ACT04—ACT06：根据路线，可能留守旧渡、参与迁徙、照顾伤者、或与主角渐行渐远。
ACT07：长平余波中承受旧渡或迁民线重创。
ACT08：可在暮年回响中出现，也可只留下碎米、热水桶、旧渡空灶等物件。
```

禾安不应为主角停在原地。

### 11.3 韩宁

```text
ACT01：拒绝旧里，护住残简。
ACT02：根据主角选择，透露或隐藏残简细节。
ACT03：新法编户让他的旧籍风险加重。
ACT04—ACT05：可能离开、失踪、短暂同行或暗中保留线索。
ACT06—ACT07：残简线在战争前后重新浮出，可能导致失踪、战死或牵连。
ACT08：若存活，可成为无名录关键证人；若死亡 / 失踪，其残简成为无名录核心材料。
```

### 11.4 柳娘

```text
ACT01：旧曲停在地名处。
ACT02：用唱、喊名和戏箱安住流民。
ACT03—ACT05：口述线、戏子线、亡国旧曲加深。
ACT06—ACT07：长平前后，旧曲从安人变成记人。
ACT08：可让无名录以旧曲 / 口述形式进入民间。
```

### 11.5 公孙砚

```text
ACT03：新法入乡正式登场。
ACT04—ACT06：推动制度、编户、征发与治理。
ACT07：长平后看见制度面对海量死亡的失效或冷酷极限。
ACT08：可能坚持交官档，也可能承认官档装不下全部无名者。
```

### 11.6 申不疑

```text
ACT05：以制度重构思想登场或加深。
ACT06：用未来逻辑解释当下痛苦。
ACT07：长平检验其思想冷度。
ACT08：其思想可能被更强权力采用，也可能被现实吞没。
```

### 11.7 荀白

```text
ACT05：百家辩论与问题点亮。
ACT06：语言试图介入战前局势。
ACT07：长平后第一次真正说不出话。
ACT08：可能成为教学者、沉默者或重新发问者。
```

### 11.8 青缗

```text
ACT04—ACT05：商路、消息、关验入口。
ACT06：战前粮道吞并商路。
ACT07：在保路、保货、保人中做不可逆选择。
ACT08：其道路信息可能成为无名录民间部分的重要来源。
```

## 12. 设计禁忌

```text
不要让辛衡突然死，只为了催泪。
不要让长平死亡只是背景数字。
不要让所有 NPC 都跟着主角走。
不要让职业线只换文本，不换责任入口。
不要让 NPC 的死亡完全由玩家是否选对决定。
不要让玩家可以救下所有重要人物。
不要让历史伤口变成可完美通关的谜题。
```

## 13. 一句话总结

```text
第一章不是十条职业副本。
它是一段完整人生：少年种下第一笔亏欠，青年被选择磨出一双手，中年在长平看见所有答案破碎，晚年把无名者交给后来的人。
```
