# 第一章《礼崩之世》记忆碎片表 V0.4

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：当前第一章记忆碎片总表，八职业口径  
> 用途：规定第一章从 10 岁到 75 岁之间，裂钟与无名者回声如何配合主线、八职业线、乡土地基、隐退倾向和汇总节点出现。

## 1. 第一章记忆系统任务

第一章记忆系统只完成四件事：

```text
让主角感到裂钟、名册、河水、旧曲、白骨和旧碗有无法解释的熟悉。
让同一个母题在现实选择后获得第二层含义。
逐步否定“这只是普通梦境”，但不确认任何具体前世。
在 ACT08 只明确提示一句：这不是你第一次看见山河改色。
```

第一章不回答：

```text
苏醒者第一个姓名。
苏醒者是否曾是某个帝王、圣人或贵族。
谁安排轮回。
裂钟是否法器。
无名的最终名字是什么。
```

## 2. 年龄段记忆节奏

| 年龄段 | 对应 ACT | 记忆强度 | 主要触发物 | 作用 |
|---|---|---|---|---|
| 10 岁 | ACT01 | 轻微裂缝 | 裂钟、水声、空木牍、湿简、旧碗 | 让主角知道异常存在，但不抢走现实危机 |
| 11—15 岁 | ACT02 | 现实误认 | 旧仓、粮符、父亲旧笔盒、辛衡老伯旧册 | 把父亲官粮线和名籍风险连起来 |
| 16—20 岁 | ACT03 | 因果共鸣 | 新法木牌、户伍什、编户现场 | 让主角感到“人被重新写法”并非第一次发生 |
| 20—25 岁 | ACT04 | 情绪回声 | 辛衡老伯旧笔、未完成名单、职业工具 | 让职业责任与记录亏欠绑定 |
| 25—30 岁 | ACT05 | 残梦 | 辛衡老伯死后书案、干墨、没写完的人名 | 让主角第一次在梦中听见“写不完”的重量 |
| 31—35 岁 | ACT06 | 因果共鸣增强 | 战前名单、盟书、粮道图、军籍 | 提醒名籍已变成战争入口，但不预告长平结局 |
| 36 岁 | ACT07 | 强烈回声 | 白骨、死伤册、无人认领者、断裂旧曲 | 让长平成为现实创伤与历史回声叠合处 |
| 37—40 岁 | ACT07 后 | 现实刺痛 | 旧渡灶边、禾安、梁成残名、锅盖声、旧碗 | 把长平大伤口压回一个具体死讯 |
| 75 岁 | ACT08 | 稳定提示 | 无名录、裂钟残响、洛水、周亡旧器、禾安粥碗 | 收束为“这不是你第一次看见山河改色” |

## 3. 八职业记忆差异

记忆碎片不提供职业技能答案。

不同职业线只是触发物不同：

| 职业线 | 主要触发物 | 记忆侧重点 |
|---|---|---|
| 医者 | 伤口、药箱、临终口供 | 身体被救下后仍需要位置 |
| 吏官 / 记录 | 旧册、错籍、空格、删改痕迹 | 一笔能救人，也能追索人 |
| 商贾 | 关验、路标、货袋、失踪记号 | 路断时人连选择都没有 |
| 武将 | 兵籍、粮道、阵前名单 | 名籍如何提前把人写进刀口 |
| 戏子 | 旧曲、节拍、人名停顿 | 记忆可由口述保存，也会残缺 |
| 工匠 | 车辙、桥、仓、裂钟残片 | 器物被放进不同秩序里 |
| 谋士 | 盟书、删改句、游说稿 | 聪明也会制造代价 |
| 仕官 | 法令、木牌、官档缺口 | 治理最容易看不见人的脸 |

隐退倾向不作为独立职业记忆线，而表现为：

```text
私藏见证。
不入官档材料。
无人公开承认的证言。
晚年是否把无名录藏入民间、拆分或埋回洛水。
```

## 4. 乡土地基记忆

“农人”不作为独立职业记忆线。

旧渡、土地、灶火、田亩、空户和粥碗作为全职业共用记忆地基出现。

| 触发物 | 记忆侧重点 |
|---|---|
| 稀粥 | 善意不是凭空来的，善意要米、水、柴和谁先倒下的现实 |
| 旧碗 | 童年第一口亏欠、禾安一生灶火、阿梁死讯未送达 |
| 旧锅 | 旧渡每一天仍要过下去，不因天下大势暂停 |
| 空田 / 空户 | 有名有籍的人被征走后，留下的是一户活人的空位 |
| 灶火 | 禾安没有等主角，她一直在过自己的日子 |

## 5. 关键记忆碎片

### MEM-CH01-001 裂钟落水

```text
触发：10 岁，旧礼器库触碰裂钟。
表现：水底钟声、冰冷手指、看不清脸的人名被刮去。
限制：不解释前世，不给未来答案。
作用：建立“这不是普通旧器”的感觉。
```

### MEM-CH01-002 空木牍

```text
触发：翻车现场后，主角手里仍有空木牍。
表现：木牍上似乎有许多未写的人名，但雨一落又消失。
作用：让第一笔亏欠进入记忆系统。
```

### MEM-CH01-003 旧仓粮符

```text
触发：ACT02 旧仓放粮与父亲官粮线。
表现：父亲旧笔盒、粮车车辙、仓门木牌短暂重合。
作用：让家庭线与公共记录线相连。
```

### MEM-CH01-004 新法木牌

```text
触发：ACT03 重新编户。
表现：旧称呼被整齐写成户、伍、什，声音像木牌钉入门框。
作用：让主角感到人被重新书写。
```

### MEM-CH01-005 辛衡老伯干墨

```text
触发：ACT05 辛衡老伯老死后。
表现：干墨、半片未刮平木牍、没写完的人名。
作用：主角失去写字的人，记忆第一次从器物转向传承。
```

### MEM-CH01-006 战前名单

```text
触发：ACT06 战前名单。
表现：活人、死人、逃亡者、残籍者在同一册上翻动。
作用：让玩家明白名籍已变成战争入口。
```

### MEM-CH01-007 长平白骨

```text
触发：ACT07 长平后。
表现：白骨、断简、旧曲停顿、无人认领者的衣角。
作用：将职业线、现实创伤和历史回声汇总。
```

### MEM-CH01-008 归旧渡锅盖声

```text
触发：ACT07 后，主角离开禾安所在旧渡。
表现：锅盖在身后轻轻一响，声音比长平战鼓小，却压得更久。
作用：让玩家明白死伤册上的一个名字，最终会回到一个活人面前。
```

### MEM-CH01-009 禾安粥碗

```text
触发：ACT08 暮年回旧渡，发现禾安已逝。
表现：旧碗倒扣在灶旁，碗边缺口，碗底有灶火黑痕；碗里没有粥，也没有字。
作用：让主角明白，禾安早已用一生替那个空位留过饭。
```

### MEM-CH01-010 这不是第一次

```text
触发：ACT08 暮年，无名录最终去向前后。
表现：裂钟声稳定，不再像梦；一句清晰提示出现。
文本：这不是你第一次看见山河改色。
作用：把第一章交给全局秘密，但不解开终极答案。
```

## 6. 使用禁忌

```text
记忆不能精准预告未来事件。
记忆不能提供职业技能、战术答案、药方或官署密码。
记忆不能抢走现实危机。
记忆不能把苏醒者提前写成某个确定前世身份。
记忆不能替玩家判断选择对错。
粥碗不能变成神秘法器，只能作为普通生活物件承载记忆重量。
```

## 7. Codex 执行要求

生成第一章 ACT 或职业线时：

```text
先写现实问题，再写记忆回声。
记忆只加深主题，不替玩家解决问题。
每个关键年龄段最多设置一到两个强记忆点。
职业线记忆差异只改变触发物和视角，不改变全局真相。
乡土地基记忆必须通过禾安、灶火、旧碗、空户等普通物件表现。
隐退倾向记忆必须表现为私藏见证、不入官档或晚年去向，而不是恢复隐士职业。
```
