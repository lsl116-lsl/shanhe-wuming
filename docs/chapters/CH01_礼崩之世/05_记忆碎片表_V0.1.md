# 第一章《礼崩之世》记忆碎片表 V0.2

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：根据完整人生结构、职业成形和路线交织规则重整  
> 用途：规定第一章从 10 岁到 75 岁之间，裂钟与无名者回声如何配合主线、职业线和汇总节点出现。

## 1. 第一章记忆系统任务

第一章记忆系统只完成四件事：

```text
让主角感到裂钟、名册、河水、旧曲和白骨有无法解释的熟悉。
让同一个母题在现实选择后获得第二层含义。
逐步否定“这只是普通梦境”，但不确认任何具体前世。
在 ACT08 只明确提示一句：这不是你第一次看见山河改色。
```

第一章不回答：

```text
苏醒者第一个姓名。
苏醒者是否曾是某个帝王、圣人或贵族。
谁安排轮回。
裂钟是否法器。
无名的最终名字是什么。
```

## 2. 记忆不是个人前世录像

第一章不默认使用：

```text
PERSONAL_PAST_LIFE = 苏醒者曾经就是某个确定人物。
```

碎片来源分为：

| 来源 | 说明 | 第一章是否确认 |
|---|---|---|
| CURRENT_LIFE | 本世真实经历在梦中变形重现 | 有时可判断 |
| ASSOCIATIVE | 器物、气味、声音造成联想 | 不完全确认 |
| CAUSAL_ECHO | 与跨朝代因果节点共鸣 | 只能感到异常熟悉 |
| COLLECTIVE_ECHO | 无名者共同经验形成回声 | 不确认 |
| CLEAR_PROMPT | 全局根节点允许出现的明确提示 | ACT08 只出现一次 |

## 3. 年龄段记忆节奏

| 年龄段 | 对应 ACT | 记忆强度 | 主要触发物 | 作用 |
|---|---|---|---|---|
| 10 岁 | ACT01 | 轻微裂缝 | 裂钟、水声、空木牍、湿简 | 让主角知道异常存在，但不抢走现实危机 |
| 11—15 岁 | ACT02 | 现实误认 | 旧仓、粮符、父亲旧笔盒、辛衡旧册 | 把父亲官粮线和名籍风险连起来 |
| 16—20 岁 | ACT03 | 因果共鸣 | 新法木牌、户伍什、编户现场 | 让主角感到“人被重新写法”并非第一次发生 |
| 20—25 岁 | ACT04 | 情绪回声 | 辛衡旧笔、未完成名单、职业工具 | 让职业责任与记录亏欠绑定 |
| 25—30 岁 | ACT05 | 残梦 | 辛衡死后书案、干墨、没写完的人名 | 让主角第一次在梦中听见“写不完”的重量 |
| 31—35 岁 | ACT06 | 因果共鸣增强 | 战前名单、盟书、粮道图、军籍 | 提醒名籍已变成战争入口，但不预告长平结局 |
| 36 岁 | ACT07 | 强烈回声 | 白骨、死伤册、无人认领者、断裂旧曲 | 让长平成为现实创伤与历史回声叠合处 |
| 37—75 岁 | ACT08 | 稳定提示 | 无名录、裂钟残响、洛水、周亡旧器 | 收束为“这不是你第一次看见山河改色” |

## 4. 职业线记忆差异

记忆碎片不提供职业技能答案。

不同职业线只是触发物不同：

| 职业线 | 主要触发物 | 记忆侧重点 |
|---|---|---|
| 医者 | 伤口、药箱、临终口供 | 身体被救下后仍需要位置 |
| 吏官 / 记录 | 旧册、错籍、空格、删改痕迹 | 一笔能救人，也能追索人 |
| 商贾 | 关验、路标、货袋、失踪记号 | 路断时人连选择都没有 |
| 武将 | 兵籍、粮道、阵前名单 | 名籍如何提前把人写进刀口 |
| 戏子 | 旧曲、节拍、人名停顿 | 记忆可由口述保存，也会残缺 |
| 农人 | 种子、田界、空户、旧灶 | 天下改名后，地还要种，人未必还在 |
| 工匠 | 车辙、桥、仓、裂钟残片 | 器物被放进不同秩序里 |
| 谋士 | 盟书、删改句、游说稿 | 聪明也会制造代价 |
| 仕官 | 法令、木牌、官档缺口 | 治理最容易看不见人的脸 |
| 隐士 | 私藏见证、山路、未入官档材料 | 不选择也会留下或错过见证 |

## 5. 关键记忆碎片

### MEM-CH01-001 裂钟落水

```text
触发：10 岁，旧礼器库触碰裂钟。
表现：水底钟声、冰冷手指、看不清脸的人名被刮去。
限制：不解释前世，不给未来答案。
作用：建立“这不是普通旧器”的感觉。
```

### MEM-CH01-002 空木牍

```text
触发：翻车现场后，主角手里仍有空木牍。
表现：木牍上似乎有许多未写的人名，但雨一落又消失。
作用：让第一笔亏欠进入记忆系统。
```

### MEM-CH01-003 旧仓粮符

```text
触发：ACT02 旧仓放粮与父亲官粮线。
表现：父亲旧笔盒、粮车车辙、仓门木牌短暂重合。
作用：让家庭线与公共记录线相连。
```

### MEM-CH01-004 新法木牌

```text
触发：ACT03 重新编户。
表现：旧称呼被整齐写成户、伍、什，声音像木牌钉入门框。
作用：让主角感到人被重新书写。
```

### MEM-CH01-005 辛衡干墨

```text
触发：ACT05 辛衡老死后。
表现：干墨、半片未刮平木牍、没写完的人名。
作用：主角失去写字的人，记忆第一次从器物转向传承。
```

### MEM-CH01-006 战前名单

```text
触发：ACT06 战前名单。
表现：活人、死人、逃亡者、残籍者在同一册上翻动。
作用：让玩家明白名籍已变成战争入口。
```

### MEM-CH01-007 长平白骨

```text
触发：ACT07 长平后。
表现：白骨、断简、旧曲停顿、无人认领者的衣角。
作用：将职业线、现实创伤和历史回声汇总。
```

### MEM-CH01-008 这不是第一次

```text
触发：ACT08 暮年，无名录最终去向前后。
表现：裂钟声稳定，不再像梦；一句清晰提示出现。
文本：这不是你第一次看见山河改色。
作用：把第一章交给全局秘密，但不解开终极答案。
```

## 6. 使用禁忌

```text
记忆不能精准预告未来事件。
记忆不能提供职业技能、战术答案、药方或官署密码。
记忆不能抢走现实危机。
记忆不能把苏醒者提前写成某个确定前世身份。
记忆不能替玩家判断选择对错。
```

## 7. Codex 执行要求

生成第一章 ACT 或职业线时：

```text
先写现实问题，再写记忆回声。
记忆只加深主题，不替玩家解决问题。
每个关键年龄段最多设置一到两个强记忆点。
职业线记忆差异只改变触发物和视角，不改变全局真相。
```
