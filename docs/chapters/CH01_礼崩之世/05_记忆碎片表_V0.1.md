## 1. 第一章记忆系统的任务

第一章的记忆系统只完成四件事：

1. 让苏醒者感到自己与眼前的裂钟、名册、河水和白骨有无法解释的熟悉。
2. 让同一个母题在现实选择后获得第二层含义。
3. 逐步否定“这只是普通梦境”，但不确认任何具体前世。
4. 在 ACT08 只揭示一句：

> 这不是你第一次看见山河改色。

第一章不回答：

- 苏醒者的第一个姓名。
- 苏醒者是否来自某个帝王、圣人或贵族家族。
- 谁在幕后安排轮回。
- 裂钟是否是某种法器。
- “无名”的最终名字是什么。

这些问题必须继续留给全局根节点：

```text
SW-GLOBAL-001 苏醒者身份
SW-GLOBAL-002 从无名者到人民
```

## 2. 记忆不是个人前世录像

终章方向已经确定：苏醒者不是一条单人灵魂履历，而是千千万万无名者共同的历史回声。

因此，第一章系统底层不使用“某一世的客观录像”作为默认解释。碎片来源分为：

| 底层来源 | 说明 | 玩家第一章能否确认 |
|---|---|---|
| `CURRENT_LIFE` | 本世真实经历在梦中变形重现 | 有时可以判断 |
| `ASSOCIATIVE` | 现实器物、气味、声音造成的联想或误认 | 不能完全判断 |
| `CAUSAL_ECHO` | 与跨朝代因果节点发生共鸣 | 只能感到异常熟悉 |
| `COLLECTIVE_ECHO` | 不同无名者经验在苏醒者身上形成的共同回声 | 第一章不可确认 |
| `CLEAR_PROMPT` | 全局根节点允许出现的明确提示 | ACT08 只出现一次 |

禁止默认使用：

```text
PERSONAL_PAST_LIFE = “苏醒者曾经就是某个确定人物”
```

角色可以怀疑自己有前世，玩家也可以这样理解，但系统不能把这种怀疑提前写成事实。

## 3. 记忆表现类型

| 类型 | 表现 | 可靠部分 | 不可靠部分 | 主要作用 |
|---|---|---|---|---|
| 残梦 | 睡眠、昏厥或濒死时出现片段画面 | 感官体验本身 | 时间、人物身份、事件归属 | 建立母题与重复感 |
| 情绪回声 | 无画面，突然悲悯、恐惧、亏欠或熟悉 | 情绪真实发生 | 情绪究竟来自本世还是共同回声 | 改变玩家对现实选择的注意点 |
| 因果共鸣 | 接触旧物、文字、地点或重复命题时触发 | 当前物与旧因果确有联系 | 联系是否属于个人前世 | 提醒玩家比较两段现实 |
| 现实误认 | 把当前声音、面孔或动作看成似曾相识 | 当前刺激真实 | 苏醒者的归因可能错误 | 制造可质疑、可讨论的主观体验 |
| 明确提示 | 清晰语言或稳定结构 | 提示内容为真 | 仍不等于完整答案 | 推进全局秘密一层 |

### 3.1 可靠性规则

1. 画面可以模糊，不能故意伪造之后会被推翻的物理事实。
2. 后续只能修正“这是谁、发生在何时、意味着什么”，不能把玩家看见的裂钟改成从未存在。
3. 现实误认必须至少有两种合理解释。
4. 记忆不能精准预告未来事件。
5. 记忆不能直接提供职业技能、战术答案、药方或官署密码。

## 4. 第一章揭示等级

| 等级 | 可出现内容 | 禁止内容 | 最高所在幕 |
|---|---|---|---|
| M0 感官残留 | 声音、气味、温度、触感、无脸人影 | 语言、姓名、时代结论 | ACT01 |
| M1 重复联想 | 同一母题第二次出现，现实与梦短暂重合 | “我曾是谁”、准确历史预知 | ACT02—ACT03 |
| M2 结构共鸣 | 两种以上母题连成关系，如名字被刮去、木牌与钟声相叠 | 苏醒者身份、完整句子 | ACT04—ACT05 |
| M3 断句提示 | 多个母题形成长片段，听到不完整词语 | 完整提示、“人民”答案 | ACT06—ACT07 |
| M4 本章明确层 | 完整听清“这不是你第一次看见山河改色”，看见许多双手 | 解释谁在说、为何苏醒、无名者最终是谁 | ACT08 |

`memory_resonance` 可以改变同等级碎片的清晰程度和可用对话，但不能提前越级。即使玩家收集全部可选碎片，也不能在 ACT07 前听清完整提示。

## 5. 记忆触发总规则

### 5.1 每幕预算

| 幕 | 必选碎片 | 可选碎片上限 | 说明 |
|---|---:|---:|---|
| ACT01 | 2 | 0 | 建立开场，不用大量谜语淹没现实人物 |
| ACT02 | 1 | 1 | 让旧仓与空白身份产生联系 |
| ACT03 | 1 | 1 | 名字被重写，但不泄露韩宁父亲真相 |
| ACT04 | 1 | 1 | 木牌与裂钟首次结构性重合 |
| ACT05 | 1 | 1 | 百家之议中出现“说话者身后的人” |
| ACT06 | 1 | 1 | 地图、数字与承担者相连 |
| ACT07 | 2 | 1 | 情绪与因果爆发，可出现不完整断句 |
| ACT08 | 2 | 1 | 许多双手与完整提示，结束第一章揭示 |

每幕可选碎片不必全部播放。一次事件结束后连续弹出两段梦境会削弱现实冲突。

### 5.2 触发优先级

```text
现实事件发生
→ 玩家作出选择
→ 现实后果出现一部分
→ 记忆共鸣重新解释选择
→ 玩家决定是否追问、讲述或压下
```

除 ACT01 开场外，优先让现实先于记忆。记忆不能抢在事件前告诉玩家哪个选项会造成什么结果。

### 5.3 玩家回应

碎片触发后，玩家可有一项简短回应：

| 回应 | 改变什么 | 不改变什么 |
|---|---|---|
| 追索 | 增加观察或询问机会 | 不自动得到正确答案 |
| 与现实对照 | 解锁比较两份记录、两种说法的选项 | 不提高超自然能力 |
| 告诉故人 | 改变信任、担忧和谁知道秘密 | 不证明记忆来源 |
| 压下不提 | 降低暴露与他人关注 | 不删除已经发生的碎片 |
| 记录下来 | 让后续可对照措辞与图像 | 记录可能被他人误读 |

回应不设置“勇敢追索最好、压下最差”的固定价值。

## ACT01 裂钟之梦

### MEM-CH01-001 裂钟落水

| 字段 | 内容 |
|---|---|
| 类型 / 等级 | 残梦，M0 |
| 必选 | 是，章节第一段 |
| 主触发 | 苏醒者在旧礼器库旁醒来前 |
| 玩家感知 | 黑暗中先有钟声，随后不是钟落地，而是大量冷水从一道裂缝涌出；看不见钟外有什么。 |
| 可靠部分 | 裂纹、钟声、水的触感在苏醒者主观体验中真实存在。 |
| 不确定部分 | 钟是否真的落水、画面是否属于某个时代。 |
| 现实作用 | 醒来后玩家会优先注意现实裂钟和洛水声，可选择靠近、回避或询问。 |
| 关联因果 | `SW-CH01-001 裂钟` |
| 禁止透露 | 钟的来历、苏醒者身份、任何具体王朝名。 |
| 重复表现 | 后续只重复“裂纹中有水声”，不再完整播放。 |

**建议文本**

> 黑暗里先有一声钟响。
>
> 不是从远处传来，更像贴着骨头裂开。
>
> 冷水从看不见的缝里涌出。你伸手去堵，摸到的不是水，是一圈冰凉的铜锈。

### MEM-CH01-002 湿简与无脸之手

| 字段 | 内容 |
|---|---|
| 类型 / 等级 | 因果共鸣，M0 |
| 必选 | 是 |

> 竹简上的水渗进指缝。
>
> 另一双手仿佛也握在同一处，比你的手更粗，也更冷。
>
> 你抬头，泥地上只有自己。

## 7. 十条职业线的记忆变体

职业变体不新增隐藏真相，只改变玩家最容易注意的感官与责任。每条路线最多在 ACT04—ACT07 触发一次。

| ID | 人生线 | 主要触发 | 感知变体 | 现实作用 | 不允许产生的结论 |
|---|---|---|---|---|---|
| MEM-CH01-R01 | 隐士 | 山路接纳逃亡者 | 同一条路上传来不同方向、不同年代似的脚步声 | 注意谁被官道与地图遗漏 | “苏醒者前世一定是隐士” |
| MEM-CH01-R02 | 仕官 | 在命令上落印 | 印落下前浮现许多伸向文书的手，随后被印面遮住 | 追查谁签字、谁承担 | 官印具有超自然力量 |
| MEM-CH01-R03 | 谋士 | 删改盟书 | 被删掉的人名化成无法辨认的呼吸声，数字仍清晰 | 保留原稿或标记删改责任 | 能预知哪条策略必胜 |
| MEM-CH01-R04 | 武将 | 系甲或点伍 | 陌生的手与自己同时打同一个结，却来自不同衣袖 | 记录同伍具体身份 | 苏醒者继承前世武艺 |
| MEM-CH01-R05 | 医者 | 闻到药香、清洗伤口 | 药香后叠出许多不同时代的伤者呼吸 | 记录体貌与战后死亡 | 凭记忆获得失传药方 |
| MEM-CH01-R06 | 戏子 | 旧曲换词 | 旋律中出现许多不同嗓音，都没有唱完整国名 | 比对口述版本与删词 | 苏醒者曾是某位名伶 |

### 7.1 职业变体继承规则

- 所选路线触发对应 `R` 碎片。
- 未选路线不由玩家直接触发，但锚点 NPC 可描述相近感受；NPC 的感受不能证明其也是苏醒者。
- 转轨后只保留原路线已触发碎片，新路线可获得一个较弱变体，不能收齐全部十条。
- 职业碎片不计入全局揭示等级，只改变因果证据与对话角度。

## 8. 记忆与现实选择的绑定

每段必选碎片至少解锁一种现实行为，但不能解锁“正确答案”。

| 记忆 | 必须改变的现实层 |
|---|---|
| 裂钟落水 | 玩家是否主动接近裂钟、询问现实来源 |
| 湿简与手 | 如何处理身份敏感信息 |
| 空白木片 | 是否追问未入籍者的资格 |
| 同处三名 | 区分真实身份、合法身份和对外身份 |
| 木牌钉土 | 先查缺额将转嫁给谁 |
| 辩者身后 | 献策是否保留具体姓名与承担者 |
| 折叠地图 | 是否复查路线改变对另一地的影响 |
| 长平饥饿 | 选择界面明确显示受益者与缺额承担者 |
| 白骨湿简裂钟 | 《无名录》允许空格与未归状态 |
| 许多双手 | 《无名录》不再被表述为苏醒者个人遗产 |
| 完整提示 | 第二章自我怀疑升级，不增加任何能力 |

如果碎片只播放动画、没有改变后续观察、对话或选择表述，就应删去或合并。

## 9. 重复触发规则

### 9.1 不重复播放原文

同一碎片再次触发时，只出现一行短共鸣：

```text
你又听见裂纹里的水声。
那块空白木片再次从人群中举起。
地图背面仍有人掉下去。
```

随后更新关联因果，不重新播放完整段落。

### 9.2 重复必须增加一个变化

允许的变化：

- 多出一种感官，如先有声音，后有触感。
- 同一物从梦中进入现实。
- 同一画面加入一项当前选择造成的后果。
- 原本无词的声音出现一个断句。

不允许：

- 只为提醒玩家而原样重播。
- 每次共鸣都更响、更痛，却没有新信息。
- 通过反复点击物件刷高记忆等级。

### 9.3 防刷取

- 每个碎片记录 `seen`，完整版本只触发一次。
- 同一场景重复检查只提供现实细节，不继续增加 `memory_resonance`。
- 揭示等级由幕和骨架事件双重限制，不由累计次数单独决定。

## 11. 记忆传播与秘密知情人

记忆并非只能锁在苏醒者脑中。玩家可以告诉他人，但内容传播会改变关系与风险。

| 知情人 | 可能理解 | 可能误解 | 现实后果 |
|---|---|---|---|
| 季伯 | 把梦理解为记录与责任的焦虑 | 认为苏醒者只是受流民刺激 | 提供对照旧简的方法，不神秘化 |
| 韩宁 | 相信残简与父亲旧事触发异常 | 误以为苏醒者知道父亲真相却隐瞒 | 信任、决裂或共同记录 |
| 禾安 | 关心梦是否让苏醒者无法生活 | 认为远行和问道会带走苏醒者 | 强化现实牵挂 |
| 荀白 | 把它视作认识问题与共同经验 | 过度抽象成学说材料 | 记忆可能进入治策并被误用 |
| 申不疑 | 关心梦能否提供可执行信息 | 怀疑苏醒者借神异影响决策 | 增加制度关注或审查 |
| 公孙砚 | 要求区分梦、证言和官档 | 把无法核验内容全部排除 | 推动真相与记载分层 |
| 柳娘 | 接受曲调与口述也能保存经验 | 把苏醒者的共鸣编成过度神秘的故事 | 旧曲传播范围与变形度改变 |

第一章最多允许三名主要人物知道较完整的异常。公开宣称神异会增加关注与误读，但不能让苏醒者成为受万人追捧的神人。

## 12. 不可透露内容清单

第一章任何碎片都不得出现：

- “你的名字是人民。”
- “你就是所有人。”
- “你曾是某位帝王、名将、圣人或历史名人。”
- “某个组织让你轮回。”
- 下一章主角的姓名、职业或出生地点。
- 长平胜负的准确预言。
- 秦统一六国的确定未来画面。
- 后世城市、火车、工厂、枪炮等清晰时代图像。
- 完整的前世家庭、谱系和连续人生。
- 能直接解决当前事件的现代知识。

可以出现：

- 不同年岁、身份和性别的手。
- 无国界、无文字的抽象地图。
- 不属于单个人的饥饿、劳动、悲悯和亏欠。
- 与现实物件相似但无法断代的声音、气味和触感。
- “这不是你第一次看见山河改色”这一句唯一完整提示。

## 13. 跨章节升级规则

第一章结束后，记忆的升级方向不是“越来越清楚地记起一个前世”，而是“越来越无法用单个前世解释”。

| 章节 | 记忆新增证据 | 排除的错误答案 |
|---|---|---|
| 第一章 春秋战国 | 裂钟、无名录、许多双手、第一声提示 | 这只是普通梦境 |
| 第二章 秦汉 | 记忆与个人血缘、遗物所有权对不上 | 单一家族祖先 |
| 第三章 魏晋南北朝 | 不同家族与南北身份提出互相冲突的“前世证据” | 一条连续谱系 |
| 第四章 隋唐 | 同时熟悉盛世营造者与边塞牺牲者的感受 | 单一社会阶层 |
| 第五章 宋元 | 同时出现文人、工匠、商旅、亡国者经验 | 单一职业或文化精英 |
| 第六章 明清 | 多个普通人经验同时涌现，个人灵魂解释失效 | 单人转世 |
| 第七章 近现代 | 苏醒者在共同运动中感到记忆与同时代众人相连 | 孤立救世主 |
| 终章 | 无名者共同经验汇为人民这一历史主体 | 完成 `SW-GLOBAL-001` 与 `002` |

## 14. 后续数据化字段

重构原型时，每个碎片至少需要以下语义字段：

| 字段 | 用途 |
|---|---|
| `memory_id` | 稳定引用，例如 `MEM-CH01-014` |
| `act` | 允许出现的幕 |
| `type` | 残梦、情绪、因果共鸣、误认、明确提示 |
| `reveal_level` | M0—M4 |
| `mandatory` | 是否骨架必选 |
| `primary_trigger` | 主触发 |
| `fallback_trigger` | 必选碎片的兜底触发 |
| `requires` | 所需人物、节点、职业或现实事件 |
| `perceived_content` | 玩家实际看到或听到的内容 |
| `reliable_content` | 后续不能推翻的感官事实 |
| `uncertain_attribution` | 可在后续修正的归因 |
| `forbidden_reveal` | 本碎片不能说什么 |
| `reality_effect` | 解锁的观察、对话或选择表述 |
| `linked_causes` | 关联 `SW-CH01` 节点 |
| `repeat_line` | 重复触发时的一行短共鸣 |
| `witnesses` | 玩家告诉了谁 |
| `seen` | 是否已播放完整版本 |

记忆日志只展示 `perceived_content` 和玩家当时写下的理解，不展示底层来源、可靠度或全局答案。
