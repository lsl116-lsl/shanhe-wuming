# 第一章《礼崩之世》主角立身与职业成形规则 V0.2

> 文档状态：第一章主角人生结构与职业分流规则  
> 适用范围：第一章 ACT01—ACT08、九职业入口、旧渡现实地基、路线交织、NPC 动态逻辑、Codex 剧情与原型生成  
> 核心原则：主角必须立住，但主角不能被职业锁死。

## 1. 总原则

第一章不是让玩家开局选择职业。

第一章要写的是：

```text
同一个苏醒者，作为洛水旧渡长大的孩子，如何在十岁到七十五岁的完整人生中，被时代一步步磨出一双手。
```

职业不是身份菜单。

职业是主角在一次次选择后，被时代、关系、责任和亏欠共同推出来的人生位置。

核心句：

```text
职业不是玩家点出来的身份，而是主角被时代磨出来的手。
```

## 2. 当前职业线口径

第一章保留九条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
隐士。
```

“农人”不再作为独立职业线。

它的内容改为所有职业共同面对的现实地基：

```text
旧渡。
禾安。
粮水。
田亩。
空户。
灶火。
没有米下锅。
小时候一起喝粥的碗。
```

这意味着：

```text
土地、粮水、灶火和空户不是某条职业专属内容，而是所有职业最后都要回到的人民底色。
```

## 3. 主角固定什么

不管玩家最后走向哪条职业线，主角固定以下内容。

### 3.1 固定身份

```text
洛水旧渡长大的孩子。
十岁时写下本世姓名。
父亲随官运粮后未归。
母亲一直维持家计并望向河道尽头。
辛衡教他识字、辨名册、理解字后面站着人。
禾安是从小一起长大的现实锚点，不是恋爱对象。
韩宁、柳娘和宋地流民让他第一次理解隐名与入册的风险。
裂钟让他第一次接触无法解释的前世回响。
```

### 3.2 固定人格主轴

主角可以因玩家选择而走向不同职业，但人格主轴不能散。

主角始终是：

```text
会称量的人。
会看见两边都有人。
会害怕落错一笔。
会记得那些被省掉的人。
会在犹豫之后承担选择。
```

他不是全知穿越者，也不是开挂救世主。

他不知道历史大势，只是在这一世中一步步看见：

```text
名与籍会救人，也会害人。
秩序可以承认人，也可以追索人。
记录可以让人留下，也可以让活人被找到。
沉默可以保护人，也可以让人永远消失。
```

### 3.3 固定终点

不管玩家走哪条职业线，第一章的历史终点不变：

```text
长平发生。
周亡发生。
秦统一发生。
主角活到约七十五岁，见证天下归一。
```

玩家不能改变大历史结果。

玩家能改变的是：

```text
谁活下来。
谁被记住。
谁被牵连。
谁与主角亲近或疏远。
哪种记录形态留下来。
无名录以什么形态进入第二章。
```

## 4. 主角不能固定什么

为了保证玩家的人生选择成立，以下内容不能提前写死。

```text
主角一定当官。
主角一定当医者。
主角一定当武将。
主角一定离开旧渡后走哪条路。
主角一定与某个 NPC 长期同行。
主角一定用某种方式保存无名录。
```

主角固定的是人格和主题，不是职业和生活方式。

## 5. 职业成形方式

职业不应在开局菜单中选择。

正确方式是：

```text
玩家先在事件中处理问题。
系统记录玩家反复优先处理的对象。
NPC 根据玩家行为改变信任、距离和邀请。
到 ACT03—ACT04 前后，职业线自然显形。
```

职业不是突然出现，而是由前面的选择逐步积累。

### 5.1 内部倾向值

系统内部可以记录以下倾向，但不建议直接在 UI 中显示成数值。

```text
记录倾向：关注木牍、名册、证据、口供、谁被漏写。
救治倾向：关注伤者、药、身体、救命优先。
粮路倾向：关注粮、水、盐、药、道路、关验、交易。
器物倾向：关注车、桥、仓、工具、简牍、器物、钟。
乡土倾向：关注田亩、收成、安置、本地人与流民关系。
军旅倾向：关注护送、征发、守路、兵役、战争现场。
言说倾向：关注劝说、辩论、学说、盟书、口述。
仕途倾向：关注官署、制度、法令、治理、编户。
隐退倾向：关注旁观、保存见证、避开权力、少介入。
谋划倾向：关注联络、转圜、布局、风险交换。
```

这些倾向只决定职业显形和剧情入口，不代表善恶值。

乡土倾向不导向独立“农人”职业线，而是影响旧渡、禾安、本地户、旧仓放粮、长平后归旧渡和无名录民间去向。

### 5.2 序章第一粒种子

序章结尾翻车现场只种下第一粒种子，不立刻决定职业。

```text
先救车下孩子：救治倾向、现实行动倾向增强；禾安更容易信任主角。
先抢泥水湿简：记录倾向、名籍倾向增强；韩宁更容易靠近主角。
先让活人互认：言说倾向、共同见证倾向增强；柳娘和辛衡更容易注意主角。
```

该选择只影响后续关系和初始倾向。

不能因此直接锁定医者、吏官或戏子。

### 5.3 ACT01—ACT02 积累倾向

ACT01《雨后流民》和 ACT02《旧礼无声》继续积累倾向。

示例：

```text
优先给伤者找草药、清创、安排夜里看护：救治倾向增强。
优先整理湿简、记录口述、标记谁与谁同行：记录倾向增强。
优先处理粮水、棚位、旧渡本地户怨气：乡土 / 粮路倾向增强，但不形成农人职业。
优先修车、搭棚、处理器物损坏：器物倾向增强。
优先劝本地人与流民不要冲突：言说 / 谋划倾向增强。
优先问官署流程、辛衡旧册、谁来担责：仕途 / 记录倾向增强。
优先保持距离，只保存见证、不深介入：隐退倾向增强。
```

### 5.4 ACT03—ACT04 职业显形

职业显形不应是系统弹窗：

```text
请选择你的职业。
```

而应是剧情自然推来：

```text
有人来请你帮忙。
有人把一件工具交给你。
有人让你去一个地方。
有人因为你过去的选择信任你。
有人因为你过去的选择拒绝你。
```

职业显形应通过 NPC 邀请、事件门槛和场景责任实现。

例如：

```text
救治倾向高：有人带你去看伤者，医者线显形。
记录倾向高：辛衡或官署让你协助整理旧册，吏官 / 记录线显形。
粮路倾向高：青缗让你同行看商路和关验，商贾线显形。
器物倾向高：工匠请你修车、桥、仓，工匠线显形。
军旅倾向高：护送、征发和前线粮道逐渐把你拉入武将线。
言说倾向高：学舍、柳娘或荀白把你拉入戏子 / 辩者 / 谋士相关入口。
仕途倾向高：公孙砚或县署让你看见新法入乡，仕官线显形。
隐退倾向高：你不入局，但保留关键见证，隐士线显形。
谋划倾向高：你开始联络不同阵营，谋士线显形。
乡土倾向高：不形成职业线，而是增强旧渡 / 禾安 / 粮水 / 空户相关共用主线权重。
```

## 6. 九职业不是九个主角

九职业不能写成九个平行副本。

必须遵守：

```text
主角只有一个。
人生位置可以不同。
理解问题的入口可以不同。
但主角始终从同一个旧渡、同一场雨、同一口裂钟开始。
```

每条职业线都要领悟同一个核心问题：

```text
一个人如何被时代写进秩序，又如何在秩序里保住自己不是数字。
```

## 7. 九职业对应领悟

| 职业线 | 看到的问题 | 领悟 |
|---|---|---|
| 医者 | 人救回来以后，没有籍、没有家、没有人认，仍然活不下去 | 救命不是结束，活下去还要有位置 |
| 吏官 / 记录 | 一笔写下去能发粮，也能抓人；空着能保护，也能抹去 | 记录不是中性的，写字的人也在承担因果 |
| 商贾 | 粮、盐、药、布、消息、关验先于道理决定人能不能走到明天 | 乱世里活路常不干净，但路断了人连选择都没有 |
| 武将 | 名籍最后会变成兵额、粮道、征发、死伤册 | 战争不是战场一瞬，而是无数户人被提前写进刀口 |
| 戏子 | 有些地名不能唱，有些旧曲必须断，有些人只能靠口口相传留下 | 记住一个人，不一定靠官册，也可能靠不敢唱全的旧曲 |
| 工匠 | 车、桥、仓、器、简、钟都会被时代使用 | 器物没有善恶，但人会把器物放进不同秩序里 |
| 谋士 | 一句话、盟书、计策可以救一城，也可以让万人入册征发 | 聪明不是答案，聪明也会制造代价 |
| 仕官 | 制度能结束混乱，也会把人压成户、役、税、罪 | 治理天下时，最容易看不见一个人的脸 |
| 隐士 | 不入局不是无罪，旁观者也会留下或错过见证 | 不选择，也是一种选择 |

## 8. 旧渡现实地基

原“农人线”被迁移为全职业共用地基。

它不是职业，而是第一章的人民底色。

```text
ACT01：雨后流民、没有米下锅、禾安熬稀粥。
ACT02：旧仓放粮，本地户与流民都要活。
ACT03：田亩、户籍、赋役和连坐落到旧渡。
ACT04：禾安独自承担旧渡压力，不等主角。
ACT06：丁壮被征，灶边少了一双手。
ACT07：长平后季良战死或失踪，主角回旧渡面对禾安。
ACT08：禾安已逝，留下小时候一起喝粥的碗。
```

这条地基的共同领悟是：

```text
天下怎么改名，地还是要种。
可种地的人、烧灶的人、分粥的人，也会被名籍、征发和战争带走。
```

## 9. 主角人生框架

第一章主角年龄跨度：

```text
前 286 年，主角 10 岁。
前 221 年，秦统一，主角约 75 岁。
```

第一章不是连续日常模拟，而是用关键年龄段串起一段完整人生。

## 10. NPC 自主逻辑

NPC 不能只等主角触发。

每个关键 NPC 都要有自己的目标、恐惧、底线和行动逻辑。

主角选择改变的是：

```text
NPC 是否信任主角。
NPC 是否向主角透露信息。
NPC 是否邀请主角进入某条路线。
NPC 是否在关键节点帮助、阻拦、离开或反向行动。
```

但 NPC 自身也会根据自己的逻辑行动。

禾安尤其不能被写成主角的恋爱遗憾或等待对象。她有完整人生，最终留下的不是“等主角回来”，而是那只小时候一起喝过稀粥的碗。

## 11. 路线交织规则

职业线不能完全平行。

必须设计交织节点。

交织节点包括：

```text
旧渡流民安置。
旧仓放粮。
新法入乡。
辛衡病重与老死。
百家灯火。
上党风云。
长平战前征发。
长平战后无名者记录。
长平后归旧渡，禾安问丈夫消息。
周亡。
秦统一。
晚年回旧渡，禾安已逝，留下粥碗。
无名录最终去向。
```

玩家看到的是不同入口，但背后是同一历史伤口。

## 12. 完整故事形成规则

第一章最后不能像九条线各自结束。

必须形成一个完整故事：

```text
序章让主角落地。
ACT01—ACT02 让主角看见名与籍的第一层风险。
ACT03—ACT04 让主角在一次次选择中长出职业方向。
ACT05 让主角听见不同学说和人生答案。
ACT06—ACT07 让所有答案被战争检验。
长平后归旧渡让大历史伤口落到禾安和季良身上。
ACT08 让职业差异收束到无名录、秦统一和那只粥碗。
```

最终玩家回望时，应感觉：

```text
我不是选了一个职业。
我是一路这样选择，才活成了这个人。
```

## 13. Codex 执行要求

后续让 Codex 设计第一章 ACT 或职业入口时，必须遵守：

```text
不得做开局职业菜单。
不得把职业线写成九个互不相干的副本。
不得把农人重新作为独立职业线加入。
不得让 NPC 只等待主角选择。
不得让主角因为职业变化而失去“称量、记录、亏欠”的人格主轴。
不得让职业线绕开固定历史节点。
不得让职业线绕开长平后归旧渡节点。
不得让禾安粥碗变成神秘法器。
```

应优先实现：

```text
选择倾向累积。
NPC 信任与距离变化。
职业邀请与事件门槛。
共享历史节点。
同一主题的不同职业领悟。
旧渡现实地基。
长平后归旧渡。
无名录最终回收。
```

## 14. 一句话总结

```text
主角必须是同一个人。
九职业必须是被选择磨出来的人生位置。
旧渡、粮水、灶火和禾安不是职业线，而是所有职业最后都要回去面对的地方。
路线必须分出去，也必须在长平、旧渡、粥碗和无名录处交织回来。
```
