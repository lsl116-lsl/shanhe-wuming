# 第一章《礼崩之世》主角立身与职业成形规则 V0.1

> 文档状态：第一章主角人生结构与职业分流规则  
> 适用范围：第一章 ACT01—ACT08、十职业入口、路线交织、NPC 动态逻辑、Codex 剧情与原型生成  
> 核心原则：主角必须立住，但主角不能被职业锁死。

## 1. 总原则

第一章不是让玩家开局选择职业。

第一章要写的是：

```text
同一个苏醒者，作为洛水旧渡长大的孩子，如何在十岁到七十五岁的完整人生中，被时代一步步磨出一双手。
```

职业不是身份菜单。

职业是主角在一次次选择后，被时代、关系、责任和亏欠共同推出来的人生位置。

核心句：

```text
职业不是玩家点出来的身份，而是主角被时代磨出来的手。
```

## 2. 主角固定什么

不管玩家最后走向哪条职业线，主角固定以下内容。

### 2.1 固定身份

```text
洛水旧渡长大的孩子。
十岁时写下本世姓名。
父亲随官运粮后未归。
母亲一直维持家计并望向河道尽头。
辛衡教他识字、辨名册、理解字后面站着人。
禾安是从小一起长大的现实锚点，不是恋爱对象。
韩宁、柳娘和宋地流民让他第一次理解隐名与入册的风险。
裂钟让他第一次接触无法解释的前世回响。
```

### 2.2 固定人格主轴

主角可以因玩家选择而走向不同职业，但人格主轴不能散。

主角始终是：

```text
会称量的人。
会看见两边都有人。
会害怕落错一笔。
会记得那些被省掉的人。
会在犹豫之后承担选择。
```

他不是全知穿越者，也不是开挂救世主。

他不知道历史大势，只是在这一世中一步步看见：

```text
名与籍会救人，也会害人。
秩序可以承认人，也可以追索人。
记录可以让人留下，也可以让活人被找到。
沉默可以保护人，也可以让人永远消失。
```

### 2.3 固定终点

不管玩家走哪条职业线，第一章的历史终点不变：

```text
长平发生。
周亡发生。
秦统一发生。
主角活到约七十五岁，见证天下归一。
```

玩家不能改变大历史结果。

玩家能改变的是：

```text
谁活下来。
谁被记住。
谁被牵连。
谁与主角亲近或疏远。
哪种记录形态留下来。
无名录以什么形态进入第二章。
```

## 3. 主角不能固定什么

为了保证玩家的人生选择成立，以下内容不能提前写死。

```text
主角一定当官。
主角一定当医者。
主角一定当武将。
主角一定离开旧渡后走哪条路。
主角一定与某个 NPC 长期同行。
主角一定用某种方式保存无名录。
```

主角固定的是人格和主题，不是职业和生活方式。

## 4. 职业成形方式

职业不应在开局菜单中选择。

正确方式是：

```text
玩家先在事件中处理问题。
系统记录玩家反复优先处理的对象。
NPC 根据玩家行为改变信任、距离和邀请。
到 ACT03—ACT04 前后，职业线自然显形。
```

职业不是突然出现，而是由前面的选择逐步积累。

### 4.1 内部倾向值

系统内部可以记录以下倾向，但不建议直接在 UI 中显示成数值。

```text
记录倾向：关注木牍、名册、证据、口供、谁被漏写。
救治倾向：关注伤者、药、身体、救命优先。
粮路倾向：关注粮、水、盐、药、道路、关验、交易。
器物倾向：关注车、桥、仓、工具、简牍、器物、钟。
乡土倾向：关注田亩、收成、安置、本地人与流民关系。
军旅倾向：关注护送、征发、守路、兵役、战争现场。
言说倾向：关注劝说、辩论、学说、盟书、口述。
仕途倾向：关注官署、制度、法令、治理、编户。
隐退倾向：关注旁观、保存见证、避开权力、少介入。
谋划倾向：关注联络、转圜、布局、风险交换。
```

这些倾向只决定职业显形和剧情入口，不代表善恶值。

### 4.2 序章第一粒种子

序章结尾翻车现场只种下第一粒种子，不立刻决定职业。

```text
先救车下孩子：救治倾向、现实行动倾向增强；禾安更容易信任主角。
先抢泥水湿简：记录倾向、名籍倾向增强；韩宁更容易靠近主角。
先让活人互认：言说倾向、共同见证倾向增强；柳娘和辛衡更容易注意主角。
```

该选择只影响后续关系和初始倾向。

不能因此直接锁定医者、吏官或戏子。

### 4.3 ACT01—ACT02 积累倾向

ACT01《雨后流民》和 ACT02《旧礼无声》继续积累倾向。

示例：

```text
优先给伤者找草药、清创、安排夜里看护：救治倾向增强。
优先整理湿简、记录口述、标记谁与谁同行：记录倾向增强。
优先处理粮水、棚位、旧渡本地户怨气：乡土 / 粮路倾向增强。
优先修车、搭棚、处理器物损坏：器物倾向增强。
优先劝本地人与流民不要冲突：言说 / 谋划倾向增强。
优先问官署流程、辛衡旧册、谁来担责：仕途 / 记录倾向增强。
优先保持距离，只保存见证、不深介入：隐退倾向增强。
```

### 4.4 ACT03—ACT04 职业显形

职业显形不应是系统弹窗：

```text
请选择你的职业。
```

而应是剧情自然推来：

```text
有人来请你帮忙。
有人把一件工具交给你。
有人让你去一个地方。
有人因为你过去的选择信任你。
有人因为你过去的选择拒绝你。
```

职业显形应通过 NPC 邀请、事件门槛和场景责任实现。

例如：

```text
救治倾向高：有人带你去看伤者，医者线显形。
记录倾向高：辛衡或官署让你协助整理旧册，吏官 / 记录线显形。
粮路倾向高：青缗让你同行看商路和关验，商贾线显形。
器物倾向高：工匠请你修车、桥、仓，工匠线显形。
乡土倾向高：乡里让你参与安置、田亩和旧渡存粮，农人线显形。
军旅倾向高：护送、征发和前线粮道逐渐把你拉入武将线。
言说倾向高：学舍、柳娘或荀白把你拉入戏子 / 辩者 / 谋士相关入口。
仕途倾向高：公孙砚或县署让你看见新法入乡，仕官线显形。
隐退倾向高：你不入局，但保留关键见证，隐士线显形。
谋划倾向高：你开始联络不同阵营，谋士线显形。
```

## 5. 十职业不是十个主角

十职业不能写成十个平行副本。

必须遵守：

```text
主角只有一个。
人生位置可以不同。
理解问题的入口可以不同。
但主角始终从同一个旧渡、同一场雨、同一口裂钟开始。
```

每条职业线都要领悟同一个核心问题：

```text
一个人如何被时代写进秩序，又如何在秩序里保住自己不是数字。
```

### 5.1 十职业对应领悟

| 职业线 | 看到的问题 | 领悟 |
|---|---|---|
| 医者 | 人救回来以后，没有籍、没有家、没有人认，仍然活不下去 | 救命不是结束，活下去还要有位置 |
| 吏官 / 记录 | 一笔写下去能发粮，也能抓人；空着能保护，也能抹去 | 记录不是中性的，写字的人也在承担因果 |
| 商贾 | 粮、盐、药、布、消息、关验先于道理决定人能不能走到明天 | 乱世里活路常不干净，但路断了人连选择都没有 |
| 武将 | 名籍最后会变成兵额、粮道、征发、死伤册 | 战争不是战场一瞬，而是无数户人被提前写进刀口 |
| 戏子 | 有些地名不能唱，有些旧曲必须断，有些人只能靠口口相传留下 | 记住一个人，不一定靠官册，也可能靠不敢唱全的旧曲 |
| 农人 | 田亩、户籍、赋役、收成都落在一双手上 | 天下怎么改名，地还是要种；种地的人未必保得住位置 |
| 工匠 | 车、桥、仓、器、简、钟都会被时代使用 | 器物没有善恶，但人会把器物放进不同秩序里 |
| 谋士 | 一句话、盟书、计策可以救一城，也可以让万人入册征发 | 聪明不是答案，聪明也会制造代价 |
| 仕官 | 制度能结束混乱，也会把人压成户、役、税、罪 | 治理天下时，最容易看不见一个人的脸 |
| 隐士 | 不入局不是无罪，旁观者也会留下或错过见证 | 不选择，也是一种选择 |

## 6. 主角人生框架

第一章主角年龄跨度：

```text
前 286 年，主角 10 岁。
前 221 年，秦统一，主角约 75 岁。
```

第一章不是连续日常模拟，而是用关键年龄段串起一段完整人生。

## 7. 年龄段与路线交织

### 7.1 10 岁：旧渡落地

对应内容：序章 + ACT01《裂钟之梦 / 雨后流民》

核心事件：

```text
写下本世姓名。
宋亡消息到来。
二十三户宋地流民抵达。
韩宁、柳娘出现。
理解名与籍不是姓名问题。
触碰裂钟。
翻车现场第一次重大选择。
```

主角变化：

```text
从“我写下自己的名字”，变成“别人的名与籍正散在泥里”。
```

路线种子：

```text
救人、抢简、互认三方向只种倾向，不锁职业。
```

NPC 动态：

```text
禾安会记住主角是否先救人。
韩宁会记住主角是否先护住湿简。
柳娘会记住主角是否先组织互认。
辛衡会观察主角第一笔因果如何落下。
```

### 7.2 11—15 岁：旧仓与旧册

对应内容：ACT02《旧礼无声》

核心事件：

```text
流民暂住旧渡。
粮、水、棚位、名册、旧里、旧债开始变成现实压力。
旧仓放粮与登记矛盾出现。
父亲官粮线第一次露出痕迹。
辛衡的旧册和隐瞒开始有重量。
```

主角变化：

```text
发现救下来不等于结束。
活人要粮，要水，要安置，要被承认，也要躲开追索。
```

路线触发：

```text
反复救治伤者：医者入口加深。
反复整理口供和木牍：吏官 / 记录入口加深。
反复处理粮、水、棚位：农人 / 商贾入口加深。
反复修补车棚器物：工匠入口加深。
反复劝人、组织互认：戏子 / 谋士 / 言说入口加深。
```

NPC 动态：

```text
禾安会根据主角是否承担现实杂务，决定是否把更多旧渡压力告诉主角。
韩宁会根据主角是否保护隐名风险，决定是否透露残简细节。
辛衡会根据主角是否理解“字后面站着人”，决定是否让主角接触旧册。
主角母亲会根据主角是否追问父亲旧事，显露不同程度的沉默或阻拦。
```

### 7.3 16—20 岁：新法入乡

对应内容：ACT03《旧国被重写》与 ACT04 前半

核心事件：

```text
旧渡和周边乡里被重新编户。
旧称呼变成户、伍、什。
新法木牌钉进乡里。
田、役、债、罚、连坐开始进入日常。
旧身份被新政权重写。
```

主角变化：

```text
他开始明白：旧礼救不了天下，新法也不是单纯恶物。
新法能让一些人获得位置，也能让人变得可追索、可征发、可计算。
```

路线分化：

```text
愿意进入县署学习制度：仕官 / 吏官线加深。
愿意跟着修路、修仓、修车：工匠线加深。
愿意跟商路看关验和粮价：商贾线加深。
愿意留在乡里处理田亩安置：农人线加深。
愿意跟随医者救治迁民：医者线加深。
愿意避开官署但保留见证：隐士线加深。
```

NPC 动态：

```text
公孙砚可能第一次出现，代表新秩序的冷与必要。
禾安可能留在旧渡或乡里，越来越像现实压力的承担者。
韩宁可能因旧籍风险与主角分开或短暂同行。
辛衡可能老去，开始把未说完的旧册责任转给主角。
```

### 7.4 20—30 岁：离开旧渡，百家与列国入身

对应内容：ACT04 后半 + ACT05《百家灯火》

核心事件：

```text
主角离开或半离开旧渡。
洛邑、学舍、商路、官署、边地、乡里成为不同职业线的场景。
荀白、申不疑、青缗、公孙砚等关键人物陆续进入。
```

主角变化：

```text
他不再只问谁对谁错。
他开始问：如果你是对的，代价由谁承担？
```

职业显形：

```text
此阶段应让玩家明显感到自己的职业路径正在成形。
但仍允许交叉：医者可接触官署，商贾可保存记录，隐士也可参与见证。
```

NPC 动态：

```text
荀白会把主角带向思想辩论，但可能把痛苦变成论题。
申不疑会把主角带向制度重构，但容易看不见人脸。
青缗会让主角看见路、货、消息和活路的灰色。
公孙砚会让主角看见制度不是纸面，而是木牌、户籍和执行。
柳娘的旧曲可能在戏子线或口述线中回响。
```

### 7.5 31—36 岁：合纵、上党与长平

对应内容：ACT06《合纵连横》与 ACT07《长平血雾》

核心事件：

```text
上党风云。
合纵失效。
粮道、盟书、军籍、征发转入战争。
长平大战发生。
大量人死去，更多人变成无人确认的名与籍。
```

主角变化：

```text
他终于明白：百家之言、法令、商路、名册、器物和医术，最后都可能被战争使用。
```

职业交织：

```text
医者在救伤，但救不完。
吏官在整理死伤和失踪，但写不全。
商贾在粮道和关验中看见活路被战争吞掉。
武将在线前承担征发与死伤。
戏子保存口述和旧曲。
农人看见田亩被征发抽空。
工匠修车、桥、仓，也发现器物被战争使用。
谋士发现聪明和盟书都有代价。
仕官发现制度效率进入战争后更加冷。
隐士发现旁观也无法无罪。
```

NPC 动态：

```text
每个关键 NPC 都不应只等待主角。
公孙砚会按制度推进。
申不疑会继续相信重构。
荀白会在辩论失效后被现实击中。
青缗可能选择保路、保货、保人中的一种。
禾安若仍在旧渡或迁徙线，会以现实方式处理伤者、粮与旧渡残余。
韩宁可能因残简和旧籍线被再次卷入。
柳娘可能在战后口述和亡国旧曲中承担见证。
```

### 7.6 37—50 岁：长平余波与无名录成形

对应内容：ACT07 后半 + ACT08 前半

核心事件：

```text
幸存者回不去原来的家。
失踪者无法被确认为亡。
死者名册、逃亡者、隐名者、旧国遗民混在一起。
无名录真正成形。
```

主角变化：

```text
他不再相信“写下来就能救人”。
他知道记录有罪，沉默也有罪。
```

职业回收：

```text
每条职业线都必须把自己的工具交给无名录。
医者交出伤者口供。
吏官交出残缺名册。
商贾交出路上见闻和失踪名单。
武将交出阵前征发与死伤记录。
戏子交出口述与旧曲。
农人交出迁民、田亩和空户记录。
工匠交出器物、车辙和地点证据。
谋士交出盟书背后的代价。
仕官交出制度内部的缺口。
隐士交出自己保存的见证。
```

NPC 动态：

```text
有人会要求公开无名录。
有人会要求藏起来。
有人会要求交给官档。
有人会要求烧掉或拆散。
主角与 NPC 的关系根据前半生选择产生不同站位。
```

### 7.7 50—65 岁：周亡与新秩序推进

对应内容：ACT08 中段

核心事件：

```text
周王室彻底失去现实意义。
旧礼最后的象征崩塌。
秦制继续推进。
更多地方被编入统一秩序。
```

主角变化：

```text
少年时，他怕人没有名。
中年时，他怕完整身籍害死活人。
晚年时，他怕所有人的名与籍都只剩户、役、数。
```

路线交织：

```text
此阶段职业差异仍在，但主线开始明显收束。
不同职业都看见同一个事实：天下越来越能被管理，也越来越能追索每一个人。
```

NPC 动态：

```text
公孙砚可能在制度中升沉。
申不疑的思想可能被现实采用，也可能被更强权力吞没。
荀白可能转向沉默、教学或重新发问。
青缗可能成为道路网络的一部分，也可能被道路吞没。
禾安、韩宁、柳娘是否仍在主角身边，取决于早中期选择，但他们的因果必须回响。
```

### 7.8 66—75 岁：天下将一，暮年回望

对应内容：ACT08 结尾

核心事件：

```text
秦统一。
天下终于有了一个名字。
主角回到或遥望洛水旧渡。
无名录的最终去向被决定。
```

主角变化：

```text
他没有阻止天下归一。
也没有救下所有人。
但他把一生见过的无名者，以某种形式交给后来的人。
```

最终选择：

```text
交给官档。
藏入民间。
托给旧曲和口述。
拆成数份。
埋回洛水与裂钟之间。
```

职业收束：

```text
无论主角是什么职业，最后问题都回到：
天下有了一个名字，可一个人呢？他的名，他的籍，他身后那一户活人，又该写在哪里？
```

## 8. NPC 自主逻辑

NPC 不能只等主角触发。

每个关键 NPC 都要有自己的目标、恐惧、底线和行动逻辑。

主角选择改变的是：

```text
NPC 是否信任主角。
NPC 是否向主角透露信息。
NPC 是否邀请主角进入某条路线。
NPC 是否在关键节点帮助、阻拦、离开或反向行动。
```

但 NPC 自身也会根据自己的逻辑行动。

## 9. NPC 状态字段建议

每个关键 NPC 可维护以下内部状态：

```text
trust：对主角的信任。
distance：与主角的心理距离。
risk：自身或其家族被牵连风险。
need：当前最想解决的现实问题。
secret：是否保留秘密。
debt：是否认为欠主角或主角欠自己。
path：NPC 自己正在走向的路线。
```

这些状态不一定全部显示给玩家。

但剧情生成和事件判断需要使用。

## 10. NPC 动态示例

### 禾安

```text
如果主角多次优先救人、做现实杂务，禾安更愿意告诉主角旧渡存粮压力。
如果主角多次优先记录而延误救治，禾安不会否定主角，但会记住那一刻的冷。
如果主角长期离开旧渡，禾安会自己承担旧渡现实压力，不会停在原地等主角。
```

### 韩宁

```text
如果主角保护隐名风险，韩宁逐步透露残简线索。
如果主角急于写全旧里，韩宁会后撤，甚至转向自己行动。
如果主角在长平前后仍保存旧册线，韩宁可能重新出现并推动无名录关键材料。
```

### 辛衡

```text
如果主角理解记录的两面性，辛衡会让主角接触更深旧册。
如果主角只把记录当成正确答案，辛衡会保留更多。
辛衡不一定一直活到中后期，但他的笔、木牍和未说完的话必须回响。
```

### 柳娘

```text
如果主角重视口述和共同见证，柳娘会让旧曲成为无名录的一种形态。
如果主角只信官册，柳娘可能仍唱，但不会把最深的停顿交给主角。
柳娘不会为了主角存在，她有自己的戏班、旧曲和保护方式。
```

### 公孙砚

```text
如果主角理解制度必要性，公孙砚可能邀请主角进入新法执行现场。
如果主角只指责新法冷酷，公孙砚会把主角视为不懂乱世的人。
公孙砚会按自己的制度逻辑推进，不会因为主角不喜欢就停手。
```

## 11. 路线交织规则

职业线不能完全平行。

必须设计交织节点。

交织节点包括：

```text
旧渡流民安置。
旧仓放粮。
新法入乡。
洛邑 / 学舍 / 商路相遇。
上党风云。
长平战前征发。
长平战后无名者记录。
周亡。
秦统一。
无名录最终去向。
```

在这些节点，职业线会从不同方向进入同一事件。

示例：长平战后：

```text
医者从伤者进入。
吏官从死伤册进入。
商贾从粮道进入。
武将从战场进入。
戏子从口述进入。
农人从迁民进入。
工匠从车辙和器物进入。
谋士从盟书失败进入。
仕官从制度记录进入。
隐士从旁观见证进入。
```

玩家看到的是不同入口，但背后是同一历史伤口。

## 12. 完整故事形成规则

第一章最后不能像十条线各自结束。

必须形成一个完整故事：

```text
序章让主角落地。
ACT01—ACT02 让主角看见名与籍的第一层风险。
ACT03—ACT04 让主角在一次次选择中长出职业方向。
ACT05 让主角听见不同学说和人生答案。
ACT06—ACT07 让所有答案被战争检验。
ACT08 让职业差异收束到无名录与天下归一。
```

最终玩家回望时，应感觉：

```text
我不是选了一个职业。
我是一路这样选择，才活成了这个人。
```

## 13. Codex 执行要求

后续让 Codex 设计第一章 ACT 或职业入口时，必须遵守：

```text
不得做开局职业菜单。
不得把职业线写成十个互不相干的副本。
不得让 NPC 只等待主角选择。
不得让主角因为职业变化而失去“称量、记录、亏欠”的人格主轴。
不得让职业线绕开固定历史节点。
```

应优先实现：

```text
选择倾向累积。
NPC 信任与距离变化。
职业邀请与事件门槛。
共享历史节点。
同一主题的不同职业领悟。
无名录最终回收。
```

## 14. 一句话总结

```text
主角必须是同一个人。
职业必须是被选择磨出来的人生位置。
NPC 必须按自己的逻辑活着。
路线必须分出去，也必须在历史伤口处交织回来。
```
