# 第一章《礼崩之世》关键人物星座原型 V0.1

> 文档状态：人物底层原型表  
> 适用范围：第一章主线人物、序章关键人物延展、立绘、场景小人、动画调度、Codex 角色行为生成  
> 使用原则：星座是人物发动机，不是剧情标签；游戏文本中不直接出现现代星座概念。

## 1. 总原则

本表用于帮助后续写作、动画、立绘和互动设计把关键人物区分开。

星座不能作为浅层标签使用。

不允许写成：

```text
因为他是某星座，所以他就怎样。
```

应该写成：

```text
这个人面对压力时，第一反应是什么？
他最想保住什么？
他最害怕什么？
他做错事时，通常错在哪里？
```

玩家在游戏里感受到的应当是人物性格和行动方式，而不是星座设定。

## 3. 主角：天秤

主角的天秤底色不是现代意义上的优雅、社交或漂亮话。

他的核心是：

```text
称量。
关系。
位置。
公平。
犹豫后的承担。
```

第一章里，主角反复面对的问题是：

```text
写还是不写？
救人还是留证？
名还是籍？
秩序还是活人？
旧礼还是新法？
记录还是沉默？
```

他能看见两边都有道理，也能看见两边都有人要承担代价。

### 表现方式

```text
说话不急。
观察比判断更早。
落笔前会停。
常看见别人没说出口的迟疑。
做选择时不是热血冲动，而是知道亏欠仍然伸手。
```

### 阴影

```text
太想称量清楚，容易晚一步。
太想让各方都有位置，容易被现实撕开。
太怕落错一笔，所以有时不敢马上落笔。
```

### 动画关键词

```text
笔尖停顿。
看向两边。
手指摩挲木牍边缘。
听见裂钟时身体先停。
确认行动后眼神稳定下来。
```

## 4. 禾安：白羊

禾安的白羊底色不是“暴躁”或“无脑冲”。

她的核心是：

```text
行动。
火。
直接。
保护。
先处理眼前的人。
```

她看见人快死、火快灭、水不够、米不够时，不会先讲道理。

她会先动手。

### 表现方式

```text
话快。
走路快。
手上总有活。
嘴上现实，手上不慢。
看见主角发呆会直接喊。
遇到伤者先拖水桶、搬柴、喊人。
```

### 阴影

```text
急起来容易觉得别人都在磨蹭。
会先救眼前人，之后才慢慢理解记录、身籍和追索的风险。
她不是不会算账，她只是认为有些账要等人活过今晚再算。
```

### 动画关键词

```text
抱柴小跑。
卷袖。
倒碎米。
拨灶火。
拖热水桶。
回头喊主角。
```

### 与主角的关系句

```text
主角怕落错一笔。
禾安怕晚伸一只手。
```

这不是恋爱张力，而是处世方式的张力。

## 5. 辛衡：处女

辛衡适合处女座，不是洁癖，而是“知道一笔一划都可能出错”。

他的核心是：

```text
细节。
秩序。
校正。
谨慎。
责任感。
怕错误造成无法挽回的后果。
```

他相信记录，但也知道记录会伤人。

### 表现方式

```text
笔尖悬在木牍上。
看见缺字会皱眉。
听见旧里不会立刻追问。
说话慢，因为他知道每句话都可能把人推出来。
```

### 阴影

```text
太知道风险，所以总是有所保留。
太知道错一笔的后果，所以有时不敢落笔。
他可能写过、删过、隐过一些名字，这些旧事成为他的债。
```

### 动画关键词

```text
敲案。
停笔。
推木牍。
看墨迹是否晕开。
递给主角空木牍。
```

## 6. 韩宁：天蝎

韩宁适合天蝎座。

他不是普通阴郁少年，而是被逼到墙角后，把所有秘密都攥在手里的人。

他的核心是：

```text
警惕。
秘密。
强烈的生存本能。
保护欲。
不轻易信任。
一旦信任，就很深。
```

### 表现方式

```text
别人问旧里，他先按住袖口。
身体往后退，眼神却不退。
他不是不想被救，他是不敢被完整看见。
他会试探别人是否真的懂隐名风险。
```

### 阴影

```text
会隐瞒。
会试探。
会把别人挡在外面。
会因为保护家人，让旧渡也一起承担风险。
```

### 动画关键词

```text
按袖中木片。
侧身护住母亲和妹妹。
看见湿简落泥时本能扑过去。
被拉住时眼神像被逼到墙角的兽。
```

## 7. 韩宁的母亲：巨蟹

韩宁的母亲适合巨蟹座，但不是温柔慈母模板，而是壳很硬的巨蟹。

她的核心是：

```text
家。
保护。
记忆。
血缘。
防御。
为了孩子可以立刻跪下，也可以立刻挡在前面。
```

### 表现方式

```text
她不一定大哭。
她先按住韩宁的手。
她比韩宁更早判断危险。
她知道父名、旧里、残简连起来会出事。
```

### 阴影

```text
为了护住自己家，她会切断信息。
她知道旧渡也需要登记，但她不能把孩子交出去。
她的保护会让别人也承担不完整信息带来的风险。
```

### 动画关键词

```text
挡在韩宁前面。
按住韩宁的手。
听见父名或旧里时立刻绷紧。
跪下不是软弱，而是立刻切断追问。
```

## 8. 柳娘：双鱼

柳娘适合双鱼座。

她是序章里“声音”和“旧梦”的人，靠戏安人，也知道戏会害人。

她的核心是：

```text
共情。
艺术。
旧梦。
安抚。
牺牲。
知道人心最软的地方在哪里。
```

### 表现方式

```text
她会唱。
但唱到地名处停住。
她用戏箱垫漏风处。
她知道孩子怕，所以哼旧曲。
可她也知道旧曲里有不能唱出口的地名。
```

### 阴影

```text
她会主动删掉故乡。
她为了保护活人，让旧曲残缺。
她安慰别人时，其实也在割掉自己的来处。
```

### 动画关键词

```text
发簪端正。
扶住戏箱。
唱到地名处眼神落下。
声音停住，雨声接上。
```

## 9. 主角母亲：金牛

主角母亲适合金牛座。

她不是靠情绪爆发打动人，而是靠撑住打动人。

她的核心是：

```text
土地。
粮食。
家计。
忍耐。
固执。
把日子一寸一寸撑下去。
```

### 表现方式

```text
数米。
数柴。
数布。
望河道尽头。
不说等。
但一直看。
```

### 阴影

```text
她可能明知道等不到，却不愿承认。
她的坚持会支撑这个家，也会把主角困在父亲未归这件事里。
她守住家的同时，也守住了一个无法确认的空位。
```

### 动画关键词

```text
手在数米，眼睛被船声牵走。
听见河道木缆响，会停一下。
每有船来，她看一眼，但不解释。
```

## 10. 主角父亲：射手，暂定

父亲暂定射手座。

他现在不能定死，因为后续可能涉及官粮、旧仓、失踪、责任甚至亏欠。

如果后续发现他更像被职责压住的人，可以改为摩羯。

### 当前核心

```text
远行。
道路。
承诺。
信念。
离开旧处。
被更大的方向带走。
```

### 表现方式

父亲序章不登场，而通过缺席物件出现：

```text
旧笔盒。
磨旧笔杆。
官粮车辙。
河道尽头。
母亲每次看船。
```

### 阴影

```text
射手会离开。
会相信远方有更重要的事。
但留下的人，要替他的离开承担日子。
```

### 暂定句

```text
他给主角留下的不是答案，是一个永远朝向远处的空位。
```

## 11. 公孙砚：摩羯

公孙砚如果作为新法执行者，非常适合摩羯座。

他的核心是：

```text
制度。
责任。
阶梯。
秩序。
耐心。
为了长远目标忍受冷酷。
```

他不能是坏人。

他应当真心相信：

```text
没有法度，乱世不会停。
没有户籍，粮发不下去。
没有军功，旧贵族不会让路。
```

### 表现方式

```text
说话不急。
不解释太多。
不怕别人讨厌他。
怕秩序塌掉后，更多人死。
他可以看起来冷，但那种冷来自长期执行制度。
```

### 阴影

```text
容易把具体的人看成户、役、兵额、粮数。
不是没有悲悯，而是认为悲悯不能治天下。
```

### 动画关键词

```text
整理木牌。
看户籍而不是看脸。
把新法木牌钉正。
走路稳，不急，不回头。
```

## 12. 申不疑：水瓶

申不疑承担思想上的“新法如刀 / 制度重构”角色时，适合水瓶座。

他的核心是：

```text
理性。
革新。
抽离。
未来。
重构旧秩序。
不太在乎眼前人的情绪。
```

他和公孙砚的区别是：

```text
公孙砚负责把法落到地上。
申不疑负责想象法如何重塑天下。
```

### 表现方式

```text
他说出很锋利的新秩序逻辑。
不沉迷旧礼。
看问题像看结构。
会觉得个人痛苦不能阻止天下重排。
```

### 阴影

```text
太远。
太冷。
太相信系统。
容易把人当成可以被重新排列的单位。
```

### 动画关键词

```text
看地图。
看制度图示。
说话时眼神不总落在人脸上。
手指划过边界和户数。
```

## 13. 荀白：双子

荀白如果承担百家争鸣、辩论、学舍和思想灯火角色，适合双子座。

他的核心是：

```text
语言。
辩论。
好奇。
多面。
连接不同思想。
看见一件事可以有很多种说法。
```

### 表现方式

```text
说话快。
问题多。
能把旧礼、新法、仁义、功利都拿出来辩。
不一定马上给答案，但能让主角看见答案不止一种。
```

### 阴影

```text
太会说。
有时容易把痛苦变成论题。
如果不被现实击中，可能会离人太远。
```

### 动画关键词

```text
手势多。
边走边说。
把竹简摊开又合上。
被现实击中时，第一次说不出话。
```

## 14. 青缗：双子，暂定

青缗暂定双子座偏商路型。

如果后续写成守财、守粮、守实际利益的人，可改为金牛。

当前建议双子，是因为她更适合承担商路、消息、人情和风险流动。

### 核心

```text
商路。
消息。
转圜。
口才。
变化。
知道哪里有粮，哪里有关验，哪里不能走。
```

### 表现方式

```text
消息灵。
说话绕。
见人说人话，见官说官话。
看似轻巧，其实一直在算风险。
```

### 阴影

```text
太会变通。
别人可能觉得她不可靠。
她会说“活路不是清白换来的”，这会让玩家不舒服。
```

### 动画关键词

```text
看路标。
摸钱绳。
听消息时眼神很快。
和不同人说话时姿态微变。
```

## 15. 人物张力网

第一章关键人物之间应形成以下张力：

```text
主角天秤：称量。
禾安白羊：行动。
辛衡处女：校正。
韩宁天蝎：隐藏。
韩宁母亲巨蟹：保护。
柳娘双鱼：安魂。
主角母亲金牛：守家。
主角父亲射手：远行。
公孙砚摩羯：建制。
申不疑水瓶：重构。
荀白双子：发问。
青缗双子：流动。
```

它们共同服务第一章主题：

```text
一个人如何被时代写进秩序，又如何在秩序里保住自己不是数字。
```

## 16. 后续调整原则

本表是 V0.1，不是永久锁死。

允许后续调整：

```text
主角父亲：射手 / 摩羯之间可根据官粮旧案真相调整。
青缗：双子 / 金牛之间可根据商贾线功能调整。
其他人物若剧情功能发生变化，也可重评星座原型。
```

但调整时必须说明：

```text
人物发动机变了什么。
他面对压力时的第一反应是否改变。
他最想保住的东西是否改变。
```
