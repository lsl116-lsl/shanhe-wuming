# 第一章《礼崩之世》职业线嵌入表 V0.3

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：根据最新主线重整，删除“农人”独立职业线  
> 用途：规定九条职业线如何由玩家选择自然成形，如何拥有独立故事线，又如何在长平、旧渡、无名录和秦统一处汇总。

## 1. 核心修订

第一章不再设置“农人”作为独立职业线。

原因：

```text
农人并不是不重要。
农人太重要，所以不能被拆成一条可选职业。
土地、粮水、田亩、空户、灶火和旧渡现实压力，是第一章所有职业线共同承受的现实地基。
```

原“农人线”的功能转入：

```text
禾安旧渡共用主线。
ACT02 旧仓与旧册。
ACT07 长平后旧渡重创。
ACT08 无名录最终去向。
```

禾安不是农人职业 NPC。

禾安代表的是：

```text
旧渡。
灶火。
粮水。
童年。
没有米下锅的现实。
长平死讯最终要回到的那一户活人。
```

## 2. 九条职业线

第一章保留九条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
隐士。
```

九条职业线不是九个副本。

它们是同一个主角在同一段人生中，被不同责任磨出来的九种社会位置。

```text
主角只有一个。
职业不是开局菜单。
职业由一次次选择、NPC 信任、事件门槛和现实责任自然显形。
```

职业决定：

```text
玩家最先看见什么。
玩家能调动什么资源。
谁愿意请玩家帮忙。
玩家必须对哪一类后果负责。
玩家能为无名录补上哪一种材料。
```

职业不决定：

```text
玩家善恶。
玩家能绕开共同历史伤口。
玩家必然支持旧礼、新法、合纵或统一。
某条线拥有唯一正确结局。
```

## 3. 职业成形规则

ACT01—ACT02 不锁职业，只积累倾向。

ACT03—ACT04 前后通过剧情显形。

职业显形不能写成：

```text
请选择职业。
```

而要写成：

```text
有人来请你帮忙。
有人把一件工具交给你。
有人让你去一个地方。
有人因为你过去的选择信任你。
有人因为你过去的选择拒绝你。
```

## 4. 内部倾向与职业入口

| 内部倾向 | 玩家经常优先处理 | 可自然显形职业 / 共用地基 |
|---|---|---|
| 救治倾向 | 伤者、草药、看护、身体 | 医者 |
| 记录倾向 | 木牍、名册、口供、谁被漏写 | 吏官 / 记录 |
| 粮路倾向 | 粮、水、盐、药、道路、关验、交易 | 商贾 |
| 器物倾向 | 车、桥、仓、工具、简牍、器物、钟 | 工匠 |
| 乡土倾向 | 田亩、收成、安置、本地人与流民关系 | 不形成独立职业，进入旧渡 / 禾安 / 土地地基 |
| 军旅倾向 | 护送、征发、守路、兵役、战争现场 | 武将 |
| 言说倾向 | 劝说、辩论、学说、盟书、口述 | 戏子 / 谋士 |
| 仕途倾向 | 官署、制度、法令、治理、编户 | 仕官 |
| 隐退倾向 | 旁观、保存见证、避开权力、少介入 | 隐士 |
| 谋划倾向 | 联络、转圜、布局、风险交换 | 谋士 |

倾向值只用于剧情路由，不作为善恶值显示。

乡土倾向仍然要记录，但它不把主角导向“农人职业线”。它影响：

```text
禾安信任。
旧渡本地户态度。
ACT02 旧仓放粮压力。
长平后归旧渡节点的刺痛程度。
无名录是否更偏向民间 / 旧渡 / 空户材料。
```

## 5. 共同主线比例

建议内容比例：

| 内容类型 | 占比 | 作用 |
|---|---:|---|
| 全职业共享主线 | 约 50% | 保证第一章是一段完整人生，不因职业割裂。 |
| 共享事件的职业版本 | 约 25% | 同一事件更换信息入口、行动方式和责任。 |
| 职业独有事件 | 约 15% | 建立职业身份质感、独立 NPC 和个人亏欠。 |
| 跨职业关系与回收 | 约 10% | 让未选择职业仍作为人物和制度存在。 |

删除农人职业线后，共享主线比例提高，因为旧渡、粮水、空户、禾安和灶火必须成为全职业共同回响。

## 6. 九职业独立线与同题领悟

| 职业线 | 独立故事线入口 | 看到的问题 | 最终领悟 | 无名录贡献 |
|---|---|---|---|---|
| 医者 | 伤者、草药、迁民病症、战后医棚 | 人救回来后，没有籍、没有家、没有人认，仍然活不下去 | 救命不是结束，活下去还要有位置 | 伤者口供、临终姓名、身体旧伤标记 |
| 吏官 / 记录 | 辛衡旧册、县署档案、错籍空籍 | 一笔写下去能发粮，也能抓人；空着能保护，也能抹去 | 记录不是中性的，写字的人也在承担因果 | 残缺名册、错籍、空籍、删改痕迹 |
| 商贾 | 青缗商路、关验、粮药交换、战前粮道 | 粮、盐、药、布、消息、关验先于道理决定人能不能活 | 活路常不干净，但路断了人连选择都没有 | 路上见闻、关验记录、失踪名单 |
| 武将 | 护送、守路、征发、粮道军役 | 名籍最后会变成兵额、粮道、征发、死伤册 | 战争不是战场一瞬，而是无数户人被提前写进刀口 | 征发记录、阵前名单、无人认领者 |
| 戏子 | 柳娘旧曲、口述互认、战后唱名 | 有些地名不能唱，有些人只能靠口口相传留下 | 记住一个人，不一定靠官册，也可能靠不敢唱全的旧曲 | 旧曲、口述、人名停顿 |
| 工匠 | 车、桥、仓、器物、裂钟物证 | 器物会被时代使用，修桥也可能方便征发 | 器物没有善恶，但人会把器物放进不同秩序里 | 车辙、器物、桥仓位置、裂钟物证 |
| 谋士 | 联络、盟书、游说、风险交换 | 一句话、一封盟书、一条计策可以救一城，也可以让万人入册 | 聪明不是答案，聪明也会制造代价 | 盟书背后的代价、被计策牵动的人 |
| 仕官 | 公孙砚、县署、新法执行、编户征发 | 制度能结束混乱，也会把人压成户、役、税、罪 | 治理天下时，最容易看不见一个人的脸 | 官档缺口、执行记录、删改痕迹 |
| 隐士 | 山中见证、避开官档、旁观与保存 | 不入局不是无罪，旁观者也会留下或错过见证 | 不选择，也是一种选择 | 私人见证、不入官档的材料 |

## 7. 旧渡 / 土地 / 灶火共用地基

原“农人线”并入全职业共享地基。

这条地基贯穿第一章：

```text
ACT01：雨夜翻车后，旧渡没有米下锅，禾安熬出那锅稀粥。
ACT02：旧仓放粮，本地户与流民争粮、水、棚位和责任。
ACT03：新法入乡，田亩、户籍、赋役和连坐落到旧渡。
ACT04：禾安独自承担旧渡现实压力，不等主角。
ACT06：丁壮被征，田亩空缺，旧渡灶火少了一双手。
ACT07：长平后，禾安丈夫季良被征后战死或失踪。
ACT08：主角回旧渡，发现禾安已逝，留下小时候一起喝粥的碗。
```

这条地基的最终领悟不是职业领悟，而是第一章共同底色：

```text
天下怎么改名，地还是要种。
可种地的人、烧灶的人、分粥的人，也会被名籍、征发和战争带走。
```

## 8. ACT 分布与职业状态

| ACT | 主线状态 | 职业状态 |
|---|---|---|
| ACT01 | 雨后流民，第一笔亏欠 | 只种倾向，不锁职业 |
| ACT02 | 旧仓、旧册、父亲官粮线裂缝 | 倾向继续积累，NPC 初步改变信任 |
| ACT03 | 新法入乡，旧称呼被重写 | 第一次职业邀请出现，但仍可交叉 |
| ACT04 | 选择一双手，辛衡病重交托 | 职业责任正式显形 |
| ACT05 | 百家灯火，辛衡老死 | 职业独立线加深，主角失去第一个写字的人 |
| ACT06 | 合纵连横，战争前夜 | 各职业从不同入口卷入战争机器 |
| ACT07 | 长平血雾 | 每条职业线必须出现不可逆损失或创伤 |
| ACT08 | 天下将一，无名录去向 | 职业材料汇入无名录，路线重新交织，并回到旧渡 / 禾安遗物 |

## 9. 未选择职业的世界存在感

玩家选择一条职业线，不代表其余职业从世界消失。

未选择职业由锚点人物承担：

| 未选职业 | 世界中的主要承担者 |
|---|---|
| 医者 | 老医者 / 小蓟 |
| 吏官 / 记录 | 辛衡、孟简、公孙砚 |
| 商贾 | 青缗 |
| 武将 | 军旅青年、屠申类人物 |
| 戏子 | 柳娘、阿檀 |
| 工匠 | 鲁砚 |
| 谋士 | 苏离、荀白相关支线 |
| 仕官 | 公孙砚、申不疑 |
| 隐士 | 南郭生 |

旧渡 / 土地 / 灶火不由“未选职业锚点”承担，而由禾安和旧渡共同主线承担。

## 10. 共享交织节点

所有职业线必须经过或回响以下节点：

```text
旧渡流民安置。
旧仓放粮。
新法入乡。
辛衡病重与老死。
百家灯火。
战前名单。
长平血雾。
长平后归旧渡，禾安问丈夫消息。
无名录成形。
周亡。
秦统一。
晚年回旧渡，禾安已逝，留下小时候一起喝粥的碗。
```

不同职业从不同入口进入同一历史伤口。

示例：长平后：

```text
医者从伤者进入。
吏官从死伤册进入。
商贾从粮道进入。
武将从战场进入。
戏子从口述进入。
工匠从车辙和器物进入。
谋士从盟书失败进入。
仕官从制度记录进入。
隐士从旁观见证进入。
所有职业最后都要回到旧渡，面对禾安、季良和那只粥碗。
```

## 11. 职业线设计禁忌

```text
不得开局职业菜单。
不得把职业线写成九个平行副本。
不得让某条职业线绕开长平。
不得让某条职业线绕开长平后归旧渡节点。
不得让职业线只有换皮文本，没有独立责任。
不得让未选职业从世界消失。
不得让职业变成善恶阵营。
不得让职业结局出现完美无亏欠路线。
不得重新把农人作为独立职业线加入。
```

## 12. Codex 执行要求

设计 ACT 或职业入口时，必须先读取：

```text
08_名籍与人生主线架构_V0.1.md
09_关键人物星座原型_V0.1.md
10_主角立身与职业成形规则_V0.1.md
11_ACT年龄段路线交织与关键节点_V0.1.md
13_长平后归旧渡共用主线_V0.1.md
```

新增职业事件时必须写清：

```text
该职业从哪个共享节点进入。
该职业看见的信息与其他职业有何不同。
该职业独有责任是什么。
对应 NPC 是否自主行动。
该事件如何在长平、归旧渡或无名录阶段回收。
```

新增旧渡、土地、粮水、田亩、空户、灶火相关事件时，必须优先判断它是否应进入“共享地基”，不要轻易做成职业独占事件。
