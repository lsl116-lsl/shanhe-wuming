# 第一章《礼崩之世》职业线嵌入表 V0.4

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：当前第一章职业线总表，八职业口径  
> 用途：规定八条职业线如何由玩家选择自然成形，如何拥有可玩故事线，又如何在长平、旧渡、无名录和秦统一处汇总。

## 1. 核心修订

第一章当前结构为：

```text
八职业线 + 乡土地基 + 隐退倾向。
```

不再作为独立职业线的内容：

```text
农人：转为乡土地基。
隐士：转为隐退倾向 / 见证方式 / 晚年姿态。
```

原因：

```text
农人太底层，应该成为所有职业共同面对的人民现实，而不是一条可选职业。
隐士主题成立，但作为独立职业可玩性偏弱，容易变成少介入、旁观和保存，适合转为所有职业都可能拥有的隐退倾向。
```

## 2. 八条职业线

第一章保留八条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

八条职业线不是八个副本。

它们是同一个主角在同一段人生中，被不同责任磨出来的八种社会位置。

## 3. 两个全局地基 / 倾向

### 3.1 乡土地基

乡土地基包括：

```text
旧渡。
禾安。
粮水。
田亩。
空户。
灶火。
没有米下锅。
小时候一起喝粥的碗。
```

它影响所有职业线，不作为独立职业线。

### 3.2 隐退倾向

隐退倾向包括：

```text
少介入。
私藏见证。
不入官档。
避开权力。
晚年去向。
无名录是否更偏向私人保存。
```

南郭生保留为“隐退 / 私藏见证”相关 NPC，但不再对应独立职业线。

隐退倾向可以附着在任何职业后期：

```text
医者晚年可以私藏伤簿。
吏官晚年可以带走残册。
戏子晚年可以只传半支旧曲。
工匠晚年可以藏起裂钟残片。
谋士晚年可以停止游说，只留下被牵动的人名。
仕官晚年可以保存官档里不能公开的缺口。
```

## 4. 职业成形规则

ACT01—ACT02 不锁职业，只积累倾向。

ACT03—ACT04 前后通过剧情显形。

职业显形不能写成：

```text
请选择职业。
```

而要写成：

```text
有人来请你帮忙。
有人把一件工具交给你。
有人让你去一个地方。
有人因为你过去的选择信任你。
有人因为你过去的选择拒绝你。
```

## 5. 内部倾向与职业入口

| 内部倾向 | 玩家经常优先处理 | 导向 |
|---|---|---|
| 救治倾向 | 伤者、草药、看护、身体 | 医者 |
| 记录倾向 | 木牍、名册、口供、谁被漏写 | 吏官 / 记录 |
| 粮路倾向 | 粮、水、盐、药、道路、关验、交易 | 商贾 |
| 器物倾向 | 车、桥、仓、工具、简牍、器物、钟 | 工匠 |
| 乡土倾向 | 田亩、收成、安置、本地人与流民关系 | 乡土地基，不形成职业 |
| 军旅倾向 | 护送、征发、守路、兵役、战争现场 | 武将 |
| 言说倾向 | 劝说、辩论、学说、盟书、口述 | 戏子 / 谋士 |
| 仕途倾向 | 官署、制度、法令、治理、编户 | 仕官 |
| 隐退倾向 | 旁观、保存见证、避开权力、少介入 | 全职业可附着的晚年姿态 |
| 谋划倾向 | 联络、转圜、布局、风险交换 | 谋士 |

倾向值只用于剧情路由，不作为善恶值显示。

## 6. 八职业独立线与可玩性

| 职业线 | 核心操作 | 看到的问题 | 最终领悟 | 无名录贡献 |
|---|---|---|---|---|
| 医者 | 救治、分诊、药物、临终口供 | 人救回来后，没有籍、没有家、没有人认，仍然活不下去 | 救命不是结束，活下去还要有位置 | 伤者口供、临终姓名、身体旧伤标记 |
| 吏官 / 记录 | 写名、留空、另册、暗记、对证 | 一笔写下去能发粮，也能抓人；空着能保护，也能抹去 | 记录不是中性的，写字的人也在承担因果 | 残缺名册、错籍、空籍、删改痕迹 |
| 商贾 | 选路、换货、过关、保人或保货 | 粮、盐、药、布、消息、关验先于道理决定人能不能活 | 活路常不干净，但路断了人连选择都没有 | 路上见闻、关验记录、失踪名单 |
| 武将 | 护送、守夜、守路、撤退、保粮或保人 | 名籍最后会变成兵额、粮道、征发、死伤册 | 战争不是战场一瞬，而是无数户人被提前写进刀口 | 征发记录、阵前名单、无人认领者 |
| 戏子 | 喊名、改词、藏地名、传唱、口述保存 | 有些地名不能唱，有些人只能靠口口相传留下 | 记住一个人，不一定靠官册，也可能靠不敢唱全的旧曲 | 旧曲、口述、人名停顿 |
| 工匠 | 修车、桥、仓、木牌、判断车辙、保存物证 | 器物会被时代使用，修桥也可能方便征发 | 器物没有善恶，但人会把器物放进不同秩序里 | 车辙、器物、桥仓位置、裂钟物证 |
| 谋士 | 游说、交换、调停、布局、承担话语代价 | 一句话、一封盟书、一条计策可以救一城，也可以让万人入册 | 聪明不是答案，聪明也会制造代价 | 盟书背后的代价、被计策牵动的人 |
| 仕官 | 编户、判事、放粮、缓役、执行法令 | 制度能结束混乱，也会把人压成户、役、税、罪 | 治理天下时，最容易看不见一个人的脸 | 官档缺口、执行记录、删改痕迹 |

## 7. 仕官、谋士、吏官的边界

三条线必须划清：

```text
吏官 / 记录：这一笔写不写？写全还是留空？
仕官：这条令执行不执行？这个人按什么身份处理？
谋士：没有官印和兵权时，如何用话、关系、消息和交换推动结果？
```

一句话区分：

```text
吏官承担记录后果。
仕官承担治理后果。
谋士承担话语和布局后果。
```

## 8. 旧渡 / 土地 / 灶火共用地基

这条地基贯穿第一章：

```text
ACT01：雨夜翻车后，旧渡没有米下锅，禾安熬出那锅稀粥。
ACT02：旧仓放粮，本地户与流民争粮、水、棚位和责任。
ACT03：新法入乡，田亩、户籍、赋役和连坐落到旧渡。
ACT04：禾安独自承担旧渡现实压力，不等主角。
ACT06：丁壮被征，田亩空缺，旧渡灶火少了一双手。
ACT07：长平后，禾安丈夫梁成被征后战死或失踪。
ACT08：主角回旧渡，发现禾安已逝，留下小时候一起喝粥的碗。
```

禾安口中称丈夫为“阿梁”。官册、军籍、死伤册中写“梁成”。

## 9. 共享交织节点

所有职业线必须经过或回响以下节点：

```text
旧渡流民安置。
旧仓放粮。
新法入乡。
辛衡老伯病重与老死。
百家灯火。
战前名单。
长平血雾。
长平后归旧渡，禾安问阿梁消息。
无名录成形。
周亡。
秦统一。
晚年回旧渡，禾安已逝，留下小时候一起喝粥的碗。
```

## 10. 职业线设计禁忌

```text
不得开局职业菜单。
不得把职业线写成八个平行副本。
不得让某条职业线绕开长平。
不得让某条职业线绕开长平后归旧渡节点。
不得让职业线只有换皮文本，没有独立责任。
不得让未选职业从世界消失。
不得让职业变成善恶阵营。
不得让职业结局出现完美无亏欠路线。
不得重新把农人作为独立职业线加入。
不得重新把隐士作为独立职业线加入。
```

## 11. Codex 执行要求

新增职业事件时必须写清：

```text
该职业从哪个共享节点进入。
该职业看见的信息与其他职业有何不同。
该职业独有责任是什么。
对应 NPC 是否自主行动。
该事件如何在长平、归旧渡或无名录阶段回收。
```

新增旧渡、土地、粮水、田亩、空户、灶火相关事件时，必须优先判断它是否应进入“乡土地基”，不要轻易做成职业独占事件。

新增隐退、私藏见证、不入官档相关事件时，必须优先判断它是否应作为“倾向 / 姿态”附着到现有职业，而不是恢复隐士职业线。
