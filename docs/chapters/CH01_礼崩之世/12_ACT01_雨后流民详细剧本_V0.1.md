# 第一章 ACT01《雨后流民》详细剧本 V0.2

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 剧本定位：序章之后的第一段正式可制作剧情  
> 时间范围：前 286 年，雨夜翻车选择之后至次日清晨  
> 主角年龄：10 岁  
> 核心原则：本文件不重复序章剧本；序章已经完成“写名、宋亡、裂钟、翻车、三选一”，ACT01 从选择后果开始。

## 1. 与序章的边界

序章《雨来之前》已经完成：

```text
主角写下本世姓名。
辛衡老伯解释名与籍。
禾安把主角拉回灶火和眼前活人。
宋亡消息抵达旧渡。
韩宁、柳娘和宋地流民进入旧渡。
裂钟第一次响起。
最后一辆流民车翻进泥里。
玩家做出第一选择：救孩子 / 抢湿简 / 互认活人。
```

ACT01《雨后流民》不再重写这些内容。

ACT01 的开场状态由序章结尾的选择带入。

```text
prologue_first_action = rescue_child / save_wet_slips / mutual_witness
```

ACT01 负责回答：

```text
人被拖进旧礼器库以后，怎么办？
活下来的人如何被记下？
没有米下锅时，谁先喝一口？
旧里不能写，现名又不够用时，册子怎么落笔？
```

## 2. ACT01 核心句

```text
人还没有救完，名字已经开始伤人。
```

ACT01 的目标不是让玩家完成一场救灾任务，而是让玩家第一次理解：

```text
人命、名籍、粮水、追索会同时压下来。
主角无法一次把所有事都做对。
```

本 ACT 结尾不应有胜利感。

结尾情绪应是：

```text
这一夜只是把人从雨里拖出来。
真正麻烦，从天亮才开始。
```

## 4. 关键变量建议

这些变量用于后续 ACT02—ACT04，不建议直接显示给玩家。

### 4.1 序章输入变量

```text
prologue_first_action：序章第一选择。
child_condition：车下孩子伤势。
wet_slip_integrity：湿简完整度。
mutual_witness_count：互认成功人数。
```

### 4.2 倾向变量

```text
healing_tendency：救治倾向。
record_tendency：记录倾向。
speech_tendency：言说 / 口述倾向。
field_tendency：乡土 / 粮水倾向。
route_tendency：粮路 / 关验倾向。
craft_tendency：器物 / 修补倾向。
withdraw_tendency：隐退 / 私藏见证倾向。
```

### 4.3 NPC 状态

```text
hean_trust：禾安信任。
hanning_trust：韩宁信任。
liuniang_trust：柳娘信任。
xinheng_attention：辛衡老伯关注。
local_household_pressure：本地户压力。
refugee_panic：流民恐慌。
```

### 4.4 事件状态

```text
food_remaining：粥锅剩余。
temporary_register_mode：临时册模式。
hidden_register_risk：暗册暴露风险。
old_bell_contact_memory：裂钟记忆残留强度。
```

## 5. 人物在 ACT01 的性格表达

### 主角

主角不是空白工具人。

表现重点：

```text
看见两边都有人。
手里拿着空木牍，但眼前有人在流血。
会停顿，但不能永远停顿。
第一次发现“不做完美选择”也是成长。
```

### 禾安

禾安是行动型，不是温柔陪伴。

她的台词要短、硬、现实：

```text
“你还站着干什么？”
“先把他腿抬出来。”
“这锅粥熬稀一点，今晚能多撑三个人。可明早呢？”
“别跟我讲够不够写，先看他还喘不喘。”
```

### 辛衡老伯

辛衡老伯不是万能导师。

表现重点：

```text
慢。
稳。
笔尖悬停。
不替玩家选择。
知道写与不写都会害人。
```

台词要有重量：

```text
“这一笔，你先落在哪儿了？”
“现名能叫人答应，旧里能叫人被找到。”
“空着，也是一笔。”
“今晚的册，不求全。求活人明早还能认得彼此。”
```

### 韩宁

韩宁不是谜语人。

他不是不想被救，是怕被完整看见。

台词要有防御感：

```text
“我说了，你们就会写。”
“写全了，就会有人顺着找。”
“我不是不记得。我是不敢让别人也记得。”
“你们写你们的，我不说。”
```

### 韩宁母亲

她不是哭泣母亲模板。

```text
她比韩宁更早判断危险。
听见旧里、父名、残简时先按住韩宁的手。
可以下跪，也可以挡在前面。
保护不是软弱。
```

### 柳娘

柳娘不是气氛 NPC。

```text
她用声音安人。
她知道哪一句不能唱。
她能组织互认，也能主动删去危险信息。
```

口令示例：

```text
“能答应的，答一声。”
“别喊旧里。喊现在能叫的名。”
“这一户，三个人，还在。”
“旧词先吞下去，人活着，以后还有人记。”
```

## 6. SC01 被拖进旧礼器库

### 6.1 开场状态

画面从序章选择后切入，不重复翻车过程。

旧礼器库被临时腾空：

```text
断足的鼎推到墙边。
裂边的簋压住破草席。
残钟旁边放着热水桶。
湿简被摊在旧案上。
伤者躺在礼器空出来的地方。
外面仍有雨声。
```

裂钟不再主动解释，只让主角偶尔听见极轻的余响。

### 6.2 序章选择后果展示

#### A. 序章先救车下孩子

```text
child_condition 较好。
wet_slip_integrity 较差。
mutual_witness_count 较低。
hean_trust 增加。
```

禾安低声说：

> “腿还在，命也还在。你刚才没慢。”

韩宁看着泥里晕开的字，什么也没说，只把袖口按得更紧。

#### B. 序章先抢湿简

```text
wet_slip_integrity 较好。
child_condition 较差。
hanning_trust 增加。
hean_trust 轻微下降或产生冷感记忆。
```

韩宁第一次主动靠近主角一步：

> “那片……别给他们看全。”

禾安在另一边给孩子压伤处止血，没看主角：

> “木片没断，人骨头断了。”

这不是否定主角，而是她记住了这一刻。

#### C. 序章先让活人互认

```text
mutual_witness_count 较高。
refugee_panic 降低。
liuniang_trust 增加。
child_condition 与 wet_slip_integrity 均中等或有损失。
```

柳娘嗓子哑了，仍对主角点头：

> “有人答应，就不是一个人散在雨里。”

辛衡老伯看着临时册上的空格：

> “互认能救今晚，也能害明日。记住这个。”

## 7. SC02 临时医棚轻探索

玩家可在旧礼器库内移动或选择调查。

可调查对象：

| 调查对象 | 看到的信息 | 倾向 / 关系影响 |
|---|---|---|
| 伤者 | 伤势、发热、压伤、失血 | healing_tendency 增加 |
| 湿简 | 字迹晕开，旧里和父名残缺 | record_tendency 增加；可能触发韩宁警惕 |
| 粮袋 | 袋底只剩碎米 | field_tendency 增加；禾安后续台词变化 |
| 旧钟 / 裂钟 | 青铜锈、裂纹、极轻回响 | old_bell_contact_memory 增加 |
| 柳娘戏箱 | 箱角垫着漏风处，里面有旧曲物件 | speech_tendency 增加 |
| 韩宁袖口 | 木片边缘被刮薄 | hanning_trust 根据询问方式变化 |
| 本地户争执 | 本地人担心明早断粮和被连累 | local_household_pressure 增加 |

轻探索规则：

```text
玩家不能把所有对象查完并获得全收益。
每调查 / 帮忙一次，都会让其他压力变化。
例如：看伤者会耽误湿简晾干；帮禾安烧水会错过韩宁母亲与辛衡老伯的低声对话。
```

## 8. SC03 谁先被记下

辛衡老伯开始整理临时册。

冲突：

```text
流民需要被记下，才能明早领粮、找人、暂住。
但旧里、父名、旧邑不能轻易写全。
本地户要求清楚登记，否则不愿继续出粮和棚位。
```

可选处理：

### A. 只记现名和人数

```text
优点：风险低，流民更愿意配合。
缺点：后续分粮、寻亲和责任确认困难。
影响：speech_tendency 或 field_tendency 增加；hidden_register_risk 低。
```

辛衡老伯：

> “现名能叫人回头，但不能证明他身后那一户。”

### B. 记同行关系，不写旧里

```text
优点：有助于互认和安置。
缺点：如果关系被追索，仍可能牵连。
影响：record_tendency + speech_tendency 增加。
```

柳娘：

> “先记谁和谁一起来。地名以后再说。”

### C. 明册写现名，暗册记线索

```text
优点：保留后续追查可能。
缺点：暗册一旦暴露，风险最大。
影响：record_tendency 增加；hidden_register_risk 增加；辛衡老伯关注增加。
```

辛衡老伯看主角很久：

> “你知道暗记不是无害吧？”

## 9. SC04 粥锅前

禾安在灶边熬粥。

这不是温情场景，而是资源选择。

当前现实：

```text
碎米不够。
热水不够。
干布不够。
伤者、孩子、老人、本地户和流民都在等。
```

可选处理：

### A. 重伤者优先

```text
healing_tendency 增加。
伤者状态改善。
本地户和轻伤流民不满。
```

禾安：

> “先让快断气的喝。能骂人的，说明还能撑。”

### B. 平均分

```text
refugee_panic 降低。
重伤者风险增加。
food_remaining 快速降低。
```

本地户：

> “平均？明早你也平均给我们变出米来？”

### C. 留本地户一份

```text
local_household_pressure 降低。
流民不安增加。
field_tendency 增加。
```

禾安低声：

> “你知道留这一份，不是小气。可他们不知道。”

### D. 先热水和干布，不急着分粥

```text
craft_tendency / healing_tendency 增加。
短期饥饿压力上升。
```

老医者或禾安：

> “喝一口冷粥，不如先别让伤口再脏。”

## 10. SC05 韩宁袖中的木片

韩宁坐在角落，韩宁母亲守在他旁边。

触发方式：调查袖口、湿简、旧里问题，或序章先抢湿简。

主角可选：

### A. 只帮他把木片擦干

```text
hanning_trust 增加。
record_tendency 轻增。
不获得内容信息。
```

韩宁：

> “你不问？”

主角可答：

> “你想说的时候，再说。”

### B. 问木片是什么

```text
可能获得残简线索。
hanning_trust 视语气变化。
韩宁母亲警惕增加。
```

韩宁母亲：

> “先生，今晚先别问。”

### C. 承诺不问旧里

```text
hanning_trust 大增。
后续韩宁可能主动透露“父亲管过旧册”。
但本地户对登记不满增加。
```

韩宁：

> “你们旧渡的人，都这样说。可写的时候，手会变。”

## 11. SC06 柳娘喊名

柳娘组织流民互认。

她不唱完整旧曲，只用节拍让人回答。

三种喊名方式：

### A. 喊现名

```text
速度快。
旧里风险低。
但重名、假名、漏名概率高。
```

### B. 喊同行关系

```text
互认效果好。
能建立临时关系网。
但关系本身也可能成为追索线。
```

### C. 喊伤者位置

```text
有助于救治和安置。
但不利于完整记录。
```

柳娘提醒：

> “别喊旧里。喊现在能叫的名。”

如果玩家在序章先互认活人，柳娘此处会更信任主角：

> “你来喊。他们刚才听过你的声。”

## 12. SC07 辛衡老伯的临时册

ACT01 收束选择。

辛衡老伯把临时册摊开，让主角看。

他说：

> “今晚这些字，明早就会变成粮、水、棚位和责任。”

主角必须决定临时册模式：

### A. 公开现名册

```text
优点：简单、可交代、本地户较能接受。
缺点：信息不足，后续寻亲和旧债线困难。
后续：ACT02 分粮更顺，但韩宁线较疏远。
```

### B. 明册 + 暗记关系册

```text
优点：保留后续追查和无名录材料。
缺点：暗册暴露风险高。
后续：辛衡老伯关注上升，韩宁线可能复杂化。
```

### C. 空格证人册

```text
优点：承认“不知道”，让证人关系保留。
缺点：官府不喜欢空格，本地户也不安心。
后续：柳娘、韩宁较信任；官署线后续压力更大。
```

辛衡老伯最后说：

> “空着，也是一笔。”

## 13. SC08 天亮以后

天亮不是胜利，而是后果展示。

根据变量显示不同画面。

### 13.1 孩子状态

```text
child_condition 好：孩子醒来，禾安松一口气，但粮更少。
child_condition 差：孩子发热或昏迷，医者线后续压力增强。
```

### 13.2 湿简状态

```text
wet_slip_integrity 好：能看见部分旧字，但韩宁警惕更强。
wet_slip_integrity 差：字迹晕开，韩宁失控或沉默。
```

### 13.3 互认状态

```text
mutual_witness_count 高：流民稍安，但关系网风险上升。
mutual_witness_count 低：有人天亮仍找不到亲属，恐慌延续。
```

### 13.4 粥碗状态

无论选择如何，那只旧碗必须出现。

```text
碗边还没有缺口，或者刚在混乱中磕出第一道缺口。
禾安把它倒扣在灶边。
主角此时不会知道，这只碗会跟到他七十五岁。
```

禾安可说：

> “洗干净。明晚还得用。”

## 14. ACT02 接口

ACT01 结束后进入 ACT02《旧礼无声 / 旧仓与旧册》。必须传入：

```text
prologue_first_action
healing_tendency
record_tendency
speech_tendency
field_tendency
hean_trust
hanning_trust
liuniang_trust
xinheng_attention
local_household_pressure
refugee_panic
temporary_register_mode
hidden_register_risk
old_bell_contact_memory
```

ACT02 起始压力：

```text
粮水不够。
本地户开始算账。
流民需要继续安置。
旧仓是否开门成为下一场冲突。
辛衡老伯手里的临时册，开始真正产生后果。
```

## 15. 设计禁忌

```text
不要重复写序章的写名、宋亡、裂钟、翻车和三选一。
不要让 ACT01 变成救灾成功关卡。
不要把禾安写成温柔陪伴。
不要让韩宁只做神秘道具持有人。
不要让柳娘只负责唱歌氛围。
不要让辛衡老伯替玩家判断对错。
不要让玩家一次解决所有压力。
不要让粥碗变成神秘法器。
```
