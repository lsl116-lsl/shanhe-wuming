# 第一章《礼崩之世》章节定位与史实边界 V0.3

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 推荐主交互窗口：约前 286 年至前 221 年  
> 主空间：洛邑及洛水交通圈、韩赵魏交界、秦地新附县邑、上党与长平周边  
> 当前口径：八职业线 + 乡土地基 + 隐退倾向。

## 1. 章节责任

第一章负责建立整部游戏的叙事语法：

```text
苏醒者拥有完整本世人生，不是失忆空壳。
历史大势不能被一个普通人翻转。
职业是社会位置，不是战斗职业。
选择同时进入人物、制度、记录和后世。
统一不是答案，而是下一章的新问题。
```

本章核心问题：

```text
名是称呼，籍是位置。
入册，是被承认，也是被追索。
```

第一章最终要让玩家看见：

```text
一个人被时代写进秩序之后，如何还能不只是数字。
```

## 2. 当前职业线边界

第一章采用八条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”不再作为独立职业线。

土地、粮水、田亩、空户、灶火、没有米下锅和禾安，属于所有职业共同面对的乡土地基。

“隐士”不再作为独立职业线。

隐退、私藏见证、不入官档、少介入和晚年去向，属于所有职业都可能附着的隐退倾向。

这意味着：

```text
旧渡不是一条职业路线。
旧渡是所有职业最终都要回去面对的地方。
隐退不是一条职业路线。
隐退是主角晚年如何保存见证、如何处理无名录的一种姿态。
```

## 3. 戏剧压缩

本章以约六十五年完成一段从少年到暮年的完整人生。历史地点间的移动服从商路、征辟、行旅、从军、迁徙和职业需要，不把苏醒者写成恰好出现在所有著名事件现场的人。

允许：

```text
将分散发生的基层制度矛盾凝聚为代表性虚构县邑与聚落。
用虚构人物接触真实制度压力。
让长平成为八职业共享的历史危机，但不让所有路线都进入前线。
用长平后归旧渡，把大历史伤口落回禾安、梁成 / 阿梁、粥碗和旧渡。
用短尾声推进到前 221 年。
```

不允许：

```text
让苏醒者参与或取代真实名将、君主的决策。
用现代民族国家概念替代战国人的国、邑、宗族与属籍经验。
用后世成熟戏曲、纸张、印刷、科举等事物。
让普通人准确预知秦必然统一。
用一条现代政策解决全部时代矛盾。
把禾安写成恋爱遗憾或等待主角一生的人。
把禾安留下的粥碗写成神秘法器。
```

## 4. 时代内表达

| 项目标签 | 正文优先表达 |
|---|---|
| 戏子 | 优伶、乐人、倡者、行旅乐团 |
| 公务员 | 吏、书吏、属官 |
| 户口 | 户、籍、名籍、属籍 |
| 政策 | 法令、令、策、治术 |
| 社会 | 天下、国、邑、乡里、人群，按语境选择 |
| 身份证 | 名籍、符、传、关验等具体凭据，不使用现代词 |
| 人权 | 具体写活命、免役、保名、保家和不受滥刑 |

## 5. 普通人知识边界

苏醒者可以知道：

```text
自己亲历的征敛、登记、迁徙、粮价、军功和地方传闻。
经商旅、使者、军卒与行旅乐人传来的不完整消息。
当前职业允许看到的文书和命令。
```

苏醒者不能天然知道：

```text
列国完整战略。
君主真实意图。
后世对战国的统一评价。
长平完整伤亡数字与所有处置细节。
秦统一后的具体制度结局。
```

不同消息必须标注来源、可信度和利益关系。

## 6. 物质与文书

本章关键媒介为：

```text
竹木简牍。
木牌、符传、印记。
粮册、户籍、军册、伤簿。
车马、渡口、驿舍、商路。
青铜礼器、木尺、量具、农具、兵器与粮车。
口述、歌、节拍和地名记忆。
旧锅、热水桶、粥碗等生活器物。
```

载体都具有材料限制：

```text
简牍会受潮、断裂、刮改和散失。
木牌会腐朽、焚毁或被重新书写。
铜器会被征收、熔铸、迁移。
口述会改词、并段、误认人物。
生活器物不会自己解释意义，只能由人物记忆和选择赋予重量。
```

## 7. 长平表现边界

长平承担本章最大共同危机，但不是战争奇观。

必须表现：

```text
征兵、运粮、道路、伤病、失联、投降和战后辨认。
前线、后方、乡里和官署对同一事件的不同信息。
数字无法替代具体姓名。
梁成这样的普通丁壮如何因为有名、有籍、有户而被征发准确找到。
玩家只能改变局部生还、证据和责任链。
```

不得表现：

```text
玩家凭个人策略改变胜负。
以处置场面猎奇。
把所有秦卒或赵卒写成同一种人。
用单一史料版本宣布所有细节无争议。
```

涉及史实争议的部分，以人物所知、传闻冲突和记录差异表现，不把虚构细节伪装成定论。

## 9. 章节交付

第一章必须交出：

```text
裂钟或其损毁记录。
无名录五种去向之一。

新法木牌与编户经验。
长平亡者、失踪者和生还者的冲突记录。
一项主职业独有证据。
两至三名核心人物的可变命运。
长平后归旧渡，禾安问阿梁消息。
晚年回旧渡，禾安已逝，只留下小时候一起喝过稀粥的碗。
“这不是你第一次看见山河改色”。
```
