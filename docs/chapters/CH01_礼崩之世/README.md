# 第一章《钟裂于洛水》：礼崩之世 目录导航

> 对外章节名：《钟裂于洛水》  
> 主题名：礼崩之世  
> 当前口径：八职业线 + 乡土地基 + 隐退倾向  
> 共同人生窗口：约前 286 年至前 221 年  
> 主角年龄：10 岁至约 75 岁

## 1. 命名规则

第一章命名统一为：

```text
对外章节名：第一章《钟裂于洛水》
主题名：礼崩之世
目录名：CH01_礼崩之世
```

写作时优先使用：

```text
第一章《钟裂于洛水》：礼崩之世
```

“礼崩之世”用于说明时代主题，不单独作为对外章节标题。

## 2. 当前故事核心

第一章写的是：

```text
序章让主角做出第一笔选择。
第一章让这笔选择长成一段完整人生。
中年在长平看见无数人被压成数字；
长平后回旧渡，面对禾安问阿梁消息，却说不出口；
晚年再回旧渡时，禾安已逝，只留下小时候一起喝粥的碗；
他终于决定无名录的去向，不是为了消除亏欠，而是为了让那些没被说出口的人不至于彻底无名。
```

## 3. 与序章的边界

序章《雨来之前》负责：

```text
写下本世姓名。
父亲未归、母亲等待、辛衡老伯、禾安、韩宁、柳娘登场。
解释名与籍。
宋亡消息抵达。
裂钟第一次触发。
最后一辆流民车翻进泥里。
玩家做出第一选择：先救孩子 / 先抢湿简 / 先让活人互认。
```

第一章《钟裂于洛水》负责：

```text
承接序章三选一后果。
从旧礼器库临时医棚、临时册、粥锅、韩宁残简和柳娘喊名开始。
将这笔选择推进到旧仓、新法、百家、长平、归旧渡、无名录和秦统一。
```

第一章文件不得重复写序章可玩剧本。

## 4. 当前职业线

第一章保留八条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”和“隐士”不再作为独立职业线。

```text
乡土地基：土地、粮水、田亩、空户、旧渡、灶火、没有米下锅、禾安和粥碗。
隐退倾向：少介入、私藏见证、不入官档、晚年姿态和无名录去向。
```

南郭生保留为“隐退 / 私藏见证”相关 NPC，但不再对应独立职业线。

## 5. 禾安丈夫口径

禾安丈夫正式名暂定为：

```text
梁成。
```

日常称呼：

```text
阿梁。
```

用法：

```text
军籍、死伤册、官档中写“梁成”。
禾安口中说“阿梁”。
旁人可称“旧渡梁氏子”。
```

长平后归旧渡时，禾安问主角：

```text
梁成。旧渡梁氏，去年随征走的。
你路上，听过没有？
```

如果主角一时没有反应，禾安再补一句：

```text
我平日叫他阿梁。
```

这个名字的功能不是英雄化，而是让长平死伤册落到旧渡一户普通人身上。

## 6. 辛衡称呼口径

文档索引中可简称“辛衡”。

少年主角视角、序章、ACT01 和具体剧本文本中，优先称：

```text
辛衡老伯。
```

这样保持和序章口径一致。
