# 记录人生：册上未写全的第五个人 V0.4

> 所属章节：第一章《钟裂于洛水》：礼崩之世  
> 职业人生：记录  
> 文档定位：八职业人生独立篇之一，故事强化稿  
> 本版重点：按医者、武将篇修改经验，重顺记录职业逻辑：为什么写、写错如何伤人、不写又如何让人消失。  
> 核心命题：记录不是把册页填满；有些留白，是为了不把活人写死。

## 1. 第一根木片

主角最早学写字，不是为了做官。

是为了让旧渡灶边少乱一点。

那几年，迁来的人越来越多。谁领过粥，谁还没领，谁家有病人，谁家孩子夜里发热，光靠嘴记不住。辛衡老伯年纪大了，眼睛一到傍晚就花，常把木片递给主角。

“你手稳，替我刻一下。”

主角第一次刻的是一个孩子的名字。

韩宁。

那孩子瘦小，脸上总有灰，领粥时不敢抬头。禾安问他叫什么，他声音小得像没说。主角把耳朵凑过去，才听清两个字。

他在木片上刻下：

```text
韩宁，一碗。
```

韩宁捧着粥走了几步，又回头看那片木头。

像是在确认：自己真的有一份。

主角那时第一次觉得，写下来很有用。

一个人被写下，就不容易被挤掉。

辛衡老伯却说：“别高兴太早。”

主角问：“这也有错？”

辛衡老伯看着一地木片。

“写少了，人没饭。写多了，别人少饭。写错了，麻烦还在后头。”

## 2. 写错的一笔

主角真正懂这句话，是因为许阿芦。

许阿芦带着两个孩子住在东棚。她丈夫死在路上，旧里没人能作证，手里只剩半片残简。新法入乡，旧渡重新核户，书吏嫌她说不清，准备先把她和孩子挂到同棚另一户下面。

主角那天帮忙递牌、叫号，在草片上先记一遍。

他也觉得这样省事。

反正住在一起，先挂上去，总比没有名好。

辛衡老伯当时去后屋翻旧简，主角便照着书吏的意思写了：

```text
许阿芦，并入东棚陈户。
```

半个月后，县邑按户征粮。

陈户本就穷，被多算了三口，粮交不出，被差役拖走了家里唯一一只鸡。陈家老人骂许阿芦拖累人，许阿芦抱着孩子来找主角。

“先生，我不是他们家的人。”

主角想说那只是草片。

可县邑抄走的正册，就是从草片转过去的。

他那一笔已经走远了。

辛衡老伯没有骂他，只把那片草片放到他面前。

“看见没有？你图省事，省的是谁的事？”

主角看着那一行字，第一次觉得刻刀比木棍还重。

## 3. 留白

从那以后，主角遇到说不清的人，不敢轻易并户。

可不写也会出事。

有一队孩子被送到旧渡，四个有名，一个说不清。最大的孩子说路上本来五个人，最小的那个一直被人叫“存”，不知道姓，也不知道旧里。

书吏说：“无姓无里，怎么记？”

旁边有人说：“先并到韩宁那边吧，他们一道来的。”

主角看见那个孩子抓着韩宁的旧木片，手指捏得发白。

他想起许阿芦。

并进去容易。

以后征粮、征役、分粥、追人，都要跟着错。

于是他在草片上写：

```text
第五人，名存，姓里待核。
```

书吏皱眉：“姓和旧里都不写？”

主角说：“先留着。”

书吏说：“这样怎么成册？”

辛衡老伯从旁边抬头。

“没查清就别乱补。至少先让人留在册上。”

那一天以后，主角知道，册上的留白不是偷懒。

有时候，少写，是为了不写错。

## 4. 正册和私记

主角后来成了旧渡最会整理册子的人。

他写得快，也写得清楚。

谁是哪户，谁借住，谁领过粮，谁家男丁外出，谁夜里病重，都能在册上找到。

县邑书吏喜欢这种人。

辛衡老伯却提醒他：“写得太清楚，也未必都是好事。”

主角起初不懂。

直到有一次，差役按册来找一个逃来的旧户。

那人曾在灶边领粥。主角为了防止重领，把他旧里也写清了。差役顺着那一行字找过去，把人拖走。那人的孩子追出很远，被禾安拉回来。

禾安看着主角，说：“你写他旧里，是为了给他饭，还是为了让人抓他？”

主角说不出话。

从那以后，他开始分两种册。

正册写该让县邑知道的：几口人，领多少粮，能不能免役。

私记写不能随便给人的：谁改过名，谁从哪逃来，谁怕旧主家追，谁家男丁藏在灶棚后面养伤。

辛衡老伯发现后，没有让他烧掉。

只问：“藏在哪里？”

主角说了地方。

辛衡老伯摇头：“太近。查册的人若翻到，一窝端。”

他带主角把私记分开，藏在旧钟座下、断鼎腹里、灶后土缝中。

“正册是给人办事的。”辛衡老伯说，“私记是怕人被正册吞掉。两样都要小心。”

## 5. 秦赵开战，册子变重

秦赵在长平相持的消息传来后，旧渡的册子忽然变重。

县邑要粮，要车，要役夫，也要丁壮。

从前核户，是为了分粥、分盐、安置病人。

后来核户，是为了知道谁能走，谁该走，谁逃了。

主角开始怕点名。

他写得越清楚，差役找人越快。

可他若故意写乱，缺粮缺车又会压到别家头上。

禾安看他熬夜抄册，问：“你把册子写慢些，仗就不打了？”

主角说：“写快了，人就走得快。”

禾安把一碗粥放到他旁边。

“那就看清楚再写。别把不该走的人写走，也别把该算的压给别人。”

这话不绕。

也不安慰。

但主角听进去了。

梁成的名字就是那时从他笔下过的。

```text
梁成，旧渡梁氏，丁壮。
```

凭证齐。

旧册能对上。

主角认得这个名字。梁成曾在灶边帮禾安补过泥，也在分粮时让过孩子半步。

可这些都不是免征的理由。

他停了很久，最后还是写了下去。

写完以后，他在私记里又补了一行：

```text
梁成，灶边人，禾安常唤阿梁。
```

他那时还不知道，这一行后来会比正册那一行更难看。

## 6. 军中伍籍

主角后来被县邑借去整理军中伍籍。

不是因为他有官位。

是因为前线送来的名册太乱，同名、错里、漏户、重记，到处都是。有人活着，却被写成缺；有人死了，却还在下一批领粮名下。

他跟着书吏到军需营里，一卷一卷核。

伍长骂他慢。

小吏催他快。

主角却不敢快。

快错一笔，可能就少一份粮，也可能让活人家里提前收到死讯。

有一天，梁成所在那一伍的临时调动送到案前。

前头护粮道缺人。

梁成那一伍人还齐，被调上去。

主角只是抄伍籍的人，没有资格改调令。

他能做的，只是把调动写清楚。

```text
梁成，旧渡梁氏。
由后伍补前粮道。
```

笔落下去时，他忽然想起许阿芦那一笔。

那时他图省事，把人写进别人户里。

这一次，他没有写错。

可没写错，也不代表心里就轻。

## 7. 未归

长平之后，回来的名单比走的名单短得多。

有些人写亡。

有些人写失。

更多人只写未归。

未归最难。

亡，可以报丧。

失，还能查。

未归像一扇半关的门，等的人不肯走，写册的人也不敢关死。

梁成所在那一伍没有完整回来。

同伍残卒只说：“旧渡……梁成……他说……”

后面没了。

主角翻伍籍，看到自己写过的那道调动。

由后伍补前粮道。

字很清楚。

人没有回来。

他在正册上只能写：

```text
梁成，未归。
```

在私记里，他写得慢得多。

```text
阿梁。
由后伍补前粮道。
同伍不全返。
遗言未尽。
```

写完以后，他把那页压在旧碗底下。

他不是怕别人看见。

是怕自己看见得太快。

## 8. 禾安问阿梁

长平之后不久，主角回旧渡核缺户。

禾安正在灶边数米。她看见主角，没有问他做了多大的事，也没有叫他先生。

“你倒还认得路。”

主角站在门边，像小时候一样。

禾安把旧碗翻过来，说：“正好。我问你个人。”

“梁成。旧渡梁氏，随征走的。你册上有没有？”

主角知道有。

正册里有。

伍籍里有。

私记里也有。

禾安又说：“我平日叫他阿梁。”

主角低头看册边。

梁成是正册里的丁壮。

阿梁是灶边会补裂口的人。

这两个名字都是真的。

可他拿不出一个能让禾安安心的答案。

他说：“我……去查查看。”

禾安看着他。

“别把人查没了。”

主角懂这句话。

有些人不是死在战场上才没的。

也会死在一行写错的字里。

## 9. 册上未写全的第五个人

主角后来整理了一套写册规矩。

不是写给上头看的漂亮文章。

是写给后来抄册的人用的。

他说：

```text
能核实的，写清。
不能核实的，留白。
不得为省事并户。
不得为好看填满。
正册写办事所需。
私记慎藏，不得轻给差役。
亡、失、未归，不得混写。
```

有人嫌麻烦。

主角说：“嫌麻烦，就别写人。”

他还把几个名字留作例子。

许阿芦名下写：

```text
曾误并户，累陈户多征。
后改为独户。
```

存名下写：

```text
第五人，名存，姓里待核。
留白，后随旧渡灶边长成。
```

梁成名下，他停了很久。

最后写：

```text
正册梁成。
私记阿梁。
未归，不得作亡。
```

这一条不漂亮。

但后来有人照着它，少写错过很多人。

## 10. 最后一栏

晚年，主角回到旧渡。

辛衡老伯不在了，禾安也不在了。韩宁已经老了，手里还留着那片歪字木片。

他问主角：“没写全的地方，以后还补吗？”

主角说：“能查清，就补。查不清，就让它留着。”

韩宁问：“这样不难看吗？”

主角笑了一下。

“难看。”

他停了停。

“可乱写更难看。”

主角把正册交给该接册的人。

把写册规矩交给后来学记录的人。

至于私记，他没有一把火烧掉，也没有全交出去。

还活着的人，容易被追索的，继续藏。

已经无人可害、也无人可问的，另抄一份，放在旧碗边。

梁成那一页，他写：

```text
阿梁。
正名梁成，旧渡梁氏。
禾安之夫。
由后伍补前粮道。
长平未归。
我未能报清。
```

记录这一生最难的，不是把每一栏填满。

是知道有些没写全的地方，站着一个活过的人。

洛水边，裂钟再次响起。

钟声像刻刀停在木片上，迟迟没有落下。

```text
这不是你第一次看见山河改色。
```
