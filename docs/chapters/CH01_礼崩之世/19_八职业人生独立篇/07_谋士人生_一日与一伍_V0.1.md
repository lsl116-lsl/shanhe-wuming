# 谋士人生：一日与一伍 V0.1

> 所属章节：第一章《钟裂于洛水》：礼崩之世  
> 职业人生：谋士  
> 核心命题：说话能换时间，也会留下债。  
> 共同收束：梁成 / 阿梁、禾安、旧碗、无名录。

## 1. 他第一次换来的只是一夜

主角最早学会说话，是在旧仓门口。

流民想要粮，本地户怕明天没米，辛衡老伯的临时册还没补完，柳娘喊到嗓子发哑，禾安在灶边说水还能添，米不能再添。

眼看两边要冲起来，主角说：“今晚先按现名和同行关系分，旧里明早再问。”

这句话换来一夜。

流民没有被赶走，本地户也没有立刻翻脸。主角以为自己做得很好。

第二天，官署来问，本地户把责任推给他：“是他说先别问的。”

主角这才知道，说话能换时间，也会留下债。

辛衡老伯没有骂他，只说：“你既然开口，就要记得谁替你的话担了这一夜。”

## 2. 聪明不是答案

后来，他常被叫去说合。

本地户和流民争粮，他说合。迁民队不愿进县邑，他说合。县署催旧渡补役，他说合。有人觉得他聪明，能让人各退一步。

禾安却不太爱夸他。

她说：“你话说得好听，可锅里还是那点米。”

青缗说得更难听：“你们说话的人总喜欢把路讲宽。路真堵住了，我看你拿嘴推车。”

主角不服，却慢慢发现她们说得都不算错。

谋士不是把所有人说服成好人。

谋士只是知道每个人怕什么、要什么、能退到哪里，又会在哪一步翻脸。

这能力能救人，也能把人推向更远的代价。

## 3. 梁成这笔，被他说成了暂缓

新法入乡时，梁成因为旧户、迁户和旧册刮改痕迹，险些被写错。

书吏想先记旁户，辛衡老伯让主角拿旧册。两边争执时，主角说：“先不落役，核清旧册再定。”

这句话让梁成没有立刻被错写。

禾安抱着湿柴经过，不认识他，只嫌他挡路。梁成立刻让开，还顺手把湿柴和干柴分开。

最后，梁成被写回旧渡梁氏。

主角记住了这个名字。

他也记住，自己一句“暂缓”，有时真的能救下一笔。

很多年后，他会知道，一笔救回来，也可能让征发更准确找到这个人。

## 4. 一伍人的去向

战争前夜，主角被卷进更大的说合。

谁先供粮，谁暂缓役，哪支车队走哪条路，哪一伍补到哪里。每一句话都像在桌上轻轻推一枚木片，推远时无声，落地时才知道砸到谁。

他在名单里看见：

```text
梁成，旧渡梁氏，丁壮。
```

主角停了一下。

这名字曾因他说“暂缓”而没有被错写。现在，它清楚地出现在征发名单里。

长平前，有一次粮道安排出了争执。主角为了让更多迁民避开一条险路，劝人把一支伍暂调去护车。

那一伍后来没有回来。

他不是故意害谁。

可谋士最残酷的地方正在这里：你常常为了保更多人，把另一些人推到更远处。

长平后，他从残简、伤者口供、官档未核里一点点拼出那一伍的去向。

梁成也在其中。

## 5. 禾安问阿梁

主角回旧渡时，禾安正在数米。

她抬头说：“你倒还认得路。”

主角想起自己这些年说过的路、改过的路、劝别人走过的路，一时答不上来。

禾安把旧碗翻过来：“那正好。我问你个人。”

“梁成。旧渡梁氏，去年随征走的。你路上，听过没有？”

主角当然听过。

他不仅听过，还可能间接推过那一伍的路。

禾安补了一句：“我平日叫他阿梁。”

这句话让主角所有能辩的理由都失了声。

梁成是名单，是一伍，是一次安排的后果。

阿梁是禾安灶边的人。

她说：“他走之前把灶口补了一半，说回来再收边。后来我自己补完了。”

主角低头看册边。

禾安说：“你再看，木头也不会替你开口。”

他只能说：“我……再查查看。”

禾安看着他：“你小时候说谎，耳朵会红。现在倒不红了。”

主角这一生能替很多人开口。

这一刻，他替自己找不到一句话。

## 6. 最后一次不解释

晚年回旧渡，禾安已逝。

后人说她是“那个会留饭的老人”。

主角坐在旧灶边，看见旧碗、梁字木片、补过的灶口。他忽然明白，禾安从来不需要他把所有因果解释清楚。她要的只是一个人有没有被记得。

谋士这一生最会解释。

到最后，他决定不再解释自己的安排，只写下被自己牵动的人。

谁因他说话得了一夜。

谁因他说话多走了十里。

谁因他说话被暂缓。

谁因他说话被调去护车。

能公开的交给官档，会害活人的另藏。不能说清因果的，他放进无名录里，不替自己辩白。

洛水边，裂钟再次响起。

```text
这不是你第一次看见山河改色。
```
