# 八职业完整职业线打磨规则 V0.1

> 所属章节：第一章《钟裂于洛水》：礼崩之世  
> 目录归属：`docs/chapters/CH01_礼崩之世/19_八职业人生独立篇/`  
> 文档定位：为八篇职业人生后续 V0.4 修订提供统一标准，使 Codex 能根据每篇文章生成一条完整、独立、可玩的职业线。  
> 核心目标：八篇文章不是供 `14` 抽素材，而是八条职业线的母稿。

## 1. 当前方向校正

此前八篇 V0.3 已经完成了文学化补强：

```text
医者补了救错优先级和老医者交接。
记录补了主动留空和私卷风险。
商贾补了算错账和过期关验。
武将补了第一次下令伤人。
戏子补了声音差点害人的现实危险。
工匠补了器物反噬和鲁砚旧伤口。
谋士补了先赢一次再被胜利反咬。
仕官补了亲手官断失误和官档缝隙。
```

这些补强是必要的，但还不够。

因为最终目标不是把八篇压缩回 `14`，而是让 Codex 能根据八篇文章分别生成：

```text
医者职业线。
记录职业线。
商贾职业线。
武将职业线。
戏子职业线。
工匠职业线。
谋士职业线。
仕官职业线。
```

所以从 V0.4 开始，每篇文章都必须同时满足两种要求：

```text
作为小说：读者愿意读下去，人物有张力，情节有因果。
作为职业线母稿：Codex 能从中拆出 ACT、任务、选择节点、NPC、冲突升级、结局收束。
```

## 2. V0.4 的定位

V0.4 不再只是“精修稿”。

V0.4 应定位为：

```text
职业线完整故事母稿。
```

每篇 V0.4 的开头应标明：

```text
文档定位：八职业独立职业线母稿，可用于 Codex 生成该职业线的 ACT、任务、选择节点、NPC 关系和结局收束。
```

每篇 V0.4 都必须具备：

```text
1. 明确主角初始误解。
2. 明确职业导师或关键牵引者。
3. 明确第一次职业行动。
4. 明确第一次成功。
5. 明确第一次反噬。
6. 明确中段成长代价。
7. 明确战争前夜职业专属压力。
8. 明确长平职业专属高潮。
9. 明确归旧渡共同收束。
10. 明确晚年无名录职业专属去向。
```

## 3. 每篇必须采用的职业线结构

每篇 V0.4 建议统一分为 9 个段落。

### 3.1 ACT 0：雨后旧渡起点

功能：共用起点，但写出本职业的第一倾向。

要求：

```text
医者：手先伸向伤口。
记录：眼睛先盯住空格和第五个人。
商贾：注意到盐、药、布和路的短缺。
武将：先守门、挡风、维持秩序。
戏子：先听见柳娘喊名，意识到声音救人。
工匠：先看见旧碗缺口、门、桥、车这些东西撑住生活。
谋士：先用一句话换来一夜。
仕官：先看见无序中弱者被强者吞掉。
```

### 3.2 ACT 1：职业牵引者出现

每篇必须有一个职业牵引者。

```text
医者：老医者。
记录：辛衡老伯 + 韩宁。
商贾：青缗。
武将：护送队 / 早期队长 / 禾安的现实提醒。
戏子：柳娘 + 韩宁。
工匠：鲁砚。
谋士：荀白 / 申不疑 / 青缗 / 禾安共同反推，但主导师可偏荀白。
仕官：公孙砚。
```

牵引者不能只是“老师”。

牵引者必须同时提供：

```text
技术。
价值观。
反驳。
伤口。
```

例如：

```text
青缗不是教主角赚钱，而是教他路断以后善意也会烂在车上。
鲁砚不是教主角修桥，而是让他知道好东西也会把坏事做得更顺。
公孙砚不是冷酷工具人，而是把情感压进制度缝隙里的人。
```

### 3.3 ACT 2：第一次职业成功

每篇都需要一场主角确实“赢了”的戏。

```text
医者：救回第五个孩子或疫热病人。
记录：补上第五个人，使其获得粮水。
商贾：成功让货通过，药抵达旧渡。
武将：护送迁民队抵达。
戏子：喊名让失散者互认，避免旧里暴露。
工匠：修桥 / 修仓门，让伤者和粮车通过。
谋士：用话术拆开旧仓死局。
仕官：借制度挡住强户吞田。
```

这场成功必须让玩家觉得：

```text
这个职业真的有力量。
```

### 3.4 ACT 3：第一次职业反噬

每篇也必须有一场“职业的力量反过来伤人”的戏。

```text
医者：救了一个人，另一个人因为优先级死去。
记录：写全会追索，留空会失归属。
商贾：分药救眼前人，旧渡病人因此错过药。
武将：下令打断劫掠者的手，保住队伍。
戏子：声音差点暴露旧地名，引来追查。
工匠：桥修好后差役更快抵达，某户被提前征发。
谋士：说话赢了死局，却把代价推给担保人。
仕官：主角亲手退回申请，后来听说孩子死在路上。
```

这场反噬必须让主角发生变化。

变化不是“更成熟”这种空话，而是：

```text
以后他再做同类选择时，会犹豫、会补记、会另藏、会改变说话方式。
```

### 3.5 ACT 4：人物关系加压

每篇都要让职业选择影响角色关系。

至少要影响三类关系：

```text
禾安：代表灶边现实、乡土尺度、生活里的反问。
导师：代表职业价值观和职业伤口。
梁成 / 阿梁：先是册上名字，后是禾安生活里的人。
```

可选加压人物：

```text
韩宁：记录 / 戏子线特别重要。
柳娘：戏子线核心，也可在记录线作为声音对照。
青缗：商贾线核心，也可在谋士线提供现实反驳。
鲁砚：工匠线核心，也可帮助武将线理解车绳。
公孙砚：仕官线核心，也可在记录线、新法线出现。
```

### 3.6 ACT 5：战争前夜

每篇必须让战争先以职业能感知的方式到来。

```text
医者：伤者、疲病、疫热和药材延迟先到。
记录：名单、征发册、未核、丁壮条目先到。
商贾：价格、断路、关验变动先到。
武将：护送、点丁、车队、军需调度先到。
戏子：唱名、旧曲禁忌、战后预感先到。
工匠：车、桥、仓、器具被征用先到。
谋士：粮道安排、伍队调动、话术换时间先到。
仕官：文书、役令、征发册、官档压力先到。
```

这一段必须使读者感觉：

```text
战争不是突然发生的，而是沿着职业线早已渗进主角生活。
```

### 3.7 ACT 6：长平职业高潮

每篇的长平不能重复。

职业专属高潮如下：

```text
医者：医棚里听到梁成未尽托言。
记录：死伤册里出现梁成残名，官档只能写未核。
商贾：断粮路边拾到梁字关验残片。
武将：主角可能见过梁成补车绳，后来梁成所在伍不归。
戏子：柳娘唱到梁成时停一拍。
工匠：梁字器物 / 车绳 / 断轴成为证据。
谋士：主角曾参与调伍，梁成所在伍被推向长平。
仕官：官档在亡、失、未核之间摇摆，私卷补充。
```

长平高潮的要求：

```text
证据必须碎片化。
不能给完整死讯。
不能让主角轻易有资格告诉禾安。
必须形成“知道或几乎知道，但说不出口”的心理压力。
```

### 3.8 ACT 7：归旧渡共同收束

八篇都必须回到这一组共同核心：

```text
禾安先问：梁成。旧渡梁氏，去年随征走的。你路上，听过没有？
禾安再补：我平日叫他阿梁。
主角只能说：我……再查查看。
禾安说：你小时候说谎，耳朵会红。现在倒不红了。
```

但每篇进入这组对白前，心理压力必须不同。

```text
医者：几乎确定，但医者不能乱报死讯。
记录：官档未核，私卷已知。
商贾：路上消息不干净，但太晚才干净。
武将：可能见过梁成最后一段路。
戏子：一拍停顿不是完整死讯。
工匠：器物证据只剩梁字和断绳。
谋士：梁成可能被自己的安排推到那里。
仕官：官档能写未核，却写不出阿梁。
```

### 3.9 ACT 8：晚年无名录去向

每篇晚年不能只是重复旧碗。

必须给出职业专属的无名录去向：

```text
医者：伤簿旁录、临终口供、药杵传承。
记录：官档外私卷、空格、拆名另藏。
商贾：账外夹页、商路分散传递。
武将：战功册外名、同伍后人、无人认领者。
戏子：旧曲停顿、吞地名、水声、人名节拍。
工匠：木匣、器物拓痕、桥板、车绳、梁字器物。
谋士：不辩白的因果记录，写下被自己牵动的人。
仕官：官档副录、废页夹层、私卷与官档缝隙。
```

结尾必须回到：

```text
旧碗。
禾安已逝。
后人称“那个会留饭的老人”。
无名录不是赎罪。
裂钟回响。
```

## 4. 每篇主角性格张力

V0.4 要让主角在八篇里不是同一个“善良记录者”。

每条线的主角应有不同缺陷。

```text
医者：急于救眼前命，容易忽略救活之后的位置。
记录：迷信写清楚，后来又过度害怕写清楚。
商贾：不愿承认善意要算账，后来必须学会算人命账。
武将：不愿伤人，却发现不下令会让更多人死。
戏子：相信喊出名字就是保存，后来知道声音也会误杀。
工匠：相信好东西就是好，后来知道好东西也能让坏事更顺。
谋士：享受说服成功，后来发现胜利会把代价推给别人。
仕官：相信进入制度就能救人，后来发现自己也会成为刀口。
```

这些缺陷要靠事件体现，不靠作者解释。

## 5. 每篇 NPC 张力

### 5.1 禾安

禾安不是恋爱线，不是等待者。

她在八篇中的功能：

```text
把职业判断拉回灶边现实。
用最短的话拆掉主角的自我安慰。
证明生活不会等主角完成大道理。
把梁成从册上名字变成阿梁。
```

### 5.2 梁成 / 阿梁

梁成不能英雄化。

他的功能是：

```text
普通。
稳定。
会做活。
被准确写入册。
被准确征发。
最后以碎片证据回到主角面前。
```

“梁成”与“阿梁”的差别必须保留：

```text
梁成：制度、名单、战争里的名字。
阿梁：禾安生活里的称呼。
```

### 5.3 导师人物

导师必须有自己的伤口。

```text
老医者：知道救活不等于救完。
辛衡老伯：写过也没写好某个人。
青缗：过期关验背后有一支没等到的商队。
柳娘：知道声音保存旧国，也可能害活人。
鲁砚：年轻时修过一辆好车，后来把坏事做得更顺。
荀白 / 申不疑 / 青缗：让谋士线形成思想拉扯。
公孙砚：相信法，也知道人只能从制度缝里活几日。
```

## 6. Codex 生成职业线时应能提取的信息

每篇 V0.4 应尽量让 Codex 能提取以下内容：

```text
职业线标题。
职业核心命题。
主角初始误解。
关键导师。
关键 NPC。
主要道具 / 记忆物。
ACT 结构。
主要选择节点。
成功节点。
反噬节点。
长平专属高潮。
归旧渡共同收束。
晚年无名录去向。
可转化为任务的场景。
可转化为对白的关键句。
```

建议每篇 V0.4 文末增加一个简短附录：

```text
## Codex 拆线提示

- 主线关键词：……
- 可拆 ACT：……
- 关键 NPC：……
- 核心选择：……
- 职业专属高潮：……
- 收束方式：……
```

这个附录不影响小说阅读，但能让后续自动生成职业线更稳定。

## 7. 下一步执行顺序

建议按以下顺序升级 V0.4：

```text
1. 武将：因为它最需要从 V0.3 继续补逻辑链。
2. 谋士：因为它需要完整展示“赢一次再反咬”。
3. 商贾：因为它很适合拆任务线，先做可玩性模板。
4. 记录：因为它是母题核心，需要精细处理写 / 不写。
5. 仕官：与记录互为制度内外对照。
6. 工匠：适合做道具线和地图任务线。
7. 戏子：适合做声音、名单、旧曲任务线。
8. 医者：当前最稳，最后按统一格式补 Codex 拆线提示即可。
```

## 8. 最终判断

八篇 V0.3 已经有文学基础。

但要服务 Codex 生成职业线，V0.4 必须更结构化、更有阶段推进、更明确任务化潜力。

判断一篇 V0.4 是否合格，就看它能否回答：

```text
这条职业线为什么只能这样开始？
主角为什么会一步步成为这种人？
这条线中段有什么专属冲突？
主角在这条线里犯过什么只有这个职业才会犯的错？
长平为什么必须以这个职业的方式压到他身上？
他为什么面对禾安说不出口？
无名录为什么会以这种职业形态留下？
Codex 能不能直接按它拆成 ACT 和任务？
```

如果能回答这些问题，八篇才真正从“独立文章”升级为“八条完整职业线”。
