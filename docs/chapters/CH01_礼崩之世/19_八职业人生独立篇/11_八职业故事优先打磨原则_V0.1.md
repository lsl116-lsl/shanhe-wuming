# 八职业故事优先打磨原则 V0.1

> 所属章节：第一章《钟裂于洛水》：礼崩之世  
> 目录归属：`docs/chapters/CH01_礼崩之世/19_八职业人生独立篇/`  
> 文档定位：校正八职业后续打磨方向。先把八篇作为好故事打磨，再考虑 Codex 拆线。  
> 核心判断：故事是地基。故事不好，职业线结构再清楚，做出来也不会吸引人。

## 1. 当前方向再校正

八篇最终会服务职业线生成。

但现阶段不能急着把它们改成“可拆结构文档”。

如果故事本身不吸引人，人物没有张力，冲突没有逻辑，结尾没有余味，那么 Codex 拆出来的 ACT、任务和选择节点也只会是空架子。

因此，八篇后续 V0.4 的第一目标不是：

```text
更方便拆任务。
更方便生成职业线。
更方便结构化。
```

而是：

```text
更好读。
更牵挂。
更有因果。
更有人味。
更让读者愿意继续看下一节。
```

## 2. V0.4 的真实定位

V0.4 先定为：

```text
故事强化稿。
```

不是职业线母稿最终版。

也不是 Codex 拆线稿。

V0.4 要解决的是：

```text
这篇故事本身好不好看？
主角是不是一个会犯错、会逃避、会成长、会被记住的人？
导师是不是一个有伤口、有偏见、有力量的人？
禾安、梁成、韩宁、柳娘、青缗、鲁砚、公孙砚等人物是不是活在剧情里，而不是站出来解释主题？
每一场关键事件是不是由前一场自然推出来？
读者读到中段时，是否还想知道后面会怎样？
结尾是否有余味，而不是只完成主题表达？
```

## 3. 好故事优先于好结构

结构是必要的。

但结构不能压过故事。

每篇后续打磨时，先问故事问题，再问结构问题。

### 3.1 故事问题

```text
这个人现在想要什么？
他为什么非做这件事不可？
他最怕失去什么？
他在骗自己什么？
他和谁有未说出口的账？
这一节结尾有没有让读者想翻下一页？
```

### 3.2 结构问题

```text
这段能不能拆成任务？
有没有选择节点？
有没有职业能力展示？
有没有职业反噬？
有没有可生成 NPC 关系？
```

先回答故事问题，再处理结构问题。

否则容易变成：

```text
节点正确。
任务完整。
但没有人想玩。
```

## 4. 八篇 V0.4 的共同打磨目标

每篇 V0.4 都要重点增强以下内容。

### 4.1 主角的欲望

主角不能只是“善良地做对的事”。

他必须有更具体的欲望。

例如：

```text
医者：想证明自己真的能把人从死里拉回来。
记录：想相信只要写清楚，世界就不会乱。
商贾：想证明善意不用算得那么冷。
武将：想护住人，却不想承认护住人需要伤人。
戏子：想让名字被听见，却不愿承认声音也能害人。
工匠：想相信好手艺就是好事。
谋士：想用一句话拆开死局，也享受别人看他聪明。
仕官：想进入制度内部救人，不想承认自己也会成为刀口。
```

欲望越具体，故事越能动。

### 4.2 主角的自欺

每篇主角都要有一句内心自欺。

例如：

```text
医者：只要人没死，就还有办法。
记录：只要写清楚，就能少伤人。
商贾：先救眼前这个，后面的总会有办法。
武将：我只是护送，不是在伤人。
戏子：我喊出名字，就是在救他。
工匠：东西好用，就算好事。
谋士：我只是让大家各退一步。
仕官：我按令办，就不是我伤人。
```

故事要让这些自欺逐步破裂。

### 4.3 导师的伤口

导师必须像人，不能像功能 NPC。

每个导师都要有：

```text
他教主角什么。
他反对主角什么。
他自己曾经在哪件事上失败。
他最后留给主角的不是答案，而是一道没愈合的伤。
```

例如：

```text
老医者不是“医术老师”，而是见过太多救活以后仍无处可去的人。
辛衡老伯不是“记录老师”，而是写过一个人，却没写好。
青缗不是“商人老师”，而是曾因关验过期，没能把货送到等货的人那里。
柳娘不是“唱曲老师”，而是知道一声旧地名可以救人，也可以害人。
鲁砚不是“工匠老师”，而是年轻时修过一辆好车，后来让坏事变得更顺。
公孙砚不是“法家 NPC”，而是相信法，也知道人只能从制度缝里活几日。
```

### 4.4 禾安的作用

禾安不是恋爱线，也不是主角遗憾附属物。

她是灶边现实。

她的每次出现，都应该让主角的职业判断落地。

```text
医者救人，她问救活以后吃什么。
记录写名，她问写了粮会不会多。
商贾算路，她问晚到的药谁等。
武将护送，她问被打断手的人算谁的。
戏子唱名，她问喊完以后人在哪。
工匠修桥，她问桥过来的都是谁。
谋士说合，她问锅里米有没有多。
仕官按令，她问等核的时候锅等不等。
```

禾安的话要短。

短到像生活本身。

### 4.5 梁成 / 阿梁的普通性

梁成不能英雄化。

他越普通，越疼。

他应该反复以小动作出现：

```text
让路。
分湿柴和干柴。
挑水时把浑水放去洗柴。
补灶口。
补车绳。
做事慢，但稳。
```

“梁成”是册上的名字。

“阿梁”是禾安生活里的称呼。

故事要让读者在归旧渡之前就隐约觉得：

```text
这个普通人会被时代吞掉。
```

但不能提前煽情。

## 5. 每篇必须增强的故事钩子

八篇要各自有自己的阅读钩子。

```text
医者：第五个孩子到底能不能真正活下去？主角会不会救错人？
记录：韩宁木片到底写了什么？辛衡老伯旧简里是谁？
商贾：青缗过期关验背后那支商队发生了什么？主角算错账后如何面对旧渡？
武将：主角第一次下令伤人以后，会不会变成自己害怕的人？
戏子：哪一个名字不能唱？柳娘最后传下的停顿里藏了谁？
工匠：鲁砚那辆好车到底造成了什么后果？主角做的桥会害到谁？
谋士：主角赢下的那场说合，最后会让谁替他付账？
仕官：主角那次“不准”之后，那户人到底怎么走向死亡？
```

这些钩子要贯穿中段。

不是提出后马上回答。

## 6. V0.4 不急着加 Codex 附录

之前设想每篇文末加 Codex 拆线提示。

现在暂缓。

原因：

```text
故事还没彻底打磨前，过早加拆线提示，会让写作重心转向结构。
```

V0.4 先只打磨故事。

等八篇故事本身成立，再进入 V0.5 或单独文档：

```text
职业线拆解稿。
Codex 生成提示稿。
任务 / ACT / 选择节点表。
```

## 7. V0.4 建议打磨顺序

不按“最需要结构化”的顺序。

按“最影响故事吸引力”的顺序：

```text
1. 武将：最需要补人物张力，避免只是护送概念。
2. 谋士：最需要补主角聪明带来的快感和反噬。
3. 商贾：已经有强 NPC，适合打磨成最有阅读性的路上故事。
4. 记录：母题核心，需要打磨悬念和心理压力。
5. 戏子：语言气质好，需要补危险和余音。
6. 工匠：物件系统好，需要补具体人命后果。
7. 仕官：结构稳，需要打磨主角个人情绪裂缝。
8. 医者：目前最完整，最后做细腻度和余味修。
```

## 8. 最终判断

后续八篇不要急着“能不能拆”。

先看：

```text
读者愿不愿意读完这一篇？
读完以后，能不能记住这个职业线的主角？
能不能记住至少一个导师？
能不能记住一个职业专属伤口？
能不能在禾安说“我平日叫他阿梁”时，觉得这一刀只属于这一篇？
```

能做到这些，职业线才有地基。

Codex 只是把地基上的房子搭出来。

但地基必须先是故事。
