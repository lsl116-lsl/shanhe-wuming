> 目录归属：`docs/chapters/CH01_礼崩之世/19_八职业人生独立篇/`  
> 文档定位：把第一章八职业分别写成八篇独立人生文章；当前阶段先打磨故事本身，再服务 Codex 生成完整职业线。  
> 当前版本：八职业人生独立篇均已故事强化至 V0.4，并已形成“生活逻辑优先、人物常情优先”的统一打磨标准。  
> 使用方式：先作为八篇好故事打磨，待故事稳定后，再拆成 ACT、任务、选择节点、NPC 关系和结局收束。

## 1. 写作原则

这组文档不把“职业”写成职业介绍。

每一篇都先写成主角的一种完整人生：

```text
同一个旧渡少年。
同一个雨后起点。
同一个第五个孩子、旧碗、辛衡老伯、禾安、韩宁、柳娘和梁成入册。
不同的反复选择。
不同的成年去向。
不同的职业矛盾。
不同的长平入口。
共同收束到梁成 / 阿梁、禾安、旧碗、无名录和裂钟。
```

八篇文章彼此独立，但最后必须收敛。

收敛不是把八条线强行写成同一结局，而是让读者 / 玩家明白：

```text
不管主角成为谁，长平都会把他推回旧渡。
不管他用什么方式记录，梁成都会从“册上的名字”变成禾安口中的“阿梁”。
不管他这一生多能救、多会写、多会算、多会说，面对禾安时，他仍然可能说不出口。
不管无名录最后以什么形态留下，它都不是赎罪，而是让没有被说出口的人不彻底无名。
```

## 3. 共同收束节点

每篇文章必须在后段回到以下共同节点：

```text
战争前夜，主角以本职业方式见到“梁成，旧渡梁氏，丁壮”。
长平后，主角以本职业方式获得梁成大概率不归的碎片证据。
长平后归旧渡，禾安问“梁成。旧渡梁氏，随征走的。你路上，听过没有？”
禾安补一句：“我平日叫他阿梁。”
主角说：“我……去查查看。”
晚年回旧渡，禾安已逝，后人只记得“那个会留饭的老人”。
主角决定无名录去向。
裂钟回响，进入后续章节。
```

## 4. V0.4 修订方向

V0.4 定位为：

```text
故事强化稿。
```

V0.4 暂不优先补 Codex 拆线提示，也不急着做任务结构。

每篇 V0.4 先回答：

```text
这个故事本身好不好看？
主角有没有具体欲望和自欺？
导师是不是有伤口，而不是功能 NPC？
禾安是不是用灶边现实拆掉主角的自我安慰，或用真实关心牵住主角？
梁成 / 阿梁是不是足够普通，也足够让人心里一沉？
中段有没有持续钩子？
结尾有没有余味？
```

具体标准见：

```text
11_八职业故事优先打磨原则_V0.1.md
```

`10_八职业完整职业线打磨规则_V0.1.md` 暂作为后续“故事稳定后转职业线结构”的参考文档。
