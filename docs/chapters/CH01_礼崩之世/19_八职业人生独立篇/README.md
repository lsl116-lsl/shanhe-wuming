> 目录归属：`docs/chapters/CH01_礼崩之世/19_八职业人生独立篇/`

> 当前版本：V0.1  
> 使用方式：每篇都可以作为单独可读故事，也可以回写进 `14_第一章可读故事_V0.1.md`、`06_故事剧本_V0.1.md` 和后续可玩分支剧本。

## 1. 写作原则

这组文档不把“职业”写成职业介绍。

每一篇都写成主角的一种完整人生：

```text
同一个旧渡少年。
同一个雨后起点。
同一个第五个孩子、旧碗、辛衡老伯、禾安、韩宁、柳娘和梁成入册。
不同的反复选择。
不同的成年去向。
不同的长平入口。
共同收束到梁成 / 阿梁、禾安、旧碗、无名录和裂钟。
```

八篇文章彼此独立，但最后必须收敛。

收敛不是把八条线强行写成同一结局，而是让读者明白：

```text
不管主角成为谁，长平都会把他推回旧渡。
不管他用什么方式记录，梁成都会从“册上的名字”变成禾安口中的“阿梁”。
不管他这一生多能救、多会写、多会算、多会说，面对禾安时，他仍然可能说不出口。
不管无名录最后以什么形态留下，它都不是赎罪，而是让没有被说出口的人不彻底无名。
```

## 3. 共同收束节点

每篇文章必须在后段回到以下共同节点：

```text
战争前夜，主角以本职业方式见到“梁成，旧渡梁氏，丁壮”。
长平后，主角以本职业方式获得梁成大概率不归的碎片证据。
长平后归旧渡，禾安问“梁成。旧渡梁氏，去年随征走的。你路上，听过没有？”
禾安补一句：“我平日叫他阿梁。”
主角说：“我……再查查看。”
晚年回旧渡，禾安已逝，后人只记得“那个会留饭的老人”。
主角决定无名录去向。
裂钟回响，进入后续章节。
```
