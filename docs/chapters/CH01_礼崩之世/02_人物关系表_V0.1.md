# 第一章《礼崩之世》人物关系表 V0.2

> 目录归属：`docs/chapters/CH01_礼崩之世/`  
> 文档状态：根据 `09`、`10`、`11` 重整后的人物关系表  
> 用途：约束关键人物的首次登场、固定行动、自主逻辑、可变命运、职业入口和跨 ACT 回响。

## 1. 人物设计原则

第一章人物不能只是职业功能 NPC。

每个关键人物都必须有：

```text
来处。
想保住的东西。
害怕失去的东西。
自己的行动逻辑。
与主角关系的可变性。
不依赖主角也会推进的命运。
```

主角选择改变的是：

```text
NPC 是否信任主角。
NPC 是否透露秘密。
NPC 是否邀请主角进入某条路线。
NPC 是否在关键节点帮助、阻拦、离开或反向行动。
NPC 最后以何种方式进入无名录。
```

主角不能改变的是：

```text
NPC 有自己的恐惧和底线。
NPC 不会因为好感度放弃全部信念。
NPC 不会永远停在原地等主角。
长平、周亡、秦统一等历史伤口会把所有人推向不可逆变化。
```

## 2. 人物层级

| 层级 | 作用 | 人物 |
|---|---|---|
| A：主线关键故人 | 贯穿多 ACT，直接推动“名与籍 / 无名录”母题 | 辛衡、禾安、韩宁、柳娘、主角母亲、主角父亲 |
| B：中段关键人物 | 推动新法、百家、商路和战争前夜 | 公孙砚、申不疑、荀白、青缗 |
| C：职业线锚点 | 承担玩家未选职业在世界中的存在感 | 老医者 / 小蓟、工匠鲁砚、军旅青年、乡里老人、隐士南郭生、记录人孟简等 |

职业线锚点后续可细化，但不能喧宾夺主。

第一章核心仍以 A、B 层为主。

## 4. 主角 / 苏醒者本世

| 字段 | 内容 |
|---|---|
| 固定身份 | 洛水旧渡长大的孩子，十岁写下本世姓名。 |
| 固定关系 | 母亲、未归父亲、辛衡、禾安、旧渡。 |
| 人格主轴 | 会称量；害怕落错一笔；看见两边都有人；在犹豫后承担。 |
| 可变部分 | 职业路径、NPC 信任关系、无名录形态、哪些人被留下或错过。 |
| 不可变部分 | 不知道历史大势，不是全知穿越者，不可改变长平和秦统一。 |
| 主题作用 | 让十职业不是十个主角，而是同一个人在不同人生位置里看见同一时代。 |

## 5. 辛衡

| 字段 | 内容 |
|---|---|
| 内部原型 | 处女型：记录、校正、谨慎、怕一笔害人。 |
| 首次登场 | 序章 / ACT01。 |
| 与主角关系 | 识字先生、渡册引路者、第一位教主角“字后面站着人”的人。 |
| 想保住什么 | 那些被省掉、被改写、被错写的人。 |
| 害怕什么 | 自己一生写过的册籍最终只帮助官府征发和追索。 |
| 自主逻辑 | 会观察主角如何落笔；不会替主角选择；不会一次说透旧册和官粮线。 |
| 关键节点 | ACT04 病重并交托旧册、旧笔和未完成名单；ACT05 老死。 |
| 死亡意义 | 主角失去第一个“写字的人”，从此必须自己决定哪些字该落，哪些字该空。 |
| 可变回响 | 主角是否理解记录两面性，决定辛衡交托材料的深浅。 |

## 6. 禾安

| 字段 | 内容 |
|---|---|
| 内部原型 | 白羊型：行动、火、直接、保护、先冲出去。 |
| 首次登场 | 序章。 |
| 与主角关系 | 旧渡共同长大的同龄伙伴，现实锚点，不是恋爱对象，不发展恋爱线。 |
| 想保住什么 | 旧渡、眼前活人、粮水柴火还能撑过今晚。 |
| 害怕什么 | 外来人救了，本地人也被拖垮；人还没活过今晚，账已经把人压死。 |
| 自主逻辑 | 主角不帮，她也会拖热水桶、搬柴、喊人；她不会原地等主角。 |
| 关键节点 | ACT01 救人；ACT02 旧仓粮水压力；ACT04—ACT06 可能留守旧渡、迁徙或与主角渐远；ACT07 旧渡线可能重创。 |
| 可变关系 | 主角多次承担现实杂务，她更愿意告诉主角旧渡真实压力；若主角总为记录延误救治，她会记住那一刻的冷。 |
| 禁止写法 | 不写成女主候选、恋爱对象、甜美陪伴或只围着主角转。 |

核心关系句：

```text
主角怕落错一笔。
禾安怕晚伸一只手。
```

## 7. 韩宁

| 字段 | 内容 |
|---|---|
| 内部原型 | 天蝎型：秘密、防御、强烈保护欲、不轻易信任。 |
| 首次登场 | 序章 / ACT01。 |
| 与主角关系 | 亡国流民少年，残简与旧籍线的关键人。 |
| 想保住什么 | 母亲、妹妹、残简、还活着的人不被旧籍追索。 |
| 害怕什么 | 旧里、父名和残简被对上，牵出活人。 |
| 自主逻辑 | 别人问旧里先按袖口；湿简落泥会本能扑过去；不信任时会后撤。 |
| 关键节点 | ACT01 护残简；ACT02 根据主角行为透露或隐藏；ACT03 编户风险加重；ACT05—ACT07 残简线回潮；长平前后可能失踪、战死或旧籍暴露。 |
| 可变关系 | 主角保护隐名风险，韩宁靠近；主角急于写全旧里，韩宁后退甚至独自行动。 |

## 16. 职业线锚点原则

职业线锚点不是“支线工具人”。

他们用于保证：

```text
玩家未选择某职业时，该职业视角仍然存在于世界中。
```

示例：

```text
玩家不走医者线，老医者 / 小蓟仍会救人，也可能在长平后交出伤者口供。
玩家不走工匠线，鲁砚仍会修车、桥、仓，也可能交出车辙和器物证据。
玩家不走武将线，军旅青年仍可能战死或失踪，让长平不是背景数字。
玩家不走隐士线，南郭生仍可能保存不入官档的见证。
```

## 17. 关系状态建议

每个关键 NPC 可维护以下状态：

```text
trust：信任。
distance：心理距离。
risk：被牵连风险。
need：当前现实需求。
secret：秘密保留程度。
debt：互相亏欠。
path：NPC 自己正在走向的路线。
```

这些状态不一定显示给玩家，但要用于剧情判断。

## 18. 设计禁忌

```text
不要把禾安写成恋爱线。
不要让辛衡突然死，只为了催泪。
不要让韩宁只承担神秘残简功能。
不要让柳娘只负责唱歌氛围。
不要让公孙砚成为简单反派。
不要让申不疑只是冷血工具人。
不要让荀白只负责讲哲学课。
不要让青缗只是买卖 NPC。
不要让所有关键人物都围着主角转。
```
