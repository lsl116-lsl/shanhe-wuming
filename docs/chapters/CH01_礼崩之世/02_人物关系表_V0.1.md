> 目录归属：`docs/chapters/CH01_礼崩之世/`

> 用途：约束关键人物的首次登场、固定行动、自主逻辑、可变命运、职业入口和跨 ACT 回响。

## 1. 人物设计原则

第一章人物不能只是职业功能 NPC。

每个关键人物都必须有：

```text
来处。
想保住的东西。
害怕失去的东西。
自己的行动逻辑。
与主角关系的可变性。
不依赖主角也会推进的命运。
```

主角选择改变的是：

```text
NPC 是否信任主角。
NPC 是否透露秘密。
NPC 是否邀请主角进入某条路线。
NPC 是否在关键节点帮助、阻拦、离开或反向行动。
NPC 最后以何种方式进入无名录。
```

主角不能改变的是：

```text
NPC 有自己的恐惧和底线。
NPC 不会因为好感度放弃全部信念。
NPC 不会永远停在原地等主角。
长平、周亡、秦统一等历史伤口会把所有人推向不可逆变化。
```

## 4. 主角 / 苏醒者本世

| 字段 | 内容 |
|---|---|
| 固定身份 | 洛水旧渡长大的孩子，十岁写下本世姓名。 |
| 固定关系 | 母亲、未归父亲、辛衡、禾安、旧渡。 |
| 人格主轴 | 会称量；害怕落错一笔；看见两边都有人；在犹豫后承担。 |
| 可变部分 | 九职业路径、NPC 信任关系、无名录形态、哪些人被留下或错过。 |
| 不可变部分 | 不知道历史大势，不是全知穿越者，不可改变长平和秦统一。 |
| 主题作用 | 让九职业不是九个主角，而是同一个人在不同人生位置里看见同一时代。 |

## 5. 辛衡

| 字段 | 内容 |
|---|---|
| 内部原型 | 处女型：记录、校正、谨慎、怕一笔害人。 |
| 与主角关系 | 识字先生、渡册引路者、第一位教主角“字后面站着人”的人。 |
| 想保住什么 | 那些被省掉、被改写、被错写的人。 |
| 害怕什么 | 自己一生写过的册籍最终只帮助官府征发和追索。 |
| 自主逻辑 | 会观察主角如何落笔；不会替主角选择；不会一次说透旧册和官粮线。 |
| 关键节点 | ACT04 病重交托；ACT05 老死；之后以旧笔、旧册、空格回响。 |

## 6. 禾安

| 字段 | 内容 |
|---|---|
| 内部原型 | 白羊型：行动、火、直接、保护、先冲出去。 |
| 与主角关系 | 旧渡共同长大的同龄伙伴，现实锚点，不是恋爱对象，不发展恋爱线。 |
| 想保住什么 | 旧渡、眼前活人、粮水柴火还能撑过今晚。 |
| 害怕什么 | 外来人救了，本地人也被拖垮；人还没活过今晚，账已经把人压死。 |
| 自主逻辑 | 主角不帮，她也会拖热水桶、搬柴、喊人；她不会原地等主角。 |
| 关键节点 | ACT01 熬稀粥与旧碗出现；ACT02 旧仓粮水压力；ACT04—ACT06 独自撑住旧渡；ACT06 季良被征；ACT07 后问主角季良消息；ACT08 已逝，只留下粥碗。 |
| 可变关系 | 主角多次承担现实杂务，她更愿意告诉主角旧渡真实压力；若主角总为记录延误救治，她会记住那一刻的冷。 |
| 禁止写法 | 不写成女主候选、恋爱对象、甜美陪伴、等待主角的人或催泪工具。 |

核心关系句：

```text
主角怕落错一笔。
禾安怕晚伸一只手。
```

晚年回响句：

```text
主角以为欠禾安的是一句死讯；粥碗告诉他，禾安早已用一生替空位留过饭。
```

## 13. 职业线锚点原则

职业线锚点不是“支线工具人”。

他们用于保证：

```text
玩家未选择某职业时，该职业视角仍然存在于世界中。
```

示例：

```text
玩家不走医者线，老医者 / 小蓟仍会救人，也可能在长平后交出伤者口供。
玩家不走工匠线，鲁砚仍会修车、桥、仓，也可能交出车辙和器物证据。
玩家不走武将线，军旅青年或季良仍可能战死或失踪，让长平不是背景数字。
玩家不走隐士线，南郭生仍可能保存不入官档的见证。
```

## 14. 关系状态建议

每个关键 NPC 可维护以下状态：

```text
trust：信任。
distance：心理距离。
risk：被牵连风险。
need：当前现实需求。
secret：秘密保留程度。
debt：互相亏欠。
path：NPC 自己正在走向的路线。
```

这些状态不一定显示给玩家，但要用于剧情判断。

## 15. 设计禁忌

```text
不要把禾安写成恋爱线。
不要让禾安等主角一生。
不要让粥碗变成神秘法器。
不要让辛衡突然死，只为了催泪。
不要让韩宁只承担神秘残简功能。
不要让柳娘只负责唱歌氛围。
不要让公孙砚成为简单反派。
不要让所有关键人物都围着主角转。
```
