## 1. 人物设计原则

1. 人物先是具体的人，再代表一种历史立场。
2. 没有人只负责“讲道理”；每个人都要有想活下去、保护某人、洗清某事或完成某件工作的现实欲望。
3. 立场对立不等于人格邪恶。新法的执行者可以救过人，旧礼的维护者也可能为了名分耽误救济。
4. 故人拥有自己的行动。玩家不能用好感度让所有人放弃信念。
5. 至少一位长期故人在长平永久死亡或失踪，不设全员存活的完美路线。
6. 人物命运不只结算为“生/死”，还包括失名、改名、背债、被误写、留下后人和成为制度的一部分。
7. 第一章不提前直说“人民”。人物通过共同劳动、共同承受和彼此记住，为终章积累经验。

## 4. 主线人物档案

### CH01-CHAR-001 季伯

| 字段 | 内容 |
|---|---|
| 身份 | 洛邑旧官署退下来的书吏，熟悉户籍、仓册和旧礼文书。 |
| 首次登场 | ACT01“裂钟之梦”。 |
| 与苏醒者关系 | 收留者、识字启蒙者、第一位教他“记录要对人负责”的人。 |
| 表层愿望 | 把亡者、流民和失踪者尽可能记清。 |
| 内在恐惧 | 人死之后连一笔也不剩；自己一生写下的册籍反而只帮助官府征发。 |
| 代表主题 | 记录既能保存人，也能把人压成数字。 |
| 性格盲点 | 过度相信“写下来”本身的力量，早期低估名册作为治理工具的危险。 |

**固定行动**

- ACT01 收留苏醒者并整理流民名册。
- ACT02 依据旧礼请求赈济，亲眼看见旧礼失效。
- ACT03 把韩宁父亲的旧笔迹告诉苏醒者。
- ACT04 写下“案卷是人命压扁以后留下的形状”。
- ACT06 前后去世；死亡不由玩家撤销，避免他跨越全部主线而失去代际意义。
- ACT07 由他托付的残简进入《无名录》。

**关系变化**

- 玩家重视具体姓名：季伯信任上升，但会追问玩家是否也保护活人。
- 玩家为保护流民而改名、毁册：季伯会痛苦反对，后期可能理解但不会轻易赞同。
- 玩家把记录完全交给权力：季伯认可其保存机会，同时担心删改。

**本章命运**

固定在长平前去世，死因可以是年老、旧疾与长期劳累，不把每个重要人物都交给战争杀死。他是否与苏醒者和解、最后托付哪一枚简，由前期关系决定。

**后世回收**

- 秦汉小吏辨认其旧笔法。
- 《无名录》中某些空格旁的短痕沿用他的记法。
- 后世误把他当成官府编册者或无名抄手，形成“记录者自己也失名”的反讽。

### CH01-CHAR-002 禾安

| 字段 | 内容 |
|---|---|
| 身份 | 洛水边农户之女，后来可能成为自耕农、佃作者、流民组织者或军粮生产者。 |
| 首次登场 | ACT01。 |
| 与苏醒者关系 | 同乡、共同成长者；可发展为亲人般的牵挂、知己或克制的情感线，但不强制恋爱。 |
| 表层愿望 | 保住家人、井水、种子和下一季收成。 |
| 内在恐惧 | 所有人都在谈天下，最后却没人回来种田。 |
| 代表主题 | 所有制度和战争最终都落到田亩与家庭。 |
| 性格盲点 | 为保住眼前生活可能回避更远的危险，也可能把沉默误当作安全。 |

**固定行动**

- ACT01 帮助辨认流民中的孩童与老人。
- ACT02 参与旧仓争议，她家成为“领粮就要入籍”的具体案例。
- ACT04 因重编户口面临家庭拆分或新增役责。
- ACT06 她家至少一人进入征兵或运粮名册。
- ACT08 若生还，她是《无名录》去向选择中“交给活人”的主要支持者。

**可变命运**

- 获得新法授田，但家人被征发，成为“得田失人”的见证者。
- 随聚落迁徙，保住家庭却失去故土。
- 组织藏粮或撤离，被官署视为抗令者。
- 在长平后方生还并照顾遗属。
- 因粮道、逃亡或报复死亡；若她死亡，必须留下具有行动意义的决定，不能只作为刺激主角的工具。

**后世回收**

- 一包带地名的种子。
- 被反复丈量的一块田。
- 家族口述中“有人替未归者留饭”的习惯。
- 第二章中她的后人可能成为编户农民、戍卒家属或逃籍者。

### CH01-CHAR-003 韩宁

| 字段 | 内容 |
|---|---|
| 身份 | 亡国旧臣之女。其父不是显贵，而是保管地方户籍与征发记录的低阶旧吏。 |
| 首次登场 | ACT01，随亡国流民抵达洛邑。 |
| 与苏醒者关系 | 共同追索半名残简的故人；既可深信，也可能因“保旧名还是救活人”长期决裂。 |
| 表层愿望 | 查清父亲为何被旧主与新主同时定罪，恢复被刮去的记录。 |
| 内在恐惧 | 父亲所谓忠义只是她不肯放手的私人执念。 |
| 代表主题 | 旧国、旧债、家族名姓与普通人记录之间的冲突。 |
| 性格盲点 | 早期容易把保存旧名等同于保护所有人，低估真名暴露对逃亡者的危险。 |

**真相**

韩宁的父亲在旧国将亡时拆散百姓名册，不是为了保护旧主的财产，而是为了阻止胜者按册追捕全部逃亡者。他因此被旧主视为失职、被新主视为藏匿人口，死于狱中。

这个真相不一次说完：

- ACT01 只出现父亲笔迹。
- ACT02 确认旧籍被人为拆散。
- ACT03 得知父亲被两方定罪。
- ACT06 才发现其中一册也曾被盟军用于征发，说明好意仍可能长出苦果。

**可变命运**

- 生还并与苏醒者共同编成《无名录》。
- 在长平失踪，只留下最后一段记录，后世无法确认生死。
- 为保护真名或转移残册而死。
- 与苏醒者决裂后独自保存另一版本，使第二章出现互相矛盾的两份旧简。

无论生死，她提出的原则必须进入《无名录》：

> 不知其名，不等于此人没有名字。

**后世回收**

- 后人可能成为秦吏、儒生、反秦者、史官或普通编户，不预设“忠良之后必忠良”。
- 她隐藏的本姓在魏晋族谱中被重新解释。
- 她与父亲的记录在后世可能被当作忠君证据，也可能被重新发现为保护百姓的行为。

### CH01-CHAR-004 青缗

| 字段 | 内容 |
|---|---|
| 身份 | 商队掌计者，熟悉粮价、债契、道路、关卡和各地度量。 |
| 首次登场 | ACT02。 |
| 与苏醒者关系 | 现实主义伙伴，常在理想决定之后追问“粮从哪里来”。 |
| 表层愿望 | 让商队和依附商路生活的人都能活着回来。 |
| 内在恐惧 | 自己算得越准，战争就被供养得越久。 |
| 代表主题 | 商业网络既连接百姓，也连接战争机器。 |
| 性格盲点 | 相信所有代价都能折算，直到遇见无法赔偿的失踪与死亡。 |

**固定行动**

- ACT02 参与私下调粮。
- ACT03 帮助运输被拆散的旧籍。
- ACT05 以粮价、债务和道路参与百家问议。
- ACT06 商路图被征作军粮路线。
- ACT07 以粮册、车队记号和债契补全失踪者身份。

**可变命运**

- 因战争获利并背负“粮到军中、未到饥民”的债。
- 私运粮药救人，导致商队破产或同伴受罚。
- 试图两边维持道路，被双方怀疑。
- 长平后继续经营，主动赔偿遗属；赔偿不能消除其责任。

**后世回收**

- 带不同度量标记的粮册。
- 一笔永远无法结清的债。
- 秦汉统一度量后，旧账中出现无法换算的人命损失。

### CH01-CHAR-005 荀白

| 字段 | 内容 |
|---|---|
| 身份 | 往来列国的游学士人，与稷下学术环境有关，但不是任何真实思想家的替身。 |
| 首次登场 | ACT03 或 ACT05 正式登场。 |
| 与苏醒者关系 | 讨论者、朋友，也可能成为“替玩家总结思想却总结错了”的人。 |
| 表层愿望 | 找到一套既能施行、又不把人只当工具的治世之道。 |
| 内在恐惧 | 自己写了一生，主君只采用最便于征发的那一段。 |
| 代表主题 | 思想如何进入权力，又如何被权力选择性采用。 |
| 性格盲点 | 擅长理解复杂性，却可能以“尚需再议”拖延眼前行动。 |

**固定行动**

- ACT05 主持或参与“一户因法得田、又因法失子”的问议。
- 保存玩家治策的一个较完整版本。
- ACT06 发现治策被删成人口与粮道数字。
- ACT08 可留下对《无名录》的题记，但不得由他替无名者发言。

**可变命运**

- 入仕，争取修改执行尺度，却逐渐被制度同化。
- 退回讲学，保存文本但失去直接施行能力。
- 公开反对盟约，被驱逐或禁言。
- 为自己的迟疑承担某一地未能及时撤离的亏欠。

**后世回收**

- 未署名治策被归到某位名家门下，荀白和苏醒者都被抹去。
- 魏晋或宋代士人读到残篇，只讨论义理而忽略原始案例。

### CH01-CHAR-006 申不疑

| 字段 | 内容 |
|---|---|
| 身份 | 新贵门客，善于核定人口、土地与利害。 |
| 首次登场 | ACT03。 |
| 与苏醒者关系 | 长期对手；若彼此尊重，也可成为危险但可靠的合作者。 |
| 表层愿望 | 尽快建立能结束反复争战的强秩序。 |
| 内在恐惧 | 天下继续空谈礼义，更多像他家人一样的人死于无力执行的承诺。 |
| 代表主题 | “先有秩序，再谈仁义”是否会让仁义永远推迟。 |
| 性格盲点 | 把可执行等同于正确，把无法计量的损失视为软弱。 |

**固定行动**

- ACT03 收取旧档并提出既往不咎。
- ACT05 要求把具体遭遇改写成主君能采用的利害。
- ACT06 核定盟书人口和兵粮。
- ACT07 亲眼看见准确数字如何服务于无法接受的结果。

**可变命运**

- 坚持命令，成为《命令之债》的主要承担者。
- 暗中保留被要求销毁的军册，帮助补全《无名录》。
- 为保全秩序举报玩家，同时在另一件事上救下故人。
- 长平后进入秦制，成为第二章制度因果的前身。

**后世回收**

- 他的批注同时出现在征发册与《无名录》底本上。
- 后世无法简单判断他是告密者、救人者还是两者皆是。

### CH01-CHAR-007 柳娘

| 字段 | 内容 |
|---|---|
| 身份 | 亡国乐人行旅团的领头人；第一章叙事内不称“戏班班主”。 |
| 首次登场 | ACT01。 |
| 与苏醒者关系 | 教会苏醒者：不识字的人也有保存记忆的方法。 |
| 表层愿望 | 让同行者有饭吃，让亡国旧曲不被胜者改成颂歌。 |
| 内在恐惧 | 曲子活下来了，原本悼念的人却被唱错、唱没。 |
| 代表主题 | 口述记忆的传播力、变形与抵抗。 |
| 性格盲点 | 相信只要有人传唱就不会遗忘，低估改词、禁唱与娱乐化的消解。 |

**固定行动**

- ACT01 唱出无国名的旧曲。
- ACT02 以乐舞换粮，帮流民传播遭遇。
- ACT03 用曲调和暗语携带旧籍线索。
- ACT05 补上悼人而非只悼国的新词。
- ACT07 参与用曲调记住乡里和姓名。

**可变命运**

- 将旧曲交给阿檀等后辈，自己死于途中。
- 接受权贵供养，使曲子得以保存但被改词。
- 坚持民间传唱，传播更广却版本分裂。
- ACT08 成为《无名录》口述线的托付人。

**后世回收**

- 秦汉成为禁曲或宫廷改编旧乐。
- 隋唐进入宫乐，宋元成为亡国曲，明清成为旧戏。
- 近现代由悼亡之曲转为普通人自己的歌声。

### CH01-CHAR-008 公孙砚

| 字段 | 内容 |
|---|---|
| 身份 | 秦地边县法吏，出身不高，凭识字与执行能力获得位置。 |
| 首次登场 | ACT02 以文书署名出现，ACT04 正式登场。 |
| 与苏醒者关系 | 制度内的镜像人物：同样识字记名，却相信一致执行比私人悲悯更可靠。 |
| 表层愿望 | 建立一套不因贵贱亲疏而任意改变的法。 |
| 内在恐惧 | 一旦允许每个人以特殊困境破例，旧贵族和豪强会最先利用漏洞。 |
| 代表主题 | 公平执行与具体生存之间的张力。 |
| 性格盲点 | 把形式上的一致当成实际公平。 |

**固定行动**

- ACT04 主持清丈、编户和木牌立法。
- 将玩家处理“一户隐丁”的方式写进治策。
- ACT06 站在秦的制度逻辑上反对反复盟约。
- ACT07 接触较完整的军册或处置记录。

**可变命运**

- 坚持官册不得外泄，使《无名录》缺失关键部分。
- 看到官方删改后私下交出副本。
- 因擅改记录受罚，转而理解季伯。
- 继续升迁，把玩家的地方改良写入秦制，也可能使它成为更有效的征发办法。

**后世回收**

- 第二章中出现以他笔法重抄的秦简。
- 后人把他当作严吏或良吏，玩家知道这两个判断都不完整。

### CH01-CHAR-009 屠申

| 字段 | 内容 |
|---|---|
| 身份 | 早年从军的老卒，后来务农或护送商旅，长平时再次被卷入军中。 |
| 首次登场 | ACT02。 |
| 与苏醒者关系 | 教武、护路的长辈或袍泽。 |
| 表层愿望 | 让年轻人活着回家，不再相信“杀得多便会习惯”。 |
| 内在恐惧 | 真到命令落下时，自己仍会照做。 |
| 代表主题 | 命令、服从、创伤与幸存者责任。 |
| 性格盲点 | 以沉默保护自己，也让后来者无法提前理解战争。 |

**可变命运**

- 长平战死，留下同伍姓名与未送出的家书。
- 参与处置后生还，成为最不愿被原谅的人。
- 拒命救人，连累同伍或家属。
- 作为伤残者回乡，却无法回到战前生活。

**后世回收**

- 同伍名记、残兵器、家书。
- 后世只记将名，不记屠申；他的口述可能被误归给某位名将。

### CH01-CHAR-010 苏离

| 字段 | 内容 |
|---|---|
| 身份 | 虚构游说之士，擅长把复杂经验改写成诸侯愿意听的利害。 |
| 首次登场 | ACT05 末。 |
| 与苏醒者关系 | 借用玩家治策的人；可成为知己、剽窃者或两者同时成立。 |
| 表层愿望 | 促成列国合力，为东方争取喘息时间。 |
| 内在恐惧 | 自己一生最成功的说辞只是一场更大失败的前奏。 |
| 代表主题 | 话语走得比人更远，也可能害得比刀更深。 |
| 性格盲点 | 认为先让主君点头，再补回被删掉的人名也来得及。 |

**固定行动**

- 将玩家治策删成人口、粮道与可征发数字。
- ACT06 参与促成盟约。
- 盟约失效后必须面对至少一名承担者，而不能写完檄文便退场。

**可变命运**

- 公开承认承诺无法兑现，帮助百姓提前撤离。
- 继续用新说辞掩盖旧失败。
- 把责任推给青缗、吏官或地方守军。
- 以自己的名义保存玩家原稿，造成后世署名错位。

**后世回收**

- “名家策论”与无名原稿并存。
- 后世称颂其说辞成功，却看不见执行代价。

## 7. 关系状态设计

不使用单一“好感度”。每位 A、B 级人物至少记录以下状态：

```text
trust       是否相信玩家会遵守承诺
shared_debt 双方共同欠下或共同承担的事
rift        无法靠送礼消除的立场裂痕
whereabouts 生还 / 死亡 / 失踪 / 改名 / 被拘 / 迁徙
testimony   此人掌握并愿意留下的证言
carrier     此人最终携带的遗物、文字、曲调或地点线索
```

### 状态使用规则

- `trust` 高不等于人物服从玩家。
- `rift` 高也不等于人物必然是敌人；申不疑可在严重分歧下交出关键军册。
- `shared_debt` 必须对应具体事件，不能只是抽象数值。
- `whereabouts = missing` 应在后世保持不确定，不能立即用旁白揭晓。
- 人物死亡后，`testimony` 与 `carrier` 决定其是否仍能参与跨朝代因果。

## 8. 长平不可逆损失规则

长平不能被设计成通过数值刷满就全员生还。

1. 季伯已在战前去世，代表代际交接。
2. 魏梁、屠申、韩宁、禾安的重要家人或职业锚点中，至少一人永久死亡或失踪。
3. 不可逆损失由此前选择链决定：
   - 谁被编入名册。
   - 哪条粮道被改动。
   - 谁掌握撤离消息。
   - 谁因关系裂痕拒绝与玩家同行。
4. 玩家可以改变损失落在何处、是否有人作证、遗物能否归还，但不能取消战争代价。
5. 不用“为了虐而随机杀人”；死亡必须完成该人物自己的行动，并留下可追踪后果。
