# 《山河无名》序章设计与剧情逻辑说明 V0.1

> 序章题名：《雨来之前》
>
> 内容位置：第一章 ACT01 之前，不计入八幕结构
>
> 目标：先建立本世身份、人物关系、宋亡背景和隐名风险，再让裂钟成为唯一超出理解的异常。

## 1. 修正的问题

旧开场直接从翻车与资源取舍开始，存在四个叙事断点：

1. 玩家不知道本世是谁，却立即被要求替陌生人作出高代价选择。
2. 辛衡、禾安、韩宁和柳娘没有生活关系铺垫，像功能角色同时被投放。
3. “亡国”没有说明具体指宋亡，玩家无法建立时空位置。
4. 文本把隐藏国名与保护身份混为一谈，没有说明具体姓名为何会带来追索。

序章不负责增加新谜题，而负责把这些已知事实说清。

## 2. “我是谁”的两层答案

第一层必须在序章两分钟内明确：

```text
本世姓名：玩家输入
年龄：十岁
居处：洛邑近郊洛水旧渡
家庭：父亲随官运粮后未归；母亲在旧渡维生并等待
社会关系：辛衡是识字先生；禾安是共同长大的邻家伙伴
现实能力：能辨简单姓名、数目和渡册，不具备超时代知识
```

第二层必须继续保持未知：

```text
裂钟落水为何出现在记忆中
湿简上的陌生人之手属于谁
这些感官经验为何不能由单一本世解释
```

本世身份清楚，跨时代身份未知。前者给玩家立足点，后者才构成悬念。

## 3. 史实锚点

序章明确使用前 286 年宋亡：

- 东来商船带来宋亡消息。
- 船主只能确认宋王已死、宋地正在被不同力量接管。
- 齐、魏、楚三种关验并列出现，体现普通人接收到的不是完整战略，而是不同军队和文书已经改变道路。
- 二十三户宋地流民沿商路向洛邑移动，不把整个亡国过程写成一支整齐队伍。

史实依据为《史记·宋微子世家》所记齐愍王与魏、楚伐宋、杀王偃并三分其地。具体年份采用项目既定的前 286 年主流断代。

## 4. 隐名逻辑

序章必须明确区分：

```text
可以公开：宋亡、宋地来客、需要多少热水与空屋
谨慎公开：本人愿意使用的现名、同行关系、体貌
需要保护：具体故邑、旧姓、户属、债役、仍在原地的亲属
```

宋亡不是秘密。危险来自姓名背后的现实连接：

- 旧主按册追逃人和欠役者。
- 新接管者利用旧册寻找粮、田与劳力。
- 债主通过户属追索逃债者。
- 具体故邑与亲属关系会把官差带到仍然活着的人面前。
- 韩宁父亲拆散地方名册，因此其家人与残简同时被旧主和新来者追查。

“姓名保护人，也暴露人”在序章先成为生活规则，ACT01 再把它变成无法同时保全的选择。

## 5. 辛衡改名

原“季伯”统一改为“辛衡”：

- 避免“鸡脖”谐音。
- 避免名字被误读为排行或泛称。
- “衡”呼应其在活人、记录和制度之间衡量的角色责任。

人物关系同步调整：

```text
旧：危机中突然收留玩家的老书吏
新：玩家早已认识的识字先生与渡册引路者
```

辛衡先让玩家写自己的名字，再教玩家处理别人的名字。他后期承认曾奉命删名，人物弧线因此形成首尾对应。

## 6. 序章六节点

### 6.1 先写自己的名字

玩家输入本世姓名。辛衡明确：

> 本世的名字，不能也让旁人替你省掉。

### 6.2 这一世的名字

禾安以邻家伙伴身份登场。玩家的父亲未归、母亲等待和旧渡生活得到确认。

### 6.3 宋亡的消息

东来船主带来宋亡与二十三户流民消息。列国接管细节保持来源冲突。

### 6.4 不要叫出旧名

流民母亲刮去里籍木片上的具体里名；辛衡解释姓名如何连接户、田、债、役和亲属。韩宁说明其现名，柳娘删去故邑唱词。

### 6.5 雨来之前

辛衡准备木牍、禾安烧水、韩宁等车、柳娘搭棚。角色先通过行动成立。

### 6.6 裂钟落水

玩家清楚记得本世姓名，却经历无法归入本世十年的裂钟回声。最后一辆车翻倒，直接进入 ACT01。

## 7. 与 ACT01 的接口

ACT01 开场不再使用：

```text
在车旁醒来
不记得姓名
含糊的亡国流民
仅因唱出国名就会被追索
```

改为：

```text
玩家从旧礼器库赶到渡口
明确记得本世姓名和核心故人
明确来者是宋地流民
半名残简刮去的是故邑、里名与户属
亡国旧曲明说宋亡，停顿处隐藏具体来处
```

ACT01 的第一项选择因此不再承担世界观解释任务，只负责真正的高压取舍：先救人、先留证，或让众人互认。

## 8. 工程落点

- 序章是独立场景 JSON，排在 `sceneFiles` 首位。
- 本世姓名通过声明式文字输入写入 `player.profile`。
- 姓名提交生成 `text.submit` 与 `profile.set` 事件，可保存、导出和回放。
- 正文通过 `{{playerName}}` 读取本世姓名。
- 路线审计使用合法默认名，不增加分支数量。
- 序章结束后所有人物、事实、记录和记忆继续进入 ACT01—ACT02，不重置。

## 9. 验收标准

- [x] 玩家在第一次资源取舍前知道本世姓名、年龄、家庭和社会位置。
- [x] 辛衡与禾安在危机前以既有关系登场。
- [x] 亡国明确为宋亡。
- [x] 隐名风险落到故邑、旧姓、户属、债役和亲属。
- [x] 韩宁的现名与父亲暗册风险得到最低限度说明。
- [x] 裂钟只制造跨时代身份疑问，不抹除本世身份。
- [x] 序章直接汇入 ACT01，不重复解释。
