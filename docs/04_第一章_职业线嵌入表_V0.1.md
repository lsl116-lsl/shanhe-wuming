# 第一章《礼崩之世》职业线嵌入表 V0.1

> 文档状态：第一版完整职业线设计
>
> 上游文档：`02_第一章_礼崩之世_主线大纲_V0.1.md`、`03_第一章_人物关系表_V0.1.md`
>
> 用途：规定十条人生线如何进入同一条八幕主线，以及每条线独有的视野、资源、责任、代价和《无名录》贡献。

## 1. 核心结论

十条人生线不是十个副本，而是同一段战国晚期人生的十种社会位置。

```text
ACT01 裂钟之梦：共同成长
→ ACT02 旧礼无声：共同经历旧秩序失效
→ ACT03 旧国被重写：玩家主动选择主要人生位置
→ ACT04 新法如刀：从不同位置接触同一场“隐丁案”
→ ACT05 百家灯火：带着不同证据进入同一场问议
→ ACT06 合纵连横：同一份盟书和粮道图经过不同人的手
→ ACT07 长平血雾：十种位置被同一场战争拉到长平
→ ACT08 天下将一：职业结局不同，《无名录》去向重新合流
```

职业决定：

- 玩家最先看见什么。
- 玩家能调动什么资源。
- 谁愿意听玩家说话。
- 玩家必须对哪一类后果负责。
- 玩家能为《无名录》补上哪一种证据。

职业不决定：

- 玩家善良或邪恶。
- 玩家天然支持旧礼、新法、合纵或统一。
- 某条线必然拥有“最佳结局”。
- 玩家可以绕开共同历史代价。

## 2. 内容比例与分流规则

### 2.1 内容比例

建议第一章内容量按以下比例设计：

| 内容类型 | 占比 | 作用 |
|---|---:|---|
| 全职业共享主线 | 约 55% | 保证八幕是一条完整人生，不因职业割裂。 |
| 共享事件的职业版本 | 约 20% | 同一事件更换信息入口、可用动作与责任。 |
| 职业独有事件 | 约 15% | 建立身份质感和职业故人关系。 |
| 跨职业关系与回收 | 约 10% | 让未选择职业仍作为人物和制度存在。 |

玩家选择一条人生线，不意味着其余九条线从世界中消失。未被选择的职业由对应锚点人物承担：

| 玩家未选择的人生线 | 世界中的主要承担者 |
|---|---|
| 隐士 | 南郭生 |
| 仕官 | 申不疑、荀白或公孙砚 |
| 谋士 | 苏离 |
| 武将 | 屠申、魏梁 |
| 医者 | 小蓟 |
| 戏子 | 柳娘、阿檀 |
| 商贾 | 青缗 |
| 工匠 | 鲁砚 |
| 吏官 | 季伯、孟简、公孙砚 |
| 农人 | 禾安 |

这样，玩家即使选择医者，也会在隐丁案中遇见写名册的孟简、执行法令的公孙砚、失去劳力的禾安和试图赎役的青缗；世界不会退化成只有医者存在的职业舞台。

### 2.2 路线选择

ACT01、ACT02 的选择只产生经历和关系，不自动计算职业。

ACT03 由玩家在了解代价后主动选择主要人生位置：

| 入口行动 | 可自然进入的人生线 |
|---|---|
| 护送逃籍者离开大道 | 隐士 |
| 接受地方征辟、尝试赦免旧民 | 仕官 |
| 处理旧档与新权力的交换 | 谋士 |
| 进入守军保护或追索流民 | 武将 |
| 随迁徙者行医 | 医者 |
| 随柳娘行旅，以曲调携带线索 | 戏子 |
| 随青缗经营道路、粮食与消息 | 商贾 |
| 进入官营或民间工坊 | 工匠 |
| 进入官署抄写户籍 | 吏官 |
| 留在新划田界上建立生活 | 农人 |

前两幕行为可给出两至三条“熟悉路线”提示，但不得锁死其他选择。玩家选择的是愿意承担的社会责任，而不是数值最高的职业。

### 2.3 转轨规则

第一章原则上只记录一条主要人生线，但允许身份发生历史性变化：

- 农人被征为卒，仍是农人线，因为其核心牵挂是田地与家庭，而不是军功体系。
- 商贾被迫负责军粮，仍是商贾线，因为其资源与责任来自道路、价格和信用。
- 吏官进入军中记功，仍是吏官线，因为其关键行动是登记、删改和保存记录。
- 隐士下山救人，仍是隐士线，因为其矛盾是“不入权力是否仍要承担山下后果”。

只在 ACT04 允许一次明确转轨。转轨必须由重大因果造成，例如官职被夺、家庭失地、伤残退伍或为保护故人逃籍；不能随时更换职业刷取全部资源。

## 3. 全职业共享事件

| 共享事件 | 所在幕 | 所有路线面对的共同问题 | 职业差异来自 |
|---|---|---|---|
| 流民临时名册 | ACT01 | 先救人还是先留名，怎样避免真名伤害逃亡者 | 技能倾向与第一批故人关系，尚未正式分流 |
| 旧仓之粮 | ACT02 | 谁有资格领粮，活路是否必须以新属籍交换 | 玩家处理粮、病、秩序和记录的方式 |
| 旧籍去向 | ACT03 | 保存原名、保护现身份、制作双册或毁册 | 玩家主动选择人生位置 |
| 一户隐丁案 | ACT04 | 一家隐瞒成年劳力，全伍是否应受连坐 | 权限、证据、物资、关系与执行责任 |
| 一户得田又失子 | ACT05 | 可推广的制度是否能容纳具体人的代价 | 每条线带入问议的证据不同 |
| 盟书与粮道图 | ACT06 | 一项有利于大局的改动会把代价移给谁 | 每条线掌握的信息和可改动环节不同 |
| 长平断粮与撤离 | ACT07 前段 | 有限粮药、道路和消息先给谁 | 职业能调动的资源不同 |
| 亡者简 | ACT07 后段 | 真名、匿名、证言与家属安全如何兼顾 | 每条线能提供的独有证据不同 |
| 《无名录》去向 | ACT08 | 完整、传播、安全、可见性无法同时满足 | 职业载体改变四种去向的具体形态 |

### 3.1 ACT04“一户隐丁案”的同场关系

这不是十次不同事件，而是同一户人家、同一块新法木牌、同一份名册：

| 人生线 | 在事件中的位置 |
|---|---|
| 隐士 | 知道被隐瞒的成年男子藏在哪里。 |
| 仕官 | 有权请求缓征、赎役或调整执行尺度。 |
| 谋士 | 知道此案会如何被上级写成治乱案例。 |
| 武将 | 负责带人归伍，也知道缺员会由谁补上。 |
| 医者 | 能判断此人是否真实患病或伤残。 |
| 戏子 | 负责向不识字者宣读木牌，也听见全村私议。 |
| 商贾 | 有能力筹赎金、替代粮或运输役。 |
| 工匠 | 制作木牌、量具，也可能以工程役替代兵役。 |
| 吏官 | 亲手决定名册上写“在、亡、病、逃”中的哪一个字。 |
| 农人 | 是承担连坐与额外徭役的邻户。 |

### 3.2 ACT06“盟书与粮道图”的传递链

```text
农人提供收成与道路实况
→ 商贾汇总粮价、车马与里程
→ 工匠评估桥、车和仓的承载
→ 吏官折算成各县征发数
→ 医者申报药材与伤病承载
→ 武将判断军队可行路线
→ 谋士写入盟书与战略
→ 仕官签署、担保或驳回
→ 戏子把盟誓与征发理由传给众人
→ 隐士看见被图上直线忽略的山路与逃亡者
```

任何一环改动，都会改变后续资源与伤亡。玩家只控制自己所在的一环，不能同时拥有所有信息。

## 4. 隐士线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 山地聚落的教读者、采药者、逃籍者庇护人或不仕之士。 |
| 锚点人物 | 南郭生；与韩宁、禾安、小蓟交叉。 |
| 核心问题 | 不进入权力，是否就能免于权力造成的责任？ |
| 独有资源 | 山路、藏身处、非官府信任、野外生存与口述网络。 |
| 信息盲区 | 不易获得官署真实命令、军队调动和完整名册。 |
| 必须代价 | 每藏下一人，都可能使整个山地聚落承担清查和报复。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 护送拒绝重新入籍者离开大道，知道谁使用假名 | 山路、猎户、旧庙、南郭生 | 无法证明所有求助者可信；藏人会连累聚落 | 掌握明册之外的真实去向 |
| ACT04 | 知道隐丁藏身处，也看见邻户即将受罚 | 转移、藏匿、劝其自首或与公孙砚谈条件 | 不能同时让藏匿者安全、邻户免罚、聚落不暴露 | `SW-CH01-101 山中藏名` |
| ACT05 | 可亲赴临淄，也可托荀白带去逃籍者证言 | 不受官署筛选的口述 | 证言难核验，容易被称为偏听或私护罪人 | 让问议看见制度外的人 |
| ACT06 | 掌握盟书未标出的山路和撤离点 | 提前疏散、误导追索或开放山路 | 一条路救一批人，可能把追兵引向另一聚落 | 决定秘密撤离线是否存在 |
| ACT07 | 接纳逃兵、伤者、百姓与追捕者 | 藏身、采药、山地辨路 | 无法无限接纳；粮食与泄密风险持续上升 | 补充失踪者去向和山中埋葬地 |
| ACT08 | 暮年守护藏册或带徒弟下山 | 隐藏、分抄、口授 | 保存越隐秘，越可能无人看见 | 可强化“分给家属”或“藏入裂钟”去向 |

### 《无名录》独有贡献

- 山中临时墓地位置。
- 使用假名者的原名与保护期限。
- 逃兵、失踪者和实际生还者之间的区别。
- 由南郭生与山民共同记忆的口述版本。

这条线不能把所有逃亡都写成高尚。藏匿可能让无辜邻户承担惩罚，山中聚落也可能拒绝继续接纳外人。

## 5. 仕官线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 地方属官、主君幕中施政者或受征辟的士人。 |
| 锚点人物 | 荀白、申不疑、公孙砚。 |
| 核心问题 | 想让制度听见人的声音，是否必须先成为制度的一部分？ |
| 独有资源 | 合法发令、调粮、缓征、阅档和向上陈述的权限。 |
| 信息盲区 | 上报材料经过层层筛选，容易只看见官署认可的事实。 |
| 必须代价 | 每次“先执行再改良”都会让具体的人先承担一次后果。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 接受地方征辟，负责处理旧民赦免与归籍 | 官印、呈文、召见与有限裁量 | 想保住职位就不能公开否定整个新秩序 | 获得制度内改写旧籍的入口 |
| ACT04 | 对隐丁案有请求缓征或改役的权力 | 调粮、赎役、工程役、上书 | 破例可能被豪强利用；不破例则眼见一家失去劳力 | `SW-CH01-102 驳回奏简` |
| ACT05 | 以地方经验参与问议 | 能把个案写成政策 | 越可推广，越容易删去人名与特殊处境 | 形成治策的正式版本 |
| ACT06 | 参与签署、担保或驳回盟约 | 阅览各方承诺、改变征发时限 | 承诺一旦签下，兑现者是县邑百姓 | 留下签署责任与驳回理由 |
| ACT07 | 能调动一部分仓粮、车辆与撤离文书 | 合法放粮、延迟征发、伪造或公开抗命 | 救一处可能使另一处缺额；所有命令都有署名 | 提供命令原件、赦令和被驳回的撤离申请 |
| ACT08 | 可能升迁、罢官、被罪或退居乡里 | 官藏渠道与制度影响 | 进入官藏最完整，也最易被重抄删改 | 可强化“交入官藏”去向 |

### 《无名录》独有贡献

- 盖印的命令、赦令与驳回批语。
- “谁知道、谁签字、何时仍有机会改变”的责任链。
- 官署并非铁板一块的证据。
- 某项地方改良如何后来变成更广泛制度的前身。

仕官线的高位结局不自动优于罢官结局。评价重点是玩家用权限留下了什么，以及执行代价由谁承担。

## 6. 谋士线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 门客、游说者、军政参议或替权力整理利害的人。 |
| 锚点人物 | 苏离、申不疑、荀白。 |
| 核心问题 | 看清大势的人，是否更容易把看不见的人当作代价？ |
| 独有资源 | 多方情报、文本解释权、推演、游说与接近决策者的机会。 |
| 信息盲区 | 信息多来自汇总和转述，缺少对具体执行过程的感受。 |
| 必须代价 | 成功的说辞会脱离原意继续生长，失败也会由别人先承担。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 为新旧权力解释旧档价值 | 交换、保密、双重文本 | 任何折中都可能被双方视为背叛 | 掌握明暗两册的政治用途 |
| ACT04 | 把隐丁案推演成普遍执行问题 | 预判、设计例外、说服上级 | 人会被转化成可计算案例 | 形成“法内求生”的论证 |
| ACT05 | 整理玩家与故人的证言 | 选择措辞、署名与传播对象 | 为了被采用而删去细节 | `SW-CH01-103 被删改的治策` |
| ACT06 | 直接参与盟书、兵粮与路线推算 | 改词、隐数、夸大、揭露 | 每项策略都把风险重新分配给某地 | 生成 `空言之债` 的具体责任 |
| ACT07 | 能提前判断某些危险，却无权控制全部执行 | 送出警告、改撤离顺序、留下原始文书 | 警告一地会暴露情报来源；准确推演也可能服务杀戮 | 提供盟书原稿与删改链 |
| ACT08 | 成为名士、失意门客或匿名抄手 | 文本传播、后世署名 | 最易留下文字，也最易夺走真正经历者的声音 | 四种去向均可，但必须处理署名问题 |

### 《无名录》独有贡献

- 盟书原稿、删改稿与最终执行稿的对照。
- 粮道改变并非“意外”的证据。
- 苏离、申不疑与玩家分别删掉了哪些人名。
- 一份明确写下“此策可能由谁承担”的反向注释。

谋士线不能提供“选对策略便赢得长平”的幻想。玩家的最高能力是更早看见代价并改变局部准备，而不是翻转既定战局。

## 7. 武将线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 卒伍出身的低阶军吏、守军或随征将领，不取代真实统帅。 |
| 锚点人物 | 屠申、魏梁。 |
| 核心问题 | 命令要求你把人当作兵，袍泽却始终是具体的人。 |
| 独有资源 | 兵卒信任、军中消息、护送能力、短时强制力与接近战场。 |
| 信息盲区 | 不掌握全部外交与战略，只能接到被截断的命令。 |
| 必须代价 | 拒命会把处罚和危险转给同伍，服从则可能参与不可接受之事。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 进入边邑守军，负责保护或追索流民 | 武力、通行、同伍关系 | 保一批人可能失去军中信任；追人则伤害故人 | 认识屠申与魏梁 |
| ACT04 | 执行隐丁归伍与新法军功 | 延缓带人、替换勤务、上报伤病 | 缺额会由另一户或同伍补上 | 看见军功改变出身，也拆散家庭 |
| ACT05 | 带着军功、伤亡与卒伍经验参与问议 | 战争一线证言 | 易被各派选择性引用为强兵或反战证据 | `SW-CH01-104 同伍旧约` |
| ACT06 | 护送使者、接收上党或守粮道 | 军中路线、警戒、有限调兵 | 保护使者可能耽误百姓撤离；放人撤离可能泄露路线 | 同伍被分配到长平 |
| ACT07 | 直接面对断粮、突围、投降与处置命令 | 组织撤退、护伤者、保存军中名记 | 无法救下全部袍泽；拒命、执行和拖延各有牺牲 | 提供卒伍名单、投降经过与命令见证 |
| ACT08 | 生还者可能伤残、被赏、被罪或回乡 | 军中遗物、袍泽后人 | 战功会改善家庭，也会遮住具体责任 | 可强化“分给家属”或“交入官藏” |

### 《无名录》独有贡献

- 同伍称呼、籍贯、身体特征和最后所见。
- 区分战死、失踪、投降后失踪与逃亡。
- 一段来自执行者而非胜者史书的命令见证。
- 袍泽托付的家书和归还物。

武将线不把抗命自动写成英雄。一次拒命可能救下敌方降卒，也可能让无准备的同伍替玩家受死。

## 8. 医者线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 民间行医者、药徒或被征入军中的医者。 |
| 锚点人物 | 小蓟；与禾安、南郭生、屠申交叉。 |
| 核心问题 | 救不了天下时，先救眼前人是否已经足够？ |
| 独有资源 | 诊断、伤病记录、药材网络、进入家庭与伤营的信任。 |
| 信息盲区 | 能看见身体后果，却往往最后才知道造成后果的决策。 |
| 必须代价 | 药、时间和安全都有限，治疗次序本身就是选择。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 随迁徙人群行医，知道许多人的假名与去向 | 诊疗信任、药材、隐私 | 说出真实身份可救治或免役，也可能暴露逃亡者 | 获得身体证据与口述证言 |
| ACT04 | 判断隐丁是真病、伤残还是逃役 | 病证、缓役建议、替代医役 | 开病证会影响同伍征发，不开则可能毁掉一家 | `SW-CH01-105 病证与役籍` |
| ACT05 | 以“得田失子”家庭的身体后果参与问议 | 病案、饥荒与劳役证据 | 病案去名可保护隐私，却削弱具体见证 | 让制度争论落到身体 |
| ACT06 | 药材被军队与民间同时索取 | 配药、药路、伤病承载判断 | 留给百姓就减少军需，交军需则地方疫病无药 | 决定长平前药材去向 |
| ACT07 | 负责伤营、逃亡者或民间救治 | 分诊、辨认伤痕、记录最后语言 | 每次优先救治都意味着有人等待；玩家也可能被迫放弃记录 | 提供伤簿、体貌与死亡时间 |
| ACT08 | 医方可入官藏、民间传抄或随药箱流转 | 医者网络 | 医方流传不代表原始伤者姓名仍在 | 可强化家属分发或官藏去向 |

### 《无名录》独有贡献

- 伤者体貌、旧伤、死亡时间和最后语言。
- 军册没有记录的民夫、妇孺与逃亡者。
- 区分“当场死去”与“战后因伤病死去”。
- 一份能跨章流传的医方和伤簿。

医者线不允许靠高医术救下全部人物。技能提高的是判断与局部生还机会，不能创造无限药材、时间或安全。

- 不识字者能够记忆的姓名次序与乡里曲调。

- 亡国旧曲从悼一国转为悼普通人的关键段落。
- 谁要求改词、删词或禁唱的传播史。

戏子线不能把表演写成后世成熟戏曲。第一章正文使用优伶、乐人、歌、舞、俳谐、社场和临时乐棚等时代内表达。

## 10. 商贾线

### 路线定位

| 字段 | 内容 |

| 锚点人物 | 青缗。 |
| 核心问题 | 价格能让物资流动，却能否衡量谁更该活下去？ |
| 独有资源 | 粮、钱、车马、债契、关卡关系、跨国消息和路线。 |
| 信息盲区 | 容易把没有购买力的人排除在“需求”之外。 |
| 必须代价 | 低价救人会耗尽商队，高价维持道路又会让饥者先死。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 随青缗运输旧籍与流民，穿过不同关卡 | 夹带、债契、假货单、消息 | 商队成员会为玩家藏人承担风险 | 保存旧籍的运输痕迹 |
| ACT04 | 可为隐丁筹赎金、粮或替代运输役 | 资金、信用、交易 | 赎下一户可能抬高全村债务和粮价 | 记录人如何被折成价格 |
| ACT05 | 提供粮价、债务、度量和道路证据 | 可验证账册 | 数字可靠，却可能被用于更高效征发 | `SW-CH01-107 无法结清的粮债` |
| ACT06 | 商路图成为军粮路线 | 调车、延运、分流、隐瞒仓点 | 改一条路会救一地、饿一军或压垮另一地 | 决定被改动粮道的实际效果 |
| ACT07 | 掌握粮在哪里，也知道为何到不了饥者手中 | 私运、开仓、雇车、送信 | 公开放粮会使后续路线断裂；维持交易则眼见有人无粮 | 提供粮册、车队记号与失踪运输者 |
| ACT08 | 可继续经营、破产、被征用或转为官运 | 跨地域分发能力 | 账册最易被统一度量重写，旧单位与旧债消失 | 可强化家属分发或官藏去向 |

### 《无名录》独有贡献

- 粮队、车夫、民夫和沿途死者的姓名。
- 各国关卡戳记，证明一个人最后出现在哪里。
- 粮食实际流向与官面数字的差异。
- 给遗属的未结债、赔偿与无法折算的人命。

商贾线不把赚钱自动写成罪，也不把散尽家财自动写成最优解。商队若完全破产，后续可能再也没有人运送救命物资。

- “谁造、谁用、用来做什么”的器物责任链。

## 12. 吏官线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 县邑基层书吏、户籍吏、仓吏或军中记功吏。 |
| 锚点人物 | 季伯、孟简、公孙砚。 |
| 核心问题 | 写下一个字的人，是否要为这个字落到人身上的后果负责？ |
| 独有资源 | 原始名册、档案格式、重抄权限、印记、执行时间差。 |
| 信息盲区 | 案卷记录的是制度需要知道的部分，不等于完整人生。 |
| 必须代价 | 擅改一笔可能救人，也可能让同僚、邻户或未来继任者承担责任。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 进入官署抄写旧籍与新籍 | 留白、重抄、双册、拖延 | 官档与私录不一致会留下可追查笔迹 | 继承季伯的记录矛盾 |
| ACT04 | 亲手为隐丁写状态 | 病、亡、逃、在、缓役等字样与日期 | 每个字都会改变本人、同伍和邻户命运 | `SW-CH01-109 明暗官册` |
| ACT05 | 记录问议并决定哪些证言进入正式文本 | 完整速记、删节、匿名 | 保护身份与保留证据无法同时最大化 | 保存治策被删前版本 |
| ACT06 | 把盟书数字转为各县征兵征粮名额 | 调整舍入、先后、期限、附注 | 少征一县就会多征另一县，或使军需出现缺口 | 形成可追踪的征发链 |
| ACT07 | 接触军册、伤亡册、首级与处置记录 | 对照、抄副本、保留被命令销毁部分 | 真名可能连累逃兵家属；销毁则永远失名 | 成为《无名录》的主要文字底本 |
| ACT08 | 可将记录交官藏、分抄或藏匿 | 最强档案能力 | 最容易保存完整，也最容易被制度吸收和删改 | 四种去向均有高适配性 |

### 《无名录》独有贡献

- 官册与私录之间的逐项差异。
- 被划掉、改写、补入和留空的具体痕迹。
- 征发、调动、失踪与处置之间的时间链。
- 《无名录》可供后世辨认的底本结构。

吏官线与仕官线必须区分：仕官决定或争取政策，吏官把政策落实为具体姓名、数字和日期。

## 13. 农人线

### 路线定位

| 字段 | 内容 |
|---|---|
| 本世身份 | 新附聚落中的农户、佃作者、失地者或承担军粮的家庭成员。 |
| 锚点人物 | 禾安。 |
| 核心问题 | 天下所有主张最终落到一亩田上时，还剩下什么？ |
| 独有资源 | 土地经验、乡里互助、种子、藏粮、地名与家庭记忆。 |
| 信息盲区 | 最晚知道高层决定，几乎没有正式发言渠道。 |
| 必须代价 | 保田、保家、保粮、保名无法同时做到。 |

### 幕内嵌入

| 幕 | 社会位置与可见信息 | 可用行动与资源 | 必须承担的代价 | 主线输出 |
|---|---|---|---|---|
| ACT03 | 留在被重新划界的田上，直接经历改籍 | 乡里关系、地界记忆、共同劳作 | 接受新田可能默认旧主人的失去；拒绝则无以为生 | 保存地名与家庭迁徙史 |
| ACT04 | 是隐丁案邻户或当事家庭 | 藏人、替役、合力赎役、公开举报 | 无论选谁，下一季劳力和全伍徭役都会改变 | `SW-CH01-110 田亩未归` |
| ACT05 | 作为“一户得田又失子”的当事证言 | 具体收成、劳役、家庭变化 | 发言可能被当作各派论据，本人仍无决策权 | 让问议无法只谈国力 |
| ACT06 | 被要求供粮、运粮、留守或逃离 | 藏粮、乡路、收成判断、邻里互助 | 供粮则家中不足，藏粮则承担处罚，逃亡则失田 | 决定粮道数字是否真实可兑现 |
| ACT07 | 可能成为运粮者、战地流民、遗属或被征农卒 | 辨认乡里、寻找家人、照料遗属 | 不能同时守住田地、追寻失踪者和保护家人 | 提供地名、亲属称呼与未归者名单 |
| ACT08 | 可能获得军功田、失地迁徙或重建聚落 | 家庭口述、种子、土地延续 | 人活下来也可能永远回不到原地 | 可强化家属分发或民间口述去向 |

### 《无名录》独有贡献

- 官册没有使用的小地名、田界、井名和亲属称呼。
- 谁从哪一户被征走、谁一直没有回来。
- 一包标明故地的种子或一块带田界记号的木片。
- 战后仍需继续耕种、照顾遗属和偿还军粮债的人。

农人线不是“最朴素所以最正确”的道德路线。乡里也会排外、告发、争粮和转嫁负担；玩家必须面对共同体既互助又自保的一面。

## 14. ACT07《无名录》贡献汇流

| 人生线 | 独有材料 | 能补全的问题 | 材料自身的风险 |
|---|---|---|---|
| 隐士 | 山路、藏身者与山中墓地口述 | 谁其实生还、谁埋在官册之外 | 暴露藏匿者与山民 |
| 仕官 | 命令、赦令、驳回批语 | 谁在何时有权改变结果 | 官文可能为自己卸责 |
| 谋士 | 盟书原稿与删改链 | 风险是否早已被预见 | 文本仍缺执行现场 |
| 武将 | 卒伍名记、投降与命令见证 | 谁战死、失踪、投降后失踪 | 真实记录可能构成抗命证据 |
| 医者 | 伤簿、体貌、死亡时间 | 无名伤者是谁、战后死亡如何发生 | 病案真名会牵连逃亡者 |
| 戏子 | 曲调名序、绰号、最后言语 | 不识字者和官册外的人如何被记住 | 口述容易变形、被禁 |
| 商贾 | 粮册、车号、关卡戳记 | 一个人最后经过哪里、粮去了哪里 | 账册暴露走私、获利与私运 |
| 工匠 | 工坊记号、墓标、器物编号 | 无名遗物属于哪一队、葬于何处 | 工记也证明谁参与造械 |
| 吏官 | 官册底本、删改痕迹 | 名字如何被划去、改写与归类 | 保存副本本身可能获罪 |
| 农人 | 小地名、亲属称呼、未归口述 | 官名之外的人从哪户离开 | 乡里记忆会偏向自己人 |

### 汇流规则

1. 玩家路线提供一种主要材料。
2. 与故人的关系决定还能获得两至四种辅助材料。
3. 不允许单周目收齐全部证据。
4. 不同材料之间必须存在矛盾，例如官册记“亡”、山中口述称“生还”。
5. 《无名录》的价值不是绝对正确，而是不把矛盾和空白假装成不存在。

## 15. ACT08 职业结局与四种去向

四种去向对所有职业开放，不设职业专属正确选项。

| 人生线 | 最自然的去向 | 选择其他去向时的独特表现 |
|---|---|---|
| 隐士 | 分给家属 / 藏入裂钟 | 交官藏意味着主动走进曾回避的制度；托乐人意味着让秘密公开传播 |
| 仕官 | 交入官藏 | 分给家属意味着放弃完整控制；藏匿可能构成对自身官职的否定 |
| 谋士 | 交入官藏 / 分给家属 | 托乐人可打破精英文本垄断；藏匿则承认言辞暂时无力施行 |
| 武将 | 分给家属 | 交官藏可留下命令证据；藏入裂钟可能保护仍在军中的同伍 |
| 医者 | 分给家属 | 交官藏让伤簿成为制度证据；托乐人能传姓名但会失去医学细节 |
| 戏子 | 托付乐人 | 交官藏保存原词却限制传播；藏匿使曲子失声；分给家属形成多版本 |
| 商贾 | 分给家属 / 交入官藏 | 可借商路分散抄本；藏匿意味着冻结本可流动的记录 |
| 工匠 | 藏入裂钟 | 交官藏可借器物编号保存；托乐人让工匠姓名进入曲词 |
| 吏官 | 交入官藏 | 分散抄本能抵抗统一删改；藏匿则保真但失去公共效力 |
| 农人 | 分给家属 | 托乐人让小地名被更广记住；交官藏可能换来正式认领，也可能再被标准化 |

职业结局只改变载体能力与风险，不改变四种去向的核心取舍：

| 去向 | 优势 | 不可消除的缺陷 |
|---|---|---|
| 官藏 | 集中、较完整、便于后世查找 | 会被统一格式、删改和重新分类 |
| 家属与行旅 | 分散、贴近活人、不易一次毁尽 | 版本破碎、互相矛盾、难以汇总 |
| 裂钟或旧库 | 隐蔽、可能长期保存原貌 | 可能数十年无人看见，甚至随器物毁失 |
| 乐人旧曲 | 传播广、跨越识字限制 | 姓名和原意会变形，也容易被禁唱或收编 |

## 16. 第二章职业因果接口

第二章不需要沿用同一职业，但必须根据第一章路线优先回收一种材料：

| 第一章人生线 | 秦汉章优先回收入口 |
|---|---|
| 隐士 | 秦吏清查逃籍者时发现一处旧藏名册 |
| 仕官 | 郡县官档中出现一封未被采纳的缓征奏简 |
| 谋士 | 统一后的档案把无名原稿归到某位名士名下 |
| 武将 | 边地戍卒收到旧同伍留下的家书或名记 |
| 医者 | 戍边疫病中再次使用长平伤营留下的医方 |
| 戏子 | 市井乐人私唱被禁的亡国旧曲 |
| 商贾 | 统一度量时发现一笔旧单位无法换算的粮债 |
| 工匠 | 官营作坊重用一张旧工图，抹去原工匠姓名 |
| 吏官 | 小吏重抄旧简时发现被划去的姓名与留空记号 |
| 农人 | 新编户籍与旧田界冲突，后人拿出一块故地木片 |

这只是优先入口。《无名录》最终去向仍决定第二章开场场景，职业材料决定场景中首先被看见的细节。

## 17. 后续数据化字段

重构原型时，每条人生线至少需要以下字段；当前只规定语义，不在本阶段写代码：

| 字段 | 用途 |
|---|---|
| 路线编号 | 稳定引用隐士、仕官等十条线 |
| 时代内身份 | 避免使用不合时代的后世职业称呼 |
| 入口节点 | ACT03 的主动选择 |
| 锚点人物 | 未选择路线时由谁承担该社会位置 |
| 可见信息 | 玩家比其他路线更早知道什么 |
| 可用资源 | 该路线能合法或非正式调动什么 |
| 制度权限 | 能否阅档、发令、改册、通行、征调 |
| 强制责任 | 不能靠“不选择”回避的代价 |
| 共享事件角色 | ACT04 至 ACT07 在同一事件中的位置 |
| 独有事件 | 最多两至三个，服务职业质感而非另起主线 |
| 记录贡献 | ACT07 为《无名录》提供的材料 |
| 跨章载体 | 第二章优先回收的遗物、文字、后人或制度 |
