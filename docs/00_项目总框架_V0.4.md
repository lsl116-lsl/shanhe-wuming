# 《山河无名》项目总框架 V0.4

> 文档状态：当前最高层项目与叙事规范  
> 当前口径：序章 + 七章 + 终章；第一章《钟裂于洛水》，主题为“礼崩之世”  
> 核心母题：无名不是没有名字。无名的名字，是人民。

## 0. 核心结论

《山河无名》最适合做成：

> **以 AVG 为主体、以轻量人生 RPG 为骨架的章节式历史叙事游戏。**

比例建议：

```text
叙事、调查、对话与选择：约 70%
关系、资源、职业责任与因果管理：约 30%
```

项目不依靠高频战斗、等级刷取、装备数值和随机抽卡制造循环。它真正的循环是：

```text
进入一段人生
→ 认识具体的人
→ 从一个社会位置理解时代
→ 在有限信息和资源中选择
→ 事实、关系与记录发生分歧
→ 承担本世结果
→ 将一部分因果交给后世
→ 下一章在新的现实事件中回收
```

全游戏不是七部松散的朝代短篇，而是一场逐章推进的长问题：

```text
谁建立秩序
→ 谁承担秩序
→ 秩序崩裂后谁保存共同生活
→ 盛世由谁供养
→ 文明为何不能自动免于覆亡
→ 旧制度为何无法组织新世界
→ 无名者如何成为历史主体
```

## 1. 项目定位

### 1.1 核心一句话

一个不知来处的苏醒者，在中国历史的关键转折处一次次醒来，每一世都成为时代中的普通人；他起初寻找自己的名字，最终发现自己是千千万万无名者共同的历史回声。

### 1.2 类型定义

| 项目维度 | 定义 |
|---|---|
| 产品类型 | 单机、章节式、历史叙事人生 RPG / AVG |
| 叙事类型 | 中国历史长河、轮回人生、普通人视角、跨章因果 |
| 核心玩法 | 阅读与调查、关系选择、职业责任、有限资源、事实与记录分层 |
| 章节结构 | 序章 + 七章 + 终章；每章一段完整人生 |
| 核心体验 | 在个人无法改写的大势中，决定怎样活、怎样承担、让谁被记住 |
| 长线动力 | 寻找苏醒者身份，追踪因果在后世如何变形、断裂和重生 |
| 目标平台 | 网页验证叙事；正式版以 Godot / PC 为核心，移动端按条件评估 |
| 发行方式 | 先序章 / 第一章垂直切片，后按章持续制作和发布 |

### 1.3 本项目不是什么

```text
不是随机投胎模拟器。
不是朝代百科和历史知识问答。
不是帝王将相改史爽文。
不是互不相干的职业副本。
不是用现代知识碾压古人的穿越故事。
不是靠善恶值、好感度和完美选项判定人生。
不是以战斗刷取、装备收集或抽卡驱动的数值 RPG。
不是把“人民”作为终章突然贴上的口号。
```

## 2. 玩家体验与设计支柱

### 2.1 五项体验承诺

每章都必须让玩家：

1. **活在时代里**：有姓名、家庭、师友、社会位置、债务、疾病、饥饿、劳役和无法轻易舍弃的人。
2. **从社会位置看历史**：同一事件在不同人生位置里看到的信息、责任和代价并不相同。
3. **面对没有纯净答案的选择**：救一户可能连累邻户；保存真名可能暴露活人；统一标准可能同时打破特权和伤害具体家庭。
4. **看见选择继续生长**：通过人物、制度、文字、地点、物件和记忆回收，而不是旁白结算善恶。
5. **逐步改变“我是谁”的问题**：从寻找私人前世，转向理解无数普通人的共同经验。

### 2.2 三项不可动摇的设计支柱

#### 普通人不是历史背景

大事件必须落到一条路、一份名册、一户人的役期、一船粮、一场救治或一封未送达的信上。

#### 选择改变人间尺度，不抹掉历史

玩家不能阻止秦统一、安史之乱、宋元易代或近代民族危机，却能改变谁活下来、谁被写下、某项制度在一地如何执行，以及后来人能够依据什么理解当时。

#### 记录本身也是权力

每章都要同时追踪：

```text
事实发生了什么。
玩家知道什么。
官档怎样写。
私人怎样记。
民间怎样讲。
谁为这个版本承担代价。
```

## 3. 职业与社会位置规则

职业不是开局菜单，不是战斗职业，也不是善恶阵营。

职业决定：

```text
玩家最先看见什么。
玩家能动用什么资源。
谁会来邀请、拒绝或托付玩家。
玩家必须对哪一类后果负责。
本章能留下哪一种独有证据。
```

职业数量不固定，按章节主题裁剪。

第一章《钟裂于洛水》当前固定为：

```text
八职业线 + 乡土地基 + 隐退倾向。
```

八职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”不再作为第一章独立职业线。

```text
土地、粮水、田亩、空户、旧渡、灶火、没有米下锅、禾安和粥碗，属于所有职业共同面对的乡土地基。
```

“隐士”不再作为第一章独立职业线。

```text
隐退、私藏见证、不入官档、少介入和晚年去向，属于所有职业都可能附着的隐退倾向。
```

后续章节可以按本章经验继续裁剪，不强行恢复十职业。

## 4. 双重长线

### 4.1 外部主线：谁组织山河

```text
旧礼失效
→ 新法与统一
→ 帝国制度进入日常
→ 帝国崩裂、流亡与再组织
→ 盛世、边疆与劳动代价
→ 文治、商业、技术与覆亡
→ 旧帝国面对工业与世界体系失配
→ 无名者组织起来并成为历史主体
```

### 4.2 内部主线：苏醒者是谁

| 阶段 | 苏醒者的理解 | 必须获得的叙事证据 |
|---|---|---|
| 序章 / 第一章 | 我可能拥有一个特殊前世 | 裂钟、旧曲、名籍空格和互不完整的熟悉感 |
| 第二章 | 我不属于一个私人谱系 | 多种互相矛盾的身份经验同时出现 |
| 第三章 | 我记得的“故乡”不止一处 | 迁徙者、留守者和异乡人的记忆重叠 |
| 第四章 | 我在盛世中心与边地代价中同时醒来 | 城市繁荣与输血边疆的共同经验 |
| 第五章 | 我不是某个文明精英的转世 | 商贩、工匠、军民、亡国者经验同时复苏 |
| 第六章 | 我的记忆总在共同劳动和共同受难中出现 | 港口、船坞、乡村、工册与旧戏互相呼应 |
| 第七章 | 我不是替人民发言的人，我就在他们之中 | 组织、互助、记录和牺牲由许多普通人共同完成 |
| 终章 | 我是千千万万无名者共同的历史回声 | 全部载体汇流，但答案仍由活着的人继续书写 |

苏醒不是外来灵魂夺取身体。每一世的姓名、家庭和成长经验都真实属于本世；异常只在于，本世经验之下还会浮起不属于任何单一个人的共同回声。

## 5. 一章一生与章节窗口

基本纪律：

```text
每章选择普通人能够活过的关键窗口，不承担连续展示整部通史。
主交互跨度原则上为 30—70 年。
开场从少年或青年开始，结尾完成本世关系、职业和因果交接。
更早历史通过制度遗产、地方记忆、旧物和传说进入。
更晚历史通过晚年短尾声或下一章遗产进入。
不为罗列名人而任意延长寿命。
历史研究优先核对制度、称谓、衣食住行和普通人的行动边界。
```

全章节推荐窗口：

| 章 | 历史主题范围 | 推荐主交互窗口 | 本章主要转折 |
|---|---|---|---|
| PROLOGUE《雨来之前》 | 第一章前置 | 前 286 年旧渡雨前至翻车选择 | 本世姓名、宋亡流民、裂钟、第一选择 |
| CH01《钟裂于洛水》 | 礼崩之世 / 春秋战国遗产 | 约前 286—前 221 年 | 雨后流民、新法现实、百家余响、长平、天下归一 |
| CH02《大一统之梦》 | 秦汉 | 约前 218—前 180 年，晚年可略后 | 秦制日常、徭役戍边、秦末、楚汉、汉初继承与调整 |
| CH03《裂土与风骨》 | 魏晋南北朝 | 约 307—347 年，晚年可至东晋中期 | 永嘉之乱、洛阳崩裂、南渡、侨置、门阀与流民 |
| CH04《长安与边塞》 | 隋唐 | 约 730—763 年，晚年进入战后 | 天宝盛世末期、边塞输血、安史之乱、战后重建 |
| CH05《文治与铁骑》 | 宋元 | 约 1234—1285 年 | 南宋末世、商业与文治、战争、宋亡、元初重组 |
| CH06《旧梦与海潮》 | 明清制度遗产与晚清转折 | 约 1835—1865 年，人生可收束至 1895 年前后 | 海上冲击、战争、条约、内乱、船政与旧制失配 |
| CH07《山河重铸》 | 近现代 | 约 1905—1949 年 | 学堂与工厂、旧制退出、民族危机、社会组织、革命与新中国成立 |
| FINAL《无名者有名》 | 新时代门槛 | 1949 年后的象征性尾声 | 人民以自己的名字保存和继续历史 |

## 6. 章节接力总表

| 章 | 项目责任 | 核心问题 | 必须承接 | 必须交出 |
|---|---|---|---|---|
| 序章 | 让苏醒者落入本世 | 这一世从哪一笔开始？ | 全局起点 | 第一选择、裂钟初响、名与籍母题 |
| CH01 | 建立整套叙事语法 | 旧礼失效后，新法与统一是否能救乱世？ | 序章第一选择 | 无名录、裂钟、旧曲、新法木牌、长平旧债、禾安粥碗、统一之问 |
| CH02 | 让第一章争论成为帝国日常 | 统一以后，人真的安定了吗？ | 第一章无名录去向、编户、长平旧债 | 秦汉旧档、戍卒家书、楚汉旧债、史官未竟之笔、汉初制度 |
| CH03 | 证明制度会崩裂，而共同生活仍需被重建 | 帝国裂开以后，人靠什么维持尊严与共同生活？ | 大一统制度、史书、边地戍守、家户身份 | 侨置名册、江南渡口、门阀族谱、北地孤碑、无名录抄页 |
| CH04 | 从盛世内部看见边地、交通和劳动代价 | 盛世是否真的覆盖了边地白骨？ | 南渡经验、谱牒、重新统一、旧曲 | 长安灯火、边塞诗稿、丝路账簿、水利工图、安史残旗 |
| CH05 | 检验文明繁荣与政治军事生存并非同一件事 | 文治、商业和技术为何不能自动阻止覆亡？ | 城市、诗文、边疆压力、旧曲和工图 | 刻印残页、商税账簿、海路图、亡国曲、火器工记 |
| CH06 | 让旧帝国与工业化世界正面碰撞 | 旧制度面对新世界时为何失去组织未来的能力？ | 海贸、技术、亡国记忆、账簿与旧戏 | 海图、条约副本、船坞名册、海外来信、工人和乡民的新记录 |
| CH07 | 让无名者从被治理对象成为组织与创造主体 | 当旧秩序无法承载山河，谁来重新命名山河？ | 条约、工厂、乡村、学校、旧曲与无名名册 | 人民自己的档案、未完成的名册、公共纪念与未来问题 |
| 终章 | 回收苏醒者身份并打开未来 | 苏醒者是谁，山河由谁命名？ | 全部人物、制度、文字、地点、遗物与记忆 | 不再埋身份悬念；把继续书写的权利交给人民 |

## 7. 当前制作重点

### 7.1 序章《雨来之前》

序章负责本世入口，不是高频选择题关卡。

制作节奏固定为：

```text
动画化叙事 + 轻探索 + 少量关键选择
```

序章负责到：

```text
主角做出第一选择：先救孩子 / 先抢湿简 / 先让活人互认。
```

### 7.2 第一章《钟裂于洛水》

主题：礼崩之世。

第一章从序章三选一后果开始。

它必须完成：

```text
雨后流民。
旧仓与旧册。
新法入乡。
职业自然成形。
百家灯火。
战争前夜。
长平血雾。
长平后归旧渡，禾安问阿梁消息。
晚年回旧渡，禾安已逝，只留下粥碗。
秦统一与无名录去向。
```

第一章不得重复序章可玩剧本。

## 8. 系统框架

### 8.1 核心系统

```text
人物关系系统：信任、距离、债、秘密、风险。
资源系统：粮、药、钱、时间、证据、制度权限。
事实 / 记录分层：事实、官档、私录、口述、玩家认知。
职业责任系统：职业决定可见信息、可用资源和必须承担的后果。
因果节点系统：选择进入人物、制度、物件和后世。
记忆碎片系统：裂钟、旧物、声音和场景触发共同回声。
章节交接系统：每章根据合法分支生成交接包。
```

### 8.2 交接包字段

每章结束至少输出：

```text
historical_result
route_result
core_character_fates
truth_state
official_record
private_record
oral_version
primary_carrier
secondary_traces
institutional_legacy
memory_cue
unanswered_question
mandatory_callbacks
```

## 10. 开发原则

```text
网页用于验证核心叙事，不应无限堆单文件 HTML。
正式方向优先 Godot 第一章垂直切片。
内容与运行时分离，剧情条件和状态变化不得写死在 UI 中。
所有重要选择都要通过事件记录，便于存档升级、路线审计和跨章回收。
先证明序章与第一章能成立，再扩展后续章节。
```
