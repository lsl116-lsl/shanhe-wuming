# 《山河无名》项目总框架 V0.4

> 文档状态：当前最高层项目与叙事规范
>
> 版本日期：2026-07-01
>
> 版本定位：在 V0.3 的“一章一生、系统闭环、第一章至第二章接口”基础上，补齐第二章至终章的项目定位、历史窗口、故事责任和逐章交接，并确定章节式历史叙事人生 RPG / AVG 的产品形态、视觉方向与开发原则。
>
> 核心母题：无名不是没有名字。无名的名字，是人民。

## 0. V0.4 的核心结论

《山河无名》最适合做成：

> **以 AVG 为主体、以轻量人生 RPG 为骨架的章节式历史叙事游戏。**

比例建议：

```text
叙事、调查、对话与选择：约 70%
关系、资源、职业责任与因果管理：约 30%
```

项目不依靠高频战斗、等级刷取、装备数值和随机抽卡制造循环。它真正的循环是：

```text
进入一段人生
→ 认识具体的人
→ 从一个社会位置理解时代
→ 在有限信息和资源中选择
→ 事实、关系与记录发生分歧
→ 承担本世结果
→ 将一部分因果交给后世
→ 下一章在新的现实事件中回收
```

全游戏不是七部松散的朝代短篇，而是一场逐章推进的长问题：

```text
谁建立秩序
→ 谁承担秩序
→ 秩序崩裂后谁保存共同生活
→ 盛世由谁供养
→ 文明为何不能自动免于覆亡
→ 旧制度为何无法组织新世界
→ 无名者如何成为历史主体
```

## 1. 项目定位

### 1.1 核心一句话

一个不知来处的苏醒者，在中国历史的关键转折处一次次醒来，每一世都成为时代中的普通人；他起初寻找自己的名字，最终发现自己是千千万万无名者共同的历史回声。

### 1.2 类型定义

| 项目维度 | 定义 |
|---|---|
| 产品类型 | 单机、章节式、历史叙事人生 RPG / AVG |
| 叙事类型 | 中国历史长河、轮回人生、普通人视角、跨章因果 |
| 核心玩法 | 阅读与调查、关系选择、职业责任、有限资源、事实与记录分层 |
| 章节结构 | 每章一段完整人生；章节之间跨越年代，由制度、文字、地点、后人、遗物和共同记忆连接 |
| 核心体验 | 在个人无法改写的大势中，决定怎样活、怎样承担、让谁被记住 |
| 长线动力 | 寻找苏醒者身份，追踪因果在后世如何变形、断裂和重生 |
| 目标平台 | 先以网页验证叙事，正式版以 PC 为核心并评估移动端；微信小游戏仅作为可选发行支线 |
| 发行方式 | 先序章 / 第一章垂直切片，后按章持续制作和发布 |

### 1.3 本项目不是什么

- 不是随机投胎模拟器。
- 不是朝代百科和历史知识问答。
- 不是帝王将相改史爽文。
- 不是十条互不相干的职业副本。
- 不是用现代知识碾压古人的穿越故事。
- 不是靠善恶值、好感度和完美选项判定人生。
- 不是以战斗刷取、装备收集或抽卡驱动的数值 RPG。
- 不是把“人民”作为终章突然贴上的口号。

## 2. 玩家体验与设计支柱

### 2.1 五项体验承诺

每章都必须让玩家：

1. **活在时代里**
   - 有姓名、家庭、师友、职业、债务、疾病、饥饿、劳役和无法轻易舍弃的人。
2. **从社会位置看历史**
   - 同一事件在农人、吏官、医者、商贾、工匠、乐人和军卒眼中并不相同。
3. **面对没有纯净答案的选择**
   - 救一户可能连累邻户；保存真名可能暴露活人；统一标准可能同时打破特权和伤害具体家庭。
4. **看见选择继续生长**
   - 通过人物、制度、文字、地点、物件和记忆回收，而不是由旁白结算善恶。
5. **逐步改变“我是谁”的问题**
   - 从寻找私人前世，转向理解无数普通人的共同经验。

### 2.2 三项不可动摇的设计支柱

#### 普通人不是历史背景

大事件必须落到一条路、一份名册、一户人的役期、一船粮、一场救治或一封未送达的信上。

#### 选择改变人间尺度，不抹掉历史

玩家不能阻止秦统一、安史之乱、宋元易代或近代民族危机，却能改变谁活下来、谁被写下、某项制度在一地如何执行，以及后来人能够依据什么理解当时。

#### 记录本身也是权力

每章都要同时追踪：

```text
事实发生了什么
玩家知道什么
官档怎样写
私人怎样记
民间怎样讲
谁为这个版本承担代价
```

## 3. 双重长线

### 3.1 外部主线：谁组织山河

```text
旧礼失效
→ 新法与统一
→ 帝国制度进入日常
→ 帝国崩裂、流亡与再组织
→ 盛世、边疆与劳动代价
→ 文治、商业、技术与覆亡
→ 旧帝国面对工业与世界体系失配
→ 无名者组织起来并成为历史主体
```

### 3.2 内部主线：苏醒者是谁

| 阶段 | 苏醒者的理解 | 必须获得的叙事证据 |
|---|---|---|
| 第一章 | 我可能拥有一个特殊前世 | 裂钟、旧曲和互不完整的熟悉感 |
| 第二章 | 我不属于一个私人谱系 | 多种互相矛盾的身份经验同时出现 |
| 第三章 | 我记得的“故乡”不止一处 | 迁徙者、留守者和异乡人的记忆重叠 |
| 第四章 | 我在盛世中心与边地代价中同时醒来 | 城市繁荣与输血边疆的共同经验 |
| 第五章 | 我不是某个文明精英的转世 | 商贩、工匠、军民、亡国者经验同时复苏 |
| 第六章 | 我的记忆总在共同劳动和共同受难中出现 | 港口、船坞、乡村、工册与旧戏互相呼应 |
| 第七章 | 我不是替人民发言的人，我就在他们之中 | 组织、互助、记录和牺牲由许多普通人共同完成 |
| 终章 | 我是千千万万无名者共同的历史回声 | 全部载体汇流，但答案仍由活着的人继续书写 |

全局根节点：

```text
SW-GLOBAL-001 苏醒者身份
SW-GLOBAL-002 从无名者到人民
```

苏醒不是外来灵魂夺取身体。每一世的姓名、家庭和成长经验都真实属于本世；异常只在于，本世经验之下还会浮起不属于任何单一个人的共同回声。

## 4. 一章一生与章节时间

### 4.1 基本纪律

- 每章选择普通人能够活过的关键窗口，不承担连续展示整部通史。
- 主交互跨度原则上为 30—70 年。
- 开场从少年或青年开始，结尾完成本世关系、职业和因果交接。
- 更早历史通过制度遗产、地方记忆、旧物和传说进入。
- 更晚历史通过晚年短尾声或下一章遗产进入。
- 不为罗列名人而任意延长寿命。
- 历史研究优先核对制度、称谓、衣食住行和普通人的行动边界。

### 4.2 全章节推荐窗口

| 章 | 历史主题范围 | 推荐主交互窗口 | 本章主要转折 |
|---|---|---|---|
| CH01《礼崩之世》 | 春秋战国遗产 | 约前 286—前 221 年 | 宋地流民、新法现实、百家余响、长平、天下归一 |
| CH02《大一统之梦》 | 秦汉 | 约前 218—前 180 年，晚年可略后 | 秦制日常、徭役戍边、秦末、楚汉、汉初继承与调整 |
| CH03《裂土与风骨》 | 魏晋南北朝 | 约 307—347 年，晚年可至东晋中期 | 永嘉之乱、洛阳崩裂、南渡、侨置、门阀与流民 |
| CH04《长安与边塞》 | 隋唐 | 约 730—763 年，晚年进入战后 | 天宝盛世末期、边塞输血、安史之乱、战后重建 |
| CH05《文治与铁骑》 | 宋元 | 约 1234—1285 年 | 南宋末世、商业与文治、战争、宋亡、元初重组 |
| CH06《旧梦与海潮》 | 明清制度遗产与晚清转折 | 约 1835—1865 年，人生可收束至 1895 年前后 | 海上冲击、战争、条约、内乱、船政与旧制失配 |
| CH07《山河重铸》 | 近现代 | 约 1905—1949 年 | 学堂与工厂、旧制退出、民族危机、社会组织、革命与新中国成立 |
| 终章《无名者有名》 | 新时代门槛 | 1949 年后的象征性尾声 | 人民以自己的名字保存和继续历史 |

## 6. 第一章定位与交接锚点

### 6.1 项目定位

第一章不是全史序章，而是整套叙事语法的建立章。它必须让玩家第一次理解：

- 一章是一段完整人生。
- 历史大势不可由个人翻转。
- 职业是社会位置，不是人格和战斗职业。
- 选择同时进入人物、制度和文字。
- 普通人不是时代背景。
- 统一不是结论，而是下一轮问题的开始。

### 6.2 交给第二章

第一章强制交出：

```text
SW-CH01-001 裂钟
SW-CH01-003 亡国旧曲
SW-CH01-007 旧臣遗孤
SW-CH01-010 新法木牌
SW-CH01-018 长平白骨
SW-CH01-019 无名录
SW-CH01-022 无名录去向
SW-CH01-024 第一声真正提示
```

`SW-CH01-022` 决定第二章开场载体为官藏、家属与行旅、裂钟旧库或乐人旧曲。四线最终都汇入“核定户、田与役”这一共同现实事件。

完整衔接正文见 `docs/chapters/CH01_礼崩之世/07_至CH02衔接过渡文_V0.1.md`。

## 7. 第二章《大一统之梦》

### 7.1 项目定位

第二章负责证明：第一章讨论的“新法、户籍、军功、郡县和统一”不会在统一完成后停止，它们会进入每一户、每一笔、每条路和每一次征发。

本章不能把秦只写成暴政标签，也不能把统一措施写成功业展览。重点是同一种高度组织能力如何同时修路、统一尺度、调动资源，又怎样将沉重义务精确压到普通家庭。秦亡汉兴也不能写成旧苦难自动结束；汉初必须呈现继承、缓和和调整并存。

### 7.2 共同人生前提

苏醒者约在前 218 年以少年身份醒于秦三川郡范围内的一户编户家庭。开场第一件事不是见皇帝，而是协助本户完成户、田、役的核定。玩家从旧简、家书、裂钟夹藏或旧曲中接住第一章载体。

本世可经历：

1. 统一文字、尺度、道路和郡县成为生活现实。
2. 户籍、田亩、徭役和戍边进入家庭选择。
3. 帝国组织能力与家庭承受极限同时显现。
4. 秦末动荡和楚汉战争让统一秩序迅速崩裂。
5. 汉初在继承和调整中重建秩序。

### 7.3 核心问题

```text
统一以后，人真的安定了吗？
同一种文字和律令，是否让所有人更有名字？
一个王朝崩溃后，支撑它的制度会不会继续活着？
```

### 7.4 必须回收

- 第一章无名录去向，并体现载体已经被重抄、删改或误解。
- 新法木牌所代表的编户、军功、征发和连坐现实。
- 长平生还、失踪和后人债务，不要求一定存在血缘后代。
- 旧曲或裂钟只保留变形痕迹，不能完整保存原貌。
- 苏醒者同时熟悉官吏、农户、戍卒和乐人的经验，排除单一谱系。

### 7.5 必须埋下

```text
秦汉旧档：同一户在王朝更替前后的不同写法
戍卒家书：北地义务、家庭债务和未归者
楚汉旧债：乱世中的互救、背叛与改名
史官未竟之笔：事实、传闻与成书之间的距离
汉初玉印或基层印记：制度继承而非神器
重新抄写的无名录：名字被纳入帝国书写后的变化
```

### 7.6 交给第三章

主载体不是“千年不坏的秦简”，而是若干代重抄、并入地方档案的秦汉户籍残件，以及一封被后人当作家谱旁证的戍卒家书。

章节交接场景种子：

> 旧档已经认不出最初的笔迹。纸页上的姓氏被补过三次，祖籍被改过两次。洛阳城中，有人拿它证明自己属于这里，也有人据此证明另一家不属于这里。远处的钟声再响时，不再是统一开始，而是统一即将崩裂。

交接问题：

> 如果帝国本身也会碎裂，人靠什么保住身份、故乡和共同生活？

## 8. 第三章《裂土与风骨》

### 8.1 项目定位

第三章负责把“大一统”从理所当然重新变成失去之后的经验。所谓“风骨”不能只属于名士清谈，也必须属于背着孩子渡江的母亲、守住医方的医者、在乱军间护送同乡的脚夫，以及拒绝把流民只写成数字的小吏。

本章不能把魏晋写成纯粹浪漫的名士时代，也不能把南渡写成单向的文明移植。北方留守者、南迁者、当地居民、门阀和流民都要拥有各自的利益与尊严。

### 8.2 共同人生前提

苏醒者约在 307 年前后于洛阳或黄河交通线上醒来。家户身份与秦汉旧档有关，但这份关系既可能保护本家，也可能排斥别家。永嘉之乱到来后，玩家面对留北、南渡、护送、从军、行医、抄录或依附门阀等社会位置。

本章共享人生不要求所有路线都到建康；留在北方和迁往南方是同一场崩裂的两面，最终通过信件、名册与失联汇流。

### 8.3 核心问题

```text
帝国裂开以后，人靠什么维持尊严与共同生活？
“故乡”是土地、名册、语言，还是仍愿意接纳你的人？
保存家族名字与保存无名者，是否必然冲突？
```

### 8.4 必须回收

- 秦汉户籍残件在乱世中从治理工具变成身份证明、迁徙凭据或排斥依据。
- 戍卒家书被误作家谱证据，玩家可揭示或继续利用误认。
- 汉代制度并未因王朝崩裂消失，而是在地方、门阀和迁徙中变形。
- 无名录抄页与正规族谱发生第一次正面冲突。
- 苏醒者对北地与江南都产生“曾经生活过”的错位熟悉。

### 8.5 必须埋下

```text
江南渡口：迁徙、离散与重新安置的地点记忆
侨置名册：旧籍、新籍和谁有资格被承认
门阀族谱：保存名字，也制造名字的等级
北地孤碑：留守者与失去回信的人
无名录抄页：不按门第排列的民间记录
渡江旧曲：亡国曲再次变形，成为离乡曲
```

### 8.6 交给第四章

主要交出三类遗产：

1. 南渡家户与侨置制度留下的身份结构。
2. 北地孤碑和失联书信留下的未完成故乡。
3. 由民间抄页保存、后被乐人与商旅传播的旧曲。

章节交接场景种子：

> 数代之后，侨姓与土姓都成了旧称。渡口仍在，名册却换了格式。一个赶往长安的年轻乐人从破谱里唱出半句离乡曲；同行的工匠听不懂旧词，只觉得那节拍适合抬石。曾经用来辨认流民的字，开始写进一个重新统一的王朝。

交接问题：

> 当山河重新统一、城市重新辉煌，谁在中心享受盛世，谁在边地和道路上供养它？

## 9. 第四章《长安与边塞》

### 9.1 项目定位

第四章负责拆开“盛世”这个过于完整的词。它既要让玩家真实感受长安的开放、工艺、贸易、诗歌和制度能力，也要让玩家看见灯火所依赖的漕运、驿路、边防、征调和无数劳动。

安史之乱不是为了摧毁一幅盛世壁纸，而是检验此前所有关系：城市与边地是否真正相知，中心能否看见长期承担代价的人，文化繁荣能否自动转化为共同安全。

### 9.2 共同人生前提

苏醒者约在 730 年前后成为进入长安或与长安相连的年轻人。入口可以是工匠、军户、商旅、驿卒、农户、医者、乐人或基层文吏，但所有路线共享“中心如何获得粮、信、兵、工与故事”的主线。

前半章建立盛世生活，不能急着用灾难否定一切；后半章才让安史之乱把中心和边地的旧债同时逼到眼前。

### 9.3 核心问题

```text
盛世是否真的覆盖了边地白骨？
中心的繁荣由谁运输、守卫和承担？
诗歌与记录能否在灾难中保护具体的人？
```

### 9.4 必须回收

- 南渡形成的家户与谱牒如何进入重新统一后的社会位置。
- 渡江旧曲进入长安后被宫廷、民间和边地分别改写。
- 北地孤碑的地名在边塞路线中重新出现，但含义已经变化。
- 无名录抄页影响工役、军籍或救济记录的写法。
- 苏醒者同时熟悉长安灯火和边塞风沙，进一步排除单一阶层前世。

### 9.5 必须埋下

```text
长安灯火：中心繁荣的视觉母题
边塞诗稿：署名作品背后被删去的同行者
丝路账簿：跨地域交换与风险承担者
水利或工部工图：劳动如何成为盛世基础
驿路失信：消息、命令与逃难路线
安史残旗：战争中的立场变化，不作为英雄神器
旧曲入宫与出宫：同一旋律的权力版本与民间版本
```

### 9.6 交给第五章

主要交出的是城市治理、商业网络、印刷前身、工图传统、边防经验，以及一首从盛唐宫廷退回民间的旧曲。

章节交接场景种子：

> 长安的灯火熄灭过，又被后人写得比从前更亮。水图被辗转抄录，边塞诗只剩名句，抬粮和埋尸的人仍无名。数百年后，一座江南城市的刻坊里，旧诗、工图和商账被放在同一张案上。纸比旧日更便宜了，名字是否也因此更容易留下？

交接问题：

> 当文字、商业、城市和技术都抵达新的高度，为什么文明仍不能自动免于覆亡？

## 10. 第五章《文治与铁骑》

### 10.1 项目定位

第五章负责打破“文化繁荣等于政治军事安全”的简单想象。宋元章不能只写文人风雅和亡国悲情，也不能把征服者写成单一面孔的外部铁骑。城市居民、农户、商旅、工匠、军民、不同族群和新旧统治下的基层执行者都必须进入同一现实。

“文明”在本章不是护身符，而是人在覆亡中仍可携带、重组和分享的能力。

### 10.2 共同人生前提

苏醒者约在 1234 年前后于南宋城市、河道或港口网络中成长。前半章让玩家生活在商业、印刷、教育、工艺和地方治理中；后半章经历长期战争、流亡、宋亡与元初重组。

路线可以改变家庭迁徙、城镇供应、文书保存和人与人之间的债，不能凭一人之力挽救王朝。

### 10.3 核心问题

```text
文治、商业和技术为何不能自动阻止覆亡？
亡国以后，文化属于旧王朝、少数士人，还是仍在生活的人？
在新秩序中继续活下去，是背叛还是承担？
```

### 10.4 必须回收

- 唐代工图在宋代被重绘、改进并用于现实工程。
- 丝路账簿转化为城市、河运与海贸网络。
- 边塞诗和旧曲被刻印、演唱，也被重新署名。
- 安史之后的征调和地方自治经验成为宋代制度记忆。
- 无名记录第一次借更广泛的纸张和刻印传播，但也更容易复制错误。

### 10.5 必须埋下

```text
商税与行旅账簿：繁荣的流向和承担风险的人
刻印残页：文字扩大传播后的真实与误写
海路图：从地方贸易进入更大的海上世界
火器与工艺笔记：技术积累及其使用者
亡国曲或杂剧雏形：旧曲再次变成大众叙事
崖山海风：失去、选择与被神话化的记忆
新朝名册：同一批人如何被新的制度重新分类
```

### 10.6 交给第六章

海路图、工艺笔记、商账和旧戏不会原封不动跨越数百年。它们通过后世重刊、地方志摘录、家业传说和戏台唱本留下不同完整度的后果。

章节交接场景种子：

> 海路被后人画得更远，旧港的名字却从图上消失。火器工记只剩一页，被夹在地方志里当成奇闻；亡国曲早已唱不出原调，却仍有人在戏台上为失去的城落泪。海面出现从未见过的船影时，旧知识并非全无，只是它已不能让旧制度理解眼前的世界。

交接问题：

> 当世界的尺度、速度和武力都已经改变，旧制度为何无法把已有知识组织成新的未来？

## 11. 第六章《旧梦与海潮》

### 11.1 项目定位

第六章负责表现一个庞大旧帝国面对工业化、全球贸易和殖民扩张时的结构性失配。本章不能归结为“器物落后”或“文明不如人”，也不能让少数开眼者独占智慧。港口、船坞、乡村、军营、商路和内乱中的普通人才是变化的承受者与尝试者。

“明清”在本项目中是制度遗产范围，主交互窗口集中于晚清转折。明代海贸、火器、工艺、基层组织和旧戏通过地方志、家业与制度惯性进入，不另造一名跨越数百年的角色。

### 11.2 共同人生前提

苏醒者约在 1835 年前后进入青年期，出生地可在港口或与港口相连的内陆家户。主线通过货物、税、信件、迁徙和征调把海上冲击传入内地。

本世经历战争、条约、内乱、船政与新式工场的早期尝试，晚年可收束到 1895 年前后，以确认旧制度无法只靠局部修补继续组织世界。

### 11.3 核心问题

```text
旧制度面对新世界时，为何失去组织未来的能力？
学习新技术是否等于接受强者写下的世界秩序？
谁承担战争、赔款、内乱和改革试错的代价？
```

### 11.4 必须回收

- 宋元海路图与现实海图之间的断裂和延续。
- 火器工艺笔记证明技术并非从零开始，但制度组织方式已经失配。
- 商账进入全球贸易后改变价格、债务和家庭命运。
- 旧戏台演出的亡国故事与现实民族危机互相照见。
- 无名录由战乱死者名册进一步转向工场、船坞、乡里和迁徙记录。

### 11.5 必须埋下

```text
新旧海图：世界尺度改变，也暴露旧知识体系的边界
条约副本：国家文本如何进入具体人的税、地和生计
船坞或工场名册：共同劳动形成新的社会关系
海外来信：见闻、误解、求学和离散
乡民自救册：基层互助与组织经验
报刊剪页或新式学堂材料：公共讨论的萌芽
旧戏台的新唱词：共同记忆开始使用新的语言
```

### 11.6 交给第七章

本章不把答案交给某位改革英雄，而是交出一组尚未汇流的新主体：工人、学生、士兵、商人、乡民、女性组织者、海外归来者和基层记录者。

章节交接场景种子：

> 老人在旧戏台下听见少年改了唱词。台后堆着船坞名册、学堂课本和一张被雨打湿的条约副本，它们本不该属于同一个故事。铁路汽笛越过河面时，少年问的已不是怎样救回一个旧朝，而是谁有权决定这片山河接下来怎样生活。

交接问题：

> 当旧秩序已无法承载现实，无名者能否组织起来，成为历史的行动者而非代价？

## 12. 第七章《山河重铸》

### 12.1 项目定位

第七章不是又一次王朝更替，而是整个项目从“谁治理人民”转向“人民如何组织自身、认识自身并参与创造历史”的决定章。

本章必须避免把人民写成抽象整齐的群体。工人、农民、学生、基层士兵、女性、知识分子、商贩和不同地域的人有真实差异、误解和冲突。共同主体不是天然存在，而是在劳动、互助、斗争、失败、学习和牺牲中形成。

### 12.2 共同人生前提

苏醒者约在 1905 年前后进入少年或青年期，从学堂、乡村、铁路、工厂、码头或城市基层生活进入主线。不同社会位置共享一组结构性事件：

1. 旧君主制退出，但旧社会关系并未自动消失。
2. 新式教育、工厂、铁路、报刊和组织方式进入生活。
3. 民族危机和长期战争不断改变家庭与地方。
4. 无名者由各自承受转向建立联系、共同记录和共同决策。
5. 1949 年成为新时代门槛，而不是一切矛盾终结。

### 12.3 核心问题

```text
当旧秩序无法承载山河，谁来重新命名山河？
分散的普通人如何成为能够共同选择和行动的人民？
新的公共记录怎样避免再次把具体的人变成数字？
```

### 12.4 必须回收

- 条约副本进入土地、税、工厂、战争和地方生计。
- 船坞与工场名册转化为工人的共同身份和组织记忆。
- 乡民自救册进入乡村互助与新的社会组织。
- 海外来信、学堂材料和报刊形成新的公共语言。
- 旧曲不再只悼亡，而被不同群体改写为共同唱出的行动之声。
- 历代无名录的“由别人记录”逐渐转向“由当事人自己记录”。

### 12.5 必须埋下并在本章完成

```text
学堂课本：谁有权解释历史
工人名册：共同劳动者如何认识共同处境
乡村互助或农会记录：分散家庭如何建立公共行动
交通员家书：宏大行动中的具体关系和代价
无名烈士碑：纪念、遗漏与仍待查明的名字
人民自己的书：终章公共档案的前身
```

### 12.6 交给终章

第七章交出的不再是少数人保管的秘物，而是一份由许多人维护、允许补写和纠错的公共档案。它仍不完整，仍有空白，但空白不再被当作无关紧要。

章节交接场景种子：

> 新纸铺在旧案上。有人写烈士，有人写失散家人，有人写修路、运粮、教书和照料伤员的人。名字不断被补上，也不断有人指出写错了。裂钟般的声音再次响起，这一次不是从地下或梦里传来，而是许多人同时搬动桌椅、翻开纸页、开口争辩的声音。

交接问题：

> 如果苏醒者从来不是一个等待找回的私人名字，那么这些共同留下历史的人，是否就是他一直寻找的答案？

## 13. 终章《无名者有名》

### 13.1 项目定位

终章不是再开始一段完整朝代人生，也不是用全知旁白宣布标准答案。它是一段较短的汇流与开放式尾声：让历代载体、地点、制度、文字和普通人的选择在一个公共空间中重新相遇。

1949 年是旧秩序结束和新历史开启的门槛，不是历史终点，也不是所有问题自动消失。项目的终点应当把“继续书写、纠错和创造”的权利留给活着的人。

### 13.2 终章事件

推荐把终章设在一个由民众共同参与的档案整理、纪念设施、公共工程或演出现场。历代线索以不同完整度进入：

- 裂钟已被重铸、损毁或只剩拓片与声音记忆。
- 无名录成为许多名册、家书、碑文、账簿和口述的谱系，而非一本圣物。
- 旧曲经过亡国、南渡、宫廷、民间、戏台和行动之歌，已没有唯一原版。
- 历代制度记录显示，普通人既被书写和管理，也逐步学会自己记录、组织和纠错。
- 苏醒者的熟悉感不再指向一位祖先，而指向共同劳动、共同承担和共同保存。

### 13.3 身份揭示

揭示必须由玩家此前经历推导：

```text
苏醒者不是帝王、名士或某一位无名英雄的轮回。
他是千千万万无名者共同经验留下的历史回声。
他寻找的不是一个被抹去的私人姓名。
“无名者”真正的共同名字，是人民。
```

### 13.4 最后一幕原则

- 不用神谕替代证据。
- 不让苏醒者高于人民或替人民发言。
- 不把新时代写成静止乌托邦。
- 最后一个动作应是补写、递交、共同建造、传唱或开启新的空白页。
- 最后一个问题不再是“我是谁”，而是“我们接下来怎样继续写”。

## 14. 逐章交接的统一规则

每章结束必须生成标准交接包：

```text
from_chapter
historical_result
human_result
primary_carrier
secondary_trace
institutional_legacy
descendant_or_witness
memory_cue
unanswered_question
mandatory_callback
```

载体必须遵守：

1. 物件会损毁、迁移、熔铸和失去上下文。
2. 文字会重抄、删改、误署名和被用于新的权力目的。
3. 口述传播更广，也会改词、合并和忘记。
4. 后人不继承祖先人格，只继承处境、传说、财产或债。
5. 制度与行为习惯的回收通常比完整遗物更重要。
6. 载体毁失后只能以残片、旁证或现实后果回收，不能完整复活。
7. 回收必须改变当前章的一项判断、关系或选择，不能只做收藏品说明。

## 15. 核心系统

### 15.1 共享主线与职业社会位置

每章所有职业共享同一组历史事件。职业决定：

- 能看见的信息。
- 可调用的资源。
- 拥有的制度权限。
- 必须承担的责任。
- 能为历史留下的独有证据。

职业不是人格和善恶。未选择的职业必须由重要 NPC 继续存在，避免世界围绕玩家停转。

### 15.2 人物关系

不使用单一好感度，至少记录：

```text
trust       是否相信玩家会守约
shared_debt 双方共同承担的具体事件
rift        无法靠送礼消除的立场裂痕
whereabouts 生还、死亡、失踪、迁徙、改名
testimony   此人掌握的证言
carrier     此人带入后世的载体
```

### 15.3 因果与档案

```text
truth_state       实际发生
player_knowledge  玩家知道
official_record   官档记载
private_record    私人记载
oral_version      口述版本
cost_bearer       代价承担者
carrier           跨章载体
scheduled_return  预定回收事件
```

### 15.4 记忆

记忆分为残梦、情绪回声、因果共鸣、现实误认和明确提示。它只改变观察、询问和选择表述，不提供超时代技能、精确预知或最佳答案。

### 15.5 人生 RPG 的轻量资源

建议全游戏只保留少量可解释资源：

```text
生计：家庭与个人还能承担多少现实压力
声望：不同共同体对玩家的公开判断
信任：具体人物是否愿意交付风险
权限：当前职业和制度位置能做什么
体力 / 伤病：重大行动的身体代价
证据：玩家掌握但不一定能安全公开的记录
```

不设置传统力量、敏捷、智力升级树。能力成长通过关系、经验、工具、知识和社会位置体现。

## 16. 产品形态与内容规模

### 16.1 最适合的交互形态

推荐 2D 插画式 AVG：

- 半身人物立绘与少量表情差分。
- 场景插画分层视差。
- 地图、物件、文书和人物关系作为调查界面。
- 关键历史节点使用少量全屏事件插画。
- 低频、明确的资源与关系变化反馈。
- 人生末尾生成“本世档案”，而非传统分数结算。

轻 RPG 不应演变为大地图走格、频繁战斗和复杂装备。真正适合本题材的可玩空间是：

```text
去见谁
相信谁
公开什么
隐瞒什么
把有限粮、药、时间和权限给谁
以哪一种身份承担行动
最后把事实交给谁保存
```

### 16.2 建议内容规模

| 交付层级 | 建议规模 | 目的 |
|---|---|---|
| 核心原型 | 序章—ACT02，30—45 分钟 | 验证阅读、选择、状态和档案分层 |
| 垂直切片 | 第一章一条完整人生，首轮约 3—5 小时 | 验证美术、音频、职业差异和跨章交接 |
| 单个正式章节 | 首轮约 2.5—4 小时 | 保持章节可制作、可回看 |
| 全游戏 | 七章加终章，首轮约 20—30 小时 | 形成长线历史体验 |

每章建议约 70% 共享内容、30% 社会位置差异；差异应改变理解、责任和结果，而不是复制十套完全独立剧本。

## 17. 视觉与声音方向

### 17.1 总体美术

推荐“纸、墨、漆、铜”作为跨时代底层材质，再用每章一种时代强调色变化。不要把整个中国历史压成高饱和宫墙红与帝王金。

基础界面色：

| 用途 | 色值 | 说明 |
|---|---|---|
| 墨黑 | `#12110F` | 主背景与深色文字 |
| 漆褐 | `#211A15` | 面板与沉浸背景 |
| 暖纸 | `#E7DDC6` | 正文与亮色底 |
| 旧灰 | `#A99B84` | 次级说明 |
| 青铜 | `#B28A4A` | 章节导航、重要但非危险信息 |
| 朱砂 | `#A64B3C` | 行动、危险、不可逆选择 |
| 记忆靛 | `#66758A` | 苏醒者回声与档案差异 |
| 新生绿 | `#73805C` | 互助、修复与终章开放方向 |

章节强调色：

| 章 | 强调色方向 | 情绪用途 |
|---|---|---|
| CH01 | 青铜土色、朱砂 | 礼器裂纹、新法与血 |
| CH02 | 黑石、铁灰、印泥红 | 秦制秩序、文字与征发 |
| CH03 | 江水蓝灰、芦苇青、灰白 | 南渡、雾、失去的故乡 |
| CH04 | 长安琥珀、边塞沙、烟火红 | 盛世灯火与战乱烟尘 |
| CH05 | 墨蓝、青瓷、铁色 | 城市文治、河海与覆亡 |
| CH06 | 海青、深靛、枪铁灰 | 世界海潮、工业与旧制 |
| CH07 | 纸灰、深红、土黄 | 报刊、组织、土地与牺牲 |
| 终章 | 暖纸、深红、新生绿 | 公共书写、建设与未完未来 |

颜色不得成为唯一信息通道。不可逆选择还要用图标、文字和声音提示；正文必须支持字号调整、高对比和减少动态效果。

### 17.2 画面风格

- 水墨与淡彩只作为材质语言，不追求所有内容仿古。
- 人物面孔和劳动动作要具体，避免千人一面的“古风美型”。
- 用分层插画、轻视差、局部烟尘、水光和纸页变化制造动态。
- 把预算优先给人物立绘、关键场景、文书物件和章节首尾插画。
- 少做昂贵却不能重复利用的全动画过场。

### 17.3 声音母题

- “裂钟”从断裂礼音逐步转化为工场、汽笛、敲击与众人共同劳动的声音。
- “旧曲”每章按时代、地域和社会位置变奏，不追求一个未经变化的原版。
- 环境声优先于持续铺满的配乐：风、河、木牌、书写、车轮、驿铃、织机、船坞、印刷和人群。
- 时代乐器服务人物与场景，避免用笼统“古风 BGM”覆盖所有朝代。

## 18. 技术与开发原则

详细实施见 `docs/08_项目落地方案_V0.1.md`。总纲只确立以下不可逆原则。

### 18.1 不把平台迁移当作项目进度

“网页 → 微信小程序 → Godot”不是天然正确的升级链，它意味着三套界面和运行环境。真正应该稳定的是与平台无关的内容数据、状态规则和存档格式。

推荐路线：

```text
网页原型验证叙事
→ 尽早用 Godot 制作第一章垂直切片
→ 根据发行目标决定是否另做微信小游戏演示 / 发行支线
→ Godot 完成 PC 正式版并评估移动端
```

如果微信生态是主要市场，则应单独立项评估 Cocos Creator 全程制作，而不是中期用 Cocos、后期再完整迁移 Godot。

### 18.2 平台无关内容核心

建议目录概念：

```text
content/
  schema/
  chapters/
  characters/
  causes/
  memories/
  records/
  assets/

apps/
  web/
  godot/
  wechat/     # 可选
```

故事文本、节点条件、关系变化、因果记录和跨章交接必须可验证、可版本化，不写死在具体 UI 组件中。

### 18.3 推荐正式引擎

正式版以 Godot 4.x、GDScript、2D 管线为优先方案：

- 适合 2D AVG、跨平台和资源管理。
- GDScript 便于小团队迭代。
- 若网页导出是正式目标，不选择 C# 主工程。
- 引擎升级在章节里程碑之间进行，不在剧本冲刺期追新版本。

截至 2026-07-01，Godot 4.7 刚发布不久。项目起步建议先锁定经过补丁验证的稳定分支，完成原型兼容测试后再升级，而不是仅凭版本号追新。

### 18.4 微信形态

若进入微信生态，应使用“微信小游戏”而不是普通“微信小程序”作为游戏载体。微信运行环境不是普通浏览器，需要处理分包、远程资源、缓存和平台 API。

微信支线只有满足以下任一条件才立项：

- 用户验证显示微信渠道对目标人群有明显价值。
- 计划发布 15—30 分钟的章节试玩或传播型序章。
- 团队愿意为 Cocos / 微信适配长期保留维护预算。

## 19. 制作与发布策略

### 19.1 先证明第一章

全七章是内容长线，不是当前一次性生产任务。当前只制作：

```text
第一阶段：序章—ACT02 核心原型
第二阶段：第一章完整垂直切片
第三阶段：第一章公开试玩与数据复盘
第四阶段：第二章预制作
```

只有第一章同时证明以下事项，才进入第二章完整制作：

- 玩家理解“事实与记录不同”。
- 职业差异带来不同责任，而非只是不同文本。
- 至少一个人物关系造成真实犹豫。
- 玩家能复述本章核心问题。
- 跨章载体令人期待，而非像强制悬念。
- 内容生产速度足以支持章节制。

### 19.2 推荐小团队结构

最小稳定配置：

```text
主创 / 叙事设计 1
历史研究与编辑 1
程序 / 技术设计 1
2D 美术 / UI 1
音频按阶段合作
```

一人团队也能启动原型，但必须严格控制美术、分支和工具链规模。完整七章属于多年项目，应以第一章验证结果决定扩充团队和融资，不应在立项文档中承诺不可信的短周期。

## 20. 风险与防坑规则

| 风险 | 典型症状 | 处理规则 |
|---|---|---|
| 通史膨胀 | 每章塞满名人和事件 | 每章只保留一生可亲历的三至六个关键转折 |
| 分支爆炸 | 十职业等于十套主线 | 70% 共享事件，30% 社会位置差异 |
| 选择虚假 | 选项只改一句台词 | 每个重要选择至少改变关系、资源、记录或后续责任之一 |
| 遗物神器化 | 同一物件千年完好 | 强制设置损毁、误抄、转义和断链 |
| 人民抽象化 | 普通人只有受苦与牺牲 | 必须写劳动、欲望、幽默、矛盾、组织和创造 |
| 历史工具化 | 为主题任意改制度常识 | 各章建立史实清单和争议清单，必要时保留不确定性 |
| 技术迁移浪费 | 每阶段重写 UI 和存档 | 先固定内容模式、状态事件和存档版本 |
| 美术失控 | 每场都需独立大图 | 建立可复用背景、人物、物件和局部动画模块 |
| 口号先行 | 终章答案压过人物经验 | 所有抽象结论必须由前章具体选择累积推出 |

## 21. 章节完成标准

### 时间与史实

- [ ] 一生跨度可信。
- [ ] 历史压力落到普通人的生活机制。
- [ ] 前史与后史的进入方式明确。
- [ ] 制度、称谓、物质生活经过章节史实清单校验。

### 人物与职业

- [ ] 至少三名故人拥有独立行动和不可被玩家完全控制的立场。
- [ ] 立场对立者不是纸片反派。
- [ ] 职业改变信息、资源、权限和责任，不预设善恶。
- [ ] 未选职业仍由 NPC 存在。

### 因果与交接

- [ ] 每个必埋节点有本章结果、跨章回收和断链兜底。
- [ ] 真相、官档、私录和口述分层。
- [ ] 载体发生符合时间跨度的损毁与转义。
- [ ] 回收实际改变当前章选择。
- [ ] 标准交接包完整。

### 记忆与母题

- [ ] 记忆先服务现实选择，不提供技能和预知。
- [ ] 身份揭示只推进一层。
- [ ] 普通人拥有生活、劳动、关系、矛盾和创造。
- [ ] “人民”由具体经验推导，不由旁白代替。

### 产品与制作

- [ ] 章节首轮时长和复玩差异符合目标。
- [ ] 每个关键选择有清晰且无剧透的反馈。
- [ ] 内容可由数据校验，不依赖手工遍历所有路线。
- [ ] 视觉资产量在当前团队产能范围内。
- [ ] 存档可升级，章节交接状态可测试。

## 24. 历史与技术校准说明

本框架的历史窗口用于确保人物寿命、社会位置和历史转折相容。各章节包已经建立第一轮史实锚点、禁止项和可戏剧化边界；进入正式制作前，仍须由对应时期的专业顾问复核争议、地理、物质生活和制度细节。

当前历史锚点包括：

- 秦于前 221 年完成统一，随后推行郡县、统一文字和度量衡。
- 秦末至汉初的主要转折集中在同一代人可亲历的时间范围内。
- 永嘉之乱与南渡、安史之乱、宋元易代、晚清转折和 1905—1949 年均可分别形成一段普通人能够活过的关键人生。

技术结论以 2026-07-01 的官方资料为校准日期，正式立项或升级前应重新核对引擎稳定版、导出限制和渠道规则。
