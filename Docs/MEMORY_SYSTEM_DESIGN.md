# 山河无名 Memory System Design

## 系统定位

记忆系统是连接五千年历史的核心系统。

玩家每一次人生结束，不是结束，而是积累。

---

## 核心对象

Soul（无名意识）

包含：

- LifeExperience
- PersonalMemory
- FamilyMemory
- HistoricalMemory

---

## 生命记录

每一世结束后保存：

- 姓名
- 出生地点
- 年龄
- 职业
- 家庭关系
- 重要选择
- 遇见的人
- 最后一句话

---

## 跨时代影响

下一时代可以通过：

- 后代
- 文化传承
- 民间故事
- 地方记忆

感受到上一世留下的痕迹。

---

## 终章意义

无名收集的不是权力和成就。

而是无数普通人的人生。

最终理解：

历史不是少数人的故事，而是所有人的共同记忆。
