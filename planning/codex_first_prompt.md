```text
- 项目的核心不是寻找主角真名，而是通过不同社会位置理解历史；
- “无名”、苏醒者、裂钟和《无名录》分别是什么；
- 序章的完整流程、人物关系和结束边界；
- 当前 Godot 工程已经完成什么，哪些内容仍是占位或未完成；
- 本次任务会修改哪些文件，怎样运行和验证。

当前制作目标是完成 Godot 原生 Windows 序章《雨来之前》的完整可玩 Demo。

序章流程必须是：

标题进入
→ 旧渡日常与人物建立
→ 辛衡案前登记本世姓名
→ 商船带来“宋地乱了”的消息
→ 流民进入旧渡，韩宁、柳娘与禾安的处境展开
→ 旧礼器库裂钟触发多视角残片
→ 雨夜流民车翻倒
→ 玩家实际走向孩子、湿简或失散人群并先处理其中一项
→ 显示即时后果
→ 进入第一章《钟裂于洛水》

不得把登记姓名写成寻找真名的谜题。
不得把裂钟写成技能、预言或身份答案。
不得把翻车现场写成连续 A / B / C 菜单。
不得根据旧网页原型恢复旧项目口径。
不得只写方案；在确认现状后直接修改工程、运行测试并修复错误。

所有新内容必须服务于：让玩家从不同人的位置，看见同一场历史动荡如何产生不同的急迫、责任和记忆。
```
