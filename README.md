# 山河无名

《山河无名》是一款中国历史轮回式人生体验游戏。

当前版本：第一章《礼崩之世》  
时代范围：春秋战国  
形式：单机网页原型，无需服务器、无需安装依赖。

## 当前核心玩法

玩家进入游戏时没有固定职业，会在少年序章和后续选择中逐渐显现人生道路。

第一章目前包含 10 条人生线：

- 隐士
- 仕官
- 谋士
- 武将
- 医者
- 戏子
- 商贾
- 工匠
- 吏官
- 农人

每一世会经历：

1. 少年序章
2. 道路显形
3. 历史车轮事件
4. 职业人生事件
5. 终章感悟
6. 魂火印记沉淀
7. 转入下一世

## 历史车轮主线

第一章采用春秋战国历史推进：

1. 周室衰微
2. 春秋争霸
3. 三家分晋
4. 变法图强
5. 合纵连横
6. 长平余烬
7. 秦势东出

## 本地运行

直接用浏览器打开 `index.html` 即可。

也可以用任意静态服务器运行，例如：

```bash
python -m http.server 8000
```

然后打开浏览器访问本地服务器。
