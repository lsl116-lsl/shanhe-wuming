# 山河无名

《山河无名》是一款以中国历史长河为骨架的叙事游戏项目。

玩家扮演的不是普通转生者，而是一个反复在不同时代醒来的 **苏醒者**。他每一世都会成为时代中的无名之人：农人、小吏、医者、戏子、工匠、商贾、军卒、流民、士子、边民。每一次醒来，他都记不清前世，只能依稀记得裂钟、白骨、旧曲、残卷、河流、梦境与无法解释的亏欠。

游戏最终母题是：

> 无名不是没有名字。  
> 无名的名字，是人民。

前半段，玩家追问“我是谁”。  
中段，玩家发现“我每一世都是无名者”。  
终章，玩家明白“无名者不是孤立个体，而是贯穿历史的人民”。  
最终，属于封建秩序的旧时代终结，属于共产主义理想指引下的新时代开启，人民以自己的名字站到历史中央。

## 核心叙事原则

### 1. 先主线，后玩法

游戏不是“随机朝代投胎模拟器”。

每一章都必须是一条完整人生主线：

```text
苏醒 → 入世 → 遇人 → 入局 → 人生分流 → 种因 → 结果 → 未尽 → 记忆复苏 → 再次沉睡
```

玩法系统必须服务主线，不能把故事切碎。

### 2. 每个朝代是一章完整人生

每一章不是散事件合集，而是苏醒者在一个时代中完整活过的一生。

章节之间通过以下方式连接：

- 遗物
- 文字
- 地点
- 后人
- 制度
- 梦境
- 重复命题

### 3. 因果不是善恶值

因果不是“善有善报、恶有恶报”的简单系统。

因果的核心是：

> 选择会继续生长。

善因可能结出苦果。  
恶因可能带来短期好果。  
真正重要的是：玩家的每一次选择，都会进入历史、人、制度和后世的网中。

### 4. 职业线不是副本

当前保留 10 条人生线：

- 隐士
- 仕官
- 谋士
- 武将
- 医者
- 戏子
- 商贾
- 工匠
- 吏官
- 农人

这些不是 10 个互不相干的职业副本，而是同一条历史主线的 10 种观察位置。

### 5. 第一章必须先讲好春秋战国

当前不要急着开发秦汉、魏晋、隋唐等后续章节。

第一目标是把第一章《礼崩之世》讲好。

第一章要覆盖的不是“随机春秋战国事件”，而是一条完整人生主线：

```text
裂钟之梦
旧礼无声
旧国被重写
新法如刀
百家灯火
合纵连横
长平血雾
天下将一
```

## 第一章《礼崩之世》必须埋下的核心母题

第一章是全游戏的根，至少要埋下这些母题：

1. **裂钟**
   - 开局梦境母题
   - 代表旧礼崩坏
   - 也代表苏醒者最深处的记忆入口

2. **无名录**
   - 记录无名者、死者、流民、战卒
   - 对应游戏标题“无名”
   - 后续各朝代反复回收

3. **旧臣遗孤**
   - 代表旧国、旧债、忠义、仇恨与后人因果

4. **亡国旧曲**
   - 戏子线核心母题
   - 后续可变成禁曲、宫廷旧乐、民间戏、亡国戏

5. **新法木牌**
   - 代表变法、户籍、军功、连坐、郡县
   - 秦汉章直接承接

6. **长平白骨**
   - 第一章最大的情绪与因果爆发点
   - 战争胜负会结束，但战争因果不会结束

7. **第一声真正的提示**
   - 第一章结尾，苏醒者第一次听清：
   > 这不是你第一次看见山河改色。

## 本地运行原型

当前原型是一个单文件网页。

打开：

```text
prototype/chapter1_v4_experiment.html
```

或使用本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/prototype/chapter1_v4_experiment.html
```

注意：当前原型是历史实验版本，不应作为最终叙事结构直接继续扩写。后续应先完成第一章主线，再重构原型。
