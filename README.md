# 山河无名

《山河无名》是一款以中国历史长河为骨架、以多重普通人视角为核心的章节式历史叙事人生 RPG / AVG。

玩家作为一个反复在历史转折处醒来的见证者，每一世都真实生活在某个具体位置：可能是医者、吏员、商贾、军卒、艺人、工匠、谋士、仕官，也可能只是被时代推着走的普通人。玩家不能凭一己之力改写大历史，而是通过这些彼此不同的生活位置，看见同一事件为何会被经历、记录和解释成不同的样子。

> 山河不是一张帝王年表。
> 历史要从许多人的眼睛里，才能逐渐看清。

“无名”指长期未被主流叙事充分看见的普通人，不指主角没有名字。本项目不以寻找真名、前世身份或天命血统为主线；苏醒与残梦只负责连接不同历史视角。

## 1. 当前项目口径

```text
产品形态：章节式 2D 历史叙事人生 RPG / AVG
体验比例：叙事、调查与选择约 70%；关系、资源和职业责任约 30%
章节结构：每章一段完整人生
长线结构：序章 + 七章 + 终章
当前重点：序章《雨来之前》与第一章《钟裂于洛水》
第一章主题：礼崩之世
验证形态：Godot 原生 Windows 序章可玩原型 + 90 秒动画样片
正式方向：完成序章垂直切片，再进入第一章制作
```

本项目不以战斗刷取、装备养成、抽卡或善恶值作为核心循环。

玩家真正决定的是：

```text
去见谁、相信谁。
如何使用有限的粮、药、时间、证据和制度权限。
谁从一次选择中受益，谁承担代价。
一件事如何进入事实、官档、私录和口述。
本世留下什么，由谁带入后世。
```

玩家真正要逐步认清的是：

```text
同一场战争，在将领、士卒、医者、家属和运粮者眼中并不是同一件事。
同一项制度，对制定者、执行者、受益者和被追索者意味着不同的生活。
官档、私记、传唱、器物和口述都保存历史，也都带着各自的位置与局限。
一条人生只能看见局部；多条人生互相印证、冲突和补充，才接近历史的全貌。
```

## 2. 当前制作重点

### 序章《雨来之前》

序章负责建立本世入口：

```text
在辛衡案前登记本世姓名；该场景展示名与籍如何决定人的现实位置，不承担“寻找真名”功能。
父亲未归、母亲等待、辛衡老伯、禾安、韩宁、柳娘登场。
解释“名与籍”。
宋亡消息抵达。
裂钟第一次触发。
最后一辆流民车翻进泥里。
玩家做出第一选择：先救孩子 / 先抢湿简 / 先让活人互认。
```

序章正式制作节奏：

```text
动画化叙事 + 轻探索 + 少量关键选择
```

不得做成“剧情简介 + 连续选择题”。

### 第一章《钟裂于洛水》

主题名：礼崩之世。

第一章承接序章三选一后果，从 ACT01《雨后流民》开始。

第一章当前结构：

```text
八职业线 + 乡土地基 + 隐退倾向
```

八条职业线：

```text
医者。
吏官 / 记录。
商贾。
武将。
戏子。
工匠。
谋士。
仕官。
```

“农人”不再作为独立职业线。

```text
土地、粮水、田亩、空户、旧渡、灶火、没有米下锅、禾安和粥碗，属于所有职业共同面对的乡土地基。
```

“隐士”不再作为独立职业线。

```text
隐退、私藏见证、不入官档、少介入和晚年去向，属于所有职业都可能附着的隐退倾向。
```

第一章主线骨架：

```text
序章让主角做出第一笔选择。
第一章让这笔选择长成一段完整人生。
中年在长平看见无数人被压成数字。
长平后回旧渡，面对禾安问阿梁消息，却说不出口。
晚年再回旧渡时，禾安已逝，只留下小时候一起喝粥的碗。
主角决定无名录的去向，使它成为后世理解这一时代的一份民间材料；它不是全知真相，也不是主角身份的答案。
```

## 6. 叙事原则

### 一章一生

```text
苏醒
→ 入世
→ 遇人
→ 入局
→ 人生分流
→ 种因
→ 结果
→ 未尽
→ 记忆复苏
→ 再次沉睡
```

朝代是母题范围，不等于一世要活过数百年。每章只选普通人可亲历的关键窗口。

### 职业是社会位置

职业不是开局菜单，不是战斗职业，也不是善恶阵营。

职业决定：

```text
玩家最先看见什么。
玩家能动用什么资源。
谁会来邀请、拒绝或托付玩家。
玩家必须对哪一类后果负责。
本章能留下哪一种独有证据。
```

职业数量不固定，每章可按故事需要裁剪。

第一章固定为“八职业线 + 乡土地基 + 隐退倾向”。后续章节可以继续评估，不强行恢复十职业。

### 因果不是善恶值

每个重要选择至少影响人物、资源、事实、记录或后续责任之一。善意可能结出苦果，严厉选择也可能在特定处境中保护更多人。

### 玩家改变人间尺度

玩家不能阻止已确定的大规模历史转折，但可以改变：

```text
谁活下来、失踪、迁徙或得到确认。
一项制度在一地如何执行。
哪个版本进入官档、私录或口述。
谁保存证据，谁为公开证据承担风险。
一段因果以什么形式进入后世。
```
