# 山河无名

《山河无名》是一款以中国历史长河为骨架的章节式历史叙事人生 RPG / AVG。

玩家扮演一个反复在历史转折处醒来的“苏醒者”。他每一世都是真实生活在时代中的普通人：农人、小吏、医者、乐人、工匠、商贾、军卒、流民或士子。他起初寻找自己的私人姓名，最终发现自己是千千万万无名者共同的历史回声。

> 无名不是没有名字。  
> 无名的名字，是人民。

## 当前定位

```text
产品形态：章节式 2D 历史叙事人生 RPG / AVG
体验比例：叙事、调查与选择约 70%；关系、资源和职业责任约 30%
章节结构：每章一段完整人生
长线结构：七章加终章，跨章回收人物、制度、记录、地点与共同记忆
目标路线：网页原型验证 → Godot 第一章垂直切片 → 按章正式制作
微信形态：按渠道价值评估微信小游戏，不设为强制中间站
当前重点：评审已完成的阶段 A《雨后流民》技术样片，再扩展 ACT01—ACT02 核心原型
```

游戏不采用战斗刷取、装备养成、抽卡或简单善恶值作为核心循环。玩家真正决定的是：

- 去见谁、相信谁。
- 如何使用有限的粮、药、时间、证据和制度权限。
- 谁从一次选择中受益，谁承担代价。
- 一件事如何进入事实、官档、私录和口述。
- 本世留下什么，由谁带入后世。

## 叙事原则

### 一章一生

```text
苏醒
→ 入世
→ 遇人
→ 入局
→ 人生分流
→ 种因
→ 结果
→ 未尽
→ 记忆复苏
→ 再次沉睡
```

朝代是母题范围，不等于一世要活过数百年。每章只选普通人可亲历的关键窗口。

### 职业是社会位置

前七章保留十种社会位置，并为每种职业建立独立的欲望、关系、升级、高潮、代价和跨章材料：

- 隐士
- 仕官
- 谋士
- 武将
- 医者
- 戏子
- 商贾
- 工匠
- 吏官
- 农人

职业决定可见信息、可用资源、制度权限、必须责任和独有证据，不决定人格与善恶。所有职业共享同一历史主线。

### 因果不是善恶值

每个重要选择至少影响人物、资源、事实、记录或后续责任之一。善意可能结出苦果，严厉选择也可能在特定处境中保护更多人。

### 玩家改变人间尺度

玩家不能阻止已确定的大规模历史转折，但可以改变：

- 谁活下来、失踪、迁徙或得到确认。
- 一项制度在一地如何执行。
- 哪个版本进入官档、私录或口述。
- 谁保存证据，谁为公开证据承担风险。
- 一段因果以什么形式进入后世。

## 产品与视觉方向

推荐采用 2D 插画式 AVG：

- 半身人物立绘与少量表情差分。
- 分层场景插画和轻视差。
- 地图、文书、人物关系和物件调查。
- 关键节点使用少量全屏事件插画。
- 每章结束生成“本世档案”，不使用传统分数结算。

跨时代基础视觉为“纸、墨、漆、铜”，基础色包括：

```text
墨黑 #12110F
漆褐 #211A15
暖纸 #E7DDC6
旧灰 #A99B84
青铜 #B28A4A
朱砂 #A64B3C
记忆靛 #66758A
新生绿 #73805C
```

每章再加入自身强调色。颜色不能是唯一信息通道，正文要支持字号调整、高对比和减少动态效果。

## 开发路线

### 阶段 A：内容模式与技术样片

- [已完成] 定义场景、人物、因果、档案和存档模式。
- [已完成] 制作 ACT01《雨后流民》10—15 分钟样片。
- [已完成] 同一选择可改变人物、事实、记录、资源与后续责任。

### 阶段 B：网页核心原型

- 使用 TypeScript 与网页界面快速验证 ACT01—ACT02。
- 目标时长 30—45 分钟。
- 验证关系、代价、档案分层和存读档。

### 阶段 C：Godot 第一章垂直切片

- 使用 Godot 4.x、GDScript 和 2D 管线。
- 完成第一章一段完整人生，首轮约 3—5 小时。
- 验证正式美术、音频、职业差异和跨章交接。

### 阶段 D：公开试玩与章节制作

- 先发布 1—2 小时试玩并复盘。
- 第一章证明内容产能和用户兴趣后，再进入第二章正式制作。
- 微信小游戏只在渠道数据支持时建立独立支线。

完整路线见 `docs/08_项目落地方案_V0.1.md`。

## 阶段 A 技术样片

当前样片位于 `apps/web/`，内容源位于 `content/`，平台无关运行时位于 `packages/story-core/`。

安装与运行：

```bash
pnpm install
pnpm dev
```

浏览器访问：

```text
http://127.0.0.1:4173/
```

完整校验：

```bash
pnpm test
```
